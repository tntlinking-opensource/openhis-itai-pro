# 病案首页 — 详细设计

> **文档性质**：详细设计（LLD），指导首页表结构增量、DTO、自动取值、校验与 4401 组装  
> **上游**：[02-概要设计.md](./02-概要设计.md)、[00-功能清单.md](./00-功能清单.md) §4.2～4.4  
> **接口真源**：`whale-chs/docs/apis/44xx/4401-住院病案首页信息.md`（基线 1.6.8）  
> **版本**：v1.0 | **日期**：2026-05-29

## 1. 范围与原则

### 1.1 本文档覆盖

| 项 | 说明 |
|----|------|
| 首页 UI 分段 | 医生站/病案室表单 Tab 与字段分组 |
| 物理存储 | `mrms_case_record_homepage` 扩列、`extension_json` 键注册、子表字段 |
| 自动取值 | HIS/EMR/EncounterHistory → 首页字段映射表 |
| 提交校验 | Wave 1 必填与逻辑规则 |
| 4401 组装 | `baseinfo` / `diseinfo` / `oprninfo` / `icuinfo` 映射 |
| API DTO | `HomepageDto`、`SaveHomepageRequest` 字段清单 |

### 1.2 存储策略

| 类型 | 策略 |
|------|------|
| **高频编辑、检索、4401 必填** | `mrms_case_record_homepage` **独立列**（蛇形命名，与 4401 code 可对照） |
| **费用分项、附页、区域扩展** | `extension_json` 键值（键名 = 4401 `参数代码`） |
| **诊断 / 手术 / ICU** | 独立子表，一行对应 4401 多行节点 |
| **字段来源** | `field_sources_json`：键 = 列名或 `extension_json` 键，值 = `manual` / `auto` / `mixed` |

### 1.3 与国标 / 医保关系

- **院内首页表单**：对齐《住院病案首页》国标版面（卫统标准思路），字段尽量与 **4401 baseinfo** 同名或可推导。
- **医保上传**：`CaseRecord4401Assembler` 只认本文档映射表；院内多填字段可不上传。

## 2. 前端表单分段

| Tab/段 | 代码 | 主要内容 | Wave |
|--------|------|----------|------|
| **A 基本信息** | `basic` | 身份、地址、联系人、入院途径 | 1 |
| **B 住院信息** | `inpatient` | 入出院、科别、天数、离院方式、转科 | 1 |
| **C 诊断编码** | `diagnosis` | 出入院诊断、病理、损伤中毒（ICD 行编辑） | 1 |
| **D 手术操作** | `procedure` | 手术及操作（ICD-9-CM-3 行编辑） | 1 |
| **E 医护人员** | `staff` | 科主任、主治、住院医、护士、编码员等 | 1 |
| **F 其他信息** | `other` | 过敏、血型、尸检、昏迷时长、31 天再入院等 | 2 |
| **G 费用信息** | `fee` | 总费用及分项（只读为主） | 2 |
| **H 重症监护** | `icu` | ICU 入出时间、护理等级（子表） | 3 |

`RefreshAutoFillRequest.sections` 取值：`basic` | `inpatient` | `diagnosis` | `procedure` | `staff` | `fee` | `all`。

## 5. 诊断子表设计

### 5.1 diag_type_code（院内）与 4401 对照

| HomepageDiagType.code | 含义 | ipt_patn_disediag_type_code（4401） | maindiag_flag |
|------------------------|------|-------------------------------------|---------------|
| `discharge_main` | 出院主诊断 | `1`（出院诊断） | `1` |
| `discharge_other` | 出院其他诊断 | `1` | `0` |
| `admission_main` | 入院主诊断 | `2`（入院诊断） | `1` |
| `admission_other` | 入院其他诊断 | `2` | `0` |
| `pathology` | 病理诊断 | `3` | `0` |
| `injury_poison` | 损伤中毒 | `4` | `0` |

> 4401 字典以合订本为准；实现时建 `Mrms4401DiagTypeMapping` 常量类。

### 5.2 诊断行 DTO

```java
public class DiagnosisLineDto {
    private Long id;
```

### 5.3 诊断自动带入规则

| diagTypeCode | 来源 | Port 方法 |
|--------------|------|-----------|
| `discharge_main` / `discharge_other` | 出院诊断列表 | `DiagnosisProcedurePort.listDischargeDiagnoses` |
| `admission_main` / `admission_other` | 入院诊断列表 | `DiagnosisProcedurePort.listAdmissionDiagnoses` |
| `pathology` | 病理诊断（二期） | 同上或 Extension |
| `injury_poison` | 损伤中毒主行 | 首页主表 `damg_intx_ext_rea*` 联动 |

**合并策略**：`refreshAutoFill(section=diagnosis)` 时，若该 `diagTypeCode` 下**无任何** `fillSource=manual` 的行，则**整类替换**；否则仅追加缺失 sortNo，不删人工行。

### 7.4 fillSource 合并算法

```text
refreshAutoFill(caseRecordId, sections):
  FOR each fieldKey in sections:
    IF field_sources[fieldKey] == "manual": CONTINUE
    newVal = portResolve(fieldKey)
    IF newVal is null: CONTINUE
    IF oldVal is null OR field_sources[fieldKey] == "auto":
      set(fieldKey, newVal); field_sources[fieldKey] = "auto"
    ELSE IF oldVal != newVal:
      set(fieldKey, newVal); field_sources[fieldKey] = "mixed"

saveHomepage(request):
  FOR each fieldKey in request touched keys:
    IF request.value != autoResolvedSnapshot[fieldKey]:
      field_sources[fieldKey] = "manual"
```

`saveHomepage` 保存时由 `HomepageAutoFillMerger` 在服务端对**本次修改字段**检测是否与当前 Port 快照一致，决定 `manual` / `mixed`。

## 8. 提交校验（HomepageSubmitValidator）

### 8.1 Wave 1 必填（抛 ValidationException 汇总）

| 类别 | 字段 |
|------|------|
| 身份 | psn_name、gend_code、brdy、certno |
| 住院 | ipt_no、adm_way_code、adm_caty_code、adm_time、dscg_caty_code、dscg_time、ipt_days、dscg_way_code |
| 医护 | chfdr_name、atddr_name、ipt_dr_name |
| 诊断 | 至少 1 条 `discharge_main` 且 diag_code 非空 |
| 主档 | case_record.status 为 `draft` 或 `returned` |

### 8.2 逻辑规则

| 规则 | 说明 |
|------|------|
| R01 | `dscg_time` ≥ `adm_time` |
| R02 | `ipt_days` 与入出院日期差一致（允许 ±1 天配置容差） |
| R03 | 出院主诊断仅 1 条（`discharge_main` + `maindiag_flag=1`） |
| R04 | 同一 `diag_type_code` 内 `sort_no` 不重复 |
| R05 | 手术主操作至多 1 条 `main_oprn_flag=1` |
| R06 | `frozen=true` 禁止保存与提交 |

### 8.3 编码校验（Wave 2）

| 规则 | 说明 |
|------|------|
| R10 | 性别与诊断冲突（如男性 C51） |
| R11 | 灰码禁止作为主诊断 |
| R12 | 损伤中毒外部原因编码与诊断行一致 |
