# zxplat-starter

HIS **运行时聚合** plain jar（原 `health-starter`）。院点与 `zxplat-app` 共用；**勿**依赖 `zxplat-app` fat jar。

> **代码**：`zxplat-starter/` · 包 `com.zxplat.starter.config.*`  
> **制品**：`com.zxplat:zxplat-starter`  
> **上级索引**：[../说明.md](../说明.md) · **结构**：[模块说明-代码结构.md](./模块说明-代码结构.md)

## 职责

聚合 `zxplat-application` + `zxplat-domain` + `zxplat-framework` 及 Web/Security/Actuator/Flyway 运行时依赖；放置启动期装配类（非 Boot 主类）。

## 配置类

| 类 | 作用 |
|----|------|
| `ExtensionModuleProfileValidator` | classpath 与 `zxplat.modules.*.enabled` 一致性告警 |
| `HealthApplicationConfigurationAppService` | 登录配置装饰（财务审批 / 病案管理员等） |
| `ApplicationInitializer` | 就绪后打印服务地址 / swagger |
| `AdminPasswordInitializer` | 可选重置 admin（`zxplat.bootstrap.*`） |
| `StartupProgressLogger` | 启动进度日志 |

## 工伤（决策 4B）

**不**在 pom 硬绑 `module-wi-jilin-*`。需要时由 `zxplat-app`（或院点）`-Pwith-work-injury` 挂 `module-wi-jilin-starter`。
