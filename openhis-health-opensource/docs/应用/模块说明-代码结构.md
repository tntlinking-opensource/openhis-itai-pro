# 应用栈 · 代码结构

> **入口**：[说明.md](./说明.md) · **波次**：[wave-04-app.md](../../plans/waves/wave-04-app.md)

## Reactor（根级，不进 zxplat-core）

```text
zxplat/                          （聚合根 pom）
├── zxplat-core/zxplat-domain    ← 领域（稳定；仅此进 core）
├── zxplat-application/          ← 应用层用例编排
├── zxplat-starter/              ← 运行时聚合 plain jar
├── zxplat-app/                  ← 开发 Boot 壳 + with-* Profile
├── zxplat-framework/
└── zxplat-plugin/
```

**DDD**：`zxplat-core` 只承载相对稳定的领域；应用层 / starter / Boot **与 core 平级**。

## 依赖方向

```text
zxplat-app
  └─ zxplat-starter
       ├─ zxplat-application
       │    ├─ zxplat-domain
       │    └─ zxplat-framework
       ├─ zxplat-domain
       └─ zxplat-framework

插件仅经 zxplat-app 的 Maven Profile 挂 module-*-starter
（application / starter **禁止**依赖 module-*-bridge）
```

| 规则 | 说明 |
|------|------|
| Enforcer | `zxplat-application` 禁 `module-*-bridge`、CHS/BPC/WI 插件坐标、`com.openhis:*` |
| ArchUnit | shared/support 禁直连 Repository/JPA；禁依赖 `com.zxplat.plugin.wi` |
| 工伤 | starter **不**硬绑 WI domain；仅 `-Pwith-work-injury` |

## 默认 Profile（zxplat-app）

| Profile | 默认 | 坐标 |
|---------|------|------|
| `with-emr` | ✅ | `module-emr-starter` |
| `with-booking` | ✅ | `module-booking-starter` |
| `with-campus` | ✅ | `module-campus-starter` |
| `with-chs` / `with-chs-remote` 等 | 否 | 见 [zxplat-app/说明.md](./zxplat-app/说明.md) |
| `with-pacs` | 否 | 默认不挂 |

开关键：`zxplat.modules.{短名}.enabled`（与插件一致）。

## Java 包

| 模块 | 包根 |
|------|------|
| application | `com.zxplat.application.*` |
| starter | `com.zxplat.starter.config.*` |
| app | `com.zxplat.app.*`（主类 `HealthApplication`） |
| domain（依赖） | `com.zxplat.domain.*` |
| framework（依赖） | `com.zxplat.framework.*` |

## 启动（开发壳）

```powershell
mvn -pl zxplat-app -am install -DskipTests
mvn -pl zxplat-app spring-boot:run -DskipTests `
  "-Dspring-boot.run.arguments=--spring.datasource.url=jdbc:postgresql://localhost:5432/<db>"
```

主类：`com.zxplat.app.HealthApplication` · 默认端口见 `zxplat-app` 的 `application.yml`（8081）。  
**院点**不在本栈：见 `projects/` / whale-project 同构工程。
