## 约定

对齐插件同伴文档习惯：**每个 Maven 制品一个子目录**，入口统一 `说明.md`；AS / AS-SDD **正文**落在 `zxplat-application/` 下（与插件 `docs/模块/*/AppService` 同构）。

```text
docs/应用/
  说明.md                      ← 本页（总览入口）
  模块说明-代码结构.md          ← reactor / 依赖方向 / Profile
  zxplat-application/
    说明.md                    ← 应用层 jar + 契约目录入口
    模块说明-代码结构.md
    AppService/                ← HIS 页面 AS 正文
    AppService-SDD/            ← AS 详细设计正文
    PeisAppService/ · MrmsAppService/ · LisAppService/
    PacsAppService/ · InventoryAppService/
  zxplat-starter/说明.md
  zxplat-app/说明.md
```

| 文档树 | 内容 |
|--------|------|
| `docs/应用/` | 工程边界、装配、Profile、启动 + **HIS 应用契约正文** |
| `docs/领域/DomainModel/` | 领域契约：`com.zxplat.domain.*` |
| `docs/领域/专题/` | 需求 / DD / ops 等横切专题（**不再**放 AppService 正文） |
| `docs/模块/` | 插件：`zxplat-plugin/zxplat-module-*` |

**禁止**：把插件 DM/AS 写入本目录。  
**文档自洽**：正文与链接自包含于本仓 `docs/`（见 `plans/scripts/check-docs-self-contained.ps1`）。
