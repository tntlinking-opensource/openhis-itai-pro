## 1. 定位

检查申请 → 登记 → 执行 → 报告；DICOM 采集与 Web 阅片由 **zxplat-module-pacs-imaging** 扩展承担，**不**阻塞核心 RIS 菜单定义。

与 LIS 对称：`ServiceRequest` = 医嘱意图；**`PacsWorkItem`** = 检查执行（登记号/检查号）；**不复制**患者主数据。

---

## 2. 边界

| 在 PACS 核心 | 不在 PACS（归属） |
|--------------|-------------------|
| RIS 登记/执行/报告书写审核 | DICOM 存储集群运维 |
| `PacsWorkItem` + orderLinks | PEIS 团检编排 |
| `pacs_diagnostic_report | LIS 检验 |
| 发布后 **`cln_diagnostic_report_index`** | 医嘱开立、收费（health） |
| `pacs-adapter` 遗留 WebService | 影像采集/阅片 UI（zxplat-module-pacs-imaging） |

---

## 3. 架构分层

```text
health-application/pacs/     Pacs*AppService（10 页 + INT）
zxplat-domain/pacs/        PacsWorkItem、ImagingStudy、pacs_diagnostic_report…
zxplat-domain/clinical/    cln_diagnostic_report_index（与 LIS/PEIS 共用）
pacs-adapter/              WorkStationServer、/webservice/*、现场 PACS 对接
pacs-starter/
```

装配：`zxplat.modules.pacs.enabled=true`；可选 `imaging-starter`。

## 4. 院点 Profile

### 4.1 朝阳（D9）

| 模块 | 首版 |
|------|------|
| **LIS** | 自研 `zxplat/lis` 上线 |
| **PACS** | **pacs-adapter 对接现场 PACS**；自研 REG/EXE/REP P0 **非首版强制** |
| **PEIS** | 检查外发走 adapter；检验走自研 LIS |

全自研 RIS 仍为产品 **母集**（00/03 功能清单）；院点 Checklist 裁剪实施范围。

### 4.2 东北师大（NENU）

| 模块 | 首版 | 说明 |
|------|------|------|
| **LIS** | 自研 `zxplat/lis` | PEIS INT-01 → LisWorkItem；**AUD-05** 投影 CLN |
| **PACS** | **pacs-adapter** 对接现场 PACS | PEIS INT-01 → PacsWorkItem；**无**自研 RIS 菜单首版 |
| **PEIS** | **2026-09-01** | 与 LIS/PACS/小程序/自助机同批切换 |

**师大 PACS → 体检单 CLN 投影（P0）**：

```text
PEIS INT-01 → PacsWorkItem（zxplat-domain，同 activity_id）
  └─ pacs-adapter：/webservice/* 与现场 PACS 同步登记/报告状态
  └─ 现场审核通过（或 adapter 收到 final 回调）
       └─ adapter 调 health 内部命令（非 PEIS 重复外发）：
            PacsReportAuditAppService#approveReport 等价路径
              或 PacsAdapterReportFinalizeCommandHandler（adapter 专用薄编排）
       └─ 同事务：pacs_diagnostic_report final
            + upsert cln_diagnostic_report_index
            + LisResultProjectionService#projectFromPacsSummary（每个有 encounterId 的 SR）
            + peis_service_request_ext.pacs_dispatch_enum → resultReceived
  └─ 漏投影 → PEIS DES-08 / INT-03 补偿（与 LIS 对称）
```

> **禁止**：adapter 内写 `cln_observation` 或维护 health 侧 `pacs_item_map`；投影 **唯一** 经 CLN-007 §6.3 领域服务。  
> **关联**：AS-PACS-REP-002 REP-07、[Peis 08-Extension §3.2](../PeisAppService/08-Extension与外部依赖.md#32-pacs-adapter-院点--cln-投影)。

## 5. 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| WorkItem 模式 | `PacsWorkItem` + `PacsWorkItemOrder` | 与 LIS 一致；合并检查 N:1 |
| 患者信息 | **仅 patientId** | 与 LIS 一致；§7.3 |
| 报告读侧 | **`cln_diagnostic_report_index`** | 医生站/PEIS 统一查报告；§7.2 |
| Maven | **zxplat 子包** | §7.4 |
| `pacs_item_map` | **不建**；adapter 内私有对照 | 一体化同 `activity_id`；§7.5 |

## 7. LIS/PACS/PEIS 跨模块架构约定

> 决策摘要与 LIS 侧全文见 [LisAppService/01 §10](../LisAppService/01-概要设计.md#10-lispacspeis-跨模块架构约定)。本节为 **PACS 落点**。

### 7.1 决策摘要（PACS 相关）

| # | 议题 | PACS 落点 |
|---|------|-----------|
| D1 | Observation | 检查摘要进体检单 → `cln_observation` + 引用 DR index；**P0 主路径** [AS-PACS-REP-002](../AppService/AS-PACS-REP-002-报告审核.md) REP-07 同事务 `projectFromPacsSummary` |
| D2 | DR index | `pacs_diagnostic_report 发布后 upsert **`cln_diagnostic_report_index`** |
| D3 | 无 map | **不建** `pacs_item_map`；接单查 **`pacs_modality_capability`**（INT-07） |
| D4 | Maven | `zxplat-domain/pacs`、`health-application/pacs`、`pacs-adapter`、`pacs-starter` |
| D8 | 无 PHI 冗余 | `pacs_work_item` **仅** `patientId`/`encounterId`；列表 JOIN `adm_patient` |
| D9 | 院点 Profile | **朝阳 / 师大** 首版均为 **pacs-adapter**；自研 REG/EXE/REP **非首版阻塞**；师大 CLN 投影见 §4.2 |

### 7.2 DiagnosticReExtension 索引（D2）

- 事实表：`pacs_diagnostic_report（workItem / SR 粒度）
- 审核发布 → upsert `cln_diagnostic_report_index`（`module_enum=PACS`）
- 医生站 / PEIS / CRB：**优先查 index**

### 7.3 列表查询（D8）

- **禁止**在 `pacs_work_item` 冗余 `patient_name`、`id_card` 等
- `PacsWorkItemQueryService` JOIN `adm_patient` 或 Patient 批量读 Reader

### 7.4 Maven 落点（D4）

与 LIS/PEIS 同在 **`zxplat`** 子包；`zxplat.modules.pacs.enabled=true`；可选 `imaging-starter`。

### 7.5 项目对照 — 一体化无 map（D3）

- 与 LIS/PEIS 共用 **`activity_id`**；health **不建** `pacs_item_map`
- **INT-07**：每个 `activity_id` 须在 **`pacs_modality_capability`** 可覆盖
- **朝阳 / 外购 / 师大**：「`activity_id` ↔ 现场 EXESCODE」仅在 **pacs-adapter** 内维护

### 7.6 adapter 院点 CLN 投影（对称 LIS AUD-05）

| 项 | 口径 |
|----|------|
| **主触发** | 报告 **final** 时 `LisResultProjectionService#projectFromPacsSummary` |
| **自研 RIS** | [AS-PACS-REP-002](../AppService/AS-PACS-REP-002-报告审核.md) REP-07 编排（`PacsReportAuditAppService`） |
| **adapter 院点** | adapter 收到现场 final → 调 health **同一套** final + index + 投影命令；**不**在 adapter 直写 `cln_observation` |
| **补偿** | [AS-PEIS-DES-001](../AppService/AS-PEIS-DES-001-分科诊台.md) DES-08、[AS-PEIS-INT-001](../AppService/AS-PEIS-INT-001-LIS-PACS外发.md) INT-03 |
| **Gap** | GAP-PACS-REP-AUD-01（与 GAP-PEIS-DES-01 共用 CLN-007 实现） |
