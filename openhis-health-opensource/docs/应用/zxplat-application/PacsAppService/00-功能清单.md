## 一、模块定位

### 1.1 是什么

ZXPlat **自研 PACS/RIS 核心**：**10 个主页面 AppService**；INT-01 由医生站直调 `PacsWorkItemDomainService`（见 [AS-PACS-INT-001](../AppService/AS-PACS-INT-001-HIS接单入口.md)）。
聚焦 **登记 → 检查状态 → 报告**；DICOM 采集与 Web 阅片见增值 Module **[zxplat-module-pacs-imaging](../../../模块/zxplat-module-pacs-imaging/)**。

### 1.2 不是什么


| 不在 PACS 核心                   | 归属                                     |
| ---------------------------- | -------------------------------------- |
| 医嘱开立、签发、收费                   | health · 医生站/收费 AS                     |
| 检查 **申请单** 版式打印              | PrintTemplate（AS-BAS-PRT）                       |
| **LIS**                      | [LisAppService](../LisAppService/)（`health-application/lis`） |
| **影像采集、Web 阅片、阅片 URL 配置**    | [zxplat-module-pacs-imaging](../../../模块/zxplat-module-pacs-imaging/) 增值扩展 |
| **会诊**（`xyy*`）               | **范围外**                                |
| **医共体**（`Dcis`、`FilePush` 等） | **范围外**                                |
| **外检送检**（`Sjgl`）             | **范围外**                                |
| **导诊对账**（`Dzgl`）             | **范围外**                                |
| **统计报表**（`Cxtj`、`Ndjc` 等）    | **范围外**                                |
| **机构与站点菜单**（`OrgManager`）    | health / framework                     |
| DICOM 存储集群运维                 | 基础设施                                   |


### 1.3 领域锚点（FHIR 对齐，详见 [04-FHIR领域模型.md](./04-FHIR领域模型.md)）


| 系统         | 聚合 / FHIR                                           | 职责                           |
| ---------- | --------------------------------------------------- | ---------------------------- |
| **health** | `Encounter`、`Patient`、`ServiceRequest`、`ChargeItem` | 医嘱意图与收费事实                    |
| **pacs**   | `**PacsWorkItem`**                                  | 登记号、检查状态、模态、部位               |
| **pacs**   | `**DiagnosticReport**                              | 报告文本与 PDF                    |
| **pacs**   | `**ImagingStudy`** / `**Media**`                    | 索引字段在核心；**实体写入**在 imaging 扩展 |
| **pacs**   | `**AuditEvent`**                                    | HIS 接口日志                     |

## 二、阶段与优先级


| 阶段     | 目标                                          | 能否替代遗留                                    |
| ------ | ------------------------------------------- | ----------------------------------------- |
| **P0** | HIS 接单 + 登记 + 待摄/已检 + 报告书写审核 + 医生站可查 PDF 报告 | 替代 `WebService` + `Hzjcqk` 主路径（无 DICOM 时） |
| **P1** | 模态能力 + 模板 + 接口日志 + 报告查询                     | 替代 `TemplateManager`、`WebLog`      |
| **P2** | 本地补登记、登记条打印等边缘                              | 部分 `goSurePacs`                           |
| **P3** | 自助打印、SSO 边缘                                 | `echPacs`*（adapter）                       |


**影像能力**（DICOM、阅片）单列为 **zxplat-module-pacs-imaging P1**，不阻塞核心 RIS P0。

### P0 完工定义（核心 RIS 首版）

- 医生站签发检查 → `PacsWorkItem` + `orderLinks`
- 登记台确认/修改登记，生成 **检查号**
- 技师 **待摄 → 已检**（状态迁移；Study UID 可选，imaging 扩展后补齐）
- 报告 **书写、提交、审核发布**；医生站可看 PDF
- HIS 撤单 → PACS 作废
