# PacsAppService · 菜单与主页面 / AppService 映射

> **原则**：**1 主页面 = 1 个 AppService**；子页（弹窗、报告编辑）不单独建 AS，收敛到所属主页面契约。  
> **遗留对照**：`pacs/WebRoot/WEB-INF/jsp/business/**/*List.jsp`（约 **22** 个业务 List 页合并为 **10** 个 ZXPlat 核心主页面）  
> **影像扩展**：[../../../模块/zxplat-module-pacs-imaging/](../../../模块/zxplat-module-pacs-imaging/)（可选装配，+3 菜单）  
> **AS 索引**：[03-AppService详细设计.md](./03-AppService详细设计.md)  
> **版本**：v1.4 · **日期**：2026-06-27

---

## 一、菜单总览

```text
影像信息系统（health-application/pacs 核心）
├── 检查业务（5）
│   ├── 登记工作台          → PacsRegistrationAppService
│   ├── 检查执行            → PacsExamExecutionAppService
│   ├── 报告书写            → PacsReportComposeAppService
│   ├── 报告审核            → PacsReportAuditAppService
│   └── 报告查询            → PacsReportQueryAppService
├── 检查配置（4）
│   ├── 模态与可执行项目    → PacsModalityConfigAppService
│   ├── 报告模板            → PacsReportTemplateConfigAppService
│   ├── 设备与模态          → PacsDeviceConfigAppService
│   └── PACS 系统参数       → PacsModuleSettingsAppService
└── 运营管理（1）
    └── 接口日志            → PacsIntegrationLogAppService

影像采集与阅片（zxplat-module-pacs-imaging，增值扩展，可选）
├── 影像采集                → PacsImageCaptureAppService      [zxplat-module-pacs-imaging]
├── 影像阅片                → PacsViewerAppService            [zxplat-module-pacs-imaging]
└── 阅片服务地址            → PacsViewerUrlConfigAppService   [zxplat-module-pacs-imaging]
```

**核心菜单数**：**10** 个一级菜单项。  
**扩展菜单数**：**3** 个（仅装配 `imaging-starter` 的院点显示，见 [zxplat-module-pacs-imaging](../../../模块/zxplat-module-pacs-imaging/)）。

## 三、遗留 JSP → ZXPlat 主页面合并规则

| ZXPlat 主页面 | 合并的遗留 List / Controller |
|--------------|------------------------------|
| **登记工作台** | `hzjcqkList`（`list`）、`yyxxEdit`（编辑 Tab） |
| **检查执行** | `hzjcqkDspList`、`hzjcqkYjcList`、`hzjcqkqtYjcList`、`hzjcqkYzfList`、`wglsjList`（状态 Tab；**不含** DICOM 采集） |
| **报告书写** | `Report.jsp`（`goReport）、`WorkStationServer/saveReport |
| **报告审核** | `goShReport、`goCheckReport、`onlyCheckReport、批量 `passSh*` |
| **报告查询** | `hzjcqkBgList`、`hzjcqkBglsList`、`glReportList` |
| **模态与可执行项目**（遗留字典；health 侧 **`pacs_modality_capability`**，无 map） | `ZllxController/list`、`Zldic` |
| **报告模板** | `TemplateManager` |
| **设备与模态** | `EquipmentParameter` |
| **PACS 系统参数** | `SysconfigController`、`BasicInfoController` |
| **接口日志** | `weblogList` |

**归影像扩展包**（[zxplat-module-pacs-imaging](../../../模块/zxplat-module-pacs-imaging/)）：

| 扩展主页面 | 遗留 |

**不纳入 health-application/pacs 菜单**（范围外或归 framework / adapter）：

| 遗留 | 落点 |

| `orgManagerList` | health / framework 机构（**不做** PACS 机构菜单） |
| `operateList` | 框架操作审计或 LOG 子集 |
| `dzglList`、`djxxList`、`yjcxxList` | **范围外**（不做导诊对账） |
| `Cxtj*`、`Ndjc*`、`PatientSource` | **范围外**（不做统计报表） |
| `sjglList` | **范围外**（不做外检送检） |
| `WorkStationServerController` | **pacs-adapter**（工作站 API；影像写操作归 imaging 扩展） |
| `WebServiceController` | **pacs-adapter**（HIS HTTP） |
| `xyy*`、`Dcis*`、`FilePush*` 等 | **范围外**（会诊、医共体） |

## 五、与 health 的页面分工

| 场景 | 页面归属 | AppService |
|------|----------|------------|
| 医生站开立/签发检查 | health 医生站 | AS-OP-DOR-003 |
| 医生站看影像报告 | health 报告查询 / 外系统报告页 或 PACS 报告查询 | AS-OP-DOR-008（规划）/ `DM-CLN-006`；或 AS-PACS-REP-003 |
| 医生站看 DICOM 影像 | 扩展阅片 或 外购 Viewer URL | AS-PACS-IM-002（可选） |
| 申请单 PDF 版式 | PrintTemplate（AS-BAS-PRT） | 非 PACS AS |
| 技师工作站（C/S） | 无 ZXPlat 菜单 | pacs-adapter / imaging-adapter |
