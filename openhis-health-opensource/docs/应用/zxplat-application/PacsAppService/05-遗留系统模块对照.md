## 六、覆盖度矩阵

| 遗留模块 | ZXPlat 落点 | 覆盖评估 |
|----------|------------|----------|
| RIS 主路径 | REG/EXE/REP + INT | **P0 可上线**（无 DICOM 亦可） |
| 影像采集/阅片 | zxplat-module-pacs-imaging | **P1 扩展**（可选 License） |

| 运营 | LOG-001 | P1 |
| 会诊/医共体/外检/对账/统计 | — | **范围外** |

**结论**：核心 RIS **10 菜单**可替代遗留主路径；院点需 DICOM/阅片时装配 **zxplat-module-pacs-imaging**。
