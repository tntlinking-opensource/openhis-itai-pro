## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | 下载易用型 xlsx；上传导入；整批创建目录+维护态价；失败返回错误清单与**错误标注文件**；**按列表筛选导出单 Sheet xlsx（列序对齐导入字段）** |
| **在外** | 目录分页/详情/启停/废弃/医保对码；批号真实价（`LOT_NUMBER_*`）；耗材/诊疗导入；旧 HIS 自动转换脚本（可另立工具，不在本 IF） |
| **涉及域** | `MedicationDefinition`（主数据）；`ChargeItemDefinition`（维护态定价）；术语码表（分类/单位/剂型等） |
| **编排权威** | `MedicationCatalogAppService`：解析 → 全量校验 → 循环复用「创建目录 + `replacePriceLines`」写路径；**禁止**导入走一套、手工新建走另一套定价逻辑 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **药房 / 物价** | 打开「①从这里开始」看三步 → 在「②药品目录」从第 5 行用下拉填写 → 上传 |
| **基础资料维护员** | 执行导入；失败则「下载错误标注表」改红行后**整文件重传** |
| **系统** | 校验模板版本/列指纹；整批校验；事务内落库；失败时零写入并生成标注文件 |

### 1.3 端到端流程

```
下载模板(v1.2) → 默认打开「①从这里开始」
    → 用户在「②药品目录」从第 5 行填写（只填中文+价格，字段对齐新增药品表单）
    → 上传导入
    → Gate：文件/版本/列指纹/表头
    → 解析全部数据行（跳过空行、[示例]行）
    → 批级+行级全量校验（收集全部错误，仍不落库）
    → 任一错误 → 生成错误标注文件 + errorFileToken → 返回（库零写入）
    → 校验通过时：文件内同键只保留首行，库内已存在同键的行标记 skipExisting（不计入错误）
    → 单事务内逐行：skipExisting → 跳过；否则采番 busNo → 建档 ACTIVE → 写 PURCHASE/SALE/(可选 LIMIT)
    → 任一行写失败 → 整事务回滚 → 返回失败
    → 提交 → 返回 batchNo + successCount（实际新建条数；跳过行不计）
```

**不做独立「只预检不写」接口为本期必选项**：导入请求内先全量校验再写即可。若后续需要，另开 `IF-BAS-CAT-IMP-04`，与写路径共用 Validator。

| IF | Method / Path | 说明 |
| --- | --- | --- |

**成功响应（IMP-02）语义**：

| 字段 | 说明 |
| --- | --- |
| `batchNo` | 本批次号（审计/对账） |
| `totalCount` | 文件有效数据行数（含跳过） |
| `successCount` | **实际新建**条数（不含库内已存在跳过） |
| `failCount` | 恒为 `0`（校验/写库失败走错误响应；跳过不算失败） |

**失败响应（IMP-02）语义**：

| 字段 | 说明 |
| --- | --- |
| `message` | 摘要，如「导入失败，共 N 处错误，已全部回滚」 |
| `errors[]` | `{ excelRowNum, columnName?, code, message }`；须尽量**一次返回全部**校验错误 |
| `errorFileToken` | 非空时前端展示「下载错误标注表」→ IMP-03；token 短时有效（如 30 分钟） |

### 3.4 填写约定（给人看的规则）

1. **下拉列只选中文名，不要手填编码**；编码由系统映射。  
2. **一药一行**；禁止合并数据区单元格。  
3. 从**第 5 行**开始写；可改/删示例行，但勿改第 1～2 **行**表头。  
4. 拆零：`1 盒 = 24 片` → 采购单位=盒，拆零单位=片，拆零比=`24`。  
5. 价格 = **元 / 一个包装单位**（不是拆零单价）。  
6. 单文件有效行 **1～3000**；失败后改表并**整文件重传**。  
7. 导入失败优先点「下载错误标注表」：原数据保留，最右侧多一列「错误说明」。
8. 包装/库存/剂量四倍数均相对拆零单位；同单位时倍数须为 `1`。
9. **可整文件多次导入**：库内已有同名+同规格+同厂家的行会被跳过，只新建尚未存在的品；改价/改字段须走目录编辑，重导不会覆盖。

## 5. 写路径编排（成码约束，非类图）

```
importMedicationCatalog(file)
  1. 解析 xlsx → List<ImportRow>（带 excelRowNum）
  2. validateAll(rows) → List<Error>
       库内同键 → row.skipExisting=true（不进 errors）
       if errors not empty → 生成错误标注 xlsx + errorFileToken → throw（无写库）
  3. @Transactional
       for row in rows:
         if row.skipExisting → continue
         CreateMedicationCatalogRequest req = map(row)  // ACTIVE；价格同行
         createOneInBatch(req)  // 同 createMedicationCatalog + replacePriceLines
       publish MedicationCatalogImportedEvent(batchNo, createdCount, 0)
  4. return { batchNo, totalCount, successCount=createdCount, failCount=0 }
```

**强制**：

- 定价只走与 `MedicationCatalogAppService#createMedicationCatalog` 相同的 `replacePriceLines`（或抽私有/support 共用），避免双轨。  
- 领域 `ImportMedicationCatalogCommand` 现有行字段过窄，成码时扩展或改为应用层直接调 `createMedicationDefinition` + 定价；**以本 AS 列清单为准**，不以当前 stub CSV 五列为准。
