# 体检收费 · 应用服务设计（AS）

> **文档职责**：说明「体检收费」工作站的**接口契约（IF）**、业务语义、涉及聚合、规则（BR）、编排意图；作为上游契约供详细设计与实现对齐。  
> **本文必须写**：IF 编号；用户动作与读写属性；关键校验与状态变化；Gap；异常口径；事件语义；非功能约束；业务向测试要点。  
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径；Mapper；伪代码；写库顺序；QueryService 字段组装规则。  
> **页面边界**：体检收费员工作台——待收费/已收费双页签 → 按日与关键字筛选 PE 体检单 → 点选查看收费明细 →（自费主路径）预结算 → 正式收费；个检登记 **REG-09** 跳转本页。  
> **编码**：AS-PE-FIN-001 · **版本**：v1.0 · **日期**：2026-07-19  
> **菜单**：体检收费 · **路由**：`/peis/charge` · **遗留对照**：`/personal/charge`（待收费 / 已收费）

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 体检收费页初始化；**仅** `Encounter.class=PE` 的待收费/已收费队列分页；点选加载收费明细与套餐摘要；自费预结算与正式结算；结算后刷新队列标签 |
| **在外** | 医保平台清算细则、第三方扫码渠道签约、纸质票据物流、读卡硬件协议；**团检批量收费见 AS-PE-FIN-002**；折扣配置页；收费日结专页 |
| **跨域** | Encounter(PE)、Patient、PeisEncounterExt（套餐展示）、ChargeItem、Account/Contract、PaymentReconciliation、Invoice |
| **归属** | **health 主程序收费 AS**；**禁止**新建 `AS-PEIS-FIN-*`；PEIS 登记侧仅 **REG-08** 只读收费态、**REG-09** 跳转本页 |
| **编排权威** | 预结算/正式结算关键校验与金额对齐语义**复用**门诊收费（**AS-OP-FIN-002**）既有编排口径；本文仅约束 **PE 队列边界**与体检展示语义 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| **体检收费员** | 筛选/刷新待收或已收队列 → 点选体检单 → 查看明细 → 打开结算窗 → 预结算 → 确认收费 |
| **登记员** | 个检登记成功后经 REG-09 携带就诊上下文进入本页 |

### 1.3 术语与口径

| 术语 | 口径 |
|------|------|
| **体检单** | 一次 `Encounter(class=PE)` + `peis_encounter_ext`（流水号、套餐快照） |
| **待收费** | 该 PE 就诊下仍存在未正式收费成功的应收（含预结算**草稿**支付语义），见 **BR-PE-CHG-003** |
| **已收费** | 该 PE 就诊下无可计费未结应收，且存在至少一条已结算收费事实（或等价「已结」标签） |
| **待收明细** | 本就诊下 `ChargeItem` 状态为 **PLANNED / SETTLED** 的行（**不含 DRAFT**）；体检场景**无**门诊挂号 `adm_healthcare_service` 锚点排除需求（PE 队列本身不含 AMB 挂号费） |
| **预结算 / 正式结算** | 语义对齐 **AS-OP-FIN-002**：草稿支付流水 → 正式入账与收费项 **SETTLED** |
| **自费主路径** | P0 UI 与 IF 以个人现金账户结算为主；医保读卡/转账户 IF **占位**，不展开平台细则 |

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **本期（P0）** | IF-PE-CHG-01～07：初始化、待收队列、已收队列、明细、预结算、正式结算、按就诊刷新收费态摘要 |
| **待接通（占位）** | 医保读卡、转医保/转自费按钮；电子凭证 |
| **P1** | 本页「去退费」深链；优惠/折扣参与预结算拆分 |
| **非目标** | 门诊 AMB 队列混入；日结专页；发票段配置；折扣权限配置页；在 PEIS 域写 ChargeItem；**团检批量见 AS-PE-FIN-002** |

### 1.5 领域清单

| 聚合（域） | 在本场景中的职责（摘要） | DM 路径 |
|-----------|--------------------------|---------|
| **Encounter** | PE 就诊上下文、队列过滤（`class=PE`） | DM-ADM-002 |
| **Patient** | 队列客户姓名/性别/证件摘要 | DM-ADM-001 |
| **PeisEncounterExt** | 流水号、套餐名/快照展示 | DM-PEIS-007 |
| **ChargeItem** | 待收/已结明细、预结算与结算写态 | DM-ADM-011 |
| **Account / Contract** | 自费账户与费用性质（P0）；医保账户切换（占位） | DM-ADM-009 / DM-FIN-001 |
| **PaymentReconciliation** | 草稿/成功支付流水 | DM-FIN-002 |
| **Invoice** | 正式收费后发票草稿（实付 > 0） | DM-ADM-012 |
| **ServiceRequest** | 结算后可不强制推进分科执行态（体检执行门禁靠 REG-08）；不在本文发明 SR 迁态规则 | DM-WKF-004 |

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
|---------|------|---------|
| **BR-PE-CHG-001** | 队列与明细所涉就诊必须为 **`Encounter.class=PE`**；非 PE 拒绝加载 | IF-PE-CHG-02～06 |
| **BR-PE-CHG-002** | 待收/已收分页候选须存在符合收银口径的 **ChargeItem** 事实（至少一条 **PLANNED 或 SETTLED**）；仅草稿或无收费事实的就诊不入队 | IF-PE-CHG-02 / 03 |
| **BR-PE-CHG-003** | 待收费/已收费**页签标签**：对已入队就诊，仍存在未结清/草稿待付应收 → 待收费；否则 → 已收费 | IF-PE-CHG-02 / 03 |
| **BR-PE-CHG-004** | 明细仅含 **PLANNED、SETTLED**，**不含 DRAFT** | IF-PE-CHG-04 |
| **BR-PE-CHG-005** | 预结算所选收费项须归属当前 PE 就诊且账户/合同可解析（对齐门诊预结算门禁语义） | IF-PE-CHG-05 |
| **BR-PE-CHG-006** | 正式结算必须指向草稿支付流水，且收费项集合与草稿绑定一致；实付渠道合计与预结算现金应付对齐 | IF-PE-CHG-06 |
| **BR-PE-CHG-007** | 正式结算须防重：已成功支付流水不得再次包含本次拟收任一项 | IF-PE-CHG-06 |
| **BR-PE-CHG-008** | 零元不开票：实付 ≤ 0 不创建发票草稿；实付 > 0 开票草稿（对齐门诊零元规则） | IF-PE-CHG-06 |
| **BR-PE-CHG-009** | **REG-09** 跳转目标为本页；携带就诊与患者标识，本页可直达明细区 | IF-PE-CHG-04 / 跨 AS |
| **BR-PE-CHG-010** | HTTP **禁止**前端伪造机构 ID 收窄队列；写路径操作人由服务端会话解析 | 全写 IF |

## 2. 页面与接口总览

| IF 编号 | 用户动作 | 接口语义（业务） | 读/写 | 关键规则 | 关键状态变化 |
|---------|----------|------------------|:----:|----------|--------------|
| **IF-PE-CHG-01** | 进入体检收费页 | 下发页初始化（状态下拉、页签元数据等） | 读 | — | — |
| **IF-PE-CHG-02** | 待收费页签筛选/刷新 | 分页查询 **PE + 待收费标签** 体检单队列（含套餐/流水号摘要） | 读 | BR-PE-CHG-001～003 | — |
| **IF-PE-CHG-03** | 已收费页签筛选/刷新 | 分页查询 **PE + 已收费标签** 体检单队列 | 读 | BR-PE-CHG-001～003 | — |
| **IF-PE-CHG-04** | 点选队列行 / REG-09 带入 | 加载该 PE 就诊收费明细与套餐展示；可选收费态摘要 | 读 | BR-PE-CHG-001 / 004 / 009 | — |
| **IF-PE-CHG-05** | 结算窗预结算 | 预结算快照 → 落草稿支付流水 → 返回金额展示 | 写 | BR-PE-CHG-005 | 产生草稿支付 |
| **IF-PE-CHG-06** | 确认收费 | 草稿正式结算 → 收费项已计费 →（条件）发票草稿 | 写 | BR-PE-CHG-006～008 | ChargeItem→SETTLED；支付→成功 |
| **IF-PE-CHG-07** | 刷新单就诊收费态 | 只读返回是否已结清（供页内角标；与 REG-08 语义同族） | 读 | BR-PE-CHG-001 | — |

## 3. 缺口跟踪（Gap）

| Gap ID | 说明 | 关闭条件 |
|--------|------|----------|
| **GAP-PE-CHG-01** | PE 收银队列「按 ChargeItem 事实收敛 + PE class 过滤」是否复用门诊队列 Loader 扩展，或独立 Query 入口 | SDD 选定并成码 |
| **GAP-PE-CHG-02** | 体检项目 ChargeItem 生成时机（登记时批量建 PLANNED vs 首次打开收费页懒生成） | 与目录定价/登记编排联调后收口；**不影响**本文 IF 编号 |

> 医保读卡/转账户、退费深链标为 P1/占位，**不**记入 P0 Gap。

## 4. 接口编排说明书

### 4.1 IF-PE-CHG-01 初始化

| 维度 | 说明 |
|------|------|
| **触发** | 进入 `/peis/charge` |
| **主路径** | 返回收费项状态等下拉与页签所需元数据 |
| **失败** | 初始化不可用 → EX-PE-CHG-101 |

### 4.2 IF-PE-CHG-02 待收费队列

| 维度 | 说明 |
|------|------|
| **触发** | 关键字、业务日区间、刷新；页签=待收费 |
| **主路径** | ① 收敛 PE 且存在收银口径 ChargeItem 的就诊分页；② 回补患者与体检扩展（流水号、套餐名）；③ 打待收费标签并过滤 |
| **失败** | 查询失败 → EX-PE-CHG-102 |

### 4.3 IF-PE-CHG-03 已收费队列

| 维度 | 说明 |
|------|------|
| **触发** | 同 4.2，页签=已收费 |
| **主路径** | 同收敛与回补，过滤已收费标签 |
| **失败** | EX-PE-CHG-102 |

### 4.4 IF-PE-CHG-04 明细加载

| 维度 | 说明 |
|------|------|
| **触发** | 点选队列行，或 REG-09 带 `encounterId` 进入 |
| **主路径** | Gate：就诊为 PE；加载 PLANNED/SETTLED 明细与金额展示；装配套餐摘要 |
| **失败** | 非 PE / 就诊无效 → EX-PE-CHG-103 |

### 4.5 IF-PE-CHG-05 预结算

| 维度 | 说明 |
|------|------|
| **触发** | 结算窗确认前一步 |
| **主路径** | 校验所选明细归属本 PE 就诊 → 预结算 → 草稿支付流水 → 返回应付展示 |
| **失败** | 账户/合同不可用、明细非法 → EX-PE-CHG-201 |

### 4.6 IF-PE-CHG-06 正式结算

| 维度 | 说明 |
|------|------|
| **触发** | 结算窗「确认收费」 |
| **主路径** | 校验草稿与明细集合 → 正式结算 → 收费项 SETTLED → 条件开票 → 刷新队列 |
| **失败** | 草稿不一致、防重冲突、金额不对齐 → EX-PE-CHG-202 |

### 4.7 IF-PE-CHG-07 收费态摘要

| 维度 | 说明 |
|------|------|
| **触发** | 页内刷新角标，或登记页 REG-08 同族只读 |
| **主路径** | 按就诊返回是否已结清 / 未知 |
| **失败** | 读失败可返回 unknown，不阻断登记 |

## 5. 业务异常

| 码 | 场景 | 提示口径 |
|----|------|----------|
| EX-PE-CHG-101 | 初始化失败 | 收费页初始化失败 |
| EX-PE-CHG-102 | 队列查询失败 | 查询体检收费队列失败 |
| EX-PE-CHG-103 | 非 PE 或就诊无效 | 非体检就诊或记录不存在 |
| EX-PE-CHG-201 | 预结算失败 | 预结算失败（账户/项目/合同） |
| EX-PE-CHG-202 | 正式结算失败 | 收费失败（请勿重复提交） |

## 6. 事件

| 事件（语义） | 消费方 |
|--------------|--------|
| 门诊/通用支付结算成功（体检共用支付域事件） | 队列标签刷新；REG-08 只读态 |
| 发票草稿创建（条件） | 票据后续开具 |

本 AS **不**新发明 PE 专用收费领域事件；与 **AS-OP-FIN-002** 支付成功投影同族。

## 8. 测试要点

- 仅 PE 入队；AMB 门诊就诊不出现在本页。
- 待收费 / 已收费页签互斥与标签正确。
- REG-09 带 encounterId 直达明细。
- 自费：预结算 → 正式收费 → 明细 SETTLED → 待收队列消失、已收可见。
- 重复提交正式结算被拒绝。
- 实付 0 不开票；实付 > 0 有发票草稿语义。
