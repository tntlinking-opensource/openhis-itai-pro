# 住院护士站 · 体温单 · 应用服务设计（AS）

> **文档职责**：工作台右侧「体温单」Tab——按 **AS-IP-NUR-001** 已选就诊加载三测单曲线与网格、录入/覆盖测量值、打印。**入科时点体征**在 **001/002** 维护，与本 Tab 共用 **DM-DIA-002** 事实表，**`type_enum=TEMPERATURE_SHEET`** 独立编排。
>
> **编码**：AS-IP-NUR-007 · **版本**：v1.1.1 · **日期**：2026-06-20

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-IP-TMP-01 页初始化；IF-IP-TMP-02 加载曲线+网格+分页+指定日录入回显；IF-IP-TMP-03 按记录时点保存/覆盖；IF-IP-TMP-04 打印读侧（当前页/全部/PDF 共用） |
| **在外** | 左侧患者列表/详情（**AS-IP-NUR-001**）；入科抽屉体征（**001/002**）；护理记录（**AS-IP-NUR-014**）；Tab 内独立患者分页检索（老系统有，新 UI 无）；按时点删除（老系统有，新 UI 无）；周次/住院天数/术后天数/手术标记（读侧派生）；报表模板设计 |
| **涉及域** | VitalSign（**DM-DIA-002**）；Encounter；Location；Practitioner；Procedure（术后天数只读） |
| **编排权威** | 以本文 **§2、§4** 为准；写侧业务结果对齐既有三测单保存/检索语义，存储采用 ZXPlat 主从模型 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **病区护士** | **001** 选中患者 → 体温单 Tab → 切换 3/7/14 天窗口、翻页 → 查看曲线与网格 → **填写体温单**抽屉选日期、按 6 时点录入主录入与补充项 → **保存并下一时次**（逐槽提交）；打印当前页/全部/PDF |
| **系统** | 曲线读明细 TEMP；网格读主表+明细；同就诊+同记录时点+同类型 upsert 覆盖；补充项锚定当日 **22:00** 槽经 `detailItems` 一并保存 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **三测时点** | 固定 6 槽：`02/06/10/14/18/22`；`recorded_at = recordDate + timeSlot`（本地日期+整点） |
| **主录入** | 抽屉「生命体征（主录入）」：体温、脉搏、呼吸、心率、收缩压、舒张压 |
| **补充记录** | 抽屉「补充记录」：体重、小便次数、腹围、大便次数、身高、入量、皮试阳性、尿量、其他；**与当日 22:00 槽同单保存**（**BR-IP-TMP-011**） |
| **覆盖写** | 同就诊+同 `recorded_at`+`TEMPERATURE_SHEET`：定位已有主表首条后带 id 覆盖（**BR-IP-TMP-005**）；明细按主表 id 全量覆盖（**BR-VS-005**） |
| **体温** | 写明细 `term_code=vital_signs_code`、`item_code=TEMP`（**BR-VS-007**） |
| **入科体征** | **002 ASSIGN** 写入，时点=`encounter.start_time`；本 Tab **可读**展示，录入不强制合并 |
| **字段映射（主录入→明细 code）** | 脉搏→`PULSE`；呼吸→`RESP`；心率→`HR`；收缩压→`SBP`；舒张压→`DBP` |
| **字段映射（补充→明细 code）** | 体重→`WEIGHT`；身高→`HEIGHT`；入量→`INTAKE`；尿量→`URINE_VOL`；大便次数→`STOOL`；腹围→`WAIST`；皮试阳性→`SKIN_TEST_POSITIVE`、其他→`OTHER`（remark 投影）；API 统一 `detailItems` |

## 4. 接口编排说明书（业务步骤）

### IF-IP-TMP-01 体温单页初始化

| --- | --- |

| **主路径步骤** | 返回固定三测时点槽、窗口选项（3/7/14 天）、默认 7 天 |

| **失败分支** | — |

---

### IF-IP-TMP-02 加载体温单数据

| 维度 | 说明 |
| --- | --- |
| **触发前提** | **001** 已选中患者；或切换窗口/翻页；或打开录入抽屉需回显 |
| **主路径步骤** | 校验就诊可见 → 按窗口与页码计算 `dateFrom/dateTo` → 读曲线点（明细 `TEMP`，`TEMPERATURE_SHEET`）→ 读同时段主表与明细 → 组装日×6 槽宽表（`detailItems`）→ 结合入科日与手术记录派生住院天数、周次、术后天数 → 若请求带 `focusRecordDate`，额外返回该日 6 槽 `detailItems` 回显 |
| **关键分支** | 无数据返回空结构；入科 `start_time` 时点数据纳入网格 |
| **失败分支** | 就诊不可见 → EX-IP-TMP-102 |
| **查询侧说明** | 翻页/切窗口/刷新均重调本接口 |

---

### IF-IP-TMP-03 保存三测单（单时点）

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 抽屉内选定日期与时次，至少一项主录入或（22:00 槽）补充项非空 |
| **主路径步骤** | 校验可见性与登录用户 → 组装记录时点 → 校验时次合法 → 校验 `detailItems` 至少一项有效 → 定位已有单据（同就诊+同时点+类型首条）→ `detailItems` 映射明细（皮试阳性/其他投影 remark）→ 若时次为 22:00 可含补充 code → 填充患者、床、记录人、单据类型 → 提交领域保存 |
| **关键分支** | 全空跳过不调写；同槽二次保存为覆盖 |
| **失败分支** | 未登录 → EX-IP-TMP-101；参数非法 → EX-IP-TMP-201；无有效内容 → EX-IP-TMP-202；编码无效 → EX-IP-TMP-203；写失败 → EX-IP-TMP-204 |
| **查询侧说明** | 成功后前端刷新 IF-IP-TMP-02；可自动聚焦下一时次 |

---

### IF-IP-TMP-04 打印读侧

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已选患者；指定打印范围（当前页/全部） |
