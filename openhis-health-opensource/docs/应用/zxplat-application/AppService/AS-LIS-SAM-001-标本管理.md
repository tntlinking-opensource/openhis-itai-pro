# 检验域 · 标本管理 · 应用服务设计（AS）

> **文档职责**：说明标本管理的**接口契约（IF）**、TAT 时效监控、标本转运、业务规则（BR）。  
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径。  
> **页面边界**：标本列表 | TAT 统计看板(子Tab) | 转运管理(子Tab)  
> **子模块**：SAM-TAT 时效监控(P0)、SAM-TRANS 标本转运(P1)  
> **编码**：AS-LIS-SAM-001 · **版本**：v2.0 · **日期**：2026-06-22

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 标本列表查询；单/批核收；位置查询；TAT 统计/超时/告警；转运批次 |
| **涉及域** | LisWorkItem、LisTransferLog |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| **检验科核收员** | 扫码核收标本 → 查看 TAT 看板 |
| **标本转运员** | 建批次→送检→交接确认 |

### 1.3 术语与口径约定

| 术语 | 口径 |
|------|------|
| **核收** | collected → received |
| **TAT 超时** | statusUpdatedAt 任意节点间隔 > 阈值 → overdue |

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **P0** | SAM 本体 + SAM-TAT 看板/超时/告警 |
| **P1** | SAM-TRANS 转运批次 |

### 1.5 领域清单

| 聚合 | 职责 | DM 路径 |
|------|------|---------|
| **LisWorkItem** | 标本状态 + 时间戳 | `docs/领域/缺口/文档无代码/DM-LIS-001-LisWorkItem-检验工单.md |
| **LisTransferLog** | 转运记录 | `docs/领域/缺口/文档无代码/DM-LIS-009-LisTransferLog-标本转运.md |

### 1.6 业务规则（BR-*）

| 编号 | 规则 | 触发 IF |
|------|------|---------|
| **BR-SAM-01** | 核收前置：statusEnum = collected | SAM-02 |
| **BR-SAM-02** | 批量核收上限 → lis_config.tat.batchSize | SAM-03 |
| **BR-SAM-03** | TAT 超时：任意状态间隔 > 阈值 → overdue | TAT |
| **BR-SAM-04** | TAT 保留天数 → lis_config.tat.retentionDays | TAT |
| **BR-SAM-05** | 转运交接需记录差量 | TRANS |

## 4. 接口编排说明书（业务步骤）

### 4.1 IF-SAM-02：核收

| 维度 | 说明 |
|------|------|
| **触发前提** | 检验科扫码，LisWorkItem = collected |
| **主路径** | ① 校验 statusEnum=collected → ② 执行标本核收 → ③ statusEnum→received |
| **失败分支** | 状态不符 → "标本状态不允许核收" |
