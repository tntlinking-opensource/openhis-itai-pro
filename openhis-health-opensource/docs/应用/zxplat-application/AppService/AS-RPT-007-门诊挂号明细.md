# 门诊挂号明细 · 应用服务设计（AS）

> **文档职责**：报表中心「门诊挂号明细」只读契约。汇总：按科室或医生看每天便民/普通/专家等号源净挂号量；明细：谁挂了什么号、自费/医保及医保类型等。**仅门诊**。
>
> **编码**：AS-RPT-007 · **版本**：v1.5 · **日期**：2026-09-09  
> **族边界**：`health/设计决策/DD-报表中心-发药耗材挂号费用汇总明细族.md`

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-RPT-ORG-01～04：初始化、汇总、明细分页、导出 |
| **在外** | 门诊挂号写路径（**AS-OP-FIN-001**）；医生工作量整页（**AS-RPT-001**，可复用号源口径但不并页）；住院登记 |
| **涉及域** | **Encounter** / 参与者；**HealthcareService**（号源类型）；**ChargeItem** / **Payment**（挂号费与收退）；**Patient**；**Organization**；**Practitioner**；医保属性读模型 |
| **编排权威** | 本文；汇总须 **净**（退号冲减） |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **挂号窗 / 财务 / 管理** | 按科室或医生查号源净量 → 查明细人与号别/费用性质 → 导出 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **号源类型** | 便民 / 普通 / 专家等（`HealthcareService` / 挂号页 serviceType 展示名） |
| **汇总视角** | **按科室** 或 **按接诊医生**；维度内按号源类型计 **净挂号笔数**（及可选净挂号费） |
| **净** | 有效挂号 − 退号（CANCELLED 等冲减，对齐挂号列表业务） |
| **明细** | 患者、门诊号、科室、**接诊医生**、号源类型、挂号时间、状态、自费/医保、医保类型、挂号费金额等；**不展示挂号医生** |
| **医生筛** | `practitionerId` 按活动 **接诊医生（ADMITTER）** 收窄；未接诊则不命中 |
| **状态筛** | `statusEnum` 单值（已挂号/在诊/退号等 EncounterStatus code）；空=全部；退号展示码仍为 `CANCELLED` |
| **明细页脚** | 同筛选 **挂号 / 有效 / 已退**（对齐门诊挂号当日统计：排除 PLANNED/ENTERED_IN_ERROR；已退仅 CANCELLED） |
| **时间窗** | 挂号业务日/缴费确认时间（与 **AS-OP-FIN-001** 列表时间口径对齐，SDD 定字段） |
| **导出** | 仅当前 Tab |

### 1.4 本期范围与非目标

| 类别 | 内容 |
| --- | --- |
| **本期** | IF-RPT-ORG-01～04；仅门诊 |
| **非目标** | 住院挂号；与 AS-RPT-001 并页；写路径退号 |

### 1.5 领域清单（聚合 + 职责 + DM 路径）

| 聚合 | 职责 | DM |
| --- | --- | --- |
| **Encounter** | 挂号就诊、状态、科室 | `DM-ADM-002` |

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
| --- | --- | --- |
| **BR-RPT-ORG-001** | 日期必填；默认当日 | 01～04 |
| **BR-RPT-ORG-002** | 汇总视角科室或接诊医生二选一；按号源类型净笔数 | 02 |
| **BR-RPT-ORG-003** | 汇总必须净（退号冲减） | 02、04 |
| **BR-RPT-ORG-004** | 明细费用性质 = 就诊优先账户（用什么挂号就是什么，身份展示）；医保类型有则展示 | 03、04 |
| **BR-RPT-ORG-005** | 导出仅当前 Tab | 04 |
| **BR-RPT-ORG-006** | 仅 AMB 挂号 | 02～04 |
| **BR-RPT-ORG-007** | 医生筛与明细医生列仅活动接诊医生（ADMITTER）；不展示挂号医生 | 02～04 |
| **BR-RPT-ORG-008** | 明细页脚挂号/有效/已退口径对齐门诊挂号当日统计 | 03 |
| **BR-RPT-ORG-009** | 可选按就诊状态单值筛选；须为页初始化白名单 code；非法拒绝；空不收窄 | 01～04 |
