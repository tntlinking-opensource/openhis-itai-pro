# 药库订货单 · 应用服务设计（AS）

> **文档职责**：说明「药库订货单」页面的**接口契约（IF）**、业务语义、涉及聚合与 QueryService、规则（BR）、编排意图；作为上游契约供详细设计与实现对齐。
>
> **本文必须写**：IF 编号；用户动作与读写属性；关键校验与状态变化；Gap；异常口径；事件语义；非功能约束；业务向测试要点。
>
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径；Mapper；伪代码；写库顺序；QueryService 字段组装规则。
>
> **页面边界**：药库业务线 — 药库人员维护向供应商的**订货申请**（`SupplyType` 值 `1` / `CABINET_PURCHASE_ORDER`）：列表与详情、**手工新建**订货、（可选）**从已同意科室采购申请单拉取**预填明细、**预警快捷选品**（只读查询效期最晚批近效 / 库存低于最小值的品种，勾选后走选品带入明细）、（待审核态）改单与删单、提交/撤回审批、审批同意/驳回。订货为**申请单**；审批同意前不直接扣增库存。**进货单（type `2`）由用户在「药库进货单」应用服务/页面另行创建**（可从上订货单带入），**不在本页审批同意时自动落库**——与 **AS-INV-WHS-002** 分工；领域模型仍允许两阶段编排语义（**DM-WKF-006**），实现拆分为两个应用边界。
>
> **与科室采购申请分工**：**AS-INV-DEP-007** 仅处理科室采购申请（**`DEPT_PURCHASE_REQUEST`**）；本页**仍可手工直建订货**；拉科室申请为**可选来源**（**IF-WHS-PO-12/13**），建单时 **`original_bus_no` 可空**。
>
> **覆盖声明**：本稿为**初稿**——IF 与交互以 common 药库订货业务为基线；**正式定稿前**须用产品/UI 全量操作清单与既有应用服务实现对照修订 **§1.4、§2、§4、§5**。
>
> **编码**：AS-INV-WHS-001 · **版本**：v0.9.2 · **日期**：2026-07-15

## 1. 场景概述

### 1.1 目标与边界


| 维度         | 说明                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------- |
| **在内**     | 药库向外部供应商发起订货草稿（**可手工直建**，或从已同意 **科室采购申请** 预填）；**预警快捷选品**（只读，勾选品种后走 **IF-WHS-PO-11** 带入）；同一 `bus_no` 多行明细；状态沿「待审核 ↔ 审核中 → 同意/驳回/撤回」流转；待审核/审核中态的删改与审批动作                 |
| **在外**     | 进货单填写批号/发票/验收、入库发放与库存入账（**药库进货单**场景）；科室采购申请维护（**AS-INV-DEP-007**）；库存明细页预警工作台（**AS-INV-WHS-004**，口径不同，**不**复用其 `warningMode`）；财务月结、调价、发药链                                             |
| **跨域**     | 进货单创建与验收在 **AS-INV-WHS-002**；本场景审批同意**仅**将订货单置为 `AGREE`，**不**在本应用服务内调用 `createGoodsReceipt`；可选上游见 **AS-INV-DEP-007** |
| **编排权威**   | 以本文 **§2、§4** 为准；订货单写侧以 **DM-WKF-006** 为准；进货单创建见 **AS-INV-WHS-002**                                 |
| **前置（摘要）** | 当前登录上下文能解析药库 **Location**；物品目录、供应商主数据可用；建单人具备药库订货权限；若拉源则须存在已同意且未被占用的科室采购申请                                          |
| **后置（摘要）** | 订货单 **同意**后本子可提示用户至进货模块建单；**驳回/撤回**不产生进货单                                                        |


### 1.2 角色与关键动作


| 角色           | 关键动作                               |
| ------------ | ---------------------------------- |
| **药库制单员**    | 查询列表 → **手工新建订货** 或 **从科室采购申请拉取** →（可选）**预警查询勾选 → 选品带入** → 维护明细与供应商（数量手填）→ 提交审批（或撤回） |
| **药库主管/审批人** | 在待办或单据页执行同意 / 驳回                   |
| **科室药房管理员**（上游，非本页） | 在 **AS-INV-DEP-007** 填写/审批采购申请，供本页可选拉源 |
| **管理员**      | 待审核态修改或逻辑删除                        |


### 1.3 术语与口径约定


| 术语         | 口径                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| **订货单**    | `type_enum = 1`（`CABINET_PURCHASE_ORDER`），**申请单**性质：同意前**不**触发 **SupplyDelivery** / **InventoryItem** 数量变更 |
| **科室采购申请（可选上游）** | `original_bus_no` 可选指向 **`DEPT_PURCHASE_REQUEST`**（**AS-INV-DEP-007**）；**空则手工直建**；填则须原单 **AGREE** 且满足 **BR-WHS-PO-012** |
| **新建 `bus_no`** | 首行未显式传入 **`busNo`** 时由按日流水生成；**序号键前缀**为 **`SupplyType` 枚举内固定短码 `busNoSeqKey`**（订货 **`CPO`**）+ 业务日 + 当日序号，与其它 **`SupplyType`** **分桶**；**`type_enum` 无法匹配白名单**时回退 **`SR`**（与 **`SupplyType.busNoSeqPrefixForTypeCode`** 一致；**不含**历史 **`SQ`** 前缀） |
| **两阶段**    | 领域语义：订货同意后可承接进货单（**DM-WKF-006**）；**实现分工**：进货单在 **AS-INV-WHS-002** 创建，不在本页自动触发                                                                       |
| **源/目标位置** | 建单须 **`purposeLocationId`** 为机构内药库且经 **Location** 推导之 **`purpose_type_enum`** 满足 **DM** / **BR-SR-016**；**`source_type_enum`** 由应用层装配（订货可无源位时为 **null**）；两列持久化均为 **`SupplyRequestType#getCode()`** 字符串（**B.10.8.1**） |
| **QueryService 能力**    | 列表/明细以QueryService 展示为主；聚合状态以写侧与事件为准                                                                                 |
| **预警快捷选品** | 草稿/可编辑态入口；弹窗只读列出命中品种（**一行一目录**，与批号无关）；筛选项：**效期** / **低储** / **全部**（并集去重）；须已选表头**项目类型**（药品或耗材），查询范围随表头收窄；勾选后传 **`productDefinitionIds`** 走 **IF-WHS-PO-11**，再纳入明细；**不**写库存、**不**自动填数量 |
| **订货·效期命中** | 在库数量 &gt; 0 的批中，取该品种**效期最晚**那一批；该批剩余天数 ≤ 系统效期预警天数 → 品种进效期筛（**≠** 库存明细「任意近效批号行」**BR-INV-DTL-023**） |
| **订货·低储命中** | 全院各库房拆零合计换算后：**仅低于**目录 **`item_min_quantity`**（库存单位）；目录未维护 → 回落系统设置全局包装阈值（默认 **30**）；**不含**超最高（**≠** 明细 **BR-INV-DTL-024** 的超储侧） |
| **DM 路径**  | 下文聚合路径均指 `docs/领域/DomainModel/` 下对应文件                                                        |

## 7. 非功能性需求


| 类别      | 要求                                                 |
| ------- | -------------------------------------------------- |
| **性能**  | 列表查询与详情在正常数据量下响应可接受；选品检索分页                         |
| **幂等**  | 提交审批、同意、驳回在短时间重复请求下表现为幂等或明确「已处理」语义                 |
| **并发**  | 同一单据并发编辑以乐观策略或版本控制拒绝非法提交                           |
| **一致性** | 订货单同意与进货单编排在同一业务事务边界内对外一致；失败时订货侧状态与下游编排可补偿策略在详设中展开 |
| **审计**  | 审批动作须可追溯审批人、审批时间、可选原因                              |

## 8. 测试要点（业务视角）


| 类别      | 要点                                                       |
| ------- | -------------------------------------------------------- |
| **正向**  | 新建 → 提交 → 同意 → 列表状态为已同意；用户在进货模块从订货单生成进货单；**手工直建**与**从科室采购申请拉预填**均可；**预警弹窗**勾选 → 选品（ids）→ 手填数量保存；驳回/撤回后状态与列表一致    |
| **异常**  | 非药库位置建单、空明细、非法类型；不可编辑态修改；拉源占用冲突（EX-WHS-PO-106）；未选项目类型点预警 |
| **规则**  | BR-WHS-PO-002 药库专属；同意后订货终态与进货模块衔接一致；**BR-WHS-PO-012** 一申请一未删除订货；**BR-014** 仅最晚效期批近效；**BR-015** 仅低储不含超储；**BR-016** 预警无写 |
| **并发**  | 双开窗口同时提交审批或删除                                            |
| **跨场景** | 进货单 **AS-INV-WHS-002** 中验收 **original_bus_no** 与订货单可追溯一致；订货对科室申请的 **original_bus_no** 与 **AS-INV-DEP-007** 可追溯一致；预警口径**不**与 **AS-INV-WHS-004** `warningMode` 混用 |
