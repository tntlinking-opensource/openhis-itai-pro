# 药品结余留用报表 · 应用服务设计（AS）

> **文档职责**：报表中心「药品结余留用」只读契约。按**结余留用批次号（必选）** + **药品申请签发时间窗**查询门诊/住院患者发退药净明细，导出对齐监管《患者明细主表》19 列。
>
> **页面边界**：批次必选 → 签发时间窗 → 明细分页 → 导出（固定模板列）。**纯读**。
>
> **编码**：AS-RPT-015 · **版本**：v1.1.3 · **日期**：2026-09-18  
> **产品裁决（锁定）**：批次=`MedicationDefinition.surplusRetentionBatchCode`（必选）；时间轴=`MedicationRequest.reqAuthoredTime`（签发）；合表门诊+住院；是否中选=`centralPurchaseFlag`；**参保类型按挂账合同写省医保/市医保/自费；参保地区自费写「自费」、医保写平台参保地**；门诊无入出院时刻时与处方日期一致；**产品名称=目录商品名原样**；包装=包装单位；数量/金额净（发正退负）；科室领用不进。

## 4. 接口编排说明书（业务步骤）

### 4.1 IF-RPT-SRB-01 初始化

加载术语 `surplus_retention_batch_code` 下拉；默认签发时间为当月首尾日；默认页大小 20。

### 4.2 IF-RPT-SRB-02 明细分页

1. Gate：批次非空；签发窗合法；分页合法。  
2. Pre：目录 id ← 批次码；申请 id ← 目录 id + 签发窗；发放行 ← 申请 id 且 COMPLETED/REFUNDED。  
3. Asm：分页发放行 → 患者/就诊/目录/售价/挂账合同分类/平台参保地装配 → 19 列 DTO（类型=三值；地区自费=「自费」、医保=参保地；门诊入出院=处方日期）。

### 4.3 IF-RPT-SRB-03 导出

同筛选预解析一次；翻页收集至上限；`AnnotatedExcelExporter` 按模板列名写出。

## 8. 测试要点（业务视角）

1. 未选批次拒绝查询。  
2. 仅维护批次 A 的药品出现在批次 A 结果。  
3. 一发一退净轧差数量/金额。  
4. 门诊入出院与处方日期一致；住院有值（缺省回落处方日期）。  
5. 自费：参保地区与类型均为「自费」；医保：类型为省/市医保，地区为平台参保地展示名。  
6. 产品名称等于目录商品名称原样。  
7. 导出表头含 `*` 与模板一致。
