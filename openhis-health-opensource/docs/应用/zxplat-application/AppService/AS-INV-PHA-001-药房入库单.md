# 药房入库单 · 应用服务设计（AS）

> **文档职责**：说明「药房入库单」页面的**接口契约（IF）**、业务语义、涉及聚合与 QueryService、规则（BR）、编排意图；作为上游契约供详细设计与实现对齐。
>
> **本文必须写**：IF 编号；用户动作与读写属性；关键校验与状态变化；Gap；异常口径；事件语义；非功能约束；业务向测试要点。
>
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径；Mapper；伪代码；写库顺序；QueryService 字段组装规则。
>
> **页面边界**：药房业务线 — **`PHARMACY_STOCK_IN`** **只读台账**：列表、详情查询展示由 **药库出库单（AS-INV-WHS-003）** 审批**同意**后系统自动落库的壳单（**`AGREE`**，**`original_bus_no`** = **上游出库 `bus_no`**）。**禁止**手工新建/编辑/删除/提交/撤回/审批同意或驳回（**`PHA_IN_002`**）。库存落账与追溯在出库同意相位完成；本页**不**补录批号维定价。对历史手工单若仍存在，亦不得通过本 AS 写接口变更（统一走 **`PHA_IN_002`** 拒绝）。
>
> **与药库出库（调拨对偶）**：药库↔药房实物调拨执行链为 **请领（可选）→ 药库出库 agree → 系统 `PHARMACY_STOCK_IN`（`AGREE`）**；**不再**支持药房侧手工入库 agree 编排对侧出库。两端在 **选品行字段族、`unitBands`** 展示上与 **IF-WHS-SO-11** **同构**（只读详情）；**均不**补录 **`LOT_NUMBER_COST` / `LOT_NUMBER_PRICE`**。
>
> **覆盖声明**：本稿以 **AS-INV-WHS-003** 与当期业务口述为基线；**药房入库**独立 **HTTP 资源** 与药库出库分离；**正式定稿前**须与 **`openhis-pro-ui/apps`** 药房入库页（若已落地路径）对照片修订 **§1.4、§2、§4、§5**。
>
> **编码**：AS-INV-PHA-001 · **版本**：v0.10 · **日期**：2026-05-28

## 1. 场景概述

### 1.1 目标与边界


| 维度         | 说明                                                                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **在内**     | **只读** **`PHARMACY_STOCK_IN`**：列表（**突出来源位置——从哪入**）、详情；系统生成单 **`AGREE`** + **`original_bus_no`** 展示与跳转上游出库 |
| **在外**     | **AS-INV-WHS-003** 出库生成与库存落账；科室 **`DEPT_STOCK_IN`** 见 **`inventory/department/stockin`**（**`DEPT_IN_*`**，与本文对称只读壳单） |
| **涉及域**    | 读侧：**SupplyRequest**、**InventoryItem**、**ProductDefinition**；写侧**无**（本 AS 拒绝手工写） |
| **跨域**     | 库存变更**仅**在 **AS-INV-WHS-003** 出库 **同意** 相位完成；本页**不得**重复加库存 |
| **编排权威**   | 以本文 **§2、§4** 为准                                                                                                                                              |
| **前置（摘要）** | 目的药房位置合法；选品须传 **`sourceLocationId`** 与业务规则允许之来源库一致                                                                                                                              |
| **后置（摘要）** | **手工同意**后目的药房库存增加；**驳回/撤回** 不产生入库发放                                                                                                       |


### 1.2 角色与关键动作


| 角色           | 关键动作                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| **药房制单员**   | 查询入库列表 → 查看详情（**不可**手工建单）                                     |
| **药房主管/审批人** | 只读查阅（**不可**在本页审批）                                  |
| **管理员**      | 待审核态修改或逻辑删除                                                              |


### 1.3 术语与口径约定


| 术语              | 口径                                                                                                                    |
| --------------- | --------------------------------------------------------------------------------------------------------------------- |
| **药房入库单**      | `type_enum`=`**PHARMACY_STOCK_IN**`（**`SupplyType#getCode()`**）                                                                 |
| **`bus_no` 前缀** | 新建且首行未显式传入 **`busNo`** 时：**`SupplyType.busNoSeqKey`**（本页 **`PSI`**）+ 业务日 + 当日序号，与其它类型**分桶**；**`type_enum` 无法匹配白名单**时回退 **`SR`**（**不含 `SQ`**）                                                                 |
| **`original_bus_no`** | **系统自出库生成**：填 **`CABINET_STOCK_OUT`** 之 **`bus_no`**（与 **AS-INV-WHS-003** **BR-WHS-SO-012** 对称）。**禁止**手工填写 |
| **从哪入**        | 列表行须展示**来源位置**（**`source_location_id`** 解析展示名）；与出库列表「到何处」对偶                                                                  |
| **选品主表**       | **库存批号行**为主表联接 **ProductDefinition**；**每行一批号**；返回 **效期**、**可用量**（按 **`sourceLocationId`**）；若暴露自由选品 UI，**须展示 `lotNumber`（批号）**（与 **AS-INV-WHS-003 §1.3** 同构；本期写侧拒手工选品时仍保留契约字段）                                                                  |
| **库存自然键与可用量** | 与 **DM-WKF-008 §1.1 / §2.1 / §6.2.3**：`wkf_inventory_item` **业务唯一**为 **四元组** `(location_id, item_table, item_id, lot_number)`（须由表级 **UNIQUE** 保证）；**可用量**以 **`inventory_status_enum` = `PublicationStatus.ACTIVE.getCode()`**（**`"ACTIVE"`**）且未删、**`quantity > 0`**、无有效锁、未过期为准；选品/目录装配可用量时**仅汇总 `wkf_inventory_item.location_id` = 请求 `sourceLocationId`** 的库存行，按 **`item_id` + 归一化批号**（**`normalizeLotNumberForAvailabilityMatch`**）聚合，**与 AS-INV-WHS-003 对页同口径**。 |
| **初始化下拉**      | **目的药房**与**来源药库**（或来源类型）分列 **OptionDto**；**SupplyStatus**；入库项目类型两档；与 **IF-WHS-SO-01** 同源策略（**SDD** 与 **OptionDto** 门控一致） |
| **枚举口径**       | 一律 **`getCode()`** 字符串（**`PHARMACY_STOCK_IN`**、**`AGREE`** 等）                                                                  |
| **详情 `productCatalog` 与选品采购参考** | 与 **AS-INV-WHS-003** **IF-WHS-SO-11** / **IF-WHS-SO-03** **同构**：**`unitBands`** 四槽（含包装）、**`PURCHASE`** 采购参考价之解析与展示真源、详情各槽单价回填规则**一致**；**不因本页为药房入口而与药库出库选品/详情存在本质口径差异**；**同意**相位**不**补录批号维定价表。                                                                  |
| **DM 路径**       | 下文聚合路径均指 `docs/领域/DomainModel/` 下对应文件                                                               |
| **供应行 `item_quantity`/`unit_code`** | 与 **AS-INV-WHS-002** **§1.3** 及 **AS-INV-WHS-003** **§1.3** 同口径：**`item_quantity`** 拆零下持久化并与库存一致；**`unit_code`** 仅展示/录入；**手工同意**入账 **`InventoryItem`** 时**不得**再按 **`unit_code`** 对 **`item_quantity`** 做倍数换算。 |

## 7. 非功能性需求


| 类别      | 要求                                                  |
| ------- | --------------------------------------------------- |
| **性能**  | 批号级选品分页可接受；同意链路可异步但最终一致                         |
| **幂等**  | 同意/驳回/提交短时重复请求幂等或明确已处理                              |
| **并发**  | 同一单据并发编辑乐观控制                                        |
| **一致性** | **手工同意**与目的库存增加、追溯轨迹一致；与 **出库生成单** 的库存编排**不**双重增加                         |
| **审计**  | 审批人、审批时间、来源/目的位置、批号与数量可追溯                                   |
