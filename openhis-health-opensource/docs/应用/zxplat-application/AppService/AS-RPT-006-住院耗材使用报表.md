# 住院耗材使用报表 · 应用服务设计（AS）

> **文档职责**：报表中心「住院耗材使用报表」；与 **AS-RPT-005** 对称（住院域）。事实 = **DeviceDispense（患者）∪ 科室耗材领用/退领**；汇总主维 = **耗材房 / 品规 / 类型 / 科室**（默认耗材房），**无**患者主维。
>
> **编码**：AS-RPT-006 · **版本**：v1.11 · **日期**：2026-09-09  
> **族边界**：`health/设计决策/DD-报表中心-发药耗材挂号费用汇总明细族.md`

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-RPT-ICU-01～04 |
| **在外** | 门诊耗材 **AS-RPT-005**；护士工作量 **AS-RPT-002**；发药报表；护士站划价写路径 |
| **涉及域** | 同 AS-RPT-005，场景收窄 **IMP** / 住院库位 |
| **编排权威** | 本文；口径对齐 AS-RPT-005，仅域不同 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **住院药房 / 病区 / 财务** | 查住院患者与科室耗材净用量；明细含收退；导出 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **患者使用 / 科室领用 / 汇总维** | 同 **AS-RPT-005 §1.3**（含 **费用性质**、**记录类型/耗材类型/关键字/患者关键字/科室/执行人** 筛选与明细列；含 **账批质检** `chargeLotNumber`/`lotMismatch`） |
| **按患者维度合并** | 明细 Tab 可选 `lineMergeMode=BY_DEFINITION`：患者使用源下同就诊+品规（+单位）净合计数量与金额；隐藏业务时间/执行人/批号等；`total`=分组合计数；科室领用源忽略本开关 |
| **住院上下文字段** | 明细尽量含住院号、床号、病区 |
| **执行人** | 同 **AS-RPT-005 §1.3**：患者发放 `performer_id`、科室领用 `approver_id`；筛选项仅患者侧 |
| **患者关键字** | 同 AS-RPT-005；住院侧按姓名/住院号等收窄 IMP encounter |
| **场景** | 住院发放与住院相关科室领用（SDD 定） |

| **非目标** | 门诊耗材；按护士；患者主维汇总；写路径 |

### 1.5 领域清单（聚合 + 职责 + DM 路径）

同 **AS-RPT-005 §1.5**（住院 Encounter 上下文）。

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
| --- | --- | --- |
| **BR-RPT-ICU-001** | 时间窗必填且 `dateFrom≤dateTo`；前端 `datetimerange`；Request 仍为 `String dateFrom/dateTo`（`yyyy-MM-dd HH:mm:ss`，兼容仅日期）；仅日期时起补 `00:00:00`、止补 `23:59:59`；默认当日 `00:00:00～23:59:59` | 01～04 |
| **BR-RPT-ICU-002** | 明细两路并集 + 来源列；住院上下文字段；含 **执行人**（发耗材人） | 03、04 |
| **BR-RPT-ICU-003** | 汇总主维耗材房/品规/类型/科室；列=数量+进售单价（展示）+进售合计；默认 LOCATION；**不展示行数** | 02 |
| **BR-RPT-ICU-004** | 金额口径同 AS-RPT-005（进价按操作单位分支 / 售价单价总价，无实收；领用售价空）；Supply 白名单 | 02～04 |
| **BR-RPT-ICU-005** | 导出仅当前 Tab | 04 |
| **BR-RPT-ICU-006** | 住院域收窄（异于门诊） | 02～04 |
| **BR-RPT-ICU-007** | **账批质检**（仅 IF-03）：同 AS-RPT-005 BR-RPT-OCU-008 | 03 |
| **BR-RPT-ICU-008** | 明细可选 `lineMergeMode`：`LINE`（默认）/ `BY_DEFINITION`；`BY_DEFINITION` 仅 **患者使用**源：按 `encounterId+deviceDefId(+unitCode)` 领域 GROUP BY 真分页净合计；科室领用源忽略合并（按 LINE）；**禁止**全窗物化再截页 | 03、04 DETAIL |
