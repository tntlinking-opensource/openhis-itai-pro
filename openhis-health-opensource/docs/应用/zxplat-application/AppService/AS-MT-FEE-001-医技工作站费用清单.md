# 医技工作站 · 费用清单 · 应用服务设计（AS）

> **文档职责**：医技工作站「费用清单」——按就诊查询**登录医技科相关**费用、**住院**一键确费、打印入口；可切门诊/住院。  
> **不是**患者全院费用。  
> **导航**：`DD-医技工作站-模块索引-2026-09.md`  
> **SDD**：`health/AppService-SDD/AS-MT-FEE-001-医技工作站费用清单-SDD.md`  
> **编码**：AS-MT-FEE-001 · **版本**：v1.3.3 · **日期**：2026-10-12

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | 按 encounterScope + encounterId 查询本科相关 ChargeItem；汇总金额；**住院一键确费**（行级 `fee_confirmer_id`/`fee_confirmed_at`）；打印任务触发入口 |
| **在外** | 医技执行、医技计费写路径；收费结算；全院费用明细报表；确费头表；**门诊确费**（门诊无此业务） |
| **涉及域** | ChargeItem；ServiceRequest / DeviceRequest（锚点归属）；Encounter；Organization / Location |
| **编排权威** | 本文 §2、§4 |

### 1.2 角色与关键动作

| 角色 | 动作 |
| --- | --- |
| **医技人员** | 切门诊/住院 → 选患者 → 打开费用清单 → 查看/刷新 →（**仅住院**）一键确费 → 打印 |
| **系统** | 仅返回登录 TECH 相关费用行；确费写路径仅住院 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **相关费用** | 满足任一：① 锚诊疗请求 `org_id` ∈ **共看可见执行科**（默认登录科；院点 bus_no 共看组如 CT↔DR）；② 锚耗材发放房/请求库房挂靠科室属登录 TECH 可见轴（见 `DeviceSupplyTechVisibilitySupport`）；②b 耗材 `DeviceRequest.based_on` 挂靠本站可见诊疗（护士执行带出计价：Charge.org 常为病区，须靠主诊疗执行科纳入）；③ 收费 `org_id`/`requesting_org_id` ∈ 共看可见执行科；④ `generate_source=medical-tech-pricing` 且 org/requestingOrg ∈ 共看可见执行科（医技划价主路径，防漏） |
| **行级确费（仅住院）** | `fee_confirmer_id` 非空 = 已确费；一键 = 批量打本科未确费行；无头表；**门诊不展示、不调用** |
| **非相关** | 他科医技、护士站注射/康复等费用不进本清单 |

### 1.4 本期范围与非目标

| 类别 | 内容 |
| --- | --- |
| **本期** | IF-MT-FEE-01 查询；IF-MT-FEE-02 打印；**IF-MT-FEE-03 住院一键确费（入口下线，实现保留）** |
| **非目标** | 改费、退费、全院费用、工作量统计、逐行手工选确费、**门诊确费** |

### 1.5 领域清单

| 聚合 | 职责 | DM |
| --- | --- | --- |
| ChargeItem | 费用行；确费戳 | DM-ADM-011 |
| Encounter | 就诊 | DM-ADM-002 |
| ServiceRequest / DeviceRequest | 归属判定 | DM-WKF-004 / 003 |

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
| --- | --- | --- |
| **BR-MT-FEE-001** | 须登录 TECH；scope 与就诊类别一致 | 01～03 |
| **BR-MT-FEE-002** | 仅返回/确费「登录科相关」费用（§1.3） | 01、03 |
| **BR-MT-FEE-003** | 打印数据集合 = 当前查询结果集（或勾选子集）；禁止扩成全院费用 | 02 |
| **BR-MT-FEE-004** | **仅住院**一键确费（实现保留）：对本病本科相关且 `fee_confirmer_id` 为空的行写入当前操作人与当前时刻；已确费行跳过（幂等）；不改收费状态；`encounterScope≠INPATIENT` 拒绝。**产品入口已隐藏**；出院门禁改读医技执行净态见 **BR-IP-ATD-011⑤** | 03 |
| **BR-MT-FEE-005** | 费用清单**不展示**确费筛/确费列/确费人；不提供一键确费入口（门诊/住院同） | 01 |
| **BR-MT-FEE-006** | **住院**清单明细增列「（医技）执行人」「执行时间」：诊疗取登录 TECH 科净剩 COMPLETED Procedure 主执行人 + `recorded_time`；耗材取 DeviceDispense `performer_id` + `dispense_time`；未医技执行时为空。与计费人/划价时间分列 | 01 |

## 4. 接口编排说明书

### IF-MT-FEE-01 查询费用清单

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已选就诊；登录 TECH |
| **主路径步骤** | 校验 scope → 装载就诊下费用 → 按 BR-MT-FEE-002 过滤 → enrich 确费人/计费人/医技执行人展示名与执行时间（BR-MT-FEE-006）→ 汇总 → 返回（住院含计费人/划价时间/医技执行人/执行时间；门诊可不展示） |
| **失败分支** | EX-MT-FEE-101 |

### IF-MT-FEE-02 打印费用清单

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已有查询结果或勾选行 |
| **主路径步骤** | 组装本科相关 PrintData → 调用打印运行时绑定 → 返回任务结果 |
| **失败分支** | EX-MT-FEE-201 |

### IF-MT-FEE-03 一键确费（仅住院）

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已选**住院**就诊；登录 TECH |
| **主路径步骤** | 校验 TECH → **断言 INPATIENT** → 装载本科相关行 → 筛未确费 → `stampMedicalTechFeeConfirmation` → 返回新确费行数 |
| **失败分支** | EX-MT-FEE-301（含门诊调用「门诊无确费业务」） |
| **出院关系** | 住院出院 **BR-IP-ATD-011⑤** 要求该就诊下**各 TECH 科相关**行均已确费；本 IF 只打登录科 |

---

## 6. 事件语义与消费方

确费无独立领域事件；**住院**出院门禁读行字段。费用变更后由用户刷新列表。

---

## 7. 非功能性需求

批量过滤禁止 N+1；敏感字段按工作站脱敏惯例。

---

## 8. 测试要点

正向：仅本科行；**住院**一键后未确费变已确费；再点幂等。异常：他科费用不出现；**门诊调 IF-03 拒绝**。规则：门诊/住院切换类别正确；出院对未确费医技相关行拦 EX-IP-ATD-309。
