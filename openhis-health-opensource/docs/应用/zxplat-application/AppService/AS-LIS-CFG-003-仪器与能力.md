# 检验域 · 仪器与能力 · 应用服务设计（AS）

> **文档职责**：说明仪器主数据、通道映射、检验能力、双向通讯配置、试剂管理的**接口契约（IF）**与业务规则（BR）。  
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径。  
> **页面边界**：仪器列表 | 通道/能力配置 | 双向通讯(子Tab,P2) | 试剂管理(子Tab,P2)  
> **编码**：AS-LIS-CFG-003 · **版本**：v2.0 · **日期**：2026-06-22

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 仪器 CRUD；通道映射；检验能力（项目+试管+合管方案）；双向通讯配置(P2)；试剂管理(P2) |
| **涉及域** | LisDevice、LisDeviceChannel、LisDeviceCapability |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| **LIS 管理员** | 维护仪器 → 配置通道 → 维护能力 → 配置 BIDI(P2) → 试剂批次(P2) |

### 1.3 术语与口径约定

| 术语 | 口径 |
|------|------|
| **BIDI** | C++ 程序负责仪器实际通讯（串口/TCP/HL7）；LIS 侧仅配置连接信息+worklist下发+结果接收 |

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **P0** | 仪器 CRUD、通道映射、能力配置 |
| **P2** | BIDI 通讯配置、REAGENT 试剂批号 |

### 1.5 领域清单

| 聚合 | 职责 | DM 路径 |
|------|------|---------|
| **LisDevice** | 仪器主数据 | `docs/领域/缺口/文档无代码/DM-LIS-004-Device-检验仪器.md |

### 1.6 业务规则（BR-*）

| 编号 | 规则 | 触发 IF |
|------|------|---------|
| **BR-DEV-01** | 通道号在同一 deviceId 下唯一 | DEV-CH |
| **BR-DEV-02** | capability 每行 (deviceId, activityId, tubeSchemeId) 唯一 | DEV-CAP |
| **BR-DEV-03** | 禁用前校验：无进行中 LisWorkItem | DEV-TOGGLE |
| **BR-DEV-04** | 每个 capability 的 activityId 须有对应 channel | DEV-CAP |
