## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | 按住院站别加载模板树；载入模板新建会话；患者维度历史文书列表与打开；创建/保存文书；存为个人模板；**病程记录**列表导航（上一张/下一张）及切患者时静默打开最新病程；工具栏主动从诊断/医嘱带入光标文本；变更仅提醒 |
| **在外** | 患者队列；诊断/医嘱写操作（带入仅读列表）；入院结构化诊断自动回写（既有 bridge 能力，**非**本 Tab 主动带入）；打印预览/本就诊全部病程合并打印（本期病历 Tab 未暴露入口则不纳入）；病案首页；护士站病历调阅 |
| **涉及域** | EMR 文书与模板；住院 Encounter；就诊诊断（读）；住院医嘱请求（读） |
| **编排权威** | 以本文 **§2、§4** 为准；带入文案细则以 EMR **06** 为补充真源 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **住院医生** | 选在院患者 → 病历 Tab → 选模板或打开/切换病程 → 编辑 →（可选）诊断/医嘱带入 → 保存 |
| **系统** | 无就诊标识拒绝新建/打开；首次病程模板同就诊唯一；草稿他人只读；锁定/归档不可改；带入无新增后端写 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **当前就诊** | 左侧选中的住院就诊（医生站可见范围内） |
| **病程记录** | 文书类型为病程的文书；导航列表按创建时间升序 |
| **首次病程** | 指定首次病程模板编码创建的文书；**同一就诊仅允许一份** |
| **静默打开最新病程** | 切换患者进入病历时，若存在病程则打开最新一份，侧栏可保持模板 Tab |
| **主动带入 / 变更提醒** | 同 **AS-OP-DOR-011** / EMR 06：插入光标；提醒不自动写 |
| **复用读能力** | 诊断列表 = **AS-IP-DOR-002** 就诊诊断读 IF；医嘱列表 = **AS-IP-DOR-003** 医嘱列表读 IF（含草稿、申请单、长临等列表已有行） |

### 1.4 本期范围与非目标

| 类别 | 内容 |
| --- | --- |
| **本期（契约）** | IF-IP-MR-01～10：模板树、载入模板、历史文书、打开、创建、保存、存为个人模板、病程导航列表、从诊断带入、从医嘱带入 |
| **本期（UI）** | 与门诊共用病历表单组件；住院额外暴露病程上一张/下一张；带入与提醒按产品接线 |
| **非目标（同站其他模块）** | 患者列表、诊断写、医嘱写、中医、报告 |
| **非目标（本期未暴露）** | 打印预览、合并 PDF、版本回滚 UI、检查检验引用 |
| **非目标（解耦）** | 住院诊断保存后回写入院记录结构化数据元——既有能力，**不**纳入本 AS 主动带入 IF |
| **非目标（老系统舍弃）** | 国基侧完成/归档/质控等级按钮——新 UI 未设计，本期不纳入 |

| 规则 ID | 描述 | 绑定 IF |

| **BR-IP-MR-007** | 存为个人模板：个人归属、适用住院就诊场景 | IF-IP-MR-07 |

| **BR-IP-MR-010** | 从医嘱带入：含草稿与申请单；默认勾选草稿+已签发未停；插入光标 | IF-IP-MR-10 |
| **BR-IP-MR-011** | 诊断/医嘱变更仅提醒，禁止自动改正文 | IF-IP-MR-09 / IF-IP-MR-10 |
| **BR-IP-MR-012** | 带入文案遵循 EMR 06；住院诊断可附诊断类型展示 | IF-IP-MR-09 / IF-IP-MR-10 |
| **BR-IP-MR-013** | 只读或无光标时禁用带入 | IF-IP-MR-09 / IF-IP-MR-10 |

## 3. 缺口跟踪（Gap）

**无待跟踪缺口。**

## 4. 接口编排说明书（业务步骤）

### IF-IP-MR-01 加载住院站别模板树

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 医生已登录；进入病历 Tab |
| **主路径步骤** | 按住院站别与可见范围加载启用模板 → 组装树 |
| **关键分支** | 树为空时提示无模板 |
| **失败分支** | EX-IP-MR-101 |
| **查询侧说明** | 纯读；存模板后可刷新 |

### IF-IP-MR-02 载入模板正文（新建会话）

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已选住院就诊（**BR-IP-MR-001**） |
| **主路径步骤** | 读模板正文与类型 → 载入编辑器新建会话（不落库） |
| **关键分支** | 未保存确认放弃 |
| **失败分支** | 无就诊 → EX-IP-MR-102；模板无效 → EX-IP-MR-103 |
| **查询侧说明** | 落库在 IF-IP-MR-05 |

### IF-IP-MR-03 查询历史文书列表

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已选患者 |
| **主路径步骤** | 按患者及就诊查询文书摘要 → 历史区展示（可含非病程类型）；医生站传 `includeLinkedEncounters=true` 时，服务端按当前就诊 ∪ `amb_encounter_id` 关联对端（住院→源门诊；门诊→未取消住院线）并集返回 |
| **关键分支** | 空列表；无关联对端时行为同单就诊过滤 |
| **失败分支** | EX-IP-MR-101 |
| **查询侧说明** | 创建/保存后刷新；**对端文书只读**由前端按 `row.encounterId !== currentEncounterId` 门禁；病程导航（IF-IP-MR-08）仍仅扫当前住院就诊，不混关联门诊文书 |

### IF-IP-MR-04 打开文书内容

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 点选历史、导航或静默打开 |
| **主路径步骤** | 读正文、状态、只读、元数据 → 载入编辑器 |
| **关键分支** | 非创建者打开非病程/非会诊文书 → 只读；病程与会诊可多人编辑 |
| **失败分支** | EX-IP-MR-104 |
| **查询侧说明** | 元数据芯片与主动带入解耦 |

### IF-IP-MR-05 创建文书（首次保存）

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 新建会话保存；已有就诊 |
| **主路径步骤** | 创建草稿；若模板为首次病程则校验同就诊唯一（**BR-IP-MR-004**） |
| **关键分支** | 无 |
| **失败分支** | 首次病程已存在 → EX-IP-MR-110；未选患者 → EX-IP-MR-102 |
| **查询侧说明** | 成功后刷新历史与病程导航列表 |

### IF-IP-MR-06 保存文书内容

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已有文书标识；非只读 |
| **主路径步骤** | 校验可编辑 → 写正文 → 清脏 |
| **关键分支** | 自动保存失败仅提示 |
| **失败分支** | 只读 EX-IP-MR-106；锁定/归档 EX-IP-MR-107 |
| **查询侧说明** | 无 |

### IF-IP-MR-07 存为个人模板

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 有正文与文书类型；确认名称 |
| **主路径步骤** | 创建个人、住院适用模板 → 刷新模板树 |
| **关键分支** | 用户取消 |
| **失败分支** | EX-IP-MR-108 / EX-IP-MR-105 |
| **查询侧说明** | 触发 IF-IP-MR-01 |

### IF-IP-MR-08 病程导航列表

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 住院站别；已有就诊；进入病历或保存病程后 |
| **主路径步骤** | 查询当前就诊下病程类型文书，按创建时间升序 → 供上一张/下一张及静默打开最新 |
| **关键分支** | 无病程则导航禁用；切患者时可静默打开最新病程 |
| **失败分支** | EX-IP-MR-101 |
| **查询侧说明** | 打开具体文书仍走 IF-IP-MR-04 |

### IF-IP-MR-09 从诊断带入

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 可编辑文书；有就诊；可插入 |
| **主路径步骤** | 弹窗 → 复用住院诊断列表 → 默认全选 → 按 EMR 06 文案（可含住院诊断类型）插入光标 → 标脏 |
| **关键分支** | 空列表提示；不触碰入院结构化数据元 |
| **失败分支** | EX-IP-MR-109 / EX-IP-MR-101 |
| **查询侧说明** | 诊断保存成功仅提醒（**BR-IP-MR-011**） |

### IF-IP-MR-10 从医嘱带入

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 同 IF-IP-MR-09 |
| **主路径步骤** | 弹窗 → 复用住院医嘱列表（**含草稿、申请单**）→ 默认勾选草稿+已签发未停 → 插入光标 |
| **关键分支** | 已停默不勾选；空列表提示 |
| **失败分支** | 同 IF-IP-MR-09 |
| **查询侧说明** | 医嘱变更仅提醒 |

## 7. 非功能性需求

| 类别 | 约束 |
| --- | --- |
| **性能** | 同门诊病历经验目标；病程导航列表宜一次拉取当前就诊病程集 |
| **幂等** | 保存最后写入为准；带入可重复 |
| **并发** | 草稿创建者可写；首次病程唯一以后端校验为准 |
| **一致性** | 带入不改诊断/医嘱；与入院结构化回写互不覆盖正文主动带入结果 |
| **审计** | 创建/保存可追溯操作者 |

## 8. 测试要点（业务视角）

| 类别 | 要点 |
| --- | --- |
| **正向** | 模板新建保存；病程多份上一张/下一张；切患者静默打开最新病程；诊断/医嘱带入 |
| **异常** | 重复首次病程；只读保存；未选患者 |
| **规则** | 医嘱含草稿与申请单；变更仅黄条；带入不改 `admissionDiagnosisStructured` |
| **并发** | 两医生同开首次病程模板创建冲突 |
