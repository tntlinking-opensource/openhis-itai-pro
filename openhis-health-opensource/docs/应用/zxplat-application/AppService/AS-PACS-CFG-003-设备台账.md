# 检查域 · 设备台账 · 应用服务设计（AS）

> **编码**：AS-PACS-CFG-003 · **版本**：v1.0 · **日期**：2026-09-22  
> **菜单**：设备与模态 · **类名**：`PacsDeviceConfigAppService` · **路由**：`POST /api/app/pacsDeviceConfig/{method}`  
> **领域**：[DM-PACS-005](./DM-PACS-005-PacsDevice-设备台账.md)

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 设备台账列表/保存/启停/软删 |
| **在外** | 模态 capability（CFG-001）；报告模板（CFG-002）；打印版式；EAV 设备参数 |
| **涉及域** | PacsDevice |

### 1.2 角色

| 角色 | 动作 |
|------|------|
| **影像科管理员** | 维护设备主档（名称、模态、AE Title、启停） |

### 1.3 术语

| 术语 | 口径 |
|------|------|
| **设备台账** | `pacs_device` 主档，≠ 遗留 `GGZ_PARAMETER_EQUIPMENT` 键值参数 |
| **AE Title** | DICOM 应用实体名，供设备侧识别 |

### 1.4 本期与非目标

| 类别 | 内容 |
|------|------|
| **本期（序号 44）** | 平铺 CRUD + 模态/启停/关键字过滤 |
| **非目标** | 遗留报告主副标题/打印尺寸混入设备；EAV 参数表；机构树多院区单独字段（用租户隔离） |

### 1.5 领域清单

| 聚合 | DM |
|------|-----|
| PacsDevice | [DM-PACS-005](./DM-PACS-005-PacsDevice-设备台账.md) |

### 1.6 业务规则

| 编号 | 规则 | IF |
|------|------|-----|
| **BR-CFG3-01** | 编码、名称、模态必填 | CFG-03b |
| **BR-CFG3-02** | 同租户 `deviceCode` 未软删唯一 | CFG-03b |
| **BR-CFG3-03** | 停用/软删后默认列表不展示（`enabledOnly`） | CFG-03a/c/d |

## 2. 页面与接口总览

| IF | 用户动作 | 语义 | 读写 | 关键规则 |
|----|----------|------|:--:|----------|
| **IF-PACS-CFG-03a** | 设备列表 | 分页查询 | 读 | BR-CFG3-03 |
| **IF-PACS-CFG-03b** | 保存设备 | 新增/更新 | 写 | BR-CFG3-01/02 |
| **IF-PACS-CFG-03c** | 停用 | enabled=false | 写 | BR-CFG3-03 |
| **IF-PACS-CFG-03d** | 删除 | 软删 | 写 | BR-CFG3-03 |

## 5. 业务异常

| 码 | 场景 |
|----|------|
| `PACS_DEVICE_NOT_FOUND` | 设备不存在或已删 |
| `PACS_DEVICE_INVALID_ARGUMENT` | 编码/名称/模态空等 |
| `PACS_DEVICE_CODE_DUPLICATE` | 同租户编码冲突 |
