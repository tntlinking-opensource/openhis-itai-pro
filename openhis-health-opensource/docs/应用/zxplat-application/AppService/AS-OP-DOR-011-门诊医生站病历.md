## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | 按站别加载可用病历模板树；载入模板正文进入新建会话；按患者/就诊查询历史文书并打开；首次保存时创建文书、其后保存内容；将当前内容存为个人模板；工具栏**主动**从当前就诊诊断/医嘱勾选后插入光标纯文本；诊断或医嘱变更后仅**提醒**可重新带入（不自动写正文） |
| **在外** | 就诊接诊/完诊；诊断维护与医嘱开立写操作（仅**读**其列表用于带入）；入院结构化诊断回写；元数据芯片自动刷新扩展；检查检验引用；打印预览/合并 PDF（本期病历 Tab 未暴露入口）；模板管理后台（全院/科室模板维护）；病案首页 |
| **涉及域** | EMR 文书与模板；就诊上下文（Encounter，门控已接诊）；就诊诊断（读）；门诊医嘱请求（读） |
| **编排权威** | 以本文 **§2、§4** 为准；带入文案细则以 EMR **06** 为补充真源 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **门诊医生** | 接诊后进入病历 Tab → 选模板新建或打开历史文书 → 编辑 →（可选）从诊断/医嘱带入 → 保存；可将当前内容存为个人模板 |
| **系统** | 无就诊标识时拒绝打开/新建；只读文书禁止保存与带入；锁定/归档文书不可改；草稿他人只读；带入不新增后端写接口 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **当前就诊** | 医生站侧栏选中且已接诊的门诊就诊；须具备有效 `patientId` 与 `encounterId` |
| **新建会话** | 已选模板并载入正文，但尚未调用创建文书；首次保存时才落库 |
| **文书状态** | 草稿 / 已提交 / 已锁定 / 已归档；锁定与归档不可修改内容 |
| **只读** | 非创建者打开草稿，或文书已锁定/归档等导致不可编辑；只读时禁用保存与带入 |
| **主动带入** | 医生勾选诊断或医嘱后，将格式化纯文本插入**当前光标**；**禁止**自动同步正文 |
| **变更提醒** | 同页会话内诊断保存或医嘱暂存/签发等成功后的黄条提示；关闭后同变更周期不再弹出；不落库 |
| **复用读能力** | 带入弹窗诊断列表 = **AS-OP-DOR-002 · IF-DOR-06**；医嘱列表 = **AS-OP-DOR-003 · IF-DOR-10**（含草稿与申请单行） |

### 1.4 本期范围与非目标

| 类别 | 内容 |
| --- | --- |
| **本期（契约）** | IF-OP-MR-01～09：模板树、载入模板、文书列表、打开内容、创建、保存、存为个人模板、从诊断带入、从医嘱带入 |
| **本期（UI）** | 病历 Tab 已具备模板/历史/保存等；「从诊断/医嘱带入」与提醒条为产品已定入口，按本文接线 |
| **非目标（同站其他模块）** | 就诊管理、诊断录入写路径、医嘱开立写路径、中医专页、报告查询 |
| **非目标（本期病历 Tab 未暴露）** | 打印预览、导出 PDF、多文书合并打印、版本回滚 UI、检查检验引用 |

| 规则 ID | 描述 | 绑定 IF |

| **BR-OP-MR-002** | 模板树仅返回当前站别（门诊）可见且启用的模板 | IF-OP-MR-01 |
| **BR-OP-MR-003** | 创建文书默认草稿态；可选模板初始化正文与标题 | IF-OP-MR-05 |
| **BR-OP-MR-004** | 已锁定或已归档文书禁止保存内容 | IF-OP-MR-06 |
| **BR-OP-MR-005** | 除病程记录（`PROGRESS_NOTE`）与会诊相关文书外，仅创建者可修改；他人打开为只读。病程与会诊（类型码含 CONSULT，或源模板编码含 CONSULT / 名称含「会诊」，或标题含「会诊」）允许多人编辑。锁定/归档仍不可改 | IF-OP-MR-04 / IF-OP-MR-06 |
| **BR-OP-MR-006** | 存为个人模板：归属当前登录医务人员、范围个人、适用门诊就诊场景 | IF-OP-MR-07 |

| **BR-OP-MR-009** | 诊断或医嘱变更后仅提醒可重新带入，**禁止**自动插入或覆盖正文 | IF-OP-MR-08 / IF-OP-MR-09（提醒语义） |
| **BR-OP-MR-010** | 带入文案格式遵循 EMR 文档 06 之诊断/医嘱文案规则 | IF-OP-MR-08 / IF-OP-MR-09 |
| **BR-OP-MR-011** | 只读或无有效编辑光标时禁用带入 | IF-OP-MR-08 / IF-OP-MR-09 |

## 4. 接口编排说明书（业务步骤）

### IF-OP-MR-01 加载门诊站别模板树

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 医生已登录；进入病历 Tab 或请求刷新模板 |
| **主路径步骤** | 按门诊站别与可见范围（个人/科室/全院）加载启用模板 → 组装树供左侧展示 |
| **关键分支** | 无可用模板时树为空，提示选模板不可用 |
| **失败分支** | 加载失败 → EX-OP-MR-101 |
| **查询侧说明** | 纯读；存为个人模板成功后可再触发刷新 |

### IF-OP-MR-02 载入模板正文（新建会话）

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已接诊（**BR-OP-MR-001**）；用户点选模板 |
| **主路径步骤** | 校验就诊上下文 → 读取模板正文与文书类型 → 载入编辑器新建会话（不调用创建）→ 提示编辑后保存 |
| **关键分支** | 有未保存修改时先确认放弃 |
| **失败分支** | 未接诊 → EX-OP-MR-102；模板无效 → EX-OP-MR-103 |
| **查询侧说明** | 仅读模板；落库发生在 IF-OP-MR-05 |

### IF-OP-MR-03 查询历史文书列表

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已选患者；宜已有就诊标识 |
| **主路径步骤** | 按患者及可选就诊查询文书摘要列表 → 挂到模板树历史区；医生站传 `includeLinkedEncounters=true` 时，服务端按当前就诊 ∪ `amb_encounter_id` 关联对端（门诊→未取消住院线；住院→源门诊）并集返回 |
| **关键分支** | 无文书时历史为空；无关联对端时行为同单就诊过滤 |
| **失败分支** | 查询失败 → EX-OP-MR-101 |
| **查询侧说明** | 纯展示；创建/保存成功后刷新；**对端文书只读**由前端按 `row.encounterId !== currentEncounterId` 门禁（写仍仅落当前就诊） |

### IF-OP-MR-04 打开文书内容

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 用户点选历史文书或切换已打开子 Tab |
| **主路径步骤** | 按文书标识读取正文、状态、只读标记、元数据值 → 载入编辑器 |
| **关键分支** | 非创建者打开非病程/非会诊文书 → 只读（**BR-OP-MR-005**）；病程与会诊可多人编辑 |
| **失败分支** | 文书不存在 → EX-OP-MR-104 |
| **查询侧说明** | 打开时既有元数据芯片填充与主动带入无关，不扩展为本期契约 |

### IF-OP-MR-05 创建文书（首次保存）

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 新建会话已选模板；用户保存；已接诊 |
| **主路径步骤** | 校验就诊与模板/文书类型 → 创建草稿文书（模板初始化正文与标题）→ 返回文书标识供后续保存 |
| **关键分支** | 无 |
| **失败分支** | 未接诊 → EX-OP-MR-102；创建校验失败 → EX-OP-MR-105 |
| **查询侧说明** | 成功后刷新历史列表（IF-OP-MR-03） |

### IF-OP-MR-06 保存文书内容

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已有文书标识；用户手动保存或自动保存；非只读 |
| **主路径步骤** | 校验可编辑（非锁定/归档、创建者可改）→ 写入正文（可选版本）→ 清除脏标记 |
| **关键分支** | 自动保存失败仅提示，不阻断继续编辑 |
| **失败分支** | 只读 → EX-OP-MR-106；锁定/归档 → EX-OP-MR-107 |
| **查询侧说明** | 无强制读侧刷新 |

### IF-OP-MR-07 存为个人模板

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 编辑器有正文且文书类型已知；用户确认模板名称 |
| **主路径步骤** | 校验登录医务人员 → 以当前正文创建个人、门诊适用模板 → 刷新模板树 |
| **关键分支** | 用户取消命名则中止 |
| **失败分支** | 无医务人员上下文 → EX-OP-MR-108；保存失败 → EX-OP-MR-105 |
| **查询侧说明** | 成功后触发 IF-OP-MR-01 刷新 |

### IF-OP-MR-08 从诊断带入

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 已接诊；文书可编辑；编辑器可插入 |
| **主路径步骤** | 打开弹窗 → **复用 IF-DOR-06** 加载当前就诊诊断 → 默认全选 → 用户确认 → 按 **BR-OP-MR-010** 生成文本 → 插入光标 → 文书标脏 |
| **关键分支** | 诊断为空则提示去诊断页录入，不插入；用户取消勾选后可插入子集 |
| **失败分支** | 只读/无光标 → EX-OP-MR-109；列表失败 → EX-OP-MR-101 |
| **查询侧说明** | 不订阅诊断事件自动写正文；诊断保存成功仅触发提醒（**BR-OP-MR-009**） |

### IF-OP-MR-09 从医嘱带入

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 同 IF-OP-MR-08 |
| **主路径步骤** | 打开弹窗 → **复用 IF-DOR-10** 加载医嘱列表（**含草稿、申请单**）→ 默认勾选草稿与已签发未停 → 确认 → 按文案规则插入光标 → 标脏 |
| **关键分支** | 空列表提示；已停行默不勾选可选手动纳入 |
| **失败分支** | 同 IF-OP-MR-08 |
| **查询侧说明** | 医嘱变更成功仅提醒，不自动插入（**BR-OP-MR-009**） |

## 5. 业务异常与用户提示

| 语义代码 | 场景 | 用户提示方向 | 可重试 |
| --- | --- | --- | --- |
| EX-OP-MR-101 | 模板/文书/诊断/医嘱列表加载失败 | 加载失败，请稍后重试 | 是 |

| EX-OP-MR-104 | 文书不存在 | 文书不存在或已删除 | 否 |

| EX-OP-MR-107 | 锁定或归档后保存 | 文书已锁定或归档，不可修改 | 否 |
| EX-OP-MR-108 | 存为个人模板时无医务人员 | 当前账号未关联医务人员 | 否 |
| EX-OP-MR-109 | 带入时无光标或不可编辑 | 请先将光标置于可编辑位置 | 是 |

## 6. 事件语义与消费方

| 事件语义 | 触发相位 | 消费方 |
| --- | --- | --- |
| 文书已创建 / 已保存（若 EMR 域发布） | IF-OP-MR-05 / 06 | 历史列表刷新；质控/归档等后续能力 |
| 就诊诊断已保存（既有） | AS-OP-DOR-002 | **病历 Tab 仅提醒可重新带入**，不自动改正文 |

## 7. 非功能性需求

| 类别 | 约束 |
| --- | --- |
| **性能（经验目标）** | 模板树/文书列表/打开 ≤1500ms；保存 ≤2000ms；带入弹窗依赖诊断/医嘱列表目标同对应 AS |
| **幂等** | 重复保存以最后一次正文为准；带入为本地插入，可多次执行 |
| **并发** | 两人同改一文：创建者可写，他人只读；以后端校验为准 |
| **一致性** | 带入不修改诊断/医嘱事实；保存后方持久化带入文本 |
| **审计** | 文书创建/保存操作者可追溯 |
