## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-RPT-IMD-01～04 |
| **在外** | 住院发药/退药/汇总发药写路径；科室领用制单；门诊发药报表；用药明细；耗材报表 |
| **涉及域** | **MedicationDispense**；**MedicationDefinition**；**ChargeItem**；**SupplyRequest** / **SupplyDelivery**；**Encounter** / 在院上下文；**Location**；**Organization** |
| **编排权威** | 本文；患者侧发退事实 + 科室侧 **DEPT_ISSUE/RETURN** 药品行 + 住院相关科室药房 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **住院药房 / 病区 / 财务** | 汇总（药房/品规/类型/科室）→ 明细（发退+领用，含住院号床号）→ 导出 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **患者发/退** | `INPATIENT/TEMPORARY`+`COMPLETED`；`REFUND+REFUNDED`+**IMP** |
| **科室领用/退领** | 药品行 `DEPT_ISSUE` / `DEPT_ISSUE_RETURN`；住院相关科室药房 |
| **来源** | `PATIENT_DISPENSE` / `DEPT_ISSUE` |
| **时间窗** | 患者侧 `dispense_time`；领用侧业务时间（**非** planned_dispense_time）；前端 `datetimerange`；默认当日 `00:00:00～23:59:59` |
| **汇总** | **数量**（整数；品规维拼接包装单位）、进价单价/售价单价（批号/账单同源）、进价合计/售价合计；药房 / 品规 / 药品类型 / 科室；**品规维另给药品编码、最小数量（拼接最小单位）**；**不展示行数** |
| **费用性质筛** | `fin_contract.bus_no`；就诊下**任一**有效账户命中即入集；仅收窄**患者发药** encounter scope |
| **明细** | 两路并集；患者侧 **费用性质** 优先发放收费行 `account_id→contract_no`，账单缺失回落就诊优先合同；**医疗类别**仍取主诊断 med_type；科室领用无 encounter 留空；金额列 **进价单价/进价总价、售价单价/售价总价**（无实收）；住院号/床号（患者侧）；领用科室/单号（领用侧）；**账批质检**：明细分页 `chargeLotNumber`/`lotMismatch`（**不改正额**；汇总不做） |
| **价格** | 患者侧：有账单跟 ChargeItem；账单缺失 → 批号进价 + **批号售价**（正/退同行，白名单，同 DD v1.8）；领用 Supply 进价、售价空；进价按操作单位分支 |
| **与用药明细** | 不含待发；不按计划发药日强制选人 |

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |

| **BR-RPT-IMD-001** | 时间窗必填且 `dateFrom≤dateTo`；前端 `datetimerange`；Request 仍为 `String dateFrom/dateTo`（`yyyy-MM-dd HH:mm:ss`，兼容仅日期）；仅日期时起补 `00:00:00`、止补 `23:59:59`；默认当日 `00:00:00～23:59:59` | 01～04 |
| **BR-RPT-IMD-002** | 患者侧 IMP 已发/已退药品 | 02～04 |

| **BR-RPT-IMD-005** | 汇总列=数量+进售单价（展示）+进售合计；药房/品规/类型/科室；**品规维另给药品编码、最小数量**及 **包装/最小单位名**；数量整数展示；**不展示行数**；汇总进价一律 3 位；售价一律 2 位 | 02、04 |
| **BR-RPT-IMD-006** | 患者侧价：账单优先；退药无自身账单时补原正向售价再取负（汇总与明细同口径）；账单缺失回落批号售价（正/退，见 DD-报表进售价） | 02～04 |
| **BR-RPT-IMD-007** | 来源筛全部/患者/领用 | 02～04 |
| **BR-RPT-IMD-008** | 导出仅当前 Tab | 04 |
| **BR-RPT-IMD-009** | **禁止**用药明细口径；**禁止**耗材行 | 全文 |
| **BR-RPT-IMD-010** | **账批质检**（仅 IF-03 明细分页）：同 AS-RPT-003 BR-RPT-OMD-011；实现 `MedicationDispenseReportPricingEnricher#applyChargeDispenseLotMismatch` | 03 |
