# 住院医保费用明细 · 应用服务设计（AS）

> **文档职责**：报表中心「住院医保费用明细」只读契约。与 **AS-RPT-012** 同构，场景改为住院（`encounter_class=IMP`）；科室 = **入院科室**；业务号 = **住院号**。
>
> **页面边界**：筛选 → 查询明细分页 → 页脚合计 → 导出。**纯读**；与交账无关；冲销不展示。
>
> **编码**：AS-RPT-013 · **版本**：v1.1 · **日期**：2026-09-09  
> **对称**：`AS-RPT-012-门诊医保费用明细.md`

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-RPT-IIF-01～03：初始化、明细分页（含合计）、导出 |
| **在外** | 门诊对称页（**AS-RPT-012**）；日结交账；CHS 日对账；写路径 |
| **涉及域** | 同 AS-RPT-012；Encounter 场景为住院 |
| **编排权威** | 对齐 AS-RPT-012；本页仅住院 |
| **数据锚点** | `CONFIRMED` 净行；`IMP` |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **财务 / 医保办 / 管理** | 按结算时间与费用类别查住院医保结算明细 → 合计 → 导出 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **有效净结算** | 同 AS-RPT-012 |
| **费用类别 / 职工居民 / 编号模糊 / 合计 / 时间窗** | 同 AS-RPT-012（姓名落 `psn_name`） |
| **科室** | 住院 = **入院科室**（`Encounter.organization_id`）；转科前结清场景不另建模 |
| **明细列** | 姓名、入院科室、住院号、就医登记号、结算 ID、结算时间、医疗费总额、基金、个账、现金（**无处方号**） |

### 1.4 本期范围与非目标

| 类别 | 内容 |
| --- | --- |
| **本期** | IF-RPT-IIF-01～03；仅住院 IMP |
| **非目标** | 同 AS-RPT-012；另：不按转科过程拆行 |

### 1.5 领域清单（聚合 + 职责 + DM 路径）

同 **AS-RPT-012 §1.5**，Encounter 收窄为住院。

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
| --- | --- | --- |
| **BR-RPT-IIF-001** | 同 BR-RPT-OIF-001（时间窗） | 01～03 |
| **BR-RPT-IIF-002** | 同 BR-RPT-OIF-002（仅 CONFIRMED） | 02、03 |
| **BR-RPT-IIF-003** | 同 BR-RPT-OIF-003（省/市多选、工伤独立） | 01～03 |
| **BR-RPT-IIF-004** | 同 BR-RPT-OIF-004（职工/居民） | 02、03 |
| **BR-RPT-IIF-005** | 科室 = 入院科室；编号模糊包含匹配 | 02、03 |
| **BR-RPT-IIF-006** | 页脚四列全量合计 | 02 |
| **BR-RPT-IIF-007** | 仅住院 IMP | 02、03 |
| **BR-RPT-IIF-008** | 导出行上限 | 03 |
