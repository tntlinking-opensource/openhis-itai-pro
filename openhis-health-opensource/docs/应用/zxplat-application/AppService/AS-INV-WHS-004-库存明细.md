# 库存明细 · 应用服务设计（AS）

> **文档职责**：说明「库存明细」场景的**接口契约（IF）**、业务语义、涉及聚合与 QueryService、规则（BR）、编排意图；作为上游契约供详细设计与实现对齐。
>
> **本文必须写**：IF 编号；用户动作与读写属性；关键校验与状态变化；Gap；异常口径；事件语义；非功能约束；业务向测试要点。
>
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径；Mapper；伪代码；写库顺序；QueryService 字段组装规则。
>
> **页面边界**：药库/物资业务线 — **库存明细工作站**：**现库存**与**历史备份**两套视图（备份单号下拉、筛选、分页、关键字、底部进价/售价汇总、Excel 导出）；**现库存**侧另含**页面初始化**（筛选项）、**备份单号列表**与对选中行的**停供 / 恢复供应**。一行对应 **`wkf_inventory_item`** 一条 **InventoryItem**（现库）或**快照静表**之冻结行（备份）。现库联结 **药品/耗材定义**、**Location（库房）**、**Supplier**、**ChargeItemDefinition** 及**条件定价行**；**备份读侧只读静表已落库字段，禁止再联定价重算**。
>
> **单位与金额锚点（硬约束，现库）**：**`quantity`** = **拆零最小单位**账面数量；**`LOT_NUMBER_COST.amount`**、**`LOT_NUMBER_PRICE.amount`** 均为**按包装单位**计价之整包金额（**非**拆零单价）；**拆零换算比**仅指 **拆零单位 ↔ 包装单位**（`package_unit_ratio` / **`BAND_PACKAGE`**），**库存单位、采购单位不参与**行总额与数量展示换算；进价/售价行总额**共用同一拆零换算比**按 **§1.3·行总额** 公式计算（**满包×包装价 + 零头（包装价×余量/ratio 单步）**，**BR-MON-PKG-001**）。**备份读侧**：金额与展示列以快照写入时之冻结值为准（**BR-INV-DTL-018**）。
>
> **双链与舍入（硬约束，现库）**：**`LOT_NUMBER_COST`** 与 **`LOT_NUMBER_PRICE`** **各自完整计算**；**禁止**先把包装价除成「拆零单价」再乘数量（全量或零头均禁）；**禁止**以「拆零单价×全量 **`quantity`**」作为**主导**金额路径（与收费域小数位及舍入策略对齐，**SDD** / **BR-MON-PKG-001**）。
>
> **与订货/进货/出库分工**：本场景**不**创建或审批 **SupplyRequest**；**不**执行 **SupplyDelivery** 或 **InventoryItem** 数量增减（**停供 / 恢复供应**所致 **`inventory_status_enum`** 变更除外）。
>
> **覆盖声明**：§2 所列 IF 覆盖「库存明细」对外能力全集（初始化、现库分页/汇总/导出、**定时快照落库**、**备份单号列表**、备份分页/汇总/导出、停供、恢复供应）。
>
> **编码**：AS-INV-WHS-004 · **版本**：v0.34 · **日期**：2026-10-06

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | **初始化**筛选项；**现库存**批号级分页、同条件**底部汇总**、**Excel 导出**；**定时库存快照落库**（全量现库明细冻结写入静表）；**备份单号列表**；**备份库存**分页、同条件**底部汇总**、**Excel 导出**（读静表冻结列）；**停供**与**恢复供应**（批量更新 **`inventory_status_enum`** 至 **`PublicationStatus`** 之 **`RETIRED` / `ACTIVE`** 码并写审计）；**现库行「追溯码」查询**（本库仍在库码，**AS-CUS-TRC-001 · IF-TRC-22**） |
| **在外** | 订货、进货、出库、请领、盘点、报损、发药/耗材发放等**数量变更**编排；库房日结/动态盘点等对备份单号的消费（后续 AS）；**货位**（库位/货架）展示与落库 |
| **涉及域** | 读：**InventoryItem**、**MedicationDefinition** / **DeviceDefinition**、**Location（库房）**、**Supplier**、**ChargeItemDefinition** 及条件定价行、字典、**快照静表**；写：**InventoryItem**（仅供应状态）、**快照静表**（仅定时快照批量插入）；租户上下文 |
| **跨域** | 现库读路径联接收费域定价；备份写路径在落库前复用现库列表同等装配；备份读路径**不**再触达定价域 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **库管 / 药库人员** | 进入页 → 取筛选项与**备份单号列表** → 现库/备份视图切换 → **选备份单号（默认当天）** → 筛选与关键字 → 翻页 → 看底部汇总 → 导出 → 多选停供或恢复 → **现库行查本库仍在库追溯码** |
| **系统（定时任务）** | 按 Cron 触发快照 → 拉取**无筛选之全量现库明细** → 冻结写入静表 |
| **审计 / 财务** | 查询、导出为主，通常无写操作 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **库存行（现库）** | 一行 = **`wkf_inventory_item`** 一条 **InventoryItem**（批号级），**不按品种汇总**；药品与耗材** UNION** |
| **业务行唯一（自然键）** | **四元组** `(location_id, item_table, item_id, lot_number)`，与 **DM-WKF-008 §2.1** 一致 |
| **库存行（备份）** | 一行 = **DOC 域快照静表** **`doc_inventory_item_snapshot`** 在某 **`bus_no`** 批次下之冻结镜像；写入后**不可变** |
| **备份单号 `backupBusNo`** | 接口语义名；静表列 **`bus_no`**（**`ABU`+`yyyyMMdd`+序号**）；同批次各行相同 |
| **备份视图默认** | 用户**未选**备份单号 → 解析为**当前租户当自然日**已成功落库之备份批次（若无则空列表/零汇总，**SDD** 固定提示语义） |
| **快照列集** | **事实落库**：ID/code/数量/倍数/四价/主数据文本（`name` 等）；**字典/枚举只存 code**；**不含** `*_text` 翻译列、**不含货位**；列清单见 **SDD §3.11.2** |
| **定价（现库/快照）** | 对客仅 **四价**：**批号进价**、**批号售价**、**总进价**、**总售价**；单价口径均为**包装单位**；**禁止**重复存「展示单价+单位名」多套字段 |
| **定价装配（现库）** | **LOT_NUMBER_COST** / **LOT_NUMBER_PRICE** 取包装整包 **amount** → **lotCostPrice/lotSalePrice** + **BR-007** 行总额 |
| **定价装配（备份读）** | **禁止**联 **ChargeItemDefinition**；读静表 **`lot_number_cost_amount`/`lot_number_price_amount`/`line_*_total`** |
| **现库对客字段** | **事实**：ID、code、**lotCostPrice/lotSalePrice/lineCostTotal/linePriceTotal**、**packageUnitRatio** 等；**服务端拼装**：`*Label`（字典/枚举翻译）、`packageStockText`/`splitStockText`、**`packageSplitRatioText`（如 `1盒/36片`；同单位×1 为 `1支`；非临床 `1片x100`）**、库房/供应商名（现库读侧） |
| **关键字（现库）** | **OR** 模糊：库存项名称、批号、拼音、五笔；**及** 药品/耗材定义编码、商品名等（经 **MedicationDefinitionQueryService** / **DeviceDefinitionQueryService** 预解析 **`item_id`**，**禁止** inventory Criteria 跨表 JOIN，**B.6.4**） |
| **拆零换算比** | **1 包装 = ratio 拆零**；仅用于行总额、包装/拆零库存展示、导出列「拆零换算比」；**与库存单位、采购单位无关** |
| **行总额（现库）** | **`quantity`** 按 **packageUnitRatio** 拆整包+余量；**满包×包装价 + 零头（包装价×余量/ratio 单步）**；进/售价共用 ratio；**lotCostPrice/lotSalePrice** = 包装整包价；**禁止**包装价→拆零单价再乘（**BR-MON-PKG-001**） |
| **列表列（现库）** | 对齐 **ProductDetailPageDto**（**不含货位**）；价格列用 **lotCostPrice/lotSalePrice + packageUnitName**；**包装拆零比例**列用 **packageSplitRatioText**（规格与项目类别之间）；类别/剂型/状态等用 **code + *Label** |
| **初始化筛选项（IF-01）** | 医保等级、**供应状态**（**`PublicationStatus` 枚举**，仅 **ACTIVE/INACTIVE**）、药/耗分类、库存范围；**管辖药库+药房+科室药房**、**供应商** 多选下拉 |
| **关键字（备份）** | 与现库相同字段集合**但不含批号** |
| **定时快照范围** | **等同** IF-02 **无筛选、无关键字** 之全量结果集；**须分页循环**直至取尽，**禁止**单页上限截断 |
| **定时任务并发** | 依赖 **ZXPlat 定时任务** **`concurrentPolicy=DISALLOW`**（Quartz **`@DisallowConcurrentExecution`**）；**禁止**在库存备份业务代码内自建进程锁/Redis 锁（**BR-021**） |
| **日级幂等** | 同一租户同一自然日**至多一次成功快照**；已存在则跳过（**BR-020**） |
| **零库存 / 效期 / 多选** | **BR-001～003**（备份读侧筛选仍适用；**定时快照不受其限**） |
| **预警（现库）** | **效期预警**：按**批号**，剩余天数 ≤ 系统设置（默认 180）；**库存预警**：按**全院品种**（采购补货，**与库房/批号无关**），合计含 0=断货；目录警戒线优先，未维护回落包装阈值（默认 30）；工作台跳转带 **`warningMode`** |
| **预警可见角色** | 仅 **库管（`ROLE_WAREHOUSE`）** 或 **药师（`ROLE_PHARMACIST`）** 可见工作台卡片与 IF-12 计数 |
| **现库列表排序** | 服务返回前按 **`py_str`** 升序（**`null`** 殿后） |
| **追溯码（现库行）** | 列表**不展示** `trace_no` 逗号串；行操作「追溯码」调 **IF-INV-DTL-13** 查 **TraceNumber** 域本库仍在库码（**BR-INV-DTL-026**）；码可跳转 **AS-CUS-TRC-002** 详情 |
| **底部汇总（现库）** | 同 IF-02 筛选；**≤3 万行**；完成 **BR-005/007** 后累加 **`lineCostTotal`/`linePriceTotal`** |
| **底部汇总（备份）** | 同 IF-04 筛选；**≤3 万行**；累加静表冻结 **`lineCostTotal`/`linePriceTotal`**（**BR-018**） |
| **供应状态** | **`inventory_status_enum`** = **`PublicationStatus#getCode()`** |
