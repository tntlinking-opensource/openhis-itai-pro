# 门诊药房日结 · 应用服务设计（AS）

> **文档职责**：门诊药房日结作业页的 IF / BR / 编排权威。  
> **页面边界**：发药管理 → **门诊药房日结** — 时分秒窗 + **单药房** + **发药人多选** → 大类/品规主区 → 待交明细弹窗 → 提交（`OP_PHARMACY`/`SUBMITTED`）→ 撤回；审批在 **AS-FIN-CS-001**。  
> **边界真源**：DD 交账日结改造 **v1.5.10** + **DM-FIN-003 v3.0** + **DM-MED-002**（`cashier_settlement_id`）。
> **菜单**：**发药管理** → **门诊药房日结**（Flyway **V15**）。
> **编码**：AS-OP-PHA-006 · **版本**：v1.18 · **日期**：2026-10-14

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | 初始化（**岗位管辖药房下拉** + **药师岗发药人下拉**）；按时间窗+单药房查询（大类固定四行净额、品规净额、待交笔数）；弹窗勾选发/退明细；提交挂载 dispense；撤回待审；**管辖药房交账历史**；漏交硬栏 |
| **在外** | 发药/退药作业页；交账审批；住院药房日结；耗材日结；收款日结 |
| **涉及域** | **CashierSettlement**；**MedicationDispense**；药品目录（展示）；**ChargeItem**（主区售价）；**ChargeItemDefinition**（主区进价批号价；头表 `total_income` = 售价合计） |
| **编排权威** | 本文 §2、§4；领域 **BR-CS-*** |
| **后置** | 头 `SUBMITTED`；勾选 dispense 已挂载 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **药房人员** | 选窗+药房+发药人 → 查询 → **确认交账 → 弹窗勾选 → 确认** → 待审撤回 |
| **财务** | 审批见 **AS-FIN-CS-001** |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **范围键** | `location_id` 必填，一次只交一个药房；`org_id` 可空 |
| **管辖药房** | 岗位 `pharmacyLocationList`（`adm_pr_assign.location_id`）经 `CurrentManagedLocationIdsResolver` 收窄；下拉/查询/提交/撤回/历史同源，**不用人手工控权** |
| **时间轴** | `dispense_time`；空 → 报错（**BR-CS-014**） |
| **完成态** | 正向 COMPLETED + 退药 REFUND+REFUNDED；一发一退两行 |
| **主区金额** | 窗内全部完成态（**含已挂载**）净额；大类固定 `2/1/4/3`（**不展示净数量**）；品规按「药品+进售单价」分桶，**有事实即展示**（一发一退净 0 仍出一行）；品规区为**销售排名**，默认按售价总额降序，表头可对净数量/售价总额点选升序或降序 |
| **品规重点药筛选** | 页初始化下发 `keyDrugTypeOptions`（四旗）与 `medicinePropertyOptions`（麻/精），与 **AS-RPT-011** 同构分框；预览品规行回传药典四旗 + 药品性质码；空选=不限，两框同时选 AND（仅影响展示/导出排名，不改大类与待交口径） |
| **进/售读价** | **售价** = 发放锚点账单 `ChargeItem` 行额（有账单不回放）；**退药写路径不生成自身账单（设计）**，读侧补原正向发放售价再取负（`PharmacyDispenseRecordChargePricingAssembler#supplementRefundPricingFromOriginMedicationRequests` / 日结 `supplementMissingRefundSalePricing`，与发药报表同管线，**#4M-RFND**；**同数量总额绝对值与正向一致**）；**原正向仍不可得**（如取消执行逻辑删）时回落批号 `LOT_NUMBER_PRICE`，同批号调价回放与进价同构，按 `unitCode` 分支计行额；**禁止**目录 `SALE`。**进价** = 批号 `LOT_NUMBER_COST`（包装锚）按发药 `unitCode` 分支计行额：包装单位→`包装价×包装数量`；拆零→满包×包装价+零头单步（BR-MON-PKG-001 / `ChargeItemPackageUnitRatioSupport`）；仅调价明细批号与发药批号一致时回放；禁止串批；无调价不查 history；**禁止**回落 `PURCHASE`；**禁止** `lineTotal(包装进价, 数量)` 不判单位；品规按 `medicationId`+进/售单价分桶后先结算 2 位；大类 = 下属品规已结算额之和 |
| **待交笔数** | `pendingCount`：仅 `cashier_settlement_id IS NULL` 的源行条数（一发一退=2） |
| **发药人下拉** | 页初始化 `practitionerOptions`：平台角色 **`ROLE_PHARMACIST`**（`excludePlatformAdmin=false`，保留挂药师岗的平台 admin）；**多选、非必选**（空=不按人）；查询后合并窗内实际发药人；**不**因 `ROLE_ADMIN` 身份单独入池 |
| **头表 total_income** | **售价合计** = 主区各大类售价总额之和（含退药补价取负后轧差；批号/账单同口径；预览=窗内含已交；提交=勾选行；**不**读账单 payment；**不为**售价−进价利润） |
| **人不硬筛漏交** | 漏交扫描**不按人**；人选仅软筛与 `practitioner_ids` 快照 |

## 4. 接口编排说明书（业务步骤）

### IF-OP-PDC-01 初始化

返回默认时间窗、**岗位管辖启用药房下拉**（`CurrentManagedLocationIdsResolver#narrowActiveLocationsByManaged`）、**`practitionerOptions`（ROLE_PHARMACIST）**、**`keyDrugTypeOptions`（与 AS-RPT-011 同构）**。

### IF-OP-PDC-02 查询

校验 `locationId` **且属管辖药房**（**BR-OP-PDC-009**）；按完成态+窗汇总主区（含已交，进/售按 **BR-OP-PDC-003**）；品规行回传重点药四旗（**BR-OP-PDC-010**）；可选 `practitionerIds` 软筛；未挂载 items（弹窗列含状态/品规展示/进售）；漏交扫描（不按人）；`dispense_time` 空报错；返回 `pendingCount`。

### IF-OP-PDC-03 确认交账

打开弹窗（默认全选）→ 重锁候选 → 校验勾选 ⊆ 候选 → **须药师岗** → **管辖药房 Gate** → 漏交硬栏 → 写头 `OP_PHARMACY`/`SUBMITTED` + 快照字段 → 挂载 → 事件。非药师拒绝（EX-OP-PDC-102）。

### IF-OP-PDC-04 撤回

断言交账头药房属管辖 → **药师岗** + SUBMITTED → 清挂载 → WITHDRAWN → 事件。非药师或非待审拒绝（EX-OP-PDC-401）。

### IF-OP-PDC-05 交账历史

按 `submitted_at` 窗分页 `OP_PHARMACY` 交账单；`location_id IN` 当前管辖启用药房；无可视药房时返回空页。

## 8. 测试要点（业务视角）

主区含已交、待交变；分批勾选；一发一退两行；调价后**进价**与发药时刻批号进价一致（仅同批号回放）、**售价**与账单一致；大类=品规加总；漏交左侧**提交时**拦、右侧提醒（不灰确认入口）；发药人多选软筛不挡漏交；撤回后可再交；已审不影响退药；管辖西药房看不到中药房下拉/历史；伪造他库 `locationId` 查询/提交被拒。
