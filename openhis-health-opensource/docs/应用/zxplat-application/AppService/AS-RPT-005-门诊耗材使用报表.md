## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-RPT-OCU-01～04：初始化、汇总、明细分页、导出 |
| **在外** | 发药报表（**AS-RPT-003**）；护士工作量耗材 Tab（**AS-RPT-002**，按护士）；住院耗材报表（**AS-RPT-006**）；发药写路径 |
| **涉及域** | **DeviceDispense** / **DeviceRequest** / **DeviceDefinition**；**ChargeItem**；**SupplyRequest** / **SupplyDelivery**（科室领用等）；**Encounter** / **Patient**；**Organization**；**Location**；**Practitioner**（执行人/发耗材人） |
| **编排权威** | 本文 §2、§4；DD §3.2 |
| **数据锚点** | 患者侧：`DeviceDispense` + `ChargeItem`；科室侧：`Supply*`（`DEPT_ISSUE` 等白名单，SDD 定） |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **药房 / 科室 / 财务** | 查患者用了多少、科室领了多少；看明细含收退/退领；导出 |
| **系统** | 并集装配两路事实；汇总净；明细可区分来源 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **患者使用** | 门诊域 `DeviceDispense` 有效发/退（含护士执行、划价等）+ ChargeItem 售价 / 历史进价 |
| **科室领用** | 已同意 **`DEPT_ISSUE`**（及约定退领对冲）库存出库事实；**无患者时仍计入科室用量**；进价=Supply 落库价，售价=批号 `LOT_NUMBER_PRICE`（禁止目录 SALE） |
| **明细** | 两路并集平铺；含 **费用性质**、**医疗类别**（患者侧；科室领用无 encounter 留空）；**执行人**（发耗材人）；金额列 **进价单价/进价总价、售价单价/售价总价**（**无实收**）；须标 **来源**；**账批质检**：明细分页 `chargeLotNumber`/`lotMismatch`（退耗可经 `basedOnDispenseId` 回挂源账批；**不改正额**；汇总不做） |
| **执行人** | 发耗材人：患者发放取 `DeviceDispense.performer_id`；科室领用取 `SupplyRequest.approver_id`；缺省留空；筛选项仅收窄**患者侧** `performer_id`（领用侧不按审批人筛，对齐发药报表发药人） |
| **记录类型筛** | `ALL` / `DISPENSE` / `REFUND`；仅患者侧生效（已发 / 已退）；领用侧忽略 |
| **耗材类型筛** | `device_category_code` 多选；对患者侧与领用耗材行均生效 |
| **耗材关键字** | 名称/拼音/编码模糊 → 预解析 `device_def_id`；患者侧与领用侧均生效 |
| **患者关键字** | 姓名/门诊号等；仅收窄**患者侧** encounter scope；科室领用侧不生效 |
| **科室筛** | 患者侧=开立/就诊科室（`Encounter.organization_id`）；领用侧=领用科室（`consuming_organization_id`） |
| **费用性质筛** | `fin_contract.bus_no`；就诊下**任一**有效账户命中即入集；仅收窄**患者使用** encounter scope |
| **费用性质列** | 患者侧 = 发放收费行 `account_id→contract_no`（转自费后跟新账户）；医疗类别仍取主诊 |
| **汇总** | ① **按耗材房**；② **按品规**；③ **按类型**；④ **按科室**；汇总列：**数量**、**进价单价/售价单价**（批号/账单同源）、**进价合计/售价合计**；默认耗材房；**不展示行数** |
| **时间窗** | 患者侧发放业务时间；科室侧同意/出库业务时间（SDD 对齐字段）；前端 `datetimerange`；默认当日 `00:00:00～23:59:59` |
| **导出** | 仅当前 Tab |

## 7. 非功能性需求

| 类别 | 要求 |
| --- | --- |
| **性能** | 常规日窗汇总/分页 ≤ 2s；导出 ≤ 30s。汇总金额：**禁止**为合计拉导出级展示 enrichment；数量与定价事实同一次 `WithLines` 扫描，金额按 `ID_IN_QUERY_CHUNK_SIZE` 分块累加；**禁止**数量汇总后再按页二次扫描；**禁止**单次触顶 `EXPORT_MAX_ROWS` 静默截断页脚。患者就诊 scope 叠加业务日窗（与护士工作量同相交口径）。来源=全部明细分页：两路前缀页合并切片（对齐发药报表），**禁止**每次拉满 EXPORT_MAX_ROWS |
| **进价列角（DD §2.4 Type B）** | 汇总页脚 `purchaseNetTotalAmount` = 当次汇总行 `purchaseNetAmount` 代数和；前端纠偏；禁止页脚另扫 |
