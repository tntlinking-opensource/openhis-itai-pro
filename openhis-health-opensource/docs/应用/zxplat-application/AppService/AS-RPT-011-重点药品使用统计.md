# 重点药品使用统计 · 应用服务设计（AS）

> **文档职责**：报表中心「重点药品使用统计」只读契约。按时间窗统计门诊/住院下各 **重点药类型** 的 **净人次**、**售价净额** 与 **使用占比**；每就诊类型块末追加组内「合计」（= 全部药典药品）；无明细下钻。
>
> **编码**：AS-RPT-011 · **版本**：v1.2.5 · **日期**：2026-09-22  
> **族边界**：`health/设计决策/DD-报表中心-发药耗材挂号费用汇总明细族.md`  
> **进售价真源**：`health/设计决策/DD-报表中心-进售价口径与开立科室-2026-08.md`  
> **药典标识**：`DM-MED-001`（`basicFlag` / `nationalMonitorFlag` / `centralPurchaseFlag` / `antibioticFlag` / `pharmacologyCategoryCode`）

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-RPT-KDU-01 初始化；IF-RPT-KDU-02 汇总（就诊类型 × 重点药类型矩阵 + 组内合计 + 使用占比）；IF-RPT-KDU-03 导出 |
| **在外** | 药品目录写路径；费用明细下钻（**AS-RPT-008/009**）；发药明细（**AS-RPT-003/004**）；耗材 |
| **涉及域** | **ChargeItem**（行售价）；**PaymentReconciliation**（门诊 `bill_date`/收退）；**Encounter**（AMB/IMP）；**MedicationDefinition**（重点药旗 + 药品性质 + 目录状态） |
| **编排权威** | 本文；金额与时间窗 **对齐同域费用明细**；人次为 **净人次（方案 A）** |
| **数据锚点** | 药品行：`ChargeItem.productTable = med_medication_definition` + `productId`；标识：药典重点药旗 / 药品性质码 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **财务 / 药事 / 管理** | 选日期、就诊类型、重点药类型 → 看各类型人次/金额/占比与组内合计 → 导出 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **重点药类型** | `KeyDrugType` 四旗：`BASIC` 基药；`NATIONAL_MONITOR` 国家重点监控；`CENTRAL_PURCHASE` 集采；`ANTIBIOTIC` 抗生素。筛对应布尔旗为 true。与**药品性质**分框（UI 两下拉） |
| **药品性质** | `KeyDrugType`：`NARCOTIC` 麻醉药品；`PSYCH_ONE` 一类精神药品；`PSYCH_TWO` 二类精神药品。筛 `pharmacology_category_code`（术语 `medicine_properties`：2/4/5）等值。与重点药类型分框 |
| **就诊类型** | 门诊=`AMB`；住院=`IMP`（`Encounter.classEnum`） |
| **目录状态** | 本报表**不按**药典启用/停用收窄（筛选在药品目录维护页） |
| **结果行** | 一行 = **就诊类型 × 重点药类型**；每就诊类型块末追加「合计」行（`keyDrugTypeCode=TOTAL`，`encounterClassCode` 仍为本组 AMB/IMP） |
| **门诊/住院分块** | AMB 类型行 + AMB 合计 → IMP 类型行 + IMP 合计；**无**门诊+住院全局合计行 |
| **默认筛选** | 就诊类型未选=全部 AMB+IMP；**重点药类型与药品性质两框皆空**=矩阵七行+合计；仅选一框=只出该框命中类型行 |
| **净人次** | 同一 `encounter_id`：该类型药品在时间窗内售价净额 **> 0** 才计 1；全退净额≤0 **不计**（方案 A） |
| **售价净额** | 与费用明细售价列同构：账单 `ChargeItem.total_price` 代数和（退费负向；结算刻度展示） |
| **使用占比** | **人次占比** = 该类型净人次 / **全部药典药品合计人次** × 100；**金额占比** = 该类型金额 / **全部药典药品合计金额** × 100；合计行两项均为 100%；分母为 0 → null。分项之和不必等于合计（多旗重叠） |
| **组内合计** | 人次/金额 = 时间窗内<strong>全部</strong> `med_medication_definition` 产品行（西药/中成药等）净人次/售价；页脚合计累加各组 TOTAL 行 |
| **仅药品** | 只统计药典产品行；耗材/诊疗/挂号不计 |
| **时间窗·门诊** | 对齐 **AS-RPT-008**：Payment **`bill_date`**；状态 `SETTLED`∪`REFUNDED`；退费 payment 取负 |
| **时间窗·住院** | 对齐 **AS-RPT-009**：ChargeItem-only，`entered_date` 日窗；**退费不入**（与住院费用明细现状一致） |
| **导出** | 当前汇总全量行（含各组合计）→ Excel；无明细 Tab |

## 4. 接口编排说明书（业务步骤）

### IF-RPT-KDU-01 页面初始化

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 进入报表中心「重点药品使用统计」 |
| **主路径步骤** | 默认当日 → 下发就诊类型选项（门诊/住院）→ 下发**重点药类型**选项（基药/监控/集采/抗生素）与**药品性质**选项（麻醉/精一/精二）分框 |
| **关键分支** | — |

| **查询侧说明** | 只读；筛选项来自枚举展示，不查库亦可 |

### IF-RPT-KDU-02 汇总查询

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 改日期/筛选或点查询 |
| **主路径步骤** | 校验日期 → 解析就诊类型、重点药类型码与药品性质码（两框皆空=全部七类）→ 各类型 `listIdsByKeyDrugType(code)` → 对每个就诊类型：准备费用明细 scope → `summarizeKeyMedicationUsageMatrix` + `summarizeAllMedicationUsage` → 装配各类型行与占比 → 装配组内合计 → 页脚合计（跳过 `keyDrugTypeCode=TOTAL`） |
| **关键分支** | 某类型目录 ID 为空 → 该行人次/金额为 0；药品人次为 0 → 占比 null |
| **失败分支** | EX-RPT-KDU-102/103 |
| **查询侧说明** | 同就诊类型下矩阵一次遍历候选行；禁止为页脚另开无关全窗物化 |

### IF-RPT-KDU-03 导出

## 8. 测试要点（业务视角）

| 类别 | 要点 |
| --- | --- |
| **行结构** | 默认 AMB 七类型+合计 + IMP 七类型+合计；单选门诊仅 AMB 块 |
| **多旗** | 同时属基药+集采的就诊可分别计入两类型行；合计占比用并集不双计 |
| **净人次** | 开基药后全退 → 基药行人次 0、金额 0（或冲减后≤0） |
| **使用占比** | 分母=全部药典药品净人次/金额；无药品人次时占比「—」；各类型各自算占比 |
| **合计行** | 人次/金额=时间窗内全部西药/中成药购买者及售价，非四类重点药之和 |
| **住院** | 与住院费用明细同日窗；退费不入与 AS-RPT-009 一致 |
| **导出** | 列：就诊类型、药品类型、人次、总金额、占比(%) |
