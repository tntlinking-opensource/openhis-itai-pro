# 检验域 · 仪器结果接收 · 应用服务设计（AS）

> **文档职责**：说明仪器结果接收的**接口契约（IF）**、业务规则（BR）。后台服务，无 UI。  
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径。  
> **触发方**：C++ 双向通讯程序  
> **编码**：AS-LIS-RES-01 · **版本**：v2.0 · **日期**：2026-06-22

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 接收 C++ 程序回传的仪器结果报文 → 对照解析 → 创建/更新 Observation(preliminary) |
| **涉及域** | Observation、LisWorkItem |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| **C++ 通讯程序** | 仪器结果上报→回调 LIS RES-01 |
| **系统** | barcode 反查 workItem → 仪器码映射 → 创建/更新 Observation |

### 1.3 术语与口径约定

| 术语 | 口径 |
|------|------|
| **幂等** | 同一次测量重复发送 → 更新值（查找已有 Observation 按 workItemId+code） |
| **映射丢失** | 仪器码→LIS 码无法匹配 → 拒绝（BR-RES-02） |

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **本期** | IF-RES-01-A/B：单/批量测量值接收；流水号记录 |
| **非目标** | 仪器通讯协议（由 C++ 程序实现） |

### 1.5 领域清单

| 聚合 | 职责 | DM 路径 |
|------|------|---------|
| **Observation** | 结果值存储 | `docs/领域/缺口/文档无代码/DM-LIS-002-Observation-检验结果.md |
| **LisWorkItem** | barcode 反查工单 | `docs/领域/缺口/文档无代码/DM-LIS-001-LisWorkItem-检验工单.md |

### 1.6 业务规则（BR-*）

| 编号 | 规则 | 触发 IF |
|------|------|---------|
| **BR-RES-01** | barcode 不存在 → 拒绝 | RES-01-A/B |
| **BR-RES-02** | 映射丢失（仪器码→LIS 码）→ 拒绝 | RES-01-A/B |
| **BR-RES-03** | 幂等：同次测量 repeated → update | RES-01-A/B |
| **BR-RES-04** | 接收后 linkStatusEnum→testing | RES-01-A/B |

## 4. 接口编排说明书（业务步骤）

### 4.1 IF-RES-01-A：单个测量值接收

| 维度 | 说明 |
|------|------|
| **触发前提** | C++ 程序回传仪器结果报文 |
| **主路径** | ① 按条码反查 workItem → ② 仪器码→LIS 码映射 → ③ 查重：同 workItemId+code 已有 preliminary → ④ 有则更新测量值；无则新建 Observation(preliminary) |
| **失败分支** | barcode 不存在 → reject；映射丢失 → reject |

---

## 5. 业务异常与用户提示

| 异常码 | 场景 | 用户提示语义 |
|--------|------|-------------|
| `WORKITEM_NOT_FOUND` | 条码无对应工单 | "条码 {barcode} 未找到对应检验工单" |
| `CODE_MAPPING_MISSING` | 仪器码无映射 | "仪器码 {code} 无 LIS 映射" |

## 7. 非功能性需求

| 维度 | 承诺 |
|------|------|
| 吞吐 | 批量接口支持一次接收 200 条测量值 |
| 幂等 | 同次测量重复 → update 不重复创建 |
| 超时 | 5s 超时返回 |

---

## 8. 测试要点（业务视角）

| 场景 | 测试要点 |
|------|----------|
| 正向 | 新测量值 → Observation=preliminary |
| 幂等 | 同 workItemId+code 重复 → update |
| 异常 | barcode 不存在 → reject |
