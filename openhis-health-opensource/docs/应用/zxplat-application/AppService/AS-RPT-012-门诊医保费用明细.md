# 门诊医保费用明细 · 应用服务设计（AS）

> **文档职责**：报表中心「门诊医保费用明细」只读契约。按结算时间列出门诊有效医保/工伤结算净行（姓名、就诊科室、门诊号、就医登记号、结算 ID、结算时间、医疗费总额、基金、个账、现金），支持省/市医保多选、职工/居民细分、就诊科室与编号模糊查询；页脚四列金额合计。**不含处方号**；**冲销行不展示**。
>
> **页面边界**：筛选 → 查询明细分页 → 页脚合计 → 导出。**纯读**；与收费员交账/日结挂载无关。
>
> **编码**：AS-RPT-012 · **版本**：v1.1 · **日期**：2026-09-09  
> **对称**：`AS-RPT-013-住院医保费用明细.md`

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | IF-RPT-OIF-01～03：初始化、明细分页（含合计）、导出 |
| **在外** | 门诊/住院日结与交账（**AS-OP-FIN-004** / **AS-IP-FIN-005**）；CHS 3201/3202 日对账侧栏；住院对称页（**AS-RPT-013**）；写路径结算/冲销 |
| **涉及域** | **医保结算回执**（`yb_settlement_record`，经 SPI）；**Encounter** / **Patient** / **Organization**；**Contract**（省/市费用性质）；工伤 Module 门控 |
| **编排权威** | 本文 §2、§4；金额刻度结算 2 位 |
| **数据锚点** | 有效净结算 = `status=CONFIRMED` 且未软删；已 `REVOKED`/冲销不入集 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **财务 / 医保办 / 管理** | 按结算时间与费用类别查门诊医保结算明细 → 核对金额合计 → 导出 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **有效净结算** | 平台正式结算回执 `CONFIRMED`；冲销/撤销后的 `REVOKED` **不出现**；**不出冲销负行** |
| **费用类别** | **省医保** / **市医保**可多选（合同 `category_enum`）；**工伤**独立（`settle_mode=WORK_INJURY`），与省/市互斥；无工伤 Module 时不下发工伤选项 |
| **职工 / 居民** | 平台 `insutype` 分组：职工（310/320/330）、居民（390）；可「全部」；**不保留离休（340）** |
| **科室** | 门诊 = 就诊科室（挂号科室，`Encounter.organization_id`） |
| **编号模糊** | 结算 ID、就医登记号、门诊号、姓名等按**包含**匹配；列表仍展示完整值。姓名匹配/展示均以**患者主数据**为准（结算回执 `psn_name` 常为「患者」占位，不作真源） |
| **明细列** | 姓名、就诊科室、门诊号、就医登记号、结算 ID、结算时间、医疗费总额、基金支付总额、个人账户支付、现金支付（**无处方号**） |
| **合计** | 同筛选条件下四列金额合计（以后端全量合计为准，禁止当前页假合计） |
| **时间窗** | 结算时间 `setl_time`（空则回落创建时间）；`datetimerange`；默认近一个月（今日往前 1 个自然月 00:00:00～今日 23:59:59） |
| **导出** | 当前筛选明细 Excel |

### 1.4 本期范围与非目标

| 类别 | 内容 |
| --- | --- |
| **本期** | IF-RPT-OIF-01～03；仅门诊（`encounter_class=AMB`） |
| **非目标** | 交账挂载；冲销明细；处方号；离休险种；与日结总收入轧差勾稽 |

### 1.5 领域清单（聚合 + 职责 + DM 路径）

| 聚合 / 能力 | 职责 | DM / 落点 |
| --- | --- | --- |
| **医保结算回执** | 有效结算行与金额 | CHS `YbSettlementRecord`（经 `InsuranceSettlementRecordLookupExtension`） |
| **Encounter / Patient / Organization** | 门诊号、就诊科室、患者名回填与筛选 | `DM-ADM-002` 等 |
| **Contract** | 省/市合同 id 解析 | `DM-FIN-001`（合同） |
| **工伤 Module** | 是否暴露工伤筛选项 | `WorkInjuryModuleExtension` |

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
| --- | --- | --- |
| **BR-RPT-OIF-001** | 结算时间窗必填且起≤止；默认近一个月到时分秒 | 01～03 |
| **BR-RPT-OIF-002** | 仅 `CONFIRMED` 净行；冲销/撤销不入集 | 02、03 |
| **BR-RPT-OIF-003** | 省/市可多选；工伤独立且与省/市互斥；无工伤包不提供工伤选项 | 01～03 |
| **BR-RPT-OIF-004** | 职工/居民按 `insutype` 分组筛选；不提供离休 | 02、03 |
| **BR-RPT-OIF-005** | 科室筛 = 就诊科室（挂号科室）；编号类条件模糊包含匹配 | 02、03 |
| **BR-RPT-OIF-006** | 页脚四列金额为同筛选全量合计（结算 2 位） | 02 |
| **BR-RPT-OIF-007** | 仅门诊 AMB | 02、03 |
| **BR-RPT-OIF-008** | 导出受行上限约束 | 03 |
