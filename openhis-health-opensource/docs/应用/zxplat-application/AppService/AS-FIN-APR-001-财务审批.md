# 财务管理 · 财务审批 · 应用服务设计（AS）

> **文档职责**：说明「财务审批」单页的**接口契约（IF）**、业务语义、涉及聚合与 QueryService、规则（BR）、编排意图；作为上游契约供详细设计与实现对齐。
>
> **本文必须写**：IF 编号；用户动作与读写属性；关键校验与状态变化；Gap；异常口径；事件语义；非功能约束；业务向测试要点。
>
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径；Mapper；伪代码；写库顺序；QueryService 字段组装规则。
>
> **页面边界**：**一级「财务管理」** → **二级「财务审批」**；统一列表对待审/已审/驳回的**财务审批族**单据做**同意/驳回**；详情为**只读**，按类型复用各业务单据既有详情读能力，详情内亦可触发同意/驳回（仍走本 AS 写 IF）。**制单、改单、提交、撤回、删除**不在本页。
>
> **覆盖声明**：交互与范围以当期产品裁决为准；写侧同意/驳回业务编排**复用**各业务 AS 既有同意/驳回意图（进货入账、退货扣库、损益发放、盘点盘点发放、调价落价），本 AS 负责**统一入口、财务角色门控、财务审批族白名单与统一列表读**。
>
> **编码**：AS-FIN-APR-001 · **版本**：v0.2.3 · **日期**：2026-07-26

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | 财务审批族单据的统一分页列表（含金额口径列）；初始化筛选项；对**待审**单据**同意/驳回**（列表或只读详情均可触发）；财务角色门控；白名单类型外单据不得经本页审驳 |
| **在外** | 各业务单据的建单/改单/提交/撤回/删除；非财务审批族单据的审批（仍在原业务页）；进货验收子流程、订货单、退库入库壳单、请领/出库/调拨等纯物流审批 |
| **涉及域** | **写侧**：SupplyRequest（动账同意/驳回及下游发放/库存）、PriceAdjustment（调价同意/驳回及落价/解锁）；**读侧**：SupplyRequest / PriceAdjustment 列表聚合读、Location / Supplier / 人员展示 enrich |
| **跨域** | 同意后下游编排与各业务 AS 一致（进货→发放+库存+追溯；退货→发放+扣库；损益→发放；盘点→盘点发放；调价→写价+解锁） |
| **编排权威** | 以本文 **§2、§4** 为准；各类型同意后动账细节以对应业务 AS + DM 为准 |
| **前置（摘要）** | 单据已处于**待审**；操作者持有财务登录角色 `ROLE_ACCOUNTANT`；`type` 属于财务审批族白名单 |
| **后置（摘要）** | 同意：单据至同意/已生效终态并完成该类型既有动账编排；驳回：单据至驳回态，不产生（或按该类型既有规则回滚）动账 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
| --- | --- |
| **财务**（`ROLE_ACCOUNTANT`） | 进入财务审批页 → 筛选/翻页 → 查看只读详情 → **同意** / **驳回** |
| **无财务角色用户** | 可进入页面浏览列表/详情（若菜单授权），**不得**执行同意/驳回（按钮不可用；写接口拒绝） |
| **各业务制单员** | **不在本页**制单；在原业务页提交审批后，待审单进入本页队列 |

### 1.3 术语与口径约定

| 术语 | 口径 |
| --- | --- |
| **财务审批族（供应单）** | `SupplyType` 持久化码白名单：**进货** `CABINET_INBOUND_RECEIPT`；**退供应商** `CABINET_RETURN_TO_SUPPLIER`；**损益** `CABINET_GAIN_LOSS` / `PHARMACY_GAIN_LOSS` / `DEPT_GAIN_LOSS`；**盘点** `CABINET_STOCKTAKE` / `PHARMACY_STOCKTAKE` / `DEPT_STOCKTAKE`（不含已废止的科室耗材盘点） |
| **财务审批族（调价）** | 调价单（`PriceAdjustment`）全部纳入本页审批；**不**经 `SupplyType` 白名单，以独立域状态机为准 |
| **非财务审批族** | 订货、退库入库、请领、出库、调拨、领用等——**原业务页**审批，**不**校验财务角色，**不**出现在本页列表 |
| **待审（供应）** | `SupplyStatus` = **`APPROVAL`**（审核中） |
| **待审（调价）** | `PriceAdjustmentStatus` = **`pending`** |
| **库房** | 列表筛选项「库房」覆盖药库/药房/科室库位；按单据源或目的库位字段收窄（以实现与各业务列表一致为准） |
| **品类** | 筛选四档：药品 / 耗材 / 诊疗活动 / 医疗服务（供应单按行 `item_table` 为药/耗；调价按单头 `item_table`，含 clinical 诊疗两档）；列表行 `itemTableText` 同源投影；**不**按具体品名关键字筛明细含品单据 |
| **单号模糊** | 供应单与调价单均按 `bus_no` **模糊**匹配 |
| **默认筛选（前端）** | 进入页：单据类型默认 **空（全部类型）**、审批状态默认 **待审**；**后端不得写死**默认 type/status，未传条件则按入参语义查询 |
| **动态金额列** | **选定单一单据类型**：列头按该类型展示对应金额名（进货=进货金额；退供应商=退货金额；损益=盈亏金额；盘点=实盘金额+盈亏金额；**调价=仅进价盈亏+售价盈亏**，且隐藏库房/供应商列）；**单据类型空/全部**：字段并集列——供应「金额」+ **实盘金额** + **盈亏金额** + **进价盈亏** + **售价盈亏** 并存，行上仅填有值字段（禁止把盘点/损益塞进供应「金额」） |
| **金额口径** | **进货**：进货金额（行金额汇总）；**退供应商**：退货金额（行金额汇总）；**盘点**：实盘金额 + 盈亏金额；**损益**：盈亏金额；**调价**：**进价盈亏**与**售价盈亏**分列展示（对齐调价域 `totalPurchaseImpact` / `totalSellingImpact`，**禁止**加总为一列） |
| **详情** | 前端按 `documentKind` + `busNo` 打开对应业务只读详情（复用既有详情读 IF）；详情只读，操作区同意/驳回调用本 AS 写 IF |
| **原页按钮** | 财务审批族单据在原业务页（含调价工作站）**不再展示**同意/驳回；非财务审批族仍在原页审驳 |
| **菜单归属** | **一级「财务管理」** → **二级「财务审批」**；建议路由 `/finance/approval` |
| **AS 编码 FIN-APR** | `AS-FIN-APR-001`：FIN=院级财务管理；APR=审批工作台；**≠** `AS-OP-FIN-*` / `AS-IP-FIN-*` |

## 4. 接口编排说明书（业务步骤）

### IF-APR-01 初始化

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 用户进入「财务管理 · 财务审批」 |
| **主路径** | 返回：单据类型（财务审批族各码 + 调价 + 全部）、审批状态（待审/已同意或已生效/已驳回等，供应与调价展示文案统一映射）、库房位置、供应商、品类（药品/耗材/诊疗活动/医疗服务）、可选制单人/审批人下拉；**不下发**写死的默认选中值（由前端自带默认：类型空=全部、状态待审） |
| **关键分支** | 库房列表可按管辖收窄（与库存业务页同类口径）；管辖空过渡态不误收成空 |
| **失败分支** | 主数据不可用时返回空选项，不阻断进页 |
| **查询侧说明** | 仅选项投影 |

### IF-APR-02 统一列表

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 筛选、翻页、刷新、重置；条件均可选 |
| **主路径** | 在财务审批族范围内按条件过滤；**一行一 `bus_no`**；装配单号、单据类型、库房、供应商（适用时）、品类、制单人、制单时间、审批状态、审批人、审批时间、及金额字段（§1.3）；供应单与调价单合并为同一分页结果集（排序建议：待审优先或按制单/申请时间倒序，以实现约定为准） |
| **关键分支** | 仅选供应类型 → 只查供应；仅选调价 → 只查调价；全部 → 并集；未传 type/status → **不**默认进货/待审 |
| **失败分支** | 非法类型码、非法品类 → 参数错误 |
| **查询侧说明** | 列表展示；金额由行汇总/调价已固化盈亏投影，禁止前端重算 |

### IF-APR-03 审批同意

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 列表或只读详情点击同意；单据待审；操作者具备财务角色 `ROLE_ACCOUNTANT`；类型∈财务审批族 |
| **主路径** | ① 校验角色与白名单与待审态；② 按类型分发：**进货**→与进货同意相同动账意图；**退供应商**→与退货同意相同；**损益**→与损益同意相同；**盘点**→与盘点同意相同；**调价**→与调价同意相同（落价+解锁） |
| **关键分支** | 无 |
| **失败分支** | 无角色、类型不在白名单、非待审、重复同意、下游动账失败 → 整单失败可见 |
| **查询侧说明** | 成功后列表/详情刷新 |

### IF-APR-04 审批驳回

| 维度 | 说明 |
| --- | --- |
| **触发前提** | 列表或只读详情点击驳回；单据待审；财务角色；类型∈白名单 |
| **主路径** | ① 校验角色/白名单/待审；② 按类型分发驳回（调价须驳回原因；供应按对应业务口径写原因）；调价物流单须解锁 |
| **关键分支** | 无 |
| **失败分支** | 同同意之门控失败；调价缺驳回原因 |
| **查询侧说明** | 成功后列表刷新 |

## 5. 业务异常与用户提示

| 异常场景 | 用户提示语义 | 可重试 |
| --- | --- | --- |
| 无财务角色 | 无财务审批权限，无法审批或驳回 | 否（换账号） |
| 类型不在财务审批族 | 该单据不在财务审批范围 | 否 |
| 非待审态同意/驳回 | 当前状态不可审批 | 否（刷新） |
| 单号不存在 | 单据不存在或已删除 | 否 |
| 重复同意 / 已发放 | 已审批或已入账，勿重复操作 | 否 |
| 同意后下游库存/发放失败 | 审批未生效，请稍后重试或联系管理员 | 视原因 |
| 调价驳回原因缺失 | 请填写驳回原因 | 是 |
| 列表非法筛选参数 | 请检查筛选条件 | 是 |

## 6. 事件语义与消费方

| 事件（语义） | 触发相位 | 消费方（语义） | 幂等 |
| --- | --- | --- | --- |
| 供应单已同意 | IF-APR-03（供应类型） | 与各 INV 同意后一致：发放/库存/追溯等应用编排 | 防重复同意 |
| 供应单已驳回 | IF-APR-04（供应类型） | 列表/详情刷新；无动账 | 防重复驳回 |
| 调价已生效 | IF-APR-03（调价） | 定价读侧、pending 阻断解除、库存锁解除（物流） | 防重复批准 |
| 调价已驳回 | IF-APR-04（调价） | 解锁；可回原调价页改单再提 | 防重复驳回 |

## 7. 非功能性需求

| 项 | 承诺 |
| --- | --- |
| **性能** | 列表默认页大小与库存单据列表同级；并集分页须可验收（见 Gap-APR-002） |
| **幂等** | 同意/驳回对已终态单据拒绝，不产生二次动账 |
| **并发** | 同意路径沿用各业务 AS 乐观锁/防重复发放口径 |
| **一致性** | 同意与下游动账同一业务事务边界（与对应业务 AS 一致） |
| **审计** | 审批人、审批时间落库；写操作可追溯操作者 |
| **安全** | 写 IF 强制财务角色；读 IF 跟随菜单授权 |
