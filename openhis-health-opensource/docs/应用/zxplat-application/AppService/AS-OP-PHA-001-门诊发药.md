> **文档职责**：说明「门诊发药」药房工作站的**接口契约（IF）**、业务语义、涉及聚合与 QueryService、规则（BR）、编排意图；作为上游契约供详细设计与实现对齐。
>

>
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径；Mapper；伪代码；写库顺序；QueryService 字段组装规则。
>
> **页面边界**：调配药师在门诊发药工作站对就诊队列（**已发药/待发药**）筛选与刷新 → 选择就诊 → 按西药/中药切换查看药品发药单明细与**候选库房×批号库存** →（可选）采集追溯码 →（可选）表格与纸质处方单视图对照 → **保存配药** → **发药**；或与收费、医生站医嘱开立、库存及医保销售上传等上下游联动；支持单行 **作废**。

## 1. 场景概述

### 1.1 目标与边界


| 维度         | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **在内**     | 发药页初始化（科室、调配药师候选、就诊类型、**已发药/待发药**队列筛选语义对应的下拉等）；**就诊队列**仅包含：该就诊下存在至少一条 **MedicationDispense** 且其 `**DispenseStatus` 为 `PREPARATION`、`IN_PROGRESS` 或 `COMPLETED`**（门诊药品），队列库房收敛：发放事实 `location_id` 须落在当前操作者**管辖库位**内（服务端解析，**非**登录科室下全部启用药房；**管辖 empty** 时不拼 `location_id` 谓词）；关键字、日期等与列表一体的过滤及刷新；前端可按 已发药 / 待发药收窄：已发药仅统计或列出 `**COMPLETED`**；**待发药**为 `**PREPARATION` ∪ `IN_PROGRESS`**（与发药单列表筛选语义一致）。选定就诊后分页加载**药品发药单/发放行**（中西药切换语义不变），行上装配 **剩余可发库存视图**：按 `**ServiceLocationTemplate`（取药科室，`DM-CUS-006`）** 在**开立/接诊科室上下文**下解析**候选发放药房**，再查询各候选药房下该药品各**批号可用数量**，供用户改选**发放药房、批号、实发数量**。用户确认后先调用 **保存配药**（`PREPARATION`→`IN_PROGRESS`，写入选定库房/批号/数量/追溯码等并校验），再调用 **发药**（仅扣减发放单所载库房+批号库存，`IN_PROGRESS`→`COMPLETED`，扣减前再次校验库存充足；追溯码出库登记；可触发医保商品销售与进销存上传）；支持 **作废** 未发放完成的药品发放单（`DECLINED` + 原因）。追溯码弹窗为采集入口，确认后的追溯码随**保存配药**提交 |
| **在外**     | 医保平台接口细则与清算、追溯码国家库解析服务、打印机驱动、药师电子签名法规细则                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **跨域**     | **Encounter**；**MedicationRequest**/**MedicationDispense**；**InventoryItem**；**ChargeItem**/**PaymentReconciliation**/**Contract**/**Account**；**TraceNoManage**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **编排权威**   | 以本文 **§2、§4** 为准：**保存配药**与**发药**分接口、顺序由前端保证（通常先保存后发药）；库存扣减仅在**发药**接口执行；进销存上传由 `InventoryUploadExtension#isEnabled` 门控，与既有门诊收费/发药协作一致                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **前置（摘要）** | 就诊已完成门诊正式结算（IF-OPC-07）；**药品**发放行已由收费链路进入可药房作业态（如 **DRAFT→PREPARATION**）；医嘱 **MedicationRequest** 门诊校对态与收费链路对齐（参见收费/医嘱 AS）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **后置（摘要）** | **发药**成功则发放行 `**COMPLETED`**，按发放单行上既定库房+批号扣减库存，追溯码出库；进销存扩展启用（`InventoryUploadExtension#isEnabled`）时尝试商品销售及进销存接口并合并提示。**保存配药**不写库存账面，仅迁移状态并持久化用户选定要素                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |


### 1.2 角色与关键动作


| 角色              | 关键动作                                                                                                      |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| **门诊药房调配/发药人员** | 筛选队列（已发/待发）→ 选择患者 → 切换中西药 → 查看/调整库房·批号·数量 →（可选）扫追溯码 →（可选）处方单视图核对 → 选择调配药师 → **保存配药** → **发药**；或对单行 **作废** |


### 1.3 术语与口径约定


| 术语             | 口径                                                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **待发药患者队列**    | 以就诊为粒度展示仍有待发药业务的患者行；列表过滤与分页语义与发药页查询一致                                                                                                                     |
| **处方列表 / 发放行** | 以处方单与药品发放明细为行展示待发记录；支持按 **中药标识** 与西药列表切换过滤                                                                                                                |
| **保存配药**       | 将发放行从 `**PREPARATION`** 推进为 `**IN_PROGRESS`**；持久化用户确认的**发放库房、批号、实发数量、追溯码**等；校验所选库存对该数量充足、实发数量与医嘱开立数量一致（含临时医嘱拆分行合计口径，见 BR）                                 |
| **发药（核发）**     | 在 `**IN_PROGRESS`** 前提下，**再次**校验库存充足后，按发放单所载 **库房+批号+数量** 扣减库存（**账面 `quantity` 为拆零最小单位**；发放行 **`unit_code` 操作单位数量**须经目录**五类业务单位**倍数换成拆零后再扣，见 **BR-OPP-017**；**禁止**用追溯码贴码倍数做扣库换算），将发放行置 `**COMPLETED`**，调用 **IF-TRC-16** 写 `HOSPITAL_IO` OUT（**`recordTraceRecords`**），可按开关触发医保销售与进销存 |
| **作废**         | 将仍处于待发链路的发放单（`**PREPARATION` 或 `IN_PROGRESS`**）置 `**DECLINED`**，并记录原因（不涉及已 `**COMPLETED**` 行的退药，退药走专用流程）                                                  |
| **QueryService 能力**        | 明细与队列目标态可由 `**MedicationDispenseSlip`** 支撑                                                                                                                |
| **DM 路径**      | `docs/领域/DomainModel/` 下对应文件                                                                                                                |

## 4. 接口编排说明书（业务步骤）

### IF-OPP-01 发药页初始化


| 维度          | 说明                            |
| ----------- | ----------------------------- |
| **触发前提**    | 用户进入门诊发药工作站                   |
| **主路径步骤**   | 装载**管辖内启用药房**（`adm_location`，`pharmacyOrganizationOptions` 的 value 为 locationId）、**调配药师候选**（须 **`ROLE_PHARMACIST`** 且 `adm_pr_assign.location_id` 落在请求 `pharmacyLocationId` 或管辖内启用药房）、未发药原因、就诊类型、发药状态下拉 |
| **关键分支**    | —                             |
| **失败分支**    | 元数据不可用（EX-OPP-101）            |
| **查询侧说明** | 无                             |


### IF-OPP-02 就诊队列查询（含已发/待发筛选与刷新）


| 维度          | 说明                                                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **触发前提**    | 用户已登录且工作站会话具备**机构上下文**（用于解析可见药房）；用户设定关键字、可选日期窗、**已发药/待发药**或等价枚举、或点击刷新                                                                                                          |
| **主路径步骤**   | 服务端先解析当前机构下**启用中药房库位**集合，再按 **MedicationDispense** 收敛就诊 ID（须存在门诊**药品**发放、**库房落在上述集合内**，且 `**DispenseStatus ∈ {PREPARATION, IN_PROGRESS, COMPLETED}`**）；可选将 `startDate`/`endDate` 与关键字预解析为就诊收窄（就诊 **`startTime`**，与收费队列同口径）后求交；按就诊 **`max(created_at)`** 倒序分页；返回就诊行及展示字段 |
| **关键分支**    | **待发药**：筛子状态 `**PREPARATION`、`IN_PROGRESS`**；已发药：筛 `**COMPLETED`**（与前端 Tab 对齐）；摘要文案与 BR-OPP-001 一致；管辖库位 empty 时不按库房收窄；无日期且无关键字时不额外收窄就诊 |
| **失败分支**    | 未登录、会话无效或机构上下文缺失（EX-OPP-102）；其余查询失败（EX-OPP-102）                                                                                                                             |
| **查询侧说明** | 就诊列表；队列事实以写模型查询或 Slip 聚合为准                                                                                                                                                  |


### IF-OPP-03 就诊药品发药单列表 / 明细加载


| 维度          | 说明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **触发前提**    | 已选就诊，可切换西药/中药；可选 **已发药/待发药** 与队列一致                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **主路径步骤**   | 按就诊分页查 **MedicationDispense** 药品行；**排除耗材**；目录发布过滤；**批量**解析开立科室（`OrganizationQueryService#mapNamesByIds`）与列表术语（`module.common` `**TerminologyOptionLoader` + `OrderCatalogDisplayAssembler`**，**禁止**循环单条查库）；装配 **患者发药信息** 展示口径：**就诊与发放主键、发放库房及名称、批号、开立科室与开单医生、发药药师（已进入发药事实时）、药品目录维度（类型/项目名称/商品名/规格/**包装最小单位换算比展示 `packageSplitRatioText`（如 `1盒/36片`；同单位×1 为 `1支`；与库存明细同族）**/厂家/所在表 `product_table_name`）、医嘱剂量·频次·用法及相关术语文案、拆零比与拆分属性、单次发药数与供应天数、请求数量与发放数量、计价单位与数量展示、单价与金额（若与 ChargeItem 锚定）、处方号与医嘱组号、诊断摘要、发药状态（存 `**DispenseStatus` code**）及展示文案、皮试/中药/输液标志及展示文案、追溯码、医嘱开具时间、就诊业务号与就诊用药类别（`med_type` 之类术语）、以及 **候选库房×批号可用库存明细列表**（供改选库房/批号/数量）；并对已锚定 **发放库房×批号** 的行 **现查**回填 **`remainingQuantity`**（最小单位账面剩余，与候选明细分列，供发药单笺面展示）。字段命名与类型以 **SDD §3.4 发放行响应 DTO** 为准，并与历史工作站导出列 **语义对齐**（范例中的 `_dictText`/`_enumText` 角色由术语装配字段承担）。 |
| **关键分支**    | 切换中西药即切换查询条件；筛选 **待发药** 时常态为 `**PREPARATION`、`IN_PROGRESS`**；已发药 为 `**COMPLETED`**；**未显式传 `locationId` 时**按管辖库位 `location_id IN` 收窄明细（与 IF-OPP-02 一致）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **失败分支**    | 就诊无效（EX-OPP-103）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **查询侧说明** | MedicationDispenseSlip；药品定义QueryService；医嘱查询模型；就诊/诊断摘要；库存明细；收费明细（可选）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |


### IF-OPP-04 保存配药


| 维度          | 说明                                                                                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **触发前提**    | 已选调配药师；勾选 `**PREPARATION`** 行；用户确认库房、批号、数量、追溯码等                                                                                                                                  |
| **主路径步骤**   | 追溯码占用/本库在院校验（有码批）；调配药师非本人；状态 `**PREPARATION`**；**库存充足**（所选库房+批号）；**实发数量=开立数量**（含临时医嘱拆分行合计）；**收费明细总价与按账单单价重算总价一致**（**BR-OPP-013** / **BR-PRICE-SRC-001**，尚无收费锚点时可跳过）；写入选定要素；**PREPARATION→IN_PROGRESS** 并记调配者与时间。前端半扫见 **BR-OPP-015**（确认后清码） |
| **失败分支**    | EX-OPP-201～204、EX-OPP-205                                                                                                                                                  |
| **查询侧说明** | MedicationDispenseSlip                                                                                                                                                           |


### IF-OPP-05 发药（核发）


| 维度          | 说明                                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------- |
| **触发前提**    | 勾选 `**IN_PROGRESS`** 行（通常对应已保存配药）                                                                        |
| **主路径步骤**   | 发放前**再次**校验所选库房+批号库存充足；按 **MedicationDispense** 所载扣减；**IN_PROGRESS→COMPLETED**；发药人/时间；有码批且行上有 `trace_no` 时经 **`TraceNumberDispenseTraceOrchestrator#recordDispenseOutLines`** 写 **IF-TRC-16**（**BR-OPP-014**：`isRemainingSplitSufficientForDispenseOut` 盖住则剩余先出 OUT，否则软跳过；**`location_type_enum`** = **`LocationQueryService#requireSupplyRequestTypeForLocationId`**）；空码/无码批跳过写追溯；进销存扩展启用则事务外上传 |
| **失败分支**    | EX-OPP-203、EX-OPP-205、EX-OPP-206、EX-OPP-207 |
| **查询侧说明** | MedicationDispenseSlip、库存与追溯QueryService 刷新                                                                         |


### IF-OPP-06 作废发放


| 维度          | 说明                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------- |
| **触发前提**    | 用户选择/确认作废原因（映射 `**NotPerformedReason`**）                                                 |
| **主路径步骤**   | 仅 `**PREPARATION` 或 `IN_PROGRESS`**；按 `**DM-MED-002`** 作废未发语义执行；置 `**DECLINED**` 并写入原因枚举 |
| **失败分支**    | EX-OPP-208                                                                               |
| **查询侧说明** | MedicationDispenseSlip                                                                   |
