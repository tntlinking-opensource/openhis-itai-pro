# 住院药房日结 · 应用服务设计（AS）

> **文档职责**：住院药房日结作业页的 IF / BR / 编排权威。  
> **页面边界**：发药管理 → **住院药房日结** — 时分秒窗 + **单药房** + **发药人多选** → 大类/品规 → 弹窗提交（`IP_PHARMACY`/`SUBMITTED`）→ 撤回；审批在 **AS-FIN-CS-001**。  
> **边界真源**：DD 交账日结改造 **v1.5.10** + **DM-FIN-003 v3.0**。

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
| --- | --- |
| **在内** | 与 **AS-OP-PHA-006** 同构；`type_enum=IP_PHARMACY`；门/住场景用 encounter/dispense_enum 收窄 |
| **在外** | 门诊药房日结；发药/退药作业；交账审批；收款日结；耗材 |
| **涉及域** | CashierSettlement；MedicationDispense；ChargeItem（主区售价）；ChargeItemDefinition（主区进价批号价） |
| **后置** | 头 SUBMITTED；dispense 挂载 |

| 角色 | 关键动作 |
| --- | --- |
| **住院药房人员** | 选窗+药房+发药人 → 查询 → **确认交账 → 弹窗勾选 → 确认** → 撤回 |
| **财务** | **AS-FIN-CS-001** |

### 1.3 术语与口径约定

同 **AS-OP-PHA-006** §1.3；类型码为 `IP_PHARMACY`；进/售读价同门诊（售价优先账单；退药无自身账单补原正向取负；仍缺则批号售价同批号回放；进价=批号包装进价按 `unitCode` 分支；头表 `total_income`=售价合计）。

### 1.4 本期范围与非目标

### 1.5 领域清单

同 AS-OP-PHA-006。

### 1.6 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
| --- | --- |
| **BR-IP-PDC-001** | 候选口径同 BR-OP-PDC-001，类型 `IP_PHARMACY` | 02、03 |
| **BR-IP-PDC-002～008** | 与 BR-OP-PDC-002～008 对称（含 `pendingCount`、账单售价+批号进价同批号回放、药师岗多选软筛、漏交不灰确认入口） | 对应 IF |
| **BR-IP-PDC-009** | 与 **BR-OP-PDC-009** 对称：药房下拉/查询·提交·撤回·交账历史均须落在岗位管辖启用药房内 | 01～05 |
| **BR-IP-PDC-010** | 与 **BR-OP-PDC-010** 对称：品规表头净数量/售价总额升降序 + 重点药类型筛选 | 01、02 |

## 2. 页面与接口总览（契约概览）

| IF 编号 | 用户动作 | 接口语义 | 读/写 | 关键状态变化 |

| IF-IP-PDC-05 | 交账历史 | 按提交时刻窗分页；**仅管辖药房** | 读 | — |
