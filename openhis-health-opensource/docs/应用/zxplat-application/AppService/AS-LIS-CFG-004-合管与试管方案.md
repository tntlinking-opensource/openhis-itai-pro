# 检验域 · 合管与试管方案 · 应用服务设计（AS）

> **文档职责**：说明合管方案（merge_profile）与试管方案（tube_scheme）的**接口契约（IF）**、业务规则（BR）。  
> **本文禁止写**：具体类名/应用方法名；Request/Response 字段明细；包路径。  
> **编码**：AS-LIS-CFG-004 · **版本**：v2.0 · **日期**：2026-06-22

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 合管方案 CRUD（名称、适用项目组、优先级、enableFlag）；试管方案 CRUD（颜色/管帽/材质/容量）；方案与仪器能力关联 |
| **涉及域** | lis_merge_profile、lis_tube_scheme、lis_device_capability |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| **LIS 管理员** | 维护合管方案 → 维护试管方案 → 关联仪器能力 |

### 1.3 术语与口径约定

| 术语 | 口径 |
|------|------|
| **合管方案** | 定义哪些检验项目可合并到同一管血，按 priority 排序 |
| **试管方案** | 物理试管属性：颜色/管帽/材质/容量 |

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **P0** | 合管方案 CRUD、试管方案 CRUD、关联仪器能力 |

### 1.5 领域清单

无独立 DM（配置表聚合，见 CFG 概要设计）。

### 1.6 业务规则（BR-*）

| 编号 | 规则 | 触发 IF |
|------|------|---------|
| **BR-CFG-MT-01** | 同一 enableFlag=true 的项目仅属于 1 个 mergeProfile | save |
| **BR-CFG-MT-02** | 禁用前校验无活跃 DeviceCapability 关联 | toggle |
| **BR-CFG-MT-03** | 变更后触发合管重算 | save |

## 4. 接口编排说明书（业务步骤）

### 4.1 IF-MT-01：合管方案保存

| 维度 | 说明 |
|------|------|
| **触发前提** | 管理员保存合管方案 |
| **主路径** | ① 校验同一项目仅属于 1 个 enableFlag=true 的 profile → ② 保存 → ③ 发布 MergeProfileChangedEvent |
| **失败分支** | 项目已被其他 profile 绑定 → reject |
