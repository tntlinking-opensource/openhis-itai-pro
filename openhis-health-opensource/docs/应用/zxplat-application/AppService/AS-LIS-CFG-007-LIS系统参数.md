## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | lis_config KV 参数读写；禁止读写 framework Setting |
| **涉及域** | LisConfig |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| **LIS 管理员** | 查询/修改系统参数 |

### 1.3 术语与口径约定

| 术语 | 口径 |
|------|------|
| **lis_config** | LIS 自有 KV 表（tenantId 必填，orgId 可选），**禁止**读写 framework Setting |

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **P1** | KV 读写、批量导入 |

### 1.5 领域清单

| 聚合 | 职责 | DM 路径 |
|------|------|---------|
| **LisConfig** | 模块参数 | `docs/领域/缺口/文档无代码/DM-LIS-008-LisConfig-模块参数.md |

### 1.6 业务规则（BR-*）

| 编号 | 规则 | 触发 IF |
|------|------|---------|
| **BR-CFG-PM-01** | **禁止**读写 framework Setting | 全部 |
| **BR-CFG-PM-02** | 危险参数变更需二次确认 | save |
| **BR-CFG-PM-03** | 变更记录 AuditLog | save |
| **BR-CFG-PM-04** | 合并相关变更 → 触发重算 | save |
| **BR-CFG-PM-05** | TAT 超时变更 → 仅对新工单生效 | save |

## 4. 接口编排说明书（业务步骤）

### 4.1 IF-CFG-PM-02：保存参数

| 维度 | 说明 |
|------|------|
| **触发前提** | 管理员修改 lis_config 值 |
| **主路径** | ① 校验 configKey 合法（非 framework Setting key）→ ② 危险参数 → 二次确认 → ③ 保存 → ④ 写 AuditLog → ⑤ 若合并相关参数 → 触发重算 |

---

## 5. 业务异常与用户提示

| 异常码 | 场景 | 用户提示语义 |
|--------|------|-------------|
| `CONFIG_KEY_INVALID` | key 非法 | "参数键无效" |
| `DANGER_CONFIRM_REQUIRED` | 危险参数 | "此参数变更可能影响系统运行，请二次确认" |
