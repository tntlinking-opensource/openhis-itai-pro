# PEIS 数据迁移方案

> **版本**：v1.3 · **日期**：2026-07-26  
> **源**：old_peis MySQL（`peis`）  
> **目标**：ZXPlat PG（health + peis + campus）  
> **场景**：校医院——学生新生检 / 在校年检 / 教职工；毕业健康档案；乱数据归类理顺  
> **工具**：[`tools/PeisMigrator`](./tools/PeisMigrator/)

---

## 0. 业务治理口径

| 概念 | 判定（可配置） | 落点 |
|------|----------------|------|
| 新生体检 | `service_type=Student` 且 `customer_frequency≤1` | `examKind=freshman` |
| 在校年检 | `service_type=Student` 且 `customer_frequency>1` | `examKind=annual` |
| 教职工体检 | `service_type=Staff` | `examKind=staff` |
| 其他 | 无法归类 | `examKind=other`（进对账报告人工复核） |
| 毕业健康档案 | `peis_health_record*` + 学籍 `GRADUATED` | `peis_patient_health_archive` |

`examKind` 写入 `peis_encounter_ext.package_snapshot_json`，跑完输出 `governance-*.json`。

## 2. 字段映射要点

### 2.1 小项 → OD

| 老 | 新 |
|----|-----|
| `code` | `code`（空则 `LEGACY_ITEM_{id}`） |
| `name` | `display` |
| `result_type` | `value_type_enum`：数值类→`quantity`，其余→`string` |
| `result_unit` | `unit_code`（双值取第一段） |
| `pause_flag=1` | `status_enum=inactive`，否则 `active` |

### 2.2 项目 → AD

| 老 | 新 |
|----|-----|
| `code` | `bus_no`（空则 `LEGACY_PROJ_{id}`） |
| `name` | `name` |
| `pinyin_code` | `py_str` |
| `clinic_type` | `type_enum`：3→`1`(检验) / 1→`2`(检查) / 其他→`5`(其他) |
| — | `category_code=PEIS` |
| `pause_flag` | `status_enum`：active / retired |

### 2.3 套餐 → AD + children

| 老 | 新 |
|----|-----|
| `code` | `bus_no`（前缀 `PKG_` 若与项目码冲突可人工改配置） |
| `name` | `name` |
| — | `type_enum=5`、`children_flag=true` |
| `sys_check_package_project` | `wkf_activity_definition_children` |

### 2.4 客户 → Patient

| 老 | 新 |
|----|-----|
| `customer_code` | `bus_no` |
| `username` | `name` |
| `sex` | `gender_enum`：1→male / 2→female / 其他→unknown |
| `id_number` | `id_card`；已存在同证件则 **LINK** 不新建 |
| `phone` / 地址 / `work_unit_text` | 对应字段 |
| — | `organization_id` = 配置项；`status_enum=active`；`active_flag=true` |

### 2.5 体检单 → Encounter / SR / Observation

| 老 | 新 |
|----|-----|
| `order_number` | `adm_encounter.bus_no` + `peis_encounter_ext.bus_no` |
| `peis_customer_id` / `customer_code` / `id_number` | 解析 `patient_id`；可补建 |
| `status` | Encounter：1→PLANNED，6→COMPLETED，其余 IN_PROGRESS |
| `group_flag` / `tjtc_id` | ext.`group_flag` / `package_activity_id` |
| project `check_flag`/`status` | SR COMPLETED/CANCELLED/ACTIVE + ext pending/checked/abandoned/deferred |
| item 结果 | `value_string` / `value_quantity`；`status` preliminary/final |

## 3. 幂等与 ID

- 新主键一律 **雪花 ID**（与 ZXPlatMigrator / zxplat-framework 同算法，epoch=2024-01-01）。
- `config/state/id-map.json` 记录 `legacyTable:legacyId → whaleId`。
- 重跑：已映射则跳过插入；按 `bus_no`/`code` 在目标库探测已有行则 **LINK**。
- P3 可按 `Order.FromDate` / `ToDate` / `MaxOrders` / `BatchSize` 限流。

---

## 4. 执行顺序

```text
1. 探测源/目标连通
2. P1：OD → 项目 AD → 套餐 AD → children → AOL → common_result
3. P2：customer → patient
4. P3：order → encounter+ext → project_rel → SR+ext → item_rel → observation
```

---

## 5. 验收

| 检查 | 期望 |
|------|------|
| OD 数 ≈ 未删小项数 | `cln_observation_definition` where category=exam_item |
| 项目 AD | `category_code=PEIS` 且无 children_flag 或 false |
| 套餐 AD | `children_flag=true` 且 children 行数对齐 |
| AOL | 每条 project_item 有对应 link |
| Patient | `bus_no=customer_code` 可查 |
| Encounter(PE) | `class_enum=PE` 且 `bus_no=order_number` |
| SR + ext | 每张单项目行有对应 SR；`peis_service_request_ext` 齐 |
| Observation | 小项结果可按 encounter_id 查回 |
