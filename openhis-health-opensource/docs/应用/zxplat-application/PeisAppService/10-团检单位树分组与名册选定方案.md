> **编码**：PEIS-GRP-TREE-PKG-001

> **页面**：团检筹备 `/peis/group-check` · **AS**： AS-PEIS-GRP-001  
> **登记**： AS-PEIS-REG-001  
> **收费**：团检套餐仍锚合同、后结；加项走 AS-PE-FIN-001  
> **小程序**：[openhis-pro-mini](../../../openhis-pro-mini/) + [zxplat-module-miniapp](../../../模块/zxplat-module-miniapp/00-功能清单.md)

本文是团检筹备改造的**产品真源**。现行 AS 仍写「批次 + 一批次一套餐 + 名册挂批次」；成码后以本文为准回写 AS/SDD/Flyway，禁止再按旧批次单套餐口径加功能。

---

## 1. 背景

### 1.1 现状

```
单位（平铺）
  └── 合同（可绑多个套餐）
        └── 批次（只能选合同里的 1 个套餐）
              └── 名册（人跟着批次，套餐 = 批次那一个）
```

建单、到检、`peis_encounter_ext.group_batch_id`、团检挂费均按「一人一批次、一批次一套餐」。

### 1.2 目标

1. 单位要有树：单位可有子单位。  
2. 「批次」改为**体检分组**：每组有多个可选套餐。  
3. **按合同导入名册**；合同名册上可为每人勾选可选套餐；建单前必须选定其中一个。  
4. 选定功能在**登记台和小程序**都要支持；小程序选定即建单。

### 1.3 非目标（本方案不改）

| 项 | 说明 |
|----|------|
| 团检收费主路径 | 仍免收费建单 `ENROLLED` + 合同后结 `markContractPaid`；FIN-002 批量收费保持冻结 |
| 加项 | 仍走筹备/登记台 `adjustRosterServiceRequests` + 个检收费页「团检加项」 |
| Campus 真源 | 学生/教职工主数据仍在 Campus；本方案不替代 [02-教职工导入同步Campus方案](../peis-import/02-教职工导入同步Campus方案.md) |
| 职业病 / 问卷 | 仍 P2/范围外 |

## 2. 已确认口径（不得 Silent 改）

| # | 项 | 定稿 |
|---|----|------|
| 1 | 分组 | **给人分**。人必须进组，再从**该组**可选套餐里勾选 |
| 2 | 多套餐 | 名册上是**可选集合**；建单前必须**选定其中一个** |
| 3 | 建单形态 | 一次体检 = **一张体检单、一个套餐**；不合并多套餐项目，不拆成多张单 |
| 4 | 小程序选定 | **选定即建单**（生成流水）；到院只做到检 |
| 5 | 登记台 | 未在小程序建过单的人：先选定再当场建单 |
| 6 | 改套餐 | **到检前**小程序和登记台都能改（流水号不变，项目按新套餐重建）；**到检后不能改** |
| 7 | 导入 | 先选合同下的**默认分组**；Excel「分组」列可覆盖；对不上则该行失败 |
| 8 | 单位树与合同 | 合同可挂**任意节点**；挂在父单位的合同，**下级单位的人也能用**；名册记下本人所在节点 |
| 9 | 可选套餐默认 | Excel 可带「套餐」列（可多个）；**没有该列则默认勾上该组全部套餐** |
| 10 | 唯一 | 同一人同一时段**全院只能有一条在册团检名册**；再导入第二个合同/组直接失败 |

附加约定（定稿时默认真源，未单列投票）：

- 分组可选套餐必须 ⊆ 合同套餐池。  
- 每人可选套餐必须 ⊆ 该组可选套餐。  
- 组内仅 1 个套餐时，选定步骤仍要确认一次，避免误建。  
- 到检后换套餐：走取消体检；已收费须先退费（沿用现规则）。  
- 仍禁止同一人同时两张在检 `Encounter(PE)`。

## 3. 目标模型

```
单位树（peis_group_company.parent_id）
  └── 合同（挂任意节点；覆盖该节点及全部下级）
        ├── 合同套餐池（peis_group_contract_package）
        └── 体检分组（原 peis_group_batch，主键沿用）
              ├── 本组可选套餐（peis_group_batch_package ⊆ 合同套餐池）
              └── 名册（人属于组；仍挂 batch_id）
                    ├── 可选套餐（peis_group_roster_package ⊆ 本组套餐）
                    └── 已选定套餐（0 或 1；选定即建单）
```

### 3.1 术语

| 术语 | 口径 |
|------|------|
| **单位节点** | 树上一行；可有父/子。合同挂点与名册「本人单位」可以不同（人在子公司，用总公司合同） |
| **合同覆盖范围** | 合同 `company_id` 及其全部子孙节点 |
| **体检分组** | 原「批次」。给人分组，不是套餐目录 |
| **可选套餐** | 名册上勾选的集合，尚未决定本次用哪一个 |
| **选定套餐** | 建单使用的那一个；写入名册 `selected_package_activity_id` 与就诊套餐快照 |
| **在册** | 未软删的 `peis_group_roster` 行（不论是否已建单） |

### 3.2 主路径

```
筹备：单位树 → 合同（套餐池）→ 分组（本组套餐）→ 按合同导入名册（进组 + 可选套餐）
        ↓
选定其中一个套餐 ──► 立刻建单（ENROLLED）──► 到检 ──► 分科
        ↑                    │
   小程序 / 登记台            └─ 到检前可换套餐（同流水，重建 SR）
```

## 4. 页面与交互

路由仍为 `/peis/group-check`，Tab 调整：

| Tab | 原 | 现 |
|-----|----|----|
| 单位档案 | 平铺列表 | **左侧树 + 右侧详情**；可建子单位 |
| 合同与分组 | 合同与批次 | 合同（套餐池、金额、后结）+ **体检分组**（多套餐） |
| 名册导入 | 先选批次 | **先选合同**，再选默认分组；按合同看全员，可筛分组 |

点选树节点后，合同/分组/名册按「该节点 + 下级」过滤。

### 4.1 名册操作

- 可改所属分组（目标组须同合同；可选套餐超出新组的要裁掉或失败提示）。  
- 可改每人可选套餐（多选，⊆ 当前组）。  
- 未选定不能建单。  
- 已建单未到检：可换选定套餐（同 §2#6）。  
- 已到检：不可换套餐。

### 4.2 Excel 模板（在现有学生/教职工/企事业模板上加列）

| 列 | 必填 | 规则 |
|----|------|------|
| 分组 | 否 | 有则覆盖导入时选择的默认组；合同下无此组名 → 该行失败 |
| 套餐 | 否 | 可多个（顿号/逗号分隔）；必须 ∈ 该行最终所在组的可选套餐；无列 → 勾上该组全部套餐 |

### 4.3 登记台

- 团检反查上下文带：合同、分组、可选套餐列表、是否已选定、是否已建单、是否已到检。  
- 未建单：选定 → `confirmBatchEnrollment`（免收费）。  
- 已建单未到检：换套餐（重建项目，不换 `encounterId` / 流水号）。  
- 已到检：只读套餐。

### 4.4 小程序

- 受检者须已绑定 Patient，且能命中**唯一**在册团检名册。  
- 列出可选套餐 → 选定 → **当场建单**。  
- 到检前可再选其它可选套餐（同登记台换套餐）。  
- 到检后入口关闭。  
- 实现落点：miniapp BFF + `openhis-pro-mini` 团检页；**不**在 PEIS 域新写 `AS-PEIS-MOB-*`。

## 5. 业务规则（草案，成码写入 AS BR-*）

| 编号 | 规则 |
|------|------|
| **BR-GRP-TREE-01** | 单位 `parent_id` 不得成环；删除有未删子节点或未删合同时拒绝 |
| **BR-GRP-TREE-02** | 合同 `company_id` 可为任意未删节点；覆盖 = 该节点 ∪ 子孙 |
| **BR-GRP-GRP-01** | 分组必属合同；本组套餐 ⊆ 合同套餐池且至少 1 个 |
| **BR-GRP-ROS-01** | 名册必属分组；人必须进组，禁止只挂合同不下组 |
| **BR-GRP-ROS-02** | 同一 `patient_id`（无档则身份证/学号/工号归一）全院同时只能有一条未删名册 |
| **BR-GRP-PKG-01** | 每人可选套餐 ⊆ 该组可选套餐；空集合不允许建单 |
| **BR-GRP-SEL-01** | 未选定套餐禁止建单 |
| **BR-GRP-SEL-02** | 选定即建单：一张 `Encounter(PE)` + ext（`group_flag`、`group_batch_id`、选定套餐快照） |
| **BR-GRP-SEL-03** | 到检前可改选定套餐：流水号不变，SR/套餐快照按新套餐重建；未结团检套餐费跟选定套餐走 |
| **BR-GRP-SEL-04** | 到检后禁止改套餐 |
| **BR-GRP-PAY-01** | 沿用现行：`ENROLLED`/`PAID` 可到检分科；免收费豁免真实收银 |

## 6. 数据与迁移

> Flyway 真源见 [06-Flyway-表结构.md](./06-Flyway-表结构.md)。现网已有 peis V3（日结菜单）；本方案增量脚本编号在成码时与模块历史对齐，**清库重建须并入 V1 最终态**。

### 6.1 表变更（逻辑）

| 对象 | 变更 |
|------|------|
| `peis_group_company` | 增 `parent_id`（可空 = 根）；索引 `(parent_id)` |
| `peis_group_batch` | **保留主键**，语义改为体检分组；`package_activity_id` 降为兼容列（= 本组第一项） |
| `peis_group_batch_package` | **新表**：`batch_id` + `package_activity_id` + `sort_order` |
| `peis_group_roster` | 增 `company_id`（本人单位节点）、`selected_package_activity_id`；`batch_id` 仍必填 |
| `peis_group_roster_package` | **新表**：`roster_id` + `package_activity_id` |
| `peis_encounter_ext` | `group_batch_id` 继续指向分组；套餐快照以选定套餐为准 |

### 6.2 历史数据

| 旧 | 新 |
|----|----|
| 单位无父 | `parent_id` 空（根） |
| 批次一个套餐 | 写入 `peis_group_batch_package` 一行；兼容列保持该套餐 |
| 名册 | `selected_package_activity_id` = 原批次套餐；可选集合 = 该套餐；`company_id` = 合同单位（无更细节点时） |

界面文案「批次」一律改为「体检分组」；API 字段 `batchId` 可暂留以免打断，OpenAPI 注释标明「分组」。

## 8. 实施顺序

| 步 | 内容 | 可验收 |
|----|------|--------|
| 1 | 库表 + 单位树 + 分组多套餐（筹备 PC） | 树维护；分组勾多个套餐 |
| 2 | 按合同导入（默认组 + Excel 分组/套餐列）+ 每人可选套餐 + 全院名册唯一 | 导入失败行可解释 |
| 3 | 选定即建单（登记台）+ 到检前换套餐 | 未选定不能建单；到检后不能换 |
| 4 | 小程序选定建单 / 换套餐 | 与 PC 同一名册、同一流水 |
| 5 | 对账、挂费、导检文案对齐选定套餐 | 对账按分组展开 |

前三步 PC 即可按新口径跑团检；小程序紧随第 4 步。
