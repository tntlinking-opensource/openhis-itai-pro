# PeisAppService · 菜单与主页面 / AppService 映射

> **原则**：**1 主页面 = 1 个 AppService**；子页（Tab、弹窗、列表查询页）不单独建 AS，收敛到所属主页面契约。  
> **遗留对照**：`sdpeis/src/client/business/src/router/index.js`（NENU 院点 **约 25 个启用** 菜单 + 大量注释菜单）  
> **AS 索引**：[03-AppService详细设计.md](./03-AppService详细设计.md) · **IF 真源**：[00-功能清单.md](./00-功能清单.md)  
> **版本**：v1.1 · **日期**：2026-07-19

---

## 一、菜单总览

```text
健康体检（菜单树：14 个 PEIS 核心 + 1 个 health 收费挂载）
├── 登记与团检（3）
│   ├── 个检登记              → PeisPersonalRegistrationAppService
│   ├── 体检收费              → PhysicalExamChargeAppService（health · AS-PE-FIN-001）
│   └── 团检管理              → PeisGroupCheckAdminAppService
├── 诊台与复查（4）
│   ├── 分科诊台              → PeisDeptExamDeskAppService
│   ├── 总检诊台              → PeisMasterReviewDeskAppService
│   ├── 复查管理              → PeisRecheckManageAppService
│   └── 危急值处理            → PeisCriticalValueDeskAppService
├── 报告（2）
│   ├── 报告打印              → PeisReportPrintAppService
│   └── 报告发放              → PeisReportGrantAppService
├── 体检配置（3）
│   ├── 体检目录              → PeisCatalogConfigAppService
│   ├── 诊断与表达式          → PeisDiagnosisConfigAppService
│   └── 系统参数              → PeisModuleSettingsAppService
├── 集成（1）
│   └── 外发集成配置          → PeisIntegrationConfigAppService
└── 统计（2）
    ├── 体检业务统计          → PeisStatisticsAppService
    └── 主任业务查询          → PeisDirectorDashboardAppService

无独立菜单（2 个 AppService，由事件/内嵌触发）
├── 预约衔接                → PeisBookingBridgeAppService
└── LIS/PACS 外发           → PeisLisPacsDockAppService
```

**PEIS 核心菜单数**：**14**（每个对应一个 PEIS Vue 主路由）。  
**health 挂载菜单**：**+1**「体检收费」（`/peis/charge`，**非** `AS-PEIS-FIN-*`）。  
**无页面 AS**：**2**（BKG-001、INT-001；不占菜单树）。

## 七、NENU 院点 P0 最小菜单集（对齐当前启用路由）
