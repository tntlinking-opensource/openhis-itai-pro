## 1. 定位

ZXPlat 生态内 **健康体检（FR-PE / M-23）** 应用层。一次完整体检以 `**Encounter(class=PE)`** 为锚，套餐展开为 `ServiceRequest[]`，小项结果 `**cln_observation**`，总检 `**DiagnosticReport**` + `**cln_diagnostic_report_index**`。

**遗留 `PeisCheckOrder`** 仅迁移对照，**不作**新代码聚合根。

---

## 2. 模块边界


| 能力                                          | 归属                                |
| ------------------------------------------- | --------------------------------- |
| 预约、到检、导检队列                                  | **booking**                       |
| 标本/检查执行、仪器结果                                | **LIS / PACS**（或 adapter 现场 PACS） |
| 患者、Encounter、ChargeItem、**cln_observation** | **health**                        |
| 分科/总检编排、PEIS 扩展                         | **health-application/peis**       |
| 团检合同 UI                                     | PEIS；名册 **Campus** Client           |

| 层级   | 模型                                                                                             |
| ---- | ---------------------------------------------------------------------------------------------- |

| 一次体检 | `Encounter(PE)` + 多模型进度                                                                        |

## 4. Maven

> **PEIS 非增值包**：无独立 `peis-starter`；随 **zxplat 主应用** 装配。

```text
zxplat/
  zxplat-domain/clinical/     cln_observation、cln_diagnostic_report_index、…
  zxplat-domain/custom/       activityobservationlink（DM-CUS-013）、…
  zxplat-domain/peis/         peis_* 
  health-application/peis/    Peis*AppService
  peis-adapter/               第三方入站 INT-05、sdpeis 兼容出站
```

| 配置项 | 说明 |
|--------|------|
| `zxplat.modules.peis.enabled=true` | 挂载 PEIS AppService、`/api/app/peis*` 路由 |
| `zxplat.modules.peis.adapter.enabled=true` | 挂载 peis-adapter 入站（师大 PACS 联调） |

前端：health 主前端 Module 注册 `/peis/*` 菜单（见 [02-交互说明](./02-交互说明.md)），**不**依赖独立 starter JAR。

## 5. 院点 Profile 与部署分工

> **用户确认（2026-06-27，v1.7 更正）**  
> - **「外发 LIS」** = **外送金域**（[LisKingMed](../../../模块/zxplat-module-lis-kingmed/)），**不是**「院内不发 LIS 申请」。  
> - **院内 LIS**：朝阳、师大均可走常规 LisWorkItem（采样/上机/审核）；PEIS **INT-01** 仍创建 **本院** WorkItem。  
> - **金域外送**：**东北师大** **2026-09-01 之前**落地（与 PEIS 同批联调）；**朝阳** 金域为 LIS 二期（约 8 月，见 [LIS README](../LisAppService/README.md)），**无 PEIS**。  
> - **PEIS、PACS（adapter）、小程序、自助机**：师大 **2026-09-01** 切换。

### 5.1 模块 × 院点

| Module | 首版院点 | 节点 / 说明 |
|--------|----------|-------------|
| **LIS（本院检验）** | 朝阳 + 师大 | 常规 LIS；PEIS INT-01 → **LisWorkItem**（一体化同 `activity_id`） |
| **金域外送** | **东北师大** | [LisKingMed EXT](../../../模块/zxplat-module-lis-kingmed/00-功能清单.md)；**9/1 前**完成；即口语「外发 LIS」 |
| **金域外送** | 朝阳 | **8 月二期**（非 PEIS 路径） |
| **PEIS** | 东北师大（NENU） | **2026-09-01** 切换 |
| **PACS** | 东北师大（adapter） | INT-01 → PacsWorkItem |
| **微信小程序** | 东北师大 | 同批 |
| **自助机** | 东北师大 | 同批 |

### 5.2 检验 / 检查链路口径（避免歧义）

```text
PEIS 登记/分科
  └─ INT-01（P0）→ 本院 LisWorkItem / PacsWorkItem  ← 朝阳/师大均有 LIS；师大检查走 PACS adapter
       └─ LIS AUD-05 发布 → projectFromLis → cln_observation（LIS 主路径）
       └─ PACS REP-07 审核通过 → projectFromPacsSummary → cln_observation（PACS 主路径）
       └─ 漏投影 → PEIS INT-03 / DES-08 补偿刷新
       └─ 若项目标记外送金域（SFWJ / AD 扩展）
            └─ LisKingMed EXT → 结果回写 lis_observation → AUD-05 后同上投影
```

### 5.3 师大 PEIS 技术口径

| 项 | 说明 |
|----|------|
| **切换节点** | **2026-09-01**；P0 在此前完成联调验收 |
| **院内 LIS** | INT-01 → LisWorkItem；**AUD-05** 主路径投影 `cln_observation` |
| **院内 PACS** | INT-01 → PacsWorkItem；现场 **pacs-adapter** 对接；审核完成后 **REP-07 等价编排** 投影 CLN（见 [Pacs 01 §4.2](../PacsAppService/01-概要设计.md#42-东北师大-nenu-profile)、[08-Extension §3.2](./08-Extension与外部依赖.md#32-pacs-adapter-院点--cln-投影)） |
| **补偿** | INT-03 / DES-08 仅漏投影时刷新 |
| **金域** | 9/1 前与 [LisKingMed](../../../模块/zxplat-module-lis-kingmed/) 联调（EXT-01～07） |
| **Campus** | 团检名册读 **Campus Client**（STU/STF） |

## 7. LIS/PACS/PEIS 跨模块架构约定

> 决策摘要与 LIS 侧全文见 [LisAppService/01 §10](../LisAppService/01-概要设计.md#10-lispacspeis-跨模块架构约定)。本节为 **PEIS 落点**。

### 7.1 决策摘要（PEIS 相关）


| #   | 议题          | PEIS 落点                                                                      |
| --- | ----------- | ---------------------------------------------------------------------------- |
| D1  | Observation | P0 `**cln_observation`** + `source_observation_id` → `lis_observation`       |
| D2  | DR index    | 总检 `MAS-04` final → upsert `**cln_diagnostic_report_index**`                 |
| D3  | 无 map       | **无** `peis_*_project_map`；外发同 `activity_id`                             |
| D4  | Maven       | `zxplat-domain/peis`、`health-application/peis`、`peis-adapter`；**无** peis-starter |
| D5  | INT 编号      | **无 IF-PEIS-INT-02**；条码绑定并入 **INT-01**；**AS-PEIS-INT-002** = 外发配置页           |
| D6  | ext 表       | `**peis_service_request_ext` 无 barcode**；条码反查 WorkItem                   |
| D7  | P0 DM       | `Encounter(PE)`、`DM-CLN-005` Observation、`DM-CLN-006` DR index               |
| D9  | 院点分工 | **院内 LIS** 朝阳+师大；**金域外送** 师大 **9/1 前**（「外发 LIS」= 金域，非不发院内申请）；PEIS/PACS/小程序/自助机→师大 |


### 7.2 Observation 与 CLN（D1 / D7）

- **禁止**新建 `peis_observation` 平行事实表
- 分科录入 / LIS 回写：`**cln_observation`**；LIS 结果须 `**source_observation_id**`
- P0 同步建设 `**ObservationDefinition**`（小项目录，原 `sys_check_item`）

### 7.3 外发与扩展表（D5 / D6）


| 原编号        | 调整                                     |
| ---------- | -------------------------------------- |
| INT-01     | 保留；子能力 **条码绑定**（真源 LIS/PACS WorkItem）  |
| ~~INT-02~~ | **废止**独立 IF                            |
| INT-07     | 外购 LIS/PACS 连接（**AS-PEIS-INT-002** 页面） |


```text
peis_service_request_ext
  service_request_id  PK/FK
  exec_status_enum
  lis_dispatch_enum
  pacs_dispatch_enum
  （无 barcode）
```

### 7.4 Maven 落点（D4）

与 LIS/PACS 同在 `**zxplat**` 子包；编排为主，临床事实落 **zxplat-domain/clinical**。
