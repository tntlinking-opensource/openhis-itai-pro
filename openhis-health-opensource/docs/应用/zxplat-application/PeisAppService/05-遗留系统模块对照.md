## 四、核心实体对照

| 遗留表/PO 前缀 | 领域概念 | ZXPlat 落点 |
|----------------|----------|------------|
| `peis_check_order` | 一次完整体检 | **`Encounter`（class=PE）** + 可选 `peis_encounter_ext` |
| `peis_check_order_project_rel` | 体检项目实例 | **`ServiceRequest`** + `peis_service_request_ext` |
| `peis_check_order_item_rel` | 小项结果 | **`Observation`**（→ `ObservationDefinition`） |
| `peis_check_order_diagnosis_rel` | 分科诊断建议 | **`peis_dept_conclusion`** 或 DR 章节；可选 `Condition` |
| `sys_check_package` / `sys_check_project` | 套餐/项目定义 | **`ActivityDefinition`** |
| `sys_check_item` | 小项定义 | **[`ObservationDefinition`](./DM-CLN-005-ObservationDefinition-临床观察定义.md)** |
| `peis_customer` | 体检客户 | **`Patient`** |
| `peis_company` / contract / group | 团检 | booking `bkg_group_checkup_*` + `Organization` |
| `peis_lis/pacs_*_compare` | 外系统码表（遗留） | **不需要**（一体化）；迁移脚本 / **adapter** 专用 |
| `peis_lis/pacs_check_result` | 外系统结果缓存 | 投影到 **`Observation`** 或引用 lis/pacs Obs |

> 完整映射与遗漏清单：[04-FHIR领域模型.md](./04-FHIR领域模型.md) §8。
