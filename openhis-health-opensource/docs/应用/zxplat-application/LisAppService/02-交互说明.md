# LisAppService · 菜单与主页面 / AppService 映射

> **原则**：**1 主页面 = 1 个 AppService**；子页（弹窗、审核页、编辑页）不单独建 AS，收敛到所属主页面契约。  
> **遗留对照**：`lis/WebRoot/WEB-INF/jsp/business/**/*List.jsp`（62 个 List 页合并为 18 个 ZXPlat 主页面）  
> **AS 索引**：[03-AppService详细设计.md](./03-AppService详细设计.md)  
> **范围真源**：[00-功能清单.md](./00-功能清单.md)  
> **版本**：v2.1 · **日期**：2026-06-22

│   ├── 结果审核            → LisResultAuditAppService      ← 含 自动审核规则 / 审核分级双签

│   └── 无主结果绑定        → LisOrphanResultAppService
├── 检验配置（7）
│   ├── 检验目录维护          → LisCatalogConfigAppService
│   ├── 标本与参考范围      → LisSpecimenRefConfigAppService
│   ├── 仪器与能力          → LisDeviceConfigAppService     ← 含 双向通讯配置 / 试剂批号追溯
│   ├── 合管与试管方案      → LisMergeProfileConfigAppService
│   ├── 报告版式            → LisReportLayoutConfigAppService
│   ├── 条码与打印机        → LisBarcodePrintConfigAppService
│   └── LIS 系统参数        → LisModuleSettingsAppService
├── 质控（1）
│   └── 质控管理            → LisQcAppService
└── 运营管理（3）
    ├── 接口日志            → LisIntegrationLogAppService
    ├── 对账管理            → LisReconcileAppService
    └── 统计报表            → LisStatisticsAppService       ← 含 TAT 统计报表

**菜单数**：核心 **18** + 金域 **2** + 采集 **1** = **21 个一级菜单项**。

## 三、新增子模块与主页面归属（v2.1）

> v2.1 新增的 IF 族不单独建菜单，作为子 Tab / 弹窗 / 配置区归属到已有主页面。

| 新增模块 | IF 族 | 归属主页面 | 交互形式 |
|----------|-------|------------|----------|
| **TAT 时效监控** | SAM-TAT | 样本管理 | 样本管理页顶部概览区（超时计数 + 颜色预警）+ TAT 统计 Tab；TAT 配置入口在 LIS 系统参数 |
| **标本转运交接** | SAM-TRANS | 样本管理 | 样本管理页"转运交接"Tab（送出登记 / 签收确认 / 交接追溯） |
| **自动审核规则** | AUD-AUTO | 结果审核 | 结果审核页"自动审核规则"子 Tab（规则配置 + 执行日志） |
| **审核分级双签** | AUD-REVIEW | 结果审核 | 结果审核页内置审核流程（初级审核 → 高级审核），双签配置在 LIS 系统参数 |
| **报告召回与修订** | REP-REVISE | 报告管理 | 已发布报告"召回修订"操作按钮 → 弹窗编辑 → 重新审核 |
| **试剂批号追溯** | RES-REAGENT | 仪器与能力 | 仪器详情页"试剂批号"子 Tab（厂商/批号/开瓶效期） |
| **双向通讯配置** | RES-BIDI | 仪器与能力 | 仪器详情页"双向通讯"子 Tab（C++ 程序对接配置） |

### 3.1 双向通讯配置（BIDI）详细说明

> **仪器通讯由独立的 C++ 程序负责**（串口/TCP 采集、HL7/ASTM 协议编解码），LIS 系统通过配置接口对接 C++ 程序。

```text
┌──────────┐   worklist下发   ┌──────────────┐   HL7/ASTM   ┌──────────┐
│ zxplat/lis │ ◄──────────────► │  C++ 通讯程序  │ ◄──────────► │ 检验仪器  │
│ (Java)   │   结果回传        │ (边缘服务)     │   原始协议    │          │
└──────────┘                  └──────────────┘              └──────────┘
```

| 配置项 | 说明 |
|--------|------|
| C++ 程序连接信息 | 服务地址、端口、认证 Token |
| worklist 格式 | HL7 v2.x ORM / ASTM 指令模板 |
| 通道-项目映射 | `lis_device_channel` 表，C++ 程序按通道号解析 |
| 心跳与重连 | C++ 程序定时上报心跳，LIS 记录 `DeviceMetric` |
| 结果回传 | C++ 程序调用 RES-01 ingress API，LIS 落库 Observation |

**交互实现**：

- **配置维护**：`仪器与能力` 主页面 → 选中仪器 → "双向通讯"子 Tab → 配置上述参数，存入 `lis_device_channel` 扩展字段
- **worklist 下发**：审核/上机环节触发 → health-application/lis 调用 C++ 程序 HTTP API（由 lis-starter 注入 URL 配置）
- **结果接收**：C++ 程序 → RES-01 ingress API（走 lis-adapter HTTP 接收，与现有 RES-01 同入口）
- **状态监控**：`接口日志` 页面可查看 C++ 程序与仪器之间的通讯日志（`AuditEvent`）
