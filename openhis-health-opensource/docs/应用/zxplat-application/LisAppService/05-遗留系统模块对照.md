# LisAppService · 遗留 LIS 模块对照

> **遗留路径**：`D:/0.product/lis/src`

## 六、核心表 → lis-domain 实体（草案）

| 遗留表 | 建议实体 | 关键字段语义 |
|--------|----------|--------------|
| `l_laborder` | **`LisWorkItem`** + **`LisWorkItemOrder`** | `BARCODE`→工单；`groupCode` 的 `+`→多条 orderLink |
| `L_LABORDER` | `LisLabOrderItem` | 申请明细行 |
| 结果明细表（DyylMapper） | `LisResultItem` | 项目、值、单位、参考范围 |
| `l_critical` | `LisCriticalValue` | 危急值 |
| `L_BAOBIAO` | `LisReportTemplate` 或 report 模板 | 报告版式 |
| `WBS_LOG` | `LisIntegrationLog` | 接口报文 |
| 仪器通道表 | `lis_device_channel` | 通道号、仪器 ID、项目映射 |
| — | `lis_device_capability` | 仪器可检项目 + 试管方案（合管） |
| — | `lis_merge_profile` / `lis_tube_scheme` | 合管方案、试管方案 |

**关联 health**（不落 lis 库重复存储）：

- `encounter_id` ← HIS 就诊  
- `service_request_id` ← `ServiceRequest.id`（经 `LisWorkItemOrder`，并管时 N:1）  
- `patient_id` ← `Patient.id`  
- `activity_id` / 项目码 ← `ActivityDefinition`
