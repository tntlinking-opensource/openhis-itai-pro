# 卫统 N041 住院病案首页 CSV 导出 — 字段对照

> **渠道**：`upload.weistat`（与 `upload.medcas` / `upload.hqms` 平级，**独立管道**）  
> **规范真源**：《国家卫生直报系统 2021 数据接口规范》表号 **N041**（西医/综合医院）  
> **业务参照**：`guoji-jsp-his` `MainMRInterfaceController.exportCSV` + `MainMRinterfaceServiceImpl.cvsExport_N041`（仅含义；成码以 ZXPlat 首页 + 本表为准）  
> **数据源**：病案首页表（`mrms_case_record` / `mrms_case_record_homepage` / 诊断 / 手术）+ 费用快照（与 4401/清单同源 `fees`←落库列）  
> **诊断编码**：出站用**国临**（`diagCode`）；医保码仅用于 medcas 上传  
> **手术编码**：出站用首页 `oprnOprtCode`（国临）。**禁止**用诊疗目录 AD.`yb_no`（费用码）。4401/4101A 出站才读**同一条** `cln_procedure_definition` 上的 `yb_no`（医保手术码；一行两码，不是诊断那种跨目录对码）。  
> **版本**：v1.7 | **日期**：2026-10-07 | **院点启用**：国基 `H22010202493`

## 1. 架构口径

```text
HomepageAggregate（loadPage 同口径）
        └── WeistatN041RowAssembler → N041_{机构名}.csv（232 列）
```

- **禁止**与 HQMS 共用列 mapper。
- HQMS 见 [12-HQMS导出-字段对照.md](./12-HQMS导出-字段对照.md)（独立管道；籍贯省 A23C 为 RC036，与本表 GG 中文地名不同）。
- 文件名：`N041_{医院名称}.csv`；编码 **GBK**（中文 Excel 双击可正常看中文；对齐国基 HQMS 写出）；列分隔 `,`；行尾 `\r\n`。  
- **勿**用无 BOM 的 UTF-8 冒充「Excel 友好」：Excel 默认按系统 ANSI(GBK) 打开时，UTF-8 中文会乱码，且多字节可能被误读成逗号导致**整行错列**（看起来像字段对不上）。

## 2. 列序真源（232）

列名顺序与国基 `cvsExport_N041` header 一致（`USERNAME` … `QTF`）。  
完整列清单见实现类 `WeistatN041Columns.ORDERED`（代码与文档同真源；改列序须同步本文件与单测）。

### 2.1 其他诊断物理列交错序

CSV 物理序（非 1→15）：`8,1,9,2,10,3,11,4,12,5,13,6,14,7,15`  
逻辑槽：`discharge_other` 按 `sortNo` 升序取第 1～15 条 → 再按上列写入 `QTZD{i}/JBDM{i}/RYBQ{i}`。

### 2.2 手术槽

最多 **7** 台；按 `sortNo` 升序取前 7。  
每槽 11 列：`SSJCZBM{n}…MZYS{n}`。  
- `SSJCZBM{n}`：首页 `oprnOprtCode`（国临）  
- `SSJCZRQ{n}`：`oprnDate`，缺则 `oprnTime` 取日 → `yyyyMMdd`  
- `YZ{n}` / `EZ{n}`：首页 `asit1Name` / `asit2Name`（对齐国基 I助/II助；空则空串）

## 5. 已知缺口（本期空列 / 后续增字段）

| # | 缺口 | 处理 |
|---|------|------|
| G1 | 新生儿出生/入院体重 | 空；若业务要报再增首页列 |
| G2 | 手术 I助/II助 | **已关闭**：`YZ{n}`/`EZ{n}` ← `asit1Name`/`asit2Name` |
| G3 | 国籍/民族/职业/婚姻卫统专用对照表 | 本期直出院内码；直报拒收再补 `weistat` 对照（勿照搬国基 `CHN`/`20` 等未核实码） |
| G4 | 切口愈合若为医保组合码 | 直出；与 N041 分列不一致时再拆对照 |
| G5 | 科室未维护 `caty` | RYKB/CYKB 空；须在科室维护「科别」后再导 |
| G6 | 首页主诊仅中医、其他诊也无西医 | ZYZD 仍出中医行（避免整列空）；应补西医主诊 |

## 6. IF / AppService

| 项 | 值 |
|----|-----|
| AppService | `MrmsWeistatExportAppService` |
| serviceName | `mrmsWeistatExport` |
| 方法 | `exportN041Csv` |
| Request | `caseRecordIds: Long[]`（多选病案主键） |
| Response | `fileName` / `contentType=text/csv;charset=UTF-8` / `body` / `exportedRowCount` |

Gate：`caseRecordIds` 非空；单批上限 200；逐条 `loadPage` 组装，缺首页仍导出空值列（不静默跳过，便于直报侧发现缺数）。
