# ZXPlat MRMS

ZXPlat MRMS（病案管理）是 **health 内嵌子域**。

> **菜单与路径真源**：[10-病案首页交付任务清单.md](./10-病案首页交付任务清单.md) 附录 A（v1.8+）。

## 菜单 ↔ 前端 ↔ 后端

## 应用层分包

```text
application/mrms/
├── caserecord/
│   ├── homepage/   # 唯一 AppService：列表 / 编辑 / 医生站查档
│   ├── coding/
│   └── volume/
├── settlelist/     # 结算清单只读预览（双码对照；ICU/输血占位）
│   └── service/MrmsSettleListPreviewAppService
├── qcworkbench/
├── borrow/
├── outpatientemr/  # 门诊病历查询（encounter 锚点；接诊可编辑；归档病例→LOCKED）
├── inpatientemr/   # 住院病例查询（encounter 锚点；相关医生可编辑；病例/病案/4401 只读）
│                   # 打开病历弹层 encounterScoped：仅本就诊文书，非患者历史
│                   # 归档病例/解档 → MrmsClinicalCaseArchiveSupport（shared.mrms）
│                   # 角色 ROLE_MRMS_ADMIN（V11）
└── upload/
    ├── medcas/     # 医保 4401 / 4101A / 4102 / 4103
    │   ├── service/MrmsCaseRecordUploadAppService
    │   └── support/InsuranceEncounterLoader, InsuranceEncounterContext, Upload*Validator
    ├── hqms/       # HQMS CSV：MrmsHqmsExportAppService
    └── weistat/    # 卫统 N041 CSV：MrmsWeistatExportAppService
```

HTTP：`POST /api/app/mrmsCaseRecordHomepage/{queryPage|getByEncounterId|loadPage|…}`

卫统导出 HTTP：`POST /api/app/mrmsWeistatExport/exportN041Csv` · 前端 `api/mrms/weistat-export.ts` · 国基开 `homepage-weistat-export.config.ts`  
HQMS 导出 HTTP：`POST /api/app/mrmsHqmsExport/exportHqmsCsv` · 前端 `api/mrms/hqms-export.ts` · 同上配置 `MRMS_HOMEPAGE_HQMS_EXPORT_ENABLED`

结算清单预览 HTTP：`POST /api/app/mrmsSettleListPreview/loadSettleListPreview` · 前端 `api/mrms/settle-list.ts` · 路由 `/mrms/settle-list/:caseRecordId?`

双码解析：`application/shared/mrms/MedcasDualCodeResolveSupport`（4401/4101A Mapper 与 settlelist 共用；西医 `requireYbOutbound`，诊断含中医走 `requireDiagnosisOutbound`）

住院病例查询 HTTP：`POST /api/app/mrmsInpatientEmrQuery/queryPage|archiveClinicalCase|unarchiveClinicalCase` · 前端 `api/mrms/inpatient-emr.ts`
门诊病历查询 HTTP：`POST /api/app/mrmsOutpatientEmrQuery/queryPage|archiveClinicalCase|unarchiveClinicalCase` · 前端 `api/mrms/outpatient-emr.ts`

补传 HTTP：`POST /api/app/mrmsCaseRecordUpload/{upload|retry|queryUploadPage|…}` · 前端 `chs/api/medcas-ops.ts`

## 前端目录

```text
views/mrms/{homepage,settle-list,qc-workbench,borrow,outpatient-emr,inpatient-emr,volume}
chs/{medcas-ops, api/medcas-ops.ts}
api/mrms/case-record-homepage.ts   # 列表/编辑/查档统一入口
api/mrms/settle-list.ts            # 结算清单预览 → /mrmsSettleListPreview/*
api/mrms/outpatient-emr.ts         # 门诊病历查询 → /mrmsOutpatientEmrQuery/*
api/mrms/inpatient-emr.ts          # 住院病例查询 → /mrmsInpatientEmrQuery/*
```

Flyway：`V25` 菜单归拢 + homepage/volume/medcas-ops + 门诊 path → `/mrms/outpatient-emr`（`whale_menus`）；住院病例查询菜单见健康库种子（`MrmsInpatientEmrQuery` → `/mrms/inpatient-emr`）；**`V11__mrms_settle_upload.sql`**（结算清单字段 + 内置 `ROLE_MRMS_ADMIN` + 门诊权限名对齐 `EmrQuery`）。
