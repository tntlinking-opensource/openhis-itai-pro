## 1. 硬规则

| # | 规则 |
|---|------|
| R1 | **一个前端页面（或固定工作站场景）= 一个主 AppService** |
| R2 | `serviceName` = 类名去掉 `AppService` 后首字母小写（ZXPlat 自动注册） |
| R3 | 全部接口 **`POST /api/app/{serviceName}/{methodName}`**（禁止 REST 式 GET/PUT/DELETE） |
| R4 | 同一页面上的按钮（保存、提交、接收、退回、打印）**不得**拆到多个 AppService |
| R5 | **跨页复用的嵌入式组件**（如 ICD Picker）可独立 AppService |
| R6 | **无 UI 的系统集成**（离院建档）在 **`CaseRecordDomainService.bootstrapIfAbsent`**，由业务 AppService 调用 |
| R7 | AppService 只做 **Gate → Pre → Cmd → Asm**；领域规则在 `zxplat-domain/mrms` |
| R8 | Request/DTO 与 AppService **同页面分包**（`homepage/request/`、`homepage/dto/`） |

### 3.1a 门诊病历查询（接诊可编辑 + 归档病例）

| 项 | 值 |
|----|-----|
| **前端页面** | `views/mrms/outpatient-emr/index.vue` |
| **路由** | `/mrms/outpatient-emr` |
| **菜单** | 病案管理 → 门诊病历查询 |
| **AppService** | `MrmsOutpatientEmrQueryAppService` |
| **serviceName** | `mrmsOutpatientEmrQuery` |
| **前端 API 文件** | `#/api/mrms/outpatient-emr.ts` |

| 方法 | HTTP | 说明 |
|------|------|------|
| `queryPage` | `POST /api/app/mrmsOutpatientEmrQuery/queryPage` | 跨患者分页检索门诊文书；回填 `admitterPractitionerId`、`clinicalArchived` |
| `archiveClinicalCase` | `POST /api/app/mrmsOutpatientEmrQuery/archiveClinicalCase` | 按就诊锁定 EMR 文书（仅 `ROLE_MRMS_ADMIN`）；**不**改病案主档状态 |
| `unarchiveClinicalCase` | `POST /api/app/mrmsOutpatientEmrQuery/unarchiveClinicalCase` | 解锁 LOCKED 文书；主档已 `archived` 时拒绝（须走质控病案解档） |

**锚点**：列表行与打开病历均按 **就诊 encounter**（非整患者）。打开 `MedicalRecordForm` 时传 `encounterScoped`：侧栏仅「本次就诊病历」，**不**拉患者跨就诊历史。

**病历编辑门禁**：登录 `practitionerId` = 行 `admitterPractitionerId` 且 `clinicalArchived≠true` → 可编辑；否则只读。

**归档病例（≠ 病案归档）**：UI 文案「归档病例」；须确认框；后端 `ROLE_MRMS_ADMIN` 校验。落 `lockAllByEncounter` → 文书 `LOCKED`。

**查看 / 打印**：前端直调 EMR `document/generatePdf` + `EmrPdfPreviewDialog`（OpenPDF）；不纳入本 AppService。

**不包含**：门诊病历书写主流程、病案主档质控/借阅（书写入口本期挂本菜单；病案主档流程仍仅住院）。

### 3.1b 住院病例查询（相关医生可编辑 + 归档病例）

| 项 | 值 |
|----|-----|
| **前端页面** | `views/mrms/inpatient-emr/index.vue` |
| **路由** | `/mrms/inpatient-emr` |
| **菜单** | 病案管理 → 住院病例查询 |
| **AppService** | `MrmsInpatientEmrQueryAppService` |
| **serviceName** | `mrmsInpatientEmrQuery` |
| **前端 API 文件** | `#/api/mrms/inpatient-emr.ts` |

| 方法 | HTTP | 说明 |
|------|------|------|
| `queryPage` | `POST /api/app/mrmsInpatientEmrQuery/queryPage` | 跨患者分页检索住院就诊；回填相关医生主键、`clinicalArchived`、主档状态/4401、**`organizationId`/`wardId`/`wardName`/`ageText`/`bedName`**（临床门禁与抬头） |
| `archiveClinicalCase` | `POST /api/app/mrmsInpatientEmrQuery/archiveClinicalCase` | 按就诊锁定 EMR（仅 `ROLE_MRMS_ADMIN`） |
| `unarchiveClinicalCase` | `POST /api/app/mrmsInpatientEmrQuery/unarchiveClinicalCase` | 解档病例；主档已归档时拒绝 |

**锚点**：以 **住院就诊 encounter** 为行；打开病历弹层同样 `encounterScoped`（仅本就诊文书）。

**行内临床入口**：病历/医嘱/体温单/护理记录（弹层）；体温单与护理记录无独立菜单。

**临床侧栏抬头（出院患者）**：列表 `queryPage` 出参回填 `ageText` / `bedName` / `wardName` / **`wardId`**（来自住院就诊上下文；无活动床时为**末次已完成** BED/WARD 位置，床列「原{房}-{床}（未占床）」，与护士站召回未占床投影同口径）。前端 `mrms-inpatient-clinical-host` 组装体温单/护理记录患者入参；体温单抬头会去掉「原…（未占床）」包装仅留中间房-床段。

**病案侧栏医嘱**：默认按开立时间**正序**（先开在上）；提供「打印长期医嘱 / 打印临时医嘱」，打印明细同为正序。护士站打印中心与医生站默认倒序**不改**。

**编辑门禁**（前端 `mrms-clinical-edit-gate.ts`；须登录 `practitionerId`；`clinicalArchived=true` 一律只读）：

| 入口 | 可写条件 | 说明 |
|------|----------|------|
| 病历 / 医嘱 | 登录科室 = 行 `organizationId`（入院科室） | 同科室大夫可写；非本科室只读 |
| 体温单 / 护理记录 | 登录科室 = 行 `organizationId`，**或** 行 `wardId` ∈ 当前账号管辖病区 | 管辖病区口径同护士站 `loadWardTree`（岗位绑定 `adm_location` WARD）；病案首页/住院病例查询打开时前端拉树比对 |

- 强制只读：`clinicalArchived` **或** 主档 `statusCode=archived`（病历场景）
- 病案管理员**不是**本科室/本病区人员时：可归档/解档病例，**不可**编辑临床文书/体温单/护理记录

**角色**：内置 `ROLE_MRMS_ADMIN`（病案管理员，Flyway `V11__mrms_settle_upload.sql`）；用户管理分配后见全部病案管理菜单。登录配置下发 `currentUser.canMrmsAdmin`，前端据此显示「归档病例 / 解档病例」。

**与病案首页列表区分**：首页/质控仍走 `MrmsCaseRecordHomepageAppService#queryPage`；本服务仅服务「住院病例查询」菜单。病案归档（质控 `archive`）更强，会级联锁定 EMR。病案首页行操作打开体温单/护理记录时，**写门禁与上表同口径**。

**loadPage 出参** `HomepagePageDto`：

```json
{
  "caseRecord": {
    "...CaseRecordDetailDto",
    "organizationId": "入院科室主键（就诊 organization_id；诊断医生下拉；出站字符串）"
  },
  "homepage": { "...HomepageDto" }
}
```

> `organizationId` 由 `loadPage` 从住院就诊上下文回填（主档无科室列），与列表行 `CaseRecordListItemDto.organizationId` 同口径。
