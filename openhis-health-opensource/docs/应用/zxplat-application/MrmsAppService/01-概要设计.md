## 1. 背景与目标

住院病案全生命周期：主档 → 首页 → 编码 → 提交/接收 → 质控 → 归档 → 检索 → 借阅 → 4401。MRMS **内嵌 health**（同进程）；**页面驱动 AppService**（一个页面一个主 Service）。

非目标见 [00-功能清单 §1.3](./00-功能清单.md)：门诊病案、OCR、DRG 引擎、4701 上传等。

### 1.1 模块边界（硬约束）

| 层 | 允许 | 禁止 |
|----|------|------|
| **zxplat-domain/mrms/** | 实体、仓储、领域服务 | 跨 Module import；HTTP |
| **health-application/mrms/** | 页面型 AppService、ExtensionImpl、domain *Adapter | 直 import `com.zxplat.framework.chs.*` / emr entity（ExtensionImpl 除外）；直注 Repository |
| **health-integration-contracts** | Extension + 中性 DTO | 独立 `health-bridge-*` 模块 |
| **zxplat-domain** | Flyway `V77～V86__mrms_*.sql` + `V25` 菜单 | — |
| **zxplat-module-emr / zxplat-module-chs-jilin** | 各自 Module 能力 | 读/写 MRMS 表 |

### 1.2 架构决策（ADR 摘要）

| # | 决策 |
|---|------|
| 1 | MRMS **内嵌 health**，同进程；无独立 `mrms-starter` |
| 2 | **页面驱动** AppService（见 [02-交互说明](./02-交互说明.md)） |
| 3 | 包根 `com.zxplat.domain.mrms` / `com.zxplat.domain.application.mrms` |
| 4 | 跨 Module → **Extension**（见 [08-Client与外部依赖](./08-Extension与外部依赖.md)）；读 HIS → `*QueryService` 或 `InsuranceEncounterLoader` |
| 5 | **1 encounter : 1 CaseRecord**；离院/业务入口 `bootstrapIfAbsent` 幂等建档 |
| 6 | 4401：组装 `MedcasHomepagePayload` → `MedcasHomepageUploadExtension` |

状态机：`DRAFT → SUBMITTED → RECEIVED → QCING → ARCHIVED`（可 `RETURNED`）。

## 3. 领域模型

### 3.1 不变量

1. `tenant_id + encounter_id`（`is_deleted=false`）唯一。
2. `medcasno` 非空时租户内唯一；bootstrap 建档可空，首次保存首页发号（`CR`+yyMM+4 位年流水）。
3. `status=archived` → 首页 `frozen=true`。
4. 仅 `draft` / `returned` 允许医生编辑首页。

### 3.2 CaseRecordStatus

```java
public enum CaseRecordStatus {
    DRAFT("draft", "草稿"),
    SUBMITTED("submitted", "已提交"),
    RETURNED("returned", "已退回"),
    RECEIVED("received", "已接收"),
    QCING("qcing", "质控中"),
    ARCHIVED("archived", "已归档");
}
```

### 3.3 状态迁移

| 当前 | 动作 | 目标 | 入口 AppService |
|------|------|------|-----------------|
| — | bootstrap | draft | `CaseRecordDomainService.bootstrapIfAbsent` |
| draft/returned | submit | submitted | `mrmsCaseRecordHomepage/submit` |
| submitted | receive | received | `mrmsCaseRecordHomepage/receive` |
| submitted/received | return | returned | `mrmsCaseRecordHomepage/returnToDoctor` |
| received | startQc | qcing | `mrmsCaseRecordQc/startQc` (W2) |
| qcing | archive | archived | `mrmsCaseRecordQc/archive` (W2) |
| archived | unarchive | received | `mrmsCaseRecordQc/unarchive` (W3) |

### 7.1 health-app

MRMS 域随 `zxplat/health-app` 默认打包，**无**独立 `mrms-starter` 依赖。

  modules:
