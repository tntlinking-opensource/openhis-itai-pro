# zxplat-application

HIS **应用层**（原 `health-application`）。

> **代码**：`zxplat-application/` · 包 `com.zxplat.application.*`  
> **制品**：`com.zxplat:zxplat-application`  
> **上级**：[../说明.md](../说明.md) · **结构**：[模块说明-代码结构.md](./模块说明-代码结构.md)

## 职责

用例编排（`*AppService`）：读组装、写 Command、调领域服务与 QueryService；经框架自动接口暴露 HTTP。

## 边界

| 允许 | 禁止 |
|------|------|
| 依赖 `zxplat-domain`、`zxplat-framework` | 依赖任一 `module-*-bridge` |
| 经 domain `infrastructure.integration` Extension SPI 触达插件能力 | 直接依赖插件 contracts / WI domain |
