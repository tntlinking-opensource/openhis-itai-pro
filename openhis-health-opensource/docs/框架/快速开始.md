# 快速开始

> 在 monorepo 内启动带 ZXPlat Framework 的 HIS Host（`zxplat-app`）。

## 1. 环境要求

| 项 | 版本 |
|----|------|
| JDK | 17+ |
| Maven | 3.6+ |
| PostgreSQL | 16+ |
| 代码仓 | `zxplat`（`D:\0.product\02.ZXPlat\zxplat`） |

## 2. 准备数据库

```sql
CREATE DATABASE zxplat;
```

默认连接（`zxplat-app/src/main/resources/application.yml`）：

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/zxplat
    username: postgres
    password: root
```

可通过环境变量覆盖：`DB_USERNAME`、`DB_PASSWORD`。

## 3. 编译框架

```bash
cd zxplat
mvn clean install -f zxplat-framework/pom.xml -DskipTests
```

## 4. 启动 zxplat-app

```bash
cd zxplat-app
mvn spring-boot:run
```

或从根目录：

```bash
mvn spring-boot:run -pl zxplat-app -am
```

启动类：`zxplat-app（入口类待迁）`  
默认端口：**8081**（见 `application.yml`）。

## 5. 访问接口文档

| 地址 | 说明 |
|------|------|
| http://localhost:8081/swagger-ui.html | Swagger UI |
| http://localhost:8081/v3/api-docs | OpenAPI JSON |

## 6. 默认账号

| 项 | 值 |
|----|-----|
| 用户名 | `admin` |
| 密码 | `Admin@123456` |

## 7. 登录与调用 API

### 7.1 登录（兼容路径）

```bash
POST http://localhost:8081/api/auth/login
Content-Type: application/json

{
  "userName": "admin",
  "password": "Admin@123456"
}
```

也可通过 Auto API：

```bash
POST http://localhost:8081/api/app/auth/login
Content-Type: application/json

[{"userName":"admin","password":"Admin@123456"}]
```

### 7.2 携带 Token 调用 AppService

```bash
POST http://localhost:8081/api/app/user/getList
Authorization: Bearer {accessToken}
Content-Type: application/json

[{"pageIndex":0,"pageSize":10}]
```

### 7.3 登录后会话

登录成功后需按业务完成租户/医院/科室选择（见 [身份认证.md](./包/身份认证.md) 中 `AuthAppService` 的 `selectTenant`、`selectHospital`、`selectOrganizationUnit`）。

## 8. 可选：挂载业务扩展 Module

在 `zxplat-app/pom.xml` 中通过 Maven Profile 引入 starter，并在 `application.yml` 启用：

```yaml
zxplat:
  modules:
    emr:
      enabled: true
```

Profile 示例：`-Pwith-emr`、``。详见 [模块化开发规范.md](../架构/模块化开发规范.md)。

## 9. 常用配置位置

| 文件 | 用途 |
