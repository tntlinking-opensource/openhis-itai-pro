# 部署

> `zxplat-app` / `project-H*` 院端 Windows 生产环境部署要点。  
> **操作真源**：[运维手册/部署手册.md](../../运维手册/部署手册.md)、[04-HIS发布与热更新方案.md](../../运维手册/04-HIS发布与热更新方案.md)。

## 环境要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows Server 2019+ / Win10+ |
| JDK | 17（`E:\whale\jdk-17`） |
| 数据库 | PostgreSQL 16+ |
| 进程管理 | NSSM（`E:\whale\nssm\nssm.exe`） |
| 内存 | 最低 4GB，推荐 8GB+（`-Xmx2g` 起） |

## 构建

推荐走统一发布脚本（构建机 Windows）：

```powershell
cd publish
.\publish.ps1 -BackendTarget project -Project H22010402403 -ListenPort 28080 -BackendPort 8082
```

手动 Maven 构建（开发调试）：

```powershell
cd zxplat
mvn clean package -pl zxplat-app -am -DskipTests
```

产物：`zxplat-app/target/zxplat-app-*.jar` 或 `publish/releases/{version}/project-*.jar`

全量源码在 monorepo 内构建，见 [00-总览/zxplat-维护者指南.md](../../00-总览/zxplat-维护者指南.md)。

## 运行（调试，不经 NSSM）

```powershell
cd E:\whale\zxplat-app
E:\whale\jdk-17\bin\java.exe -Xms512m -Xmx2g -jar zxplat-app-2.0.2.4.jar `
  --spring.profiles.active=dev `
  --server.port=8081
```

敏感配置通过环境变量注入（与 NSSM `AppEnvironmentExtra` 一致）：

| 变量 | 说明 |
|------|------|
| `DB_USERNAME` | 数据库用户 |
| `DB_PASSWORD` | 数据库密码 |
| `JWT_SECRET` | ≥ 32 字符 |

## 生产配置建议

院点 jar 内 `application.yml` prod 段，或通过 NSSM 环境变量覆盖：

```yaml
spring:
  datasource:
    url: jdbc:postgresql://172.16.101.2:5432/whale_pro
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
  flyway:
    validate-on-migrate: true
  lifecycle:
    timeout-per-shutdown-phase: 120s
  quartz:
    properties:
      org.quartz.jobStore.isClustered: true

server:
  shutdown: graceful

app:
  jwt:
    secret: ${JWT_SECRET}
  session-store:
    type: jdbc
  rate-limit:
    enabled: true
    max-requests-per-minute: 100

logging:
  file:
    name: logs/zxplat-core.log
```

## 数据库

- Flyway 由 `ModularFlywayConfiguration` 在启动时按模块执行。
- 培训库 `zxplat-app`、正式库 `zxplat_pro` 分离（推荐）。
- 生产首次部署前备份数据库；**禁止**在生产启用 `flyway.clean`。

## Quartz 集群

正式库蓝绿（8082 / 8083）重叠窗口内，Quartz Cron 依赖 `isClustered: true` 避免双跑。切流后应停止 inactive 槽位。

## 前端反代（便携 Nginx）

院端由便携 Nginx（`ZXPlatWebApp` / `ZXPlatWebProject`）托管静态资源并反代 `/api`。正式环境通过 `zxplat-web\config.env` 的 `BACKEND_PORT` 切换 8082 / 8083：

```ini
LISTEN_PORT=28080
BACKEND_HOST=127.0.0.1
BACKEND_PORT=8082
BACKEND_V1_PORT=8082
BACKEND_V2_PORT=8083
```

Nginx 生产模板见仓库 `publish/lib/portable/nginx.conf.template`（随 `zxplat-web-deploy-*.zip` 下发），详见 [前端部署.md](./前端部署.md)。

## NSSM 服务示例

**推荐**：用 **ZXPlatOps.Desk**「服务」页安装（`INssmServiceInstaller`）。真源：`tools/ZXPlatOps`。

| NSSM 项 | 建议值 |
|---------|--------|
| `Application` | `E:\whale\jdk-17\bin\java.exe` |
| `AppParameters` | `-Xms512m -Xmx2g -jar project-H22010402403-*.jar --server.port=8082` |
| `AppEnvironmentExtra` | `SPRING_PROFILES_ACTIVE=prod`、`DB_USERNAME`、`DB_PASSWORD`、`JWT_SECRET` |
| `AppStopMethodConsole` | **120000** ms（对齐 graceful shutdown） |
| `AppExit Default` | Restart |

五服务对照见 [部署手册 §3.2](../../运维手册/部署手册.md)。
