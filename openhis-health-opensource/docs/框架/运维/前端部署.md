# 前端部署

> `zxplat-ui`（主应用 `web-ele`）院端 Windows 生产环境构建与部署要点。

## 适用范围

| 项 | 说明 |
|----|------|
| 工程 | `zxplat-ui` |
| 主应用 | `apps/web-ele`（Vue 3 + Element Plus + Vben Admin） |
| 后端 | `zxplat-app`（培训 :8081）/ `project-H*`（正式 :8082 / :8083） |
| 部署形态 | **便携 Nginx** + NSSM（`ZXPlatWebApp` / `ZXPlatWebProject`） |

院端标准拓扑见 [运维手册/04-HIS发布与热更新方案.md](../../运维手册/04-HIS发布与热更新方案.md) §3、[部署手册 §4](../../运维手册/部署手册.md)。

---

## 1. 环境要求

### 1.1 构建机

| 项 | 要求 |
|----|------|
| 操作系统 | Windows（与 `publish/` 脚本一致） |
| Node.js | >= 20.12.0 |
| pnpm | >= 10.0.0（项目锁定 `pnpm@10.22.0`） |
| 内存 | 建议 8GB+（`NODE_OPTIONS=--max-old-space-size=8192`） |

### 1.2 运行环境（院端服务器）

| 项 | 要求 |
|----|------|
| Web 服务器 | 便携 Nginx（随 `zxplat-web-deploy-*.zip` 部署；服务由 ZXPlatOps.Desk 安装） |
| NSSM 服务 | `ZXPlatWebApp`（培训 :18080）、`ZXPlatWebProject`（正式 :28080） |
| 磁盘 | `html\` 约 20–80 MB |
| 网络 | 客户端可访问 :18080 / :28080；Nginx 反代到本机后端端口 |

> 前端为纯静态 SPA，**服务器上不需要 Node.js**（仅构建机需要）。

## 2. 构建

发布脚本统一到 **`publish/`**，产物在 `publish/releases/{version}/`：

```powershell
cd publish

# 前后端一起（正式院点）
.\publish.ps1 -BackendTarget project -Project H22010402403 -ListenPort 28080 -BackendPort 8082

# 仅前端
.\publish-frontend.ps1
```

### 2.1 构建产物

| 文件 | 说明 |
|------|------|
| `zxplat-web-dist-{version}.zip` | 前端静态资源 |
| `zxplat-web-deploy-{version}.zip` | 前端 + Windows 便携 Nginx（解压即用） |
| `project-H*-{version}.jar` | 后端 fat jar（若走完整 publish） |
| `manifest.json` | 发布清单 |

验证：

```powershell
Get-Content publish\releases\latest.json
Get-ChildItem publish\releases\*\manifest.json
```

### 2.2 手动构建（开发调试）

```powershell
cd zxplat-ui
pnpm install --frozen-lockfile
pnpm run build:ele
# 产物：apps/web-ele/dist/
```

## 3. 生产环境变量

构建时读取 `apps/web-ele/.env.production`。院端通常 **无需修改**：

| 变量 | 生产默认值 | 说明 |
|------|-----------|------|
| `VITE_BASE` | `/` | 静态资源公共路径 |
| `VITE_GLOB_API_URL` | `/api` | API 前缀；Nginx 反代到后端 |
| `VITE_ROUTER_HISTORY` | `hash` | 路由模式（`/#/path`） |
| `VITE_COMPRESS` | `gzip` | 构建产物压缩 |

> Vite 环境变量在 **构建时** 注入，部署后改文件无效，须重新构建。

## 4. 部署拓扑（院端 Windows）

```text
浏览器
   │
   ▼
便携 Nginx :18080（培训）/ :28080（正式）
   ├── /              → E:\whale\zxplat-web*\html\（静态 SPA）
   ├── /api/          → http://127.0.0.1:BACKEND_PORT/api/app/
   ├── /ws            → 后端 WebSocket / STOMP
   └── /uploads       → 后端上传（按需）

BACKEND_PORT 由 zxplat-web\config.env 维护（正式蓝绿 8082 / 8083）
```

**要点**：

- 前端请求 `/api`，Nginx 反代到后端 `/api/app/...`。
- 生产 **不硬编码** 后端 IP；切流只改 `config.env` + 重载 Nginx。
- 路由为 **hash 模式**，URL 形如 `http://172.16.101.2:28080/#/dashboard`。

## 5. 院端目录布局

```text
E:\whale\
├── zxplat-web-app\             # 培训前端 :18080
│   ├── html\                    # dist 解压目标
│   ├── conf\nginx.conf
│   └── nginx.exe
└── zxplat-web\                 # 正式前端 :28080
    ├── html\
    ├── conf\nginx.conf
    ├── config.env               # BACKEND_PORT 蓝绿切流
    └── nginx.exe
```

首次部署由 ZXPlatOps.Desk「服务」页安装 NSSM；Nginx `conf/nginx.conf` 来自便携包模板 `publish/lib/portable/nginx.conf.template`。

## 6. 上传与发版

### 6.1 上传到服务器

| 目标 | 内容 |
|------|------|
| `zxplat-web\html\` | 正式前端 dist |
| `zxplat-web-app\html\` | 培训前端 dist |

构建机示例：

```powershell
# 共享路径（朝阳）
Copy-Item publish\releases\2.0.2.5\zxplat-web-dist-*.zip \\172.16.101.2\whale\staging\
# 服务器解压到 html\，或使用 Runbook：
cd E:\whale\services
.\publish-runbook.ps1 -Phase FrontendOnly -ReleaseDir D:\...\publish\releases\2.0.2.5
```

### 6.2 config.env（正式前端）

```ini
LISTEN_PORT=28080
BACKEND_HOST=127.0.0.1
BACKEND_PORT=8082
BACKEND_V1_PORT=8082
BACKEND_V2_PORT=8083
```

手动切后端：

```powershell
cd E:\whale\services
.\switch-backend.ps1 -ActivePort 8083
Restart-Service ZXPlatWebProject
```

### 6.3 Nginx 配置要点

仓库 `zxplat-ui/scripts/deploy/nginx.conf` 为演示用（仅静态 :8080）。院端生产配置以 `publish/lib/portable/nginx.conf.template` 为准（随便携包下发），须包含 `/api/` 反代，以及 SPA 缓存头（`index.html` 禁止缓存，`/assets` 长缓存）：

```nginx
location = /index.html {
    add_header Cache-Control "no-cache, no-store, must-revalidate" always;
    add_header Pragma "no-cache" always;
}

location /assets/ {
    expires 1y;
    add_header Cache-Control "public, immutable" always;
}

location / {
    try_files $uri $uri/ /index.html;
    add_header Cache-Control "no-cache, no-store, must-revalidate" always;
    add_header Pragma "no-cache" always;
}

location /api/ {
    proxy_pass http://127.0.0.1:$backend_port/api/app/;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 180s;
}
```

`$backend_port` 由 `config.env` 在启动时注入（见 `publish/lib/portable` 启动脚本）。

重载：

```powershell
Restart-Service ZXPlatWebProject
# 或调试：cd E:\whale\zxplat-web && .\nginx.exe -s reload
```

## 7. 便携包试用（单机验证）

`zxplat-web-deploy-{version}.zip` 适合本机或试点验证：

1. 解压到任意目录（路径避免中文与空格）
2. 确保后端已启动（默认 `http://127.0.0.1:8081`）
3. 编辑 `config.env` 后运行 **`start.bat`**
4. 访问 `http://localhost:8080/`

院端生产请使用 §5 的 `E:\whale\zxplat-web*` + NSSM 服务，而非长期依赖 start.bat。

## 8. 本地客户端依赖

部分能力依赖工作站 **ZXPlat.Win**（`http://127.0.0.1:5000`），与 Web 服务器无关：

| 能力 | 本地服务 |
|------|---------|
| 医保读卡 | ZXPlat.Win |
| 银联扫码 / POS | ZXPlat.Win `/api/unionpay/*` |
| 本地打印 | ZXPlat.Win / hiprint |

Web 部署完成后，须在业务工作站安装并启动 ZXPlat.Win。

## 9. 发版与回滚

前端为静态资源，**换包 + 重启 Nginx 服务** 即生效，无需重启后端 jar。

### 9.1 发版

```powershell
cd E:\whale\services
.\publish-runbook.ps1 -Phase FrontendOnly -ReleaseDir D:\...\publish\releases\2.0.2.5
```

或手动覆盖 `html\` 后 `Restart-Service ZXPlatWebProject`。

### 9.2 回滚

```powershell
# 恢复上一版 html 备份
Remove-Item E:\whale\zxplat-web\html\* -Recurse -Force
Expand-Archive E:\backup\zxplat-web-dist-YYYYMMDD.zip -DestinationPath E:\whale\zxplat-web\html
Restart-Service ZXPlatWebProject
```

## 10. 部署验收清单

| # | 检查项 | 方法 | 预期 |
|---|--------|------|------|
| 1 | 首页可访问 | `http://{IP}:28080/` | 登录页，无 404 |
| 2 | 静态资源 | F12 Network | `*.js` / `*.css` 200 |
| 3 | API 连通 | 登录 | Token 正常，无 502 |
| 4 | 路由 | 各菜单 | `/#/...` 可刷新 |
| 5 | 蓝绿 | Cutover 后 | 接口仍正常，BACKEND_PORT 已切换 |
| 6 | 长请求 | 医保 / 开票 | 无 60s 超时 |

## 11. 常见问题

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 白屏 / JS 404 | `VITE_BASE` 与部署路径不一致 | 确认部署在 `html\` 根路径 |
| 502 | 后端未启动或 `BACKEND_PORT` 错误 | `Get-Service ZXPlatProject*`；查 health |
| CORS | 前端直连后端 IP | 生产应同域 `/api` 反代 |
| 旧功能仍出现 | 浏览器缓存了 `index.html` | 确认 Nginx 已对 `index.html` 设 `no-cache`（便携模板已落地；下次前端上线/切流会自动补齐）；**普通 F5** 即可。长开页签需再刷新一次 |
| Nginx bind 10013 | 端口保留 | 以管理员运行或换端口 |
