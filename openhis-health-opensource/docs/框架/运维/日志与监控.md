# 日志与监控

> zxplat-app / project-H* 日志体系与院端 Windows 可观测性配置。

## 日志文件

| 项 | 值 |
|----|-----|
| 应用默认路径 | `{jar目录}/logs/zxplat-core.log` |
| 院端示例 | `E:\whale\project-H22010402403\logs\zxplat-core.log` |
| NSSM  stdout/stderr | `{jar目录}/logs/nssm-stdout.log`、`nssm-stderr.log` |
| Nginx 错误日志 | `E:\whale\zxplat-web\logs\error.log` |
| 滚动 | 应用 max-size 100MB；NSSM `AppRotateFiles` 10MB |

配置见 `zxplat-app/src/main/resources/application.yml` 的 `logging.file.*`。

## 关键 Logger

| Logger | 级别建议 | 内容 |
|--------|----------|------|
| `zxplat.startup` | INFO | Flyway、缓存预热、端口就绪 |
| `zxplat.access` | INFO | API 访问摘要 |
| `com.zxplat.framework` | INFO/WARN | 框架业务 |
| `com.zxplat.domain` | INFO | HIS 业务 |
| `org.flywaydb` | INFO | 迁移执行 |

开发环境可临时打开 `com.zxplat.framework.web.api.AppServiceControllerRegistrar` 为 DEBUG 排查 Auto API 注册。

## 日志格式

```
%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level [%X{requestId}] [%X{tenantId}] [%X{userId}] %logger{36} - %msg%n
```

MDC 字段：`requestId`、`tenantId`、`userId`。

## API 请求体日志

| 配置键 | 默认 |
|--------|------|
| `app.logging.api-params-enabled` | `true` |
| `app.logging.api-params-max-length` | `2000` |

生产环境建议关闭或设为 WARN，避免敏感数据落盘。

## Spring Boot Actuator

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics
  endpoint:
    health:
      show-details: when-authorized
      probes:
        enabled: true
```

院端探活（PowerShell）：

```powershell
Invoke-WebRequest http://127.0.0.1:8082/actuator/health -UseBasicParsing
Invoke-WebRequest http://127.0.0.1:8083/actuator/health -UseBasicParsing
cd E:\whale\services
.\publish-runbook.ps1 -Phase Status
```

## 院端日常监控

| 方式 | 说明 |
|------|------|
| ZXPlatOps.Desk | 仪表盘、巡检页、磁盘与端口（见 [ZXPlatOps.Desk操作手册.md](../../运维手册/ZXPlatOps.Desk操作手册.md)） |
| Windows 性能监视器 | CPU / 内存 / 磁盘 |
| PostgreSQL | `pg_stat_activity`、`pg_stat_replication`（见 [运维手册 §3.1](../../运维手册/运维手册.md)） |
| 可选 | Prometheus + Grafana + postgres_exporter |
