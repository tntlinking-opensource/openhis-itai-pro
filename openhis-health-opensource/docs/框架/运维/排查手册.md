# 故障排查

> 开发联调与院端 Windows 运维常见问题。

## 401 / 403 认证失败

### 症状

调用 AppService 返回 401 或 403；日志出现 JWT 验证失败。

### 排查

1. 确认 `Authorization: Bearer {token}` 格式正确（Bearer 后有空格）。
2. Token 是否过期（默认 access token 2 小时）→ 调用 `refreshToken` 或重新 `login`。
3. 是否完成登录后会话：`selectTenant` → `selectHospital` → `selectOrganizationUnit`。
4. 检查 `app.jwt.secret` / NSSM 环境变量 `JWT_SECRET` 各实例是否一致。

### 解决

```http
POST /api/app/auth/login
Content-Type: application/json

[{"userName":"admin","password":"Admin@123456"}]
```

## 租户上下文缺失

### 症状

多租户数据查不到；日志「已登录但未建立会话租户」。

### 原因

`TenantInterceptor` 以服务端会话为准，未调用 `selectTenant`。

### 解决

```http
POST /api/app/auth/selectTenant
Authorization: Bearer {token}

[{"tenantId": 1}]
```

## AppService 404 / 方法未注册

### 排查

1. 类名是否以 `AppService` 结尾。
2. 是否标注 `@Service`。
3. 是否在 `com.zxplat` 包下被 Spring 扫描或 AutoConfiguration 注册。
4. 启动日志搜索「AppService 方法注册完成」。

扩展 Module 未启用时，可能返回友好业务错误而非 404（见包 **core** 的 `ExtensionModuleAppServiceRegistry`）。

## 数据库 / Flyway

| 问题 | 处理 |
|------|------|
| 连接失败 | 检查 `spring.datasource.*`、PostgreSQL 服务、Windows 防火墙 |
| 迁移失败 | 查看 `org.flywaydb` 日志；勿随意修改已执行脚本 checksum |
| 表缺失 | 确认 `ModularFlywayConfiguration` 已执行对应模块 migration |

## Quartz 任务不执行

1. `app.quartz.enabled` 是否为 `true`。
2. 任务状态是否为启用（非 Paused）。
3. Cron 表达式：`ScheduledJobAppService.validateCron` 验证。
4. `IJob` handler Bean 是否存在于 Spring 上下文。
5. 蓝绿双实例：确认 prod `isClustered: true`；切流后 inactive 槽位应停止。

## 权限不足

1. `PermissionAppService.getByUser` 查看用户有效权限。
2. 角色是否分配 Navigation 权限（`RoleAppService.assignPermissions`）。
3. 权限缓存 TTL：`app.cache.permission.expire-after-write`（默认 5m）。

## 代理登录异常

- Token 30 分钟过期 → 重新 `impersonate` 或 `stopImpersonating`。
- 检查 `whale_security_logs` 中 `IMPERSONATION_*` 记录。

## 院端 502 / 服务异常

| 步骤 | 命令 |
|------|------|
| 服务状态 | `Get-Service ZXPlat*` |
| 发版状态 | `cd E:\whale\services; .\publish-runbook.ps1 -Phase Status` |
| 活跃后端 | 查看 `E:\whale\zxplat-web\config.env` 的 `BACKEND_PORT` |
| health | `Invoke-WebRequest http://127.0.0.1:8082/actuator/health -UseBasicParsing` |

详见 [应急预案 §3.1](../../运维手册/应急预案.md)。

## 日志位置

**开发（相对 jar 目录）**

```text
logs/zxplat-core.log
```

**院端（朝阳示例）**

```powershell
Get-Content E:\whale\project-H22010402403\logs\zxplat-core.log -Tail 100 -Wait
Get-Content E:\whale\zxplat-app\logs\zxplat-core.log -Tail 100 -Wait
Select-String -Path E:\whale\project-H22010402403\logs\zxplat-core.log -Pattern 'ERROR'
Get-Content E:\whale\zxplat-web\logs\error.log -Tail 50
```
