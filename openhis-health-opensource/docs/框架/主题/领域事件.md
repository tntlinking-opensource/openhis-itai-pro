# 领域事件（Domain Events）

> 本地事件总线，基于 Spring ApplicationEvent，对标 ABP Local Event Bus。

## 核心组件

| 类型 | 说明 |
|------|------|
| `IEvent` | 事件接口 |
| `DomainEvent` | 领域事件基类 |
| `ApplicationEvent` | 应用/跨模块事件基类 |
| `IDomainEventPublisher` | 发布接口 |
| `DomainEventPublisher` | 实现（桥接 `ApplicationEventPublisher`） |
| `@DomainEventHandler` | 监听器注解 |
| `DomainEventListener` | 监听基础设施 |

Bean 注册：`ZxplatCoreAutoConfiguration` 提供 `IDomainEventPublisher`（`@ConditionalOnMissingBean`）。

## 定义事件

```java
@Getter
@Setter
@NoArgsConstructor
public class PatientCreatedEvent extends DomainEvent {
    private Long patientId;
    private String patientName;

    public PatientCreatedEvent(Long patientId, String patientName) {
        super(patientId, "Patient");
        this.patientId = patientId;
        this.patientName = patientName;
    }
}
```

## 发布事件

```java
@Service
@RequiredArgsConstructor
public class PatientManager {
    private final IDomainEventPublisher eventPublisher;

    public Patient create(CreatePatientParam param) {
        Patient patient = patientRepository.save(...);
        eventPublisher.publish(new PatientCreatedEvent(patient.getId(), patient.getName()));
        return patient;
    }
}
```

事件在**事务提交后**发布，保证与持久化一致。

## 监听事件

```java
@Component
public class PatientCreatedHandler {

    @DomainEventHandler
    public void handle(PatientCreatedEvent event) {
        // 处理逻辑
    }
}
```

## 设计约束

- **仅本地事件**：不支持分布式消息队列。
- 监听器内避免长时间阻塞；必要时 `@Async`。
- 跨模块通信用 `ApplicationEvent` 或 contracts Client，而非直接依赖实现类。
