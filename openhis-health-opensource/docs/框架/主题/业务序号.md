# 业务序号（Business Sequence）

> 基于数据库的递增序号，支持多租户隔离与格式化输出。

## 服务

**类**：`com.zxplat.framework.core.infrastructure.sequence.BusinessSequenceService`  
**表**：`whale_sequence`（`seq_key`, `current_value`）

## 租户隔离

有当前租户上下文时，内部 key 自动变为 `{tenantId}:{key}`，各租户独立递增；无租户时使用全局 key。

## 常用 API

| 方法 | 说明 |
|------|------|
| `nextValue(key, delta)` | 原子递增，返回新值 |
| `nextFormattedSequence(prefix, suffixLength)` | 格式化序号，如 `ORD00000001` |
| `nextFormattedSequenceWithDay(prefix, suffixLength)` | 含日期前缀，如 `ORD202606190001` |

## 使用示例

```java
@Service
@RequiredArgsConstructor
public class OrderAppService {
    private final BusinessSequenceService sequenceService;

    public String generateOrderNo() {
        return sequenceService.nextFormattedSequence("ORD", 8);
    }
}
```

## 注意事项

1. 序号生成在数据库事务内完成，依赖 `whale_sequence` 行锁/UPSERT。
2. 高并发场景注意 key 粒度，避免热点单行；可按业务拆分 prefix。
3. 不要用 Redis 序号替代（框架已统一为 DB 实现）。
