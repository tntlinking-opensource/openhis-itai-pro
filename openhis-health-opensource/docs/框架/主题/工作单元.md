# 工作单元（Unit of Work）

> AppService 方法自动事务管理，对标 ABP `IUnitOfWork`。

## 机制

ZXPlat 通过两个 AOP 切面管理 `com.zxplat..*AppService` 方法的事务：

| 切面 | Order | 行为 |
|------|-------|------|
| `ReadOnlyTransactionAspect` | 0 | 方法名以 `get`/`find`/`list`/`query`/`search`/`count`/`exists`/`check` 开头 → **只读事务** |
| `AppServiceAspect` | 1 | 其余方法 → **读写事务**（`PROPAGATION_REQUIRED`） |

切点覆盖 `com.zxplat` 下所有包（框架 + health 业务模块）。

## 读写判定

```java
// 只读 — ReadOnlyTransactionAspect 处理
public UserDto getById(IdRequest request) { ... }
public PagedResult<UserDto> getList(UserQueryRequest request) { ... }

// 读写 — AppServiceAspect 处理
public UserDto create(CreateUserRequest request) { ... }
public void delete(DeleteUserRequest request) { ... }
```

新增 AppService 方法时请遵循此前缀约定，避免查询方法误开写事务。

## 异常与回滚

`AppServiceAspect` 在异常时回滚事务，并记录：

- method 签名
- traceId（来自 MDC）
- 业务代码定位栈

## 与 @Transactional 的关系

- AppService 层**优先依赖 AOP**，无需在每个方法上重复 `@Transactional`。
- 领域服务 / Repository 内部如需独立事务，可显式使用 `@Transactional`（注意传播行为）。
