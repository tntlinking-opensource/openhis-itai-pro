# 代理登录（Impersonation）

> 管理员以另一用户身份操作，对标 ABP Impersonation。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| `impersonate` | `POST /api/app/auth/impersonate` | 开始代理 |
| `stopImpersonating` | `POST /api/app/auth/stopImpersonating` | 结束代理 |

请求体示例：

```json
[{
  "targetUserId": 2,
  "reason": "协助排查问题"
}]
```

## 响应

`ImpersonateResponse` 包含：

- 新的 `accessToken` / `refreshToken`（较短过期，默认 30 分钟）
- `user` — 被代理用户
- `impersonator` — 代理者信息
- `application` — 含 impersonator 字段的前端配置

JWT Claims 写入 impersonator 信息；`ApplicationConfigurationAppService.applyImpersonatorFields` 同步到 `CurrentUserDto`。

## 安全审计

`SecurityLogService` 记录：

| Action | 说明 |
|--------|------|
| `IMPERSONATION_START` | 开始代理（审计主体为代理者，目标用户写入 extraProperties） |
| `IMPERSONATION_END` | 结束代理 |

`SecurityLog` 实现 `IExcludeFromAudit`，不重复写入 `whale_audit_logs`。

## 配置

```yaml
app:
  jwt:
    impersonation-access-token-expiration: 1800000  # 30 分钟
```

## 前端约定

1. 代理成功后替换 Token，UI 显示「正在以 xxx 身份操作」。
2. 调用 `stopImpersonating` 恢复原会话 Token。
3. 权限以**被代理用户**为准；审计与安全日志保留**代理者**身份。
