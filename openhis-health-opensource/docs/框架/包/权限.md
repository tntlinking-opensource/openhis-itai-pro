# 包 · permission（权限）

> **源码包**：`com.zxplat.framework.permission`  ·  目录：`zxplat-framework/src/main/java/com/zxplat/framework/permission/`

> 权限定义、授予、校验与缓存。

## Overview

| 项 | 值 |
|----|-----|
| 制品 | `com.zxplat:zxplat-framework`（包 permission） |
| 包根 | `com.zxplat.framework.permission` |
| AutoConfiguration | `ZxplatPermissionAutoConfiguration` |

## Key Types

| 类型 | 说明 |
|------|------|
| `Permission` | 权限定义实体 |
| `PermissionGrant` | 授予记录 |
| `PermissionChecker` | 运行时权限校验 |
| `IPermissionGrantService` | 授予 SPI（`PermissionAppService` 实现） |

## AppServices · PermissionAppService

| 方法 | 说明 |
|------|------|
| `getAll` / `getTree` / `getList` | 权限定义查询 |
| `getById` / `create` / `update` / `delete` | CRUD |
| `getGrants` | 某权限名的授予列表 |
| `batchGrant` / `batchRevoke` | 批量授予/撤销 |
| `getByUser` / `getByRole` | 用户/角色已授予权限名 |
| `grant` / `revoke` | 单条授予/撤销（Provider + Key） |
| `hasGrants` / `getGrantedPermissionNames` | Provider 维度查询 |
| `retainExistingPermissionDefinitions` | 过滤有效权限名 |

### Provider 约定

| providerName | 含义 | providerKey |
|--------------|------|-------------|
| `U` | 用户 | 用户 ID |
| `R` | 角色 | 角色 ID |

## Configuration

```yaml
app:
  cache:
    permission:
      expire-after-write: 5m
      maximum-size: 5000
```

## Database

| 表 | 说明 |
|----|------|
| `whale_permissions` | 权限定义 |
| `whale_permission_grants` | 授予记录 |

## Extension Points

- 菜单模块可提供 `PermissionTreeProvider` 对齐 Navigation 权限树。
- 业务代码注入 `PermissionChecker` 做细粒度校验。
