# 包 · tenant（租户）

> **源码包**：`com.zxplat.framework.tenant`  ·  目录：`zxplat-framework/src/main/java/com/zxplat/framework/tenant/`

> 租户（医院/机构）管理。

## Overview

| 项 | 值 |
|----|-----|
| 制品 | `com.zxplat:zxplat-framework`（包 tenant） |
| 包根 | `com.zxplat.framework.tenant` |
| AutoConfiguration | `ZxplatTenantAutoConfiguration` |

## Key Types

| 类型 | 说明 |
|------|------|
| `Tenant` | 租户实体（code、name、isEnabled 等） |
| `TenantAppService` | 租户 CRUD AppService |

## AppServices · TenantAppService

| 方法 | Auto API 示例 | 说明 |
|------|---------------|------|
| `getById` | `POST /api/app/tenant/getById` `[1]` | 按 ID |
| `getByCode` | `POST /api/app/tenant/getByCode` `["HOSP001"]` | 按编码 |
| `getList` | `POST /api/app/tenant/getList` | 分页 |
| `create` | `POST /api/app/tenant/create` | 创建 |
| `update` | `POST /api/app/tenant/update` | 更新 |
| `delete` | `POST /api/app/tenant/delete` `[1]` | 软删除 |
| `enable` / `disable` | `POST /api/app/tenant/enable` | 启用/禁用 |

## Configuration

```yaml
app:
  cache:
    tenant:
      expire-after-write: 30m
      maximum-size: 100
```

## Database

| 表 | 说明 |
|----|------|
| `whale_tenants` | 租户主表 |
| `whale_user_tenants` | 用户-租户（identity 模块使用） |
