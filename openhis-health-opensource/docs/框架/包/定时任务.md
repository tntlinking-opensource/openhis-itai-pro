# 包 · job（定时任务）

> **源码包**：`com.zxplat.framework.job`  ·  目录：`zxplat-framework/src/main/java/com/zxplat/framework/job/`

> 基于 Quartz 的定时任务管理与执行日志。

## Overview

| 项 | 值 |
|----|-----|
| 制品 | `com.zxplat:zxplat-framework`（包 job） |
| 包根 | `com.zxplat.framework.job` |
| AutoConfiguration | `ZxplatJobAutoConfiguration` |
| Quartz 适配 | `zxplat-framework` 的 `QuartzJobAdapter`、`QuartzConfig` |

## Key Types

| 类型 | 说明 |
|------|------|
| `ScheduledJob` | 任务定义实体 |
| `ScheduledJobExecutionLog` | 执行日志 |
| `IJob` | 业务 Job 处理器接口（Spring Bean） |
| `QuartzJobAdapter` | 将 Quartz 触发映射到 `IJob` |

## AppServices

### ScheduledJobAppService

| 方法 | 说明 |
|------|------|
| `getList` / `getByKey` | 查询 |
| `create` / `update` / `delete` | CRUD（新建默认暂停） |
| `changeStatus` | 启用/暂停 |
| `runNow` | 立即执行一次 |
| `validateCron` / `buildCron` | Cron 校验与 UI 构建 |
| `listHandlers` | 可用 `IJob` Bean 列表 |
| `listTenantOptions` | 租户下拉 |
| `getOptions` | UI 枚举（状态、misfire、预设） |

### ScheduledJobExecutionLogAppService

| 方法 | 说明 |
|------|------|
| `getList` | 执行历史分页 |
| `getById` | 单条日志 |

## 实现自定义 Job

1. 实现 `IJob` 接口，注册为 Spring `@Component`。
2. 在管理界面或 API 创建 `ScheduledJob`，指定 handler 名称与 Cron。
3. `listHandlers` 可看到已注册的 handler。

也可在 `*AppService` 方法上标注 `@SchedulableJob`（见 [核心.md](./核心.md)）。若方法内部自行管理事务（如分批提交），设 `openAppServiceTransaction = false`，由 `AppServiceAspect` 跳过外层事务；`AppServiceJobMethodInvoker` 须经代理 Method 调用才能生效。

## Configuration

```yaml
app:
  quartz:
    enabled: true

spring:
  quartz:
    job-store-type: jdbc
    jdbc:
      initialize-schema: never
    properties:
      org.quartz.jobStore.tablePrefix: ZXPLAT_QRTZ_
```
