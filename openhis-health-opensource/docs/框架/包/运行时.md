# 包 · runtime（运行时）

> **源码包**：`com.zxplat.framework.runtime`  ·  目录：`zxplat-framework/src/main/java/com/zxplat/framework/runtime/`

> 框架运行时状态采集、远程同步与中心 ingest。**默认不外联**；须显式打开同步并配置 URI/Token。

## Overview

| 项 | 值 |
|----|-----|
| 制品 | `com.zxplat:zxplat-framework`（包 runtime） |
| 包根 | `com.zxplat.framework.runtime` |
| AutoConfiguration | `ZxplatRuntimeAutoConfiguration`、`ZxplatRuntimeCollectorAutoConfiguration`（仅 `collector-enabled=true`） |

## 关键类型

| 类型 | 说明 |
|------|------|
| `FrameworkRuntimeProperties` | 配置（前缀 `zxplat.framework.runtime`） |
| `RemoteRuntimeSyncClient` | 异步向中心 POST；未启用或 URI 为空则直接返回 |
| `FrameworkRuntimeAppService` | 中心节点 ingest API |
| `FrameworkRuntimeContextResolver` | 运行时上下文解析 |

## AppServices · FrameworkRuntimeAppService

| 方法 | 说明 |
|------|------|
| `ingest` | 接收远程节点上报（需 `collector-enabled=true`，且配置 `sync-token`≥16 字符） |

## 配置

```yaml
zxplat:
  framework:
    runtime:
      remote-sync-enabled: false          # 默认关闭
      remote-sync-uri: ""                 # 启用同步时必填，如 http://center:8081/api/app/frameworkRuntime/ingest
      sync-token: ""                      # 请求头 X-Framework-Runtime-Token
      connect-timeout-ms: 5000
      read-timeout-ms: 10000
      collector-enabled: false            # 本节点作为中心收集端时 true
```

| 属性 | 默认 | 说明 |
|------|------|------|
| `remote-sync-enabled` | `false` | 是否向中心同步 |
| `remote-sync-uri` | 空 | ingest URL；空则不同步 |
| `sync-token` | 空 | 认证 Token |
| `collector-enabled` | `false` | 启用本机 ingest 端点 |

## 数据库

| 表 | 说明 |
|----|------|
| `whale_framework_runtime_state` | 运行时状态快照（物理表名仍为 whale_*） |
