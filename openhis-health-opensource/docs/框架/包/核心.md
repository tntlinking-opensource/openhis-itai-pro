# 包 · core（核心）

> **源码包**：`com.zxplat.framework.core`  ·  目录：`zxplat-framework/src/main/java/com/zxplat/framework/core/`

> 框架核心：实体基类、异常、多租户基础设施、工作单元、领域事件、业务序号、模块元数据。

## Overview

| 项 | 值 |
|----|-----|
| 制品 | `com.zxplat:zxplat-framework` |
| 包根 | `com.zxplat.framework.core` |
| AutoConfiguration | `ZxplatCoreComponentRegistrationConfiguration`（优先）+ `ZxplatCoreAutoConfiguration` |
| AppService | 无（接口 `IApplicationConfigurationAppService` 由包 `web` 实现） |

## Configuration

框架 core 无专属 CA 配置（电子签章属业务/插件侧）。

### 装配顺序（重要）

`META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中 **core 两行在最前**：

1. `ZxplatCoreComponentRegistrationConfiguration` — 先 `@ComponentScan` 注册 `core` 下组件（如 `ICurrentUser`）
2. `ZxplatCoreAutoConfiguration` — 再声明 `@Bean`（避免 Bean 创建时依赖尚未就绪）

其后才是 audit / tenant / identity / … / web。

## Extension Points

- 实现 `ZxplatModuleDescriptor` 注册扩展模块元数据。
- 实现 `IAuditingStore` 自定义审计存储（默认由包 `audit` 提供）。
- 替换 `IDomainEventPublisher` Bean（`@ConditionalOnMissingBean`）。
- 实体实现 `IExcludeFromAudit` / `IAuditSummary` 控制审计内容。
