# 包 · menu（菜单）

> **源码包**：`com.zxplat.framework.menu`  ·  目录：`zxplat-framework/src/main/java/com/zxplat/framework/menu/`

> 系统菜单树、与 Navigation 权限对齐、按登录用户过滤可见菜单。

## Overview

| 项 | 值 |
|----|-----|
| 制品 | `com.zxplat:zxplat-framework`（包 menu） |
| 包根 | `com.zxplat.framework.menu` |
| AutoConfiguration | `ZxplatMenuAutoConfiguration` |
| 依赖 | 包 `permission` |

## Key Types

| 类型 | 说明 |
|------|------|
| `Menu` | 菜单实体（树形 parentId、path、permissionName 等） |
| `MenuAppService` | 菜单 CRUD 与树查询 |

## AppServices · MenuAppService

| 方法 | 说明 |
|------|------|
| `getById` | 单条 |
| `getTree` | 完整树（管理端，含隐藏/禁用） |
| `getGrantTree` | 授权树（仅启用且可见页面） |
| `getTreeByLoginUser` | 当前用户可见菜单 |
| `getList` | 分页 |
| `create` / `update` / `delete` | CRUD |
| `enable` / `disable` | 状态 |

## 与权限的关系

- 菜单节点可关联 `permissionName`。
- 角色通过 `RoleAppService.assignPermissions` 分配 Navigation 权限。
- 前端路由与 `getTreeByLoginUser` 结果对齐。

## Database

| `whale_menus` | 菜单树 |
