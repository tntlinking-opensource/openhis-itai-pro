# 包 · setting（设置）

> **源码包**：`com.zxplat.framework.setting`  ·  目录：`zxplat-framework/src/main/java/com/zxplat/framework/setting/`

> 基于 Provider 的分层配置管理（对标 ABP Setting Management）。

## Overview

| 项 | 值 |
|----|-----|
| 制品 | `com.zxplat:zxplat-framework`（包 setting） |
| 包根 | `com.zxplat.framework.setting` |
| AutoConfiguration | `ZxplatSettingAutoConfiguration` |

## Key Types

| 类型 | 说明 |
|------|------|
| `Setting` | 配置实体（name、value、providerName、providerKey） |
| `SettingManager` | 领域层取值逻辑 |
| `SettingAppService` | 管理 API |
| `SettingDefinitionEnum` | 配置项定义（代码枚举/catalog；前端「系统设置」主列表来源） |

## Provider 模型

| providerName | 含义 | providerKey |
|--------------|------|-------------|
| `G` | 全局 | 空 |
| `T` | 租户 | 租户 ID |
| `R` | 角色 | 角色 ID |
| `U` | 用户 | 用户 ID |

**生效优先级**：`U > R > T > G`

若当前用户多个角色在 R 层命中不同 value，抛出冲突异常。

## SettingDefinitionEnum（配置源）

| name | 标题 | 值约定 | 默认（种子） |
|------|------|--------|--------------|
| `deviceAutoInventoryDeductSwich` | 耗材是否自动扣库 | `1` 开 / `0` 关 | `1` |
| `outpatientPrescriptionAmountLimitYuan` | 门诊处方金额上限（元） | 数值字符串；`99999` 实质关闭金额拆方 | 种子 **`1000`** |
| `inventoryExpireWarningDays` | 库存效期预警天数 | 剩余天数 ≤ 配置值 | 种子 **`90`** |
| `inventoryMinPackageQuantityWarning` | 库存预警包装单位数量 | 全院包装合计 &lt; 配置值 | 种子 **`30`** |
| `inpatientStandingOrderSplittable` | 住院长嘱是否可拆 | `1` 可拆（默认，按日频次槽逐点执行）/ `0` 不可拆；不可拆且长期+包装≠拆零+口服类时 **IF-IP-EXE-01** 一盒一首锚点、**IF-IP-EXE-02** 整包装写量（**AS-IP-NUR-004 BR-IP-EXE-035**）；汇总领药 IF-IP-SUM-01 仅 `planned ≤ deadline` | **`1`** |
| `doctorStationWesternDiagnosisSources` | 医生站西医诊断检索目录来源 | 逗号分隔 `source_enum`；仅西医白名单有效；空/非法回落默认 | **`hospital_dx,general_dx`** |

> 已退役：`studentSwich`（学生开关）、`ybSwich`（医保开关）、**`registrationDoctorRequired`（挂号医生必选；统一可选，见 AS-OP-FIN-001 BR-REG-001）**。学籍入口不再受设置门控；门诊发药进销存上传由 `InventoryUploadExtension#isEnabled` 门控，不读 `whale_settings`。

种子数据落在 `V10__seed_platform.sql` 的 `whale_settings`（改种子即可，不另开 Flyway）。存量库清理见 `V13__drop_registration_doctor_required_setting.sql`。

## AppServices · SettingAppService

| 方法 | 说明 |
|------|------|
| `getById` / `getByName` / `getByNameAndProvider` | 精确查询 |
| `getValue` / `getValueOrDefault` | 按 name 取值 |
| `getEffectiveValue` | 按优先级计算最终值 |
| `init` / `initDefinitions` | UI 初始化（Provider 下拉、定义 catalog） |
| `getProviderKeys` | Provider 可选 key 列表 |
| `getList` | 分页维护 |
| `create` / `update` / `delete` | CRUD |
| `setValue` | 按 name upsert |
| `deleteByName` / `deleteByProvider` | 批量删除 |

## 业务代码取值

推荐注入 `SettingManager`：

```java
String value = settingManager.getEffectiveValue("inpatientStandingOrderSplittable");
```

开关型配置开启值常量：`GeneralSharedConstants.WHALE_SETTING_SWITCH_ON`（`"1"`）。

## Configuration

app:

      maximum-size: 1000
