## 1. 定位

可选 **`module-pacs-imaging-starter`**；国基装配 **Orthanc + OHIF + DICOMweb**。  
**禁止**：自研 Viewer；把阅片菜单并入 zxplat health-app / domain 核心；未过 D-9 选型定稿即写 Orthanc 业务码。

| 维度 | 说明 |
|------|------|
| 部署 | 与 RIS 同院或同网；独立进程跑 Orthanc/OHIF |
| 开关 | `zxplat.modules.pacs.imaging.enabled` |
| 收费 | 增值 License（文档口径） |
| 依赖 | 读 `PacsWorkItem`；写 `ImagingStudy`/`Media`；回写 `hasMedia` |

---

## 2. 逻辑架构（国基）

```text
设备 ──C-STORE──► Orthanc（DICOM 原图）
报告关键图 ──HTTP──► MinIO key-images（不进 OHIF）
OHIF ◄──DICOMweb QIDO/WADO── Orthanc
```

| 数据 | 落点 |
|------|------|
| 设备入库 | Orthanc，C-STORE |
| 阅片取图 | Orthanc DICOMweb → OHIF |
| 关键图 | MinIO 桶 `key-images` |

---

## 3. Maven（目标态 · 与 modules-all 一致）

```text
zxplat-plugin/zxplat-module-pacs-imaging/
  module-pacs-imaging-domain/         ImagingStudy、Media、ViewerEndpoint
  module-pacs-imaging-application/    PacsImageCapture / PacsViewer / ViewerUrlConfig + Orthanc/MinIO 端口
  module-pacs-imaging-starter/        条件装配（可选；默认不挂 health-app）
  deploy/                             Orthanc + MinIO 联调
```

**依赖方向**：imaging → `zxplat-domain`（读工单）；**禁止** health-app 编译期依赖 imaging（扩展反向由 Port/事件注入）。**无 bridge 层。**

---

## 4. 与 RIS 衔接要点

| 时点 | 行为 |
|------|------|
| EXE `completed` | 工单进入 IM-CAP 待采集列表 |
| CAP 入库成功 | 写 StudyUID；`hasMedia=true` |
| REP 书写/预览 | 可嵌关键图列表或「打开阅片」深链（IM-002） |
| 未装 imaging | RIS 仍可 PDF 闭环；无 DICOM 阅片（国基 C7 不达标） |

## 5. 首版（国基）能力切分

| 序号段 | 内容 | 组件 |
|--------|------|------|
| 50 | IM-CFG 阅片 URL | `pacs_viewer_endpoint` → OHIF 根 |
| 51～54 | 采集列表、Study 绑定、关键图、手工 DCM | Orthanc 收 DICOM；关键图进 MinIO；adapter 写索引 |
| 55～56 | 启动 URL/Token；报告引用 | OHIF |
| 57 | Orthanc+OHIF 部署联调 | Docker Compose |
| 58 | C-STORE / MWL | Orthanc SCP；MWL 可后置 |

成码已落地：领域见 [DM-PACS-003 SDD](./DomainModel-SDD/DM-PACS-003-影像索引与阅片端点-SDD.md)；应用见 AppService AS-PACS-IM-001～003。

## 6. 非功能

| 项 | 口径 |
|----|------|
| 安全 | 阅片 Token 短时有效；DICOMweb 勿对公网裸露 |
| 备份 | Orthanc 卷与 MinIO `key-images` 都纳入院点备份 |
| 观测 | 入库失败可查 application Orthanc/MinIO 端口日志（可与 `pacs_integration_log` 对齐扩展） |
