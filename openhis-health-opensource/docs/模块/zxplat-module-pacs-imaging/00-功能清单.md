## 一、职责边界

| 在内（本 Module） | 在外 |
|-------------------|------|
| **影像采集**：Worklist、DICOM 入库、DCM/PDF 上传、关键图、视频 | 登记、检查状态机（PACS 核心 EXE） |
| **影像阅片**：Web Viewer 入口、影像列表 | 报告书写/审核（PACS 核心 REP） |
| **阅片 URL** 配置 | HIS 接单（AS-PACS-INT-001） |
| 写 `ImagingStudy`、`Media`，回写 `PacsWorkItem.hasMedia` | 机构、会诊、医共体、外检 |

---

## 二、阶段

| 阶段 | 目标 | 遗留对标 |
|------|------|----------|
| **P1** | 采集列表 + Worklist 绑定 + 关键图/DCM 上传 + 阅片入口 | `saveDcm`、`savePic`、`goCheckWpacs` |
| **P2** | DICOM C-STORE 自动入库 + MWL 下发 + 视频/标注 | Worklist 表、`WorkStationServer` 影像 API |
| **P3** | 多存储节点、采集质控统计 | 边缘能力 |

### P1 完工定义（影像扩展首版）

- 核心 **EXE 已检** 的 `PacsWorkItem` 可在 **影像采集** 工作台列出
- 可 **绑定/查询 Study UID**（`STUUID`/`XDID`），更新 `ImagingStudy`
- 支持 **DCM/关键图手工上传**（≈ `saveDcm`、`savePic`），`hasMedia=true`
- 配置 **阅片 URL** 后，**影像阅片** 页可打开该检查影像
- 报告 REP 可嵌入关键图或外链阅片（引用 IM 产出）

## 四、领域实体（草案）

| 实体 | 说明 |
|------|------|
| `ImagingStudy` | Study/Series UID、模态、与 `PacsWorkItem` 1:0..1 |
| `Media` | 关键图、截图、视频索引 |
| `DocumentReference` | 上传 DCM/PDF 文件引用 |
| `pacs_viewer_endpoint` | 阅片 URL（IM-CFG） |
| `PacsWorkItem.hasMedia` | 采集完成后回写，供 REP/核心列表展示 |
