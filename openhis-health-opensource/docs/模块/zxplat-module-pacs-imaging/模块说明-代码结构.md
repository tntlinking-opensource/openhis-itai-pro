# PACS 影像扩展 · 代码结构

> **代码根**：`zxplat-plugin/zxplat-module-pacs-imaging/`  
> **包**：`com.zxplat.plugin.pacsimaging.*`  
> **文档**：[说明.md](./说明.md)

## Maven 层（无 bridge）

```text
module-pacs-imaging-domain
        ↓
module-pacs-imaging-application   （Enforcer：禁 zxplat-application；本插件无 bridge）
        ↓
module-pacs-imaging-starter       （可选；默认不挂 health-app）
```

| Artifact | 职责 |
|----------|------|
| `module-pacs-imaging-domain` | ImagingStudy / Media / ViewerEndpoint 实体、仓储、领域服务 |
| `module-pacs-imaging-application` | AppService、Orthanc/MinIO 端口、入站 Controller、自动装配、报告 SPI |
| `module-pacs-imaging-starter` | 安装入口 |

依赖：`zxplat-framework` + `zxplat-domain`（**仅** domain，不依赖 zxplat-application）。

## SPI 落点（报告）

| 接口 | 实现 | 包 |
|------|------|-----|
| `PacsReportImagingAttachmentPort` | `PacsReportImagingAttachmentPortImpl` | `…application.report.support` |

供 REP 书写装配关键图与阅片深链；无 Study/端点时降级空字段，不阻断报告。

## 开关

```properties
zxplat.modules.pacs.imaging.enabled=true
zxplat.modules.pacs.imaging.orthanc.enabled=true
zxplat.modules.pacs.imaging.minio.enabled=true
zxplat.modules.pacs.imaging.mwl-enabled=true
zxplat.modules.pacs.imaging.notify.token=...
zxplat.modules.pacs.imaging.notify.default-tenant-id=1
```

对照：`ImagingMiddlewareProperties`（`@ConfigurationProperties(prefix = "zxplat.modules.pacs.imaging")`）。

## with-pacs

starter **可选**，默认不进入 with-pacs / health-app reactor。显式依赖 + `enabled=true` 后启用。
