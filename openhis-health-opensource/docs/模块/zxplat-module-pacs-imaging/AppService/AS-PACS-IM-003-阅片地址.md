# 影像扩展 · 阅片地址 · 应用服务设计（AS）

> **编码**：AS-PACS-IM-003 · **版本**：v1.0 · **日期**：2026-09-21  
> **菜单**：阅片服务地址 · **类名**：`PacsViewerUrlConfigAppService`  
> **路由**：`POST /api/app/pacsViewerUrlConfig/{method}`  
> **选型**：国基端点指向 OHIF；取图仍由 OHIF 走 DICOMweb，本 AS 只存根地址

---

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 按机构、模态维护 OHIF（或外链模板）根地址；按机构/模态解析一条有效端点 |
| **在外** | 拼 StudyUID（IM-002）；Orthanc 端口与 AE Title（运维手册） |
| **涉及域** | ViewerEndpoint（imaging） |

### 1.2 角色与关键动作

| 角色 | 动作 |
|------|------|
| **实施/信息科** | 查询、保存阅片根地址，按模态试匹配 |

### 1.3 术语

| 术语 | 口径 |
|------|------|
| **端点** | `baseUrl` + 启用标志；可限定 `orgId`、`modalityCode`，空表示默认 |
| **匹配** | 先机构+模态，再机构默认，再全局默认 |

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **本期（序号 50）** | CFG-01 列表与保存、CFG-02 匹配 |
| **非目标** | 在本页改 Orthanc/MinIO 地址 |

### 1.5 领域清单

| 聚合 | DM |
|------|-----|
| ViewerEndpoint | 契约见 [DM-PACS-003](../DomainModel/DM-PACS-003-影像索引与阅片端点.md)；**领域+应用已实现**（2026-09-22） |

### 1.6 业务规则

| 编号 | 规则 | IF |
|------|------|-----|
| **BR-VCFG-01** | `baseUrl` 必填，须为 http(s) 根，不含 StudyUID | CFG-01 |
| **BR-VCFG-02** | 同一机构+模态只保留一条启用记录 | CFG-01 |
| **BR-VCFG-03** | 匹配顺序：机构+模态 → 机构默认 → 全局默认 | CFG-02 |

| IF | 用户动作 | 语义 | 读写 | 关键规则 | 状态变化 | 涉及领域 |
|----|----------|------|:--:|----------|----------|----------|

## 4. 接口编排说明书

### 4.1 IF-PACS-IM-CFG-01

| 维度 | 说明 |
|------|------|
| **主路径（读）** | 按机构列出端点 |
| **主路径（写）** | 校验 URL → 同一机构+模态旧启用记录改为停用 → 保存新记录 |
| **失败** | URL 非法；越权改其他机构 |

### 4.2 IF-PACS-IM-CFG-02

| 维度 | 说明 |
|------|------|
| **主路径** | 按 BR-VCFG-03 返回一条 `baseUrl` |
| **失败** | 没有任何启用端点 |

---

## 5. 业务异常

| 码 | 场景 | 可重试 |
|----|------|:--:|
| `PACS_VIEWER_ENDPOINT_INVALID` | URL 为空或不是 http(s) | 否 |
| `PACS_VIEWER_ENDPOINT_NOT_FOUND` | 匹配不到 | 否 |

---

## 6. 事件语义

本 AS 不发布领域事件。IM-002 每次启动时读当前配置。

---

## 7. 非功能性需求

保存后下一次打开阅片即用新地址，不要求重启。

---

## 8. 测试要点

- 非法 URL 保存失败
- 同一机构+模态保存第二条后，匹配只命中新记录
- 仅有全局默认时，任意模态能匹配到该默认
