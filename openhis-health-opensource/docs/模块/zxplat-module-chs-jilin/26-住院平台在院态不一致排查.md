# 住院平台在院态不一致排查

平台真相以 **5201 `inhosp_stas`** 为准；本地只存 `yb_encounter_platform_map.mdtrt_id`，**不存**「平台已出院」布尔位。院内 `EncounterStatus` 与平台在院态不同步落库。

## 主路径（应顺畅）

| 节点 | 平台 | 本地 |
|------|------|------|
| 住院登记 | 2401 | 写 map |
| 取消登记 | 2404 | 软删 map |
| 预结算/传费 | resolveOrRegister；死号则换号重传 | map / fee_upload / pre_settle |
| 正式结算（出院全结） | 清多余在院 → 2402 → 2304 → 幂等 2402 | 支付 SUCCESS |
| 反结 / 召回 | **2305 → 2405 → 2302** 后再本地逆向 | 费用再生、就诊回退 |

## 快速核对（王文斌类乱数）

1. **医保信息查询 5201**：同人 `inhosp_stas=1` 有几条？mdtrt 是哪些？
2. **本地表**
   - `yb_encounter_platform_map`：当前就诊未删映射的 `mdtrt_id`
   - `yb_inpatient_fee_upload`：费用挂在哪个 mdtrt、`upload_status`
   - `yb_inpatient_pre_settle`：ACTIVE/SETTLED/REVOKED 与 mdtrt
   - `yb_settlement_record`：正式结算回执是否仍 CONFIRMED
3. **调用日志**：最近 2401 / 2402 / 2404 / 2304 / 2305 / 2405 成败

## 收费处「平台在院对齐」

工具栏按钮：**平台在院对齐**（读卡 → 诊断 → 可选一键修复）

| mismatchCode | 含义 | 一键修复 |
|--------------|------|----------|
| `OK` | 本地 map 在平台在院且无多余 | 无需 |
| `NO_LOCAL_MAP` | 本地无 map、平台无在院 | 无需（下次预结 2401） |
| `MULTI_INHOSP` | 同人多余在院 | 2404 清其它，保留本单 mdtrt |
| `LOCAL_DEAD` / `PLATFORM_OUT_LOCAL_IN` | 本地号不在平台在院列表 | 软删 map + 费用上传标撤销 |
| `PLATFORM_ORPHAN_INHOSP` | 平台有在院、本地无 map | **不自动清全部**；用 5201 人工 |

## 推荐处理顺序

1. 先点「平台在院对齐」看诊断  
2. 可修则一键修复；`PLATFORM_ORPHAN_INHOSP` / 清不掉的多在院 → 5201 人工 2404  
3. 再完整预结算 → 正式结算  
4. 若 HIS 已结但平台未撤：走反结/召回（现已出站 2305/2405/2302）

## 错误文案前缀

- `【多在院】`：同人多余在院，优先对齐工具或 5201  
- `【死就诊】`：本地 mdtrt 失效且自动换号失败，先对齐软删再预结
