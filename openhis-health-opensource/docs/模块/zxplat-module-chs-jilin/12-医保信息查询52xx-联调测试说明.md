# 医保信息查询（52xx）— 联调测试说明

> **前置**：[11-医保信息查询52xx-详细设计.md](./11-医保信息查询52xx-详细设计.md)  
> **环境**：吉林省医保测试平台 + `zxplat.modules.chs.enabled=true`  
> **版本**：v1.0 | **日期**：2026-06-15

---

## 1. 环境准备

| 项 | 要求 |
|----|------|
| Profile | `health-app` 使用 `-Pwith-chs` 或 `-Pdev`（embedded） |
| 契约 | `contract.{bus_no}.*` 已配置 `fixmedins_code`、国密、网关 URL |
| 签到 | 测试前执行 9001（UI 自动 `ensureInsuranceSignIn`） |
| 测试人员 | 测试库中 **已有本机构就诊/结算记录** 的参保人（需真实 `psn_no`） |
| 菜单 | Flyway V88 执行后可见「医保管理 → 医保信息查询」 |

---

## 2. 测试数据建议

| 类型 | 说明 |
|------|------|
| 门诊医保结算 | 近 30 天内完成 2207 的患者 → 5201/5203/5204 |
| 住院在院/出院 | `med_type=21`，含 `inhosp_stas` → 5201 |
| 门诊慢特病 | 已备案慢特病且有用药 → 5205 |
| 跨月累计 | 当年有多次结算 → 5206 |

读卡方式：页面「读卡」或收费窗口同款 1101；记录 `psn_no`、姓名、`insutype` 备查。

---

## 3. 功能用例

### 3.1 5201 就诊信息查询

| 步骤 | 操作 |
|------|------|
| 1 | 打开 **医保信息查询** → Tab「就诊查询」 |
| 2 | 选择契约 → 读卡 → 确认 `psn_no` 已填 |
| 3 | 医疗类别选 **11（门诊）**，时间范围 **近 30 天** → 查询 |
| 4 | 改医疗类别 **21（住院）** 再查（若有住院数据） |

**期望**：

- 列表含 `mdtrt_id`、`begntime`/`endtime`、`med_type`、`inhosp_stas`（住院）
- 平台无数据时表格为空 + 友好提示，非 500 错误

### 3.2 5202 诊断信息

| 步骤 | 操作 |
|------|------|
| 1 | 在 5201 列表选一行 → 打开「诊断」子 Tab / Drawer |
| 2 | 自动带 `mdtrt_id` + `psn_no` 请求 5202 |

**期望**：

- 至少 1 条诊断；`maindiag_flag=1` 的主诊断存在
- `diag_code` / `diag_name` 与 HIS 当次就诊一致（若同源）

### 3.3 5203 结算信息

| 步骤 | 操作 |
|------|------|
| 1 | 选含 **setl_id** 的就诊行（5201 若未返回 setl_id，从本地结算单或 3202 明细取） |
| 2 | 打开「结算」子 Tab，填写/带入 `setl_id` → 查询 |

**期望**：

- 头部：`medfee_sumamt`、`fund_pay_sumamt`、`acct_pay`、`psn_pay` 等与 2207/2304 返回一致（允许分厘差）
- `setldetail` 表：多条基金分项，`fund_pay_type` / `fund_payamt` 有值

### 3.4 5204 费用明细

| 步骤 | 操作 |
|------|------|
| 1 | 同一 `mdtrt_id` → 「费用明细」子 Tab |
| 2 | 可选填 `setl_id` 缩小范围 |

**期望**：

- 多行明细；`hilist_code`、`det_item_fee_sumamt`、`chrgitm_lv` 有值
- 条数与本地 2204 上传明细量级接近（不要求逐行一致，联调以平台为准）

### 3.5 5205 慢特病用药

| 步骤 | 操作 |
|------|------|
| 1 | Tab「慢特病用药」→ 读卡 → 时间近 **90 天** → 查询 |

**期望**：

- 慢特病患者有 `feedetail` 行；含 `hilist_name`、`fee_ocur_time`
- 非慢特病患者可为空表

### 3.6 5206 人员累计

| 步骤 | 操作 |
|------|------|
| 1 | Tab「人员累计」→ 读卡 |
| 2 | 累计年月选 **当月**（或留空）→ 查询 |

**期望**：

- `cuminfo` 含 `cum_type_code`、`cum` 数值
- 与窗口理解的「起付线累计」「账户累计」等可人工对照

---

## 4. 异常与边界

| 用例 | 操作 | 期望 |
|------|------|------|
| E1 未签到 | 清除 sign 缓存后直接查询 | UI 提示签到或自动签到 |
| E2 空 psn_no | 不读卡直接查询 | 前端校验拦截 |
| E3 超长跨度 | 5201 时间 >92 天 | 后端 `BR-MIQ-003` 拒绝 |
| E4 5203 缺 setl_id | 不填 setl_id 查 5203 | 后端校验提示 |
| E5 错误 mdtrt_id | 伪造 mdtrt_id | 平台 infcode 非 0，前端展示 err_msg |
| E6 remote | `-Pwith-chs-remote` 重复 T1–T3 | 与 embedded 结果一致 |
