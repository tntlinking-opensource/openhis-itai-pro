## 1. 挂号正式结算：支付草稿金额与收费明细不一致

| 项 | 内容 |
|----|------|
| **环节** | 市医保挂号正式缴费（IF-REG-07） |
| **报错** | `PAY-BIZ-409`：支付草稿金额与收费明细不一致，请重新预结算 |
| **场景** | `ybRegisterFee=true`，预结算成功后点缴费；有基金/个账分担时必现 |
| **要点** | 医保预结算后草稿 `displayAmount` 为个人现金应付，收费明细仍为挂号费原价；门禁按原价强等 |

## 2. 医生站签发事前提醒：`chargeItemIds` 空指针

| 项 | 内容 |
|----|------|
| **环节** | 门诊医生站签发医嘱/申请后事前提醒（trig=2） |
| **报错** | `Cannot invoke "java.util.List.size()" because "chargeItemIds" is null` |
| **前端表现** | 事前提醒失败；已尝试签退本次签发 |
| **场景** | 医保费用性质签发；门禁请求不传 `chargeItemIds`（收费页会传勾选 ID） |
| **要点** | 后端 `enrichPreSettle` 对 null 直接 `size()` |

## 5. 事前提醒：参保人所属统筹区编码长度非法

| 项 | 内容 |
|----|------|
| **环节** | 3101 平台 FSI（长春市） |
| **报错** | 参保人所属统筹区编码长度不在范围内，应该在1到10之间（发送方流水号含 H22010402403…） |
| **场景** | 医生站签发不传 `insuplcAdmdvs` |
| **要点** | `poolarea` 应填参保所属统筹区码（如 `220199`）；空则长度 0。不是 `medins_id`（机构码 `H22010402403`） |

| **报错** | 出生日期不能为空（事前） |

## 7. 签发事前提醒：性别长度不在 1～3

| 项 | 内容 |
|----|------|
| **环节** | 3101 事前提醒（`patient_dtos.gend`） |
| **报错** | FSI-事前控制失败：性别长度不在范围内，应该在1到3之间 |
| **场景** | 医生站签发门禁；Snapshot 将 HIS `genderEnum`（`MALE`/`FEMALE`，长 4～6）原样作 `gend` |
| **要点** | 医保字典 GEND 为 `1`/`2`/`0`；须映射后再出站 |

## 8. 签发事前提醒：定点医疗机构名称长度不在 1～200

| 项 | 内容 |
|----|------|
| **环节** | 3101 事前提醒（`fsi_encounter_dtos.medins_name`） |
| **报错** | FSI-事前控制失败：定点医疗机构名称长度不在范围内，应该在1到200之间 |

## 9. 整包对照：apis/3101 必填 vs 联调实报文（勿再逐字段打补丁）

对用户报文与 [apis/31xx/3101](./apis/31xx/3101-明细审核事前分析服务.md) / 联调样例一次性对照：

| 节点 | 规范必填 | 联调实报文 | 处置 |
|------|----------|------------|------|
| `gend` | Y 长≤3 | 已修为 `1` | OK |
| `medins_name` | Y 1～200 | 曾乱码/空 | UTF-8 + `findFixmedinsName` |
| `adm_dept_codg` / `dscg_dept_codg` | Y 1～30 | **缺**（仅有名称） | `yb_no`→`bus_no` 回落；本地总检 |
| `dscg_date` | Y | **缺** | 门诊=`adm_date` |
| `out_setl_flag` | Y | **缺** | 默认 `0` |
| `fsi_order_dtos.rxno` | Y | **缺** | 无电子处方时回填 `rx_id` |
| `hilist_type`/`chrg_type`/`hilist_lv`/`hilist_name`/`hilist_pric` | Y | **缺** | ContextLoader+Projector 同源补齐 |
| `spec`/`spec_unt` | Y | **缺** | 默认 `-` / 数量单位 |
| `drord_dept_codg`/`drord_dr_profttl` | Y | 科室码缺 / 职称缺 | 同科室码；职称默认 `1` |

出站前门禁 **一次列出全部缺口**（`3101 报文必填缺失（请一次补齐）：…`），避免平台再逐字段打回。

## 10. 门诊收费成功：医保全报未开电子发票

| 项 | 内容 |
|----|------|
| **环节** | 门诊正式结算后电子发票（IF-OPC-07 / BR-INV-008） |
| **现象** | 收费成功，但未开出电子发票 |
| **场景** | 市医保结算后患者现金应付 `displayAmount=0`（基金/个账已付），原闸门按现金 ≤ 0 跳过开票 |
| **要点** | 开票应按**收费项合计票面**判断；医保已付不算 0；仅真正零元收费不开票 |

## 11. 门诊日结：市医保金额为 0、总收入为 0

| 项 | 内容 |
|----|------|
| **环节** | 报表中心 → 门诊日结（IF-OP-DCL-02） |
| **现象** | 市医保结算成功（如个账 6.01、`clr_optins=220199`），日结「市医保」全 0；金额落到「省医保」；「总收入」为 0.00 |
| **场景** | 朝阳 `fin_contract.bus_no=H22010402403-220199`；医保全个账时 payment `tendered/display=0` |
| **要点** | ① 日结归桶曾用短码 `equals(220199)`，完整 bus_no 未命中后回落省桶；② 分类快照按 tendered 分摊导致 `fin_payment_rec_static.amount=0`；③ 冲销后 yb=REVOKED 但桥表曾仍 CONFIRMED，日结虚增个账 |

## 共性观察

医生站签发事前提醒（trig=2）相对收费预结算（trig=7）**少传读卡上下文**；更关键的是 Snapshot→3101 投影长期只填费用上传子集，**未按表 116/118 全量必填组装**。后续以本地总检为准，禁止再「平台报一个改一个」。
