## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 扫描约定目录（标准落地包子目录）预览 → 二次确认入库；应用（镜像叠加 + 支付对照回写）；文件/明细/报告/待办查询；标准包回下；手动重验；应用前差异预览 |
| **在外** | 13xx 下载主链（AS-CHS-CAT-002，仅回调本域校验）；国家目录选码页（AS-CHS-CAT-001）；3301/3302（AS-CHS-CAT-003）；门诊/住院开单与费用上传（消费本域门禁，非本页按钮） |
| **涉及域** | 医保文件通知（本 DM）；HIS 药品/诊疗/耗材定义与未收费费用明细（经领域 Port，不扩本 AS IF） |
| **平台 infno** | 无 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| 医保运维 / 物价 | 重新扫描、确认入库、浏览文件/明细、应用、下载标准包、手动重验、关待办 |
| 医保负责人 | 查看首页停用/甲乙类催办 |
| 系统 | CAT-002 入库成功后触发合规校验（无 UI 按钮，见 §6） |

### 1.3 术语与口径约定

| 术语 | 口径 |
|------|------|
| 标准落地包 | `notice.meta.json` + `notice.lines.csv`（见方案 §6.0） |
| doc_kind | `CATALOG_DELTA` 目录增减废；`PAYMENT_MAP` 支付对照 |
| overlay | 不改 13xx 镜像主列的通知叠加 |
| 硬阻断 | 开单与 2204/2301 上传拒绝（C-STOP-ACTIVE / C-PAY-CLASS / C-PRICE-OVER / C-PROJECT-UNMAPPED） |
| 无限价 | C-PRICE-UNKNOWN，允许开单/上传 |
| 院外洗数 | 产品不提供原件转包；洗成标准包落到约定目录后由本页「重新扫描」入库（不提供手工上传） |
| 扫描根目录 | 配置 `chs.notice.canonical-root`；结构 `{root}/{stem}/notice.meta.json` + `notice.lines.csv` |

### 1.4 本期范围与非目标

**本期：** 全品类（含制剂）+ 支付对照；标准包必留；局发原件不强制；下载校验不阻断；停用/甲乙/超限硬阻断；甲乙类应用时直接回写目录 lv 并同步未收费明细。

**非目标：** 产品内 AI 转标准包；强制存局发原件；静默改已收费历史明细；用 `01*` 伪造国家码；本页不承载 13xx 下载按钮。

**交互清单来源：** 前端页尚未落库；用户动作以方案 §4/§10 与本期评审 IF 为准（已确认）。

## 4. 接口编排说明书（业务步骤）

### 4.1 IF-CHS-CAT-005-W-01 重新扫描约定目录

| 维度 | 说明 |
|------|------|
| 触发前提 | 已登录；具备导入权限；`chs.notice.canonical-root` 已配置且可读 |
| 主路径 | 枚举一级子目录 → 解析 meta+csv → 算 hash → 对照库内标记 NEW/DUPLICATE/FAILED → 返回 scanToken 与清单 |
| 关键分支 | 请求可临时覆盖 scanRoot；已入库同 hash → DUPLICATE |
| 失败分支 | 根目录未配置/不可读 → 失败；单包缺文件或非法 → 该项 FAILED，不中断整批 |
| 查询侧 | 无持久刷新 |

### 4.2 IF-CHS-CAT-005-W-02 确认扫描入库

| 维度 | 说明 |
|------|------|
| 触发前提 | 持有有效 scanToken；用户二次确认勾选包（默认可全选 NEW） |
| 主路径 | 校验 hash → 存储标准包 → 持久化文件头与明细 → 返回各包 docId |
| 关键分支 | force=true 允许对 DUPLICATE 软删旧 doc 重导 |
| 失败分支 | 令牌过期；单包存储失败记入结果，其它包可继续（按实现批事务约定） |
| 查询侧 | 成功后文件列表可见新文件 |

### 4.3 IF-CHS-CAT-005-W-03 应用文件

| 维度 | 说明 |
|------|------|
| 触发前提 | 文件已入库且未撤销；用户二次确认（宜先看 R-06） |
| 主路径 | 按行动作：STOP/ADD/MODIFY 写 overlay；SET_PAY_CLASS 写 overlay+回写院内 lv+同步未收费明细+记 apply_log（含单据列表）→ 更新 apply_status → 重算待办 |
| 关键分支 | 仅 project 无国家码 → 映射 PENDING，不造假 hilist |
| 失败分支 | 部分行失败可记行级结果；关键写失败整单回滚（见 NFR） |
| 查询侧 | 应用后催办与选码可用语义变化 |

### 4.4 IF-CHS-CAT-005-W-04 关闭待办

| 维度 | 说明 |
|------|------|
| 触发前提 | 待办 OPEN；用户声明已处理原因 |
| 主路径 | 关闭待办记录 |
| 关键分支 | — |
| 失败分支 | 待办不存在/已关闭 |
| 查询侧 | 汇总减少；**不**自动解除硬阻断（阻断只看生效条件） |

### 4.5 IF-CHS-CAT-005-W-05 再次执行校验

| 维度 | 说明 |
|------|------|
| 触发前提 | 可选 contract/listType；权限 |
| 主路径 | 对照已应用通知与镜像/院内 → 生成报告并覆盖最新 |
| 关键分支 | 不下发平台；不改游标 |
| 失败分支 | 报告生成失败提示可重试 |
| 查询侧 | R-03 可见新报告 |

### 4.6 IF-CHS-CAT-005-R-01～R-06（读）

| IF | 主路径摘要 |
|----|------------|
| R-01 | 按过滤条件分页文件头 |
| R-02 | 按 docId + action 等分页明细 |
| R-03 | 按契约/目录类型取最新合规报告 |
| R-04 | 汇总停用/甲乙类 OPEN 数 + 分页待办 |
| R-05 | 校验 doc 存在 → 回写标准包字节流 |
| R-06 | 估算即将写入的 overlay/回写/未收费同步样例与计数 |

## 5. 业务异常与用户提示

| 场景 | 用户提示语义 | 可重试 |
|------|--------------|--------|
| 扫描根未配置/不可读 | 请配置 chs.notice.canonical-root 并放入标准包目录 | 是（改配置） |
| 单包格式不支持/损坏 | 该项 FAILED；请院外洗包后重新扫描 | 是（修目录后重扫） |
| 重复导入 | 扫描结果标 DUPLICATE；默认识别跳过 | 否（除非 force 重导） |
| 预览缺主键 | 指出 Sheet/列问题 | 是 |
| 应用失败 | 应用未完成，请重试或联系管理员 | 是 |
| 待办已关闭 | 无需重复关闭 | 否 |
| 报告生成失败 | 重验失败，请稍后重试 | 是 |
| 硬阻断（结算侧） | 编码+原因码+来源文件/限价/等级 | 改数据后重试 |

## 6. 事件语义与消费方

| 事件 | 触发相位 | 消费方 | 幂等 |
|------|----------|--------|------|
| CatalogNoticeImported | W-02 成功后 | 审计/可选通知 | 按 docId |
| CatalogNoticeApplied | W-03 成功后 | 待办重算、选码可用 | 按 docId+appliedAt |
| CatalogNoticeComplianceRan | W-05 或 CAT-002 入库钩子 | 下载页校验条、报告页 | 覆盖最新报告 |
| CatalogImportCompleted（外来） | CAT-002 入库成功 | 本域自动跑合规（等同 W-05 语义，无独立 IF） | 同 listType 可重入 |

## 7. 非功能性需求

| 项 | 承诺 |
|----|------|
| 性能 | 单次预览/入库建议支持万行级异步升级路径（首期可同步+超时提示） |
| 幂等 | W-02 靠 hash；W-03 重复应用以最新覆盖 overlay 并追加日志 |
| 并发 | 同 doc 应用串行；报告覆盖写最后成功为准 |
| 一致性 | 应用单事务；下载钩子校验失败不影响下载事务 |
| 审计 | 应用与 lv 回写必留 apply_log；未收费单据列表入库 |
| 附件 | 仅标准包必留 |
