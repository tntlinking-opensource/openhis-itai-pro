# 事前提醒试调 · 应用服务设计（AS）

> **页面边界**：医保办在 **事前提醒试调** 单页内手工/按就诊触发 **3101**，并对违规明细试发 **3103** 反馈。**在内** 试调 IF；**在外** 收费主路径嵌入对话框与 W2 Extension 挂接。
>
> **编码**：AS-CHS-AUD-001 · **版本**：v0.1 · **日期**：2026-07-23  
> **详细设计编号**：AS-CHS-AUD-001

---

## 1. 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 3101 手工 Command、3101 从门诊就诊组装、3103 反馈试调；结果落库摘要 |
| **在外** | 医生站/收费处嵌入对话框（W2）；违规统计研讨页（W3）；3102 |
| **平台 infno** | 3101、3103 |
| **路由** | `/chs/detail-audit-try` |

## 2. 接口概览

| IF 编号 | 语义 | infno | HTTP 方法 |
|---------|------|-------|-----------|
| IF-CHS-AUD-C-01 | 手工/粘贴 Command 事前分析 | 3101 | `analyze3101` |
| IF-CHS-AUD-C-02 | 从门诊就诊组装后事前分析 | 3101 | `analyze3101FromEncounter` |
| IF-CHS-AUD-C-03 | 事前提醒反馈 | 3103 | `feedback3103` |

## 3. 关键业务规则

| 规则 | 说明 |
|------|------|
| syscode | 必填：入参或 `zxplat.chs.audit.syscode`；无默认 |
| warn_rslt_id | 填明细 `jrd_id`（吉林 R7）；无明细时回退 `jr_id` |
| dspo_way=1 | `dspo_way_rea` 必填 |
| 平台失败 | 阻断，不可静默继续 |
| 资金链 | 本页不进入 2206/2303 |
