# 对账清算中心 · 应用服务设计（AS）

> **文档职责**：说明「医保对账清算中心」页面的**接口契约（IF）**、业务语义、涉及领域与平台 infno、编排意图。
>
> **本文禁止写**：具体类名/方法名；Request/Response 字段明细；包路径。
>
> **页面边界**：医保/财务运维人员在同一 **对账清算中心**（单 Vue 页、多 Tab）内完成：**日对账（3201）**、**明细对账（3202，含 9101 上传 + 9102 下载解析）**、**本地对账/清算流水查阅**、**吉林省月清算（3206A→3203A→3205A/3204A）**、**清算金额汇总**、**跨省三方对账失败查询（3209A）**。本页为 **医保基金对账与清算运维** 边界。
>
> **与收银分工**：门诊/住院 **2207/2304 结算** 在收银 Extension（**在外**）；本页 **不发起** 正常结算，仅对账、清算与结果查阅。
>
> **与工伤分工**：页内「工伤对账（1320）」Tab 调用 **zxplat-module-work-injury**（**在外**，不纳入本 AS IF 编号）。
>
> **编码**：AS-CHS-REC-001 · **版本**：v0.4 · **日期**：2026-09-29  
> **详细设计编号**：AS-CHS-REC-001

## 1. 场景概述

### 1.1 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | **3201** 日对账并落本地日账结果；**3202** 明细对账（9101 文件上传 → 3202 申请 → 9102 下载 → 解析入库）；**3203A** 吉林清算申请、**3204A** 撤销、**3205A** 状态查询、**3206A** 清算机构查询；**3209A** 跨省失败数据查询；**summarizeClearAmounts** / **previewReconDetailRows** 本地汇总；**listLocal** 系列查本地已落库对账/清算/明细流水 |
| **在外** | 2207/2304/2601 结算与冲正；**1320 工伤对账**（独立 module）；目录 **9102** 在目录下载 AS 亦使用（共享 invoker，边界不同） |
| **涉及域** | **YbReconciliation** 相关实体与服务；本地汇总 Query（结算快照 + 撤销凭证）；契约配置 |
| **平台 infno** | 3201、3202、3203A、3204A、3205A、3206A、3209A；文件 9101、9102 |
| **编排权威** | 3202 多步经 **workflow**（9101 → 3202 → 9102）；其余 infno 经对应 **invoker** |
| **前置** | 有效契约；写操作前 **9001**；3202 需可生成符合平台要求的明细文件 |
| **后置** | 对账/清算结果持久化；本地列表可查阅历史 |

### 1.2 角色与关键动作

| 角色 | 关键动作 |
|------|----------|
| **医保办** | 日对账 → 不平则明细对账 → 查阅本地流水 |
| **财务/医保清算** | 汇总清算金额 → 查清算机构 → 提交 3203A → 查 3205A 状态 → 必要时 3204A 撤销 |
| **跨省业务运维** | 3209A 查询未成功数据 |

### 1.3 页内 Tab 与 AS 关系

| Tab（UI） | 性质 | AS 内组织 |
|-----------|------|-----------|
| 日对账（3201） | 平台写 + 本地列表 | 多 IF，**同一 AS** |
| 月清算（3206A→3203A） | 清算闭环 | 多 IF，**同一 AS** |
| 工伤对账（1320） | 独立模块 | **在外**，不记本 AS IF |

> Tab 为同一「对账清算中心」页面边界内的子能力，**不拆** 多个 AppService（对齐 health 单据页多方法模式，而非护士站多 AS）。

### 1.4 本期范围与非目标

| 类别 | 内容 |
|------|------|
| **本期** | 吉林省 3203A 清算链路；3202 文件对账；本地三类 list |
| **非目标** | 银行到账核对；HIS 收银日报（health 财务 AS） |

### 1.5 业务规则（BR-*）

| 规则 ID | 描述 | 绑定 IF |
|---------|------|---------|
| **BR-CHS-REC-001** | 写操作须有效契约与签到 | IF-CHS-REC-W-* |
| **BR-CHS-REC-002** | 3201 须指定对账日期区间与险种等必填项 | IF-CHS-REC-W-01 |
| **BR-CHS-REC-003** | 3202 须先 9101 上传明细文件获 file_qury_no | IF-CHS-REC-W-02 |
| **BR-CHS-REC-004** | 3203A 前须 3206A 选定 clr_optins 且汇总金额一致 | IF-CHS-REC-W-03 |
| **BR-CHS-REC-005** | 3204A 仅对可撤销态清算单 | IF-CHS-REC-W-04 |
| **BR-CHS-REC-006** | 本地 list 按 tenant + contract + 月份过滤 | IF-CHS-REC-R-L* |
| **BR-CHS-REC-007** | IF-CHS-REC-R-02 仅读本院 HIS 结算快照（门诊正式结算 + 住院已结算预结算）与同窗撤销凭证，按险种（insutype）+ 清算类别（clrType）分组返回列表；可选过滤这两维；**不调用医保平台**。与 W-01 分工：R-02 只预览本地金额，真正对总账走 W-01（3201） | IF-CHS-REC-R-02 |
| **BR-CHS-REC-008** | 对账金额口径：医疗费总额 / 基金统筹 / 医保现金 / 个账支付按正向结算累加（含已撤销回执）、同窗撤销抵减（**一收一退净额为 0，不入净额**）；笔数口径：正向与撤销**各计 1 笔**（一收一退计 **2**）。3202 明细：**正向行仅 `status=CONFIRMED`**（`refd_setl_flag=0`）；**已 `REVOKED` 不得再以原 `setl_id` 打正向**（中心侧已是退费，会报「退费状态不一致」），只经同窗撤销凭证出反向（`revoke_setl_id` + `refd_setl_flag=1`） | IF-CHS-REC-R-02 / W-01 / W-02 |

## 3. 编排与领域（意图）

| 能力 | 编排意图 |
|------|----------|
| 3201 | Recon3201Invoker → 落本地日账；金额/笔数缺省时按本行险种×清算类别从本地汇总 **find** 补齐（口径同 **BR-CHS-REC-008**） |
| 3202 | Recon3202Workflow：生成明细文件（正向+撤销反向）→ Recon9101 → Recon3202 → Cat9102 解析 → 领域持久化；金额缺省时对区间汇总行 **merge** 折叠为合计 |
| 3203A–3206A、3209A | 各 Recon invoker |
| 本地 list | YbReconciliationDomainService / QueryService |
| 本地汇总（R-02） | 按险种×清算类别返回分组 **List**（正向结算累加 − 同窗撤销抵减；笔数含撤销）；供 UI 预览；3201/3202 金额缺省时分别按本行维度 find / merge 折叠区间合计 |
| 明细预览（R-01） | 同窗 **CONFIRMED** 正式结算正向行（`refd_setl_flag=0`）+ 撤销反向行（`=1`，`revoke_setl_id`）；**不含 REVOKED 正向**；跨日退费时原结算可在窗外，仍按撤销关联补全 |

## 4. 异常与非功能

| 类型 | 口径 |
|------|------|
| 3202 文件 | 生成/上传/下载任一步失败则整链失败，不落半态 |
| 平台对账不平 | 返回 stmt 结果码，UI 展示；允许发起 3202 |
| 清算 | 3205A 轮询状态；3204A 拒绝时展示平台原因 |
| 超时 | 3202 链路过长，前端须长超时 |

---

## 5. 业务向测试要点

1. 3201 成功后本地日账可 list；与平台 stmt 结果一致展示。
2. 3202：9101 上传 → 3202 返回 file → 9102 下载解析 → 本地明细 list 有新增。
3. 3206A 返回机构列表 → 3203A 提交 → 3205A 可查状态 → 3204A 可撤销。
4. 3209A 在跨省场景返回失败行。
5. 工伤 Tab 启用时调用 work-injury API，**不** 经过 `insuranceReconciliation` 的 320x IF。
6. R-02：同区间有多险种/清算类别时返回**多行分组**；可选过滤 `insutype`/`clrType` 仅收窄结果行；全程**不调医保平台**（与 W-01 分工）。
7. R-02 / W-01：**一收一退**同窗时四项金额净额为 0，笔数计 2；3202 正向仅 CONFIRMED；已撤销只出 `refd_setl_flag=1` 反向行（勿把 REVOKED 塞回正向）。
