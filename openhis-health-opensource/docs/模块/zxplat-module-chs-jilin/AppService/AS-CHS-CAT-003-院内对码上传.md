# 院内对码上传 · 应用服务设计（AS）

> **页面边界**：实施/药学/物价人员将 **院内药品、诊疗、耗材** 与国家目录编码建立对照并 **3301 上传 / 3302 撤销**；药品侧提供 **选码推荐**（可触发 1312 补库）。**在内** 三品类 3301/3302 与推荐；**在外** 国家目录镜像维护（CAT-001/002）、Workbench 批量作业（**AS-CHS-CAT-004**）、health 主数据维护页。
>
> **编码**：AS-CHS-CAT-003 · **版本**：v0.1 · **日期**：2026-07-11  
> **详细设计编号**：AS-CHS-CAT-003

---

## 1. 目标与边界

| 维度 | 说明 |
|------|------|
| **在内** | 药品/诊疗/耗材 3301 上传、3302 撤销；药品 mapping 推荐 |
| **在外** | health 药品/诊疗/耗材定义编辑（本页仅读 yb_no 并回写 match 标志经 adapter）；Workbench |
| **平台 infno** | 3301、3302、1312（推荐补库） |
| **跨域** | 读 health **MedicationDefinition** / **ActivityDefinition** / **DeviceDefinition** 组装 3301 行 |

## 2. 接口概览

| IF 编号 | 用户动作 | 读/写 | infno |
|---------|----------|-------|-------|
| IF-CHS-CAT-003-R-01 | 药品选码推荐 | 读 | 1312（可选） |
| IF-CHS-CAT-003-W-01 | 药品 3301 上传 | 写 | 3301 |
| IF-CHS-CAT-003-W-02 | 药品 3302 撤销 | 写 | 3302 |
| IF-CHS-CAT-003-W-03 | 诊疗 3301/3302 | 写 | 3301/3302 |
| IF-CHS-CAT-003-W-04 | 耗材 3301/3302 | 写 | 3301/3302 |

## 3. 演进备注

当前实现为 **单 AppService** 承载三品类；若 AS 评审将「诊疗/耗材对码」定义为 **在外** 独立菜单，可拆 **AS-CHS-CAT-003B/C** 而不改 infno 编排。
