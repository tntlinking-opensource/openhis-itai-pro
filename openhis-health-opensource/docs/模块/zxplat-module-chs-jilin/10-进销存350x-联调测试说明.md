## 3. 业务挂接入口（自动上报）

> **3502 搭配规则（吉林省）**：**3501** 成对 3502；**3503/3504** 成功后跟 3502（108/109）；**发药 3502(107)→3505**；**退药 3506→3502(106，批次=退药单号)**；单向隔离。详见 [09 §2.6](./09-医保进销存-详细设计.md#26-3502-用途与-infno-搭配吉林省落地--代码真源)。

| 场景 | 页面 | 期望 infno | 调完是否再调 3502 |
|------|------|------------|-------------------|
| 进货同意 | 药库进货 | 3503 | **否** |
| 药库退货供应商 | 药库退货 | 3504 | **否** |
| 盘点同意 | 药库/药房/科室盘点 | **3502**（仅盈亏行 103/104） | —（**不调 3501**） |
| 损益同意 | 药库/药房/科室损益 | 3502（reason=101–111） | — |
| 科室领用同意 | 科室领用 | 3502(**107** 其他出库) | — |
| 科室退领同意 | 科室退领 | 3502(**106** 其他入库) | — |
| **门诊**发药 | 发药页 | **3502(107)→3505**（**afterCommit + 异步**） | 3502 失败仍继续 3505 |
| **住院**按患者发药 | 发药页 | **不报 3505** | 院内绑码+HIS OUT；清床/无床直结再报 |
| 住院**汇总**核发 | 汇总发药页 | **不报** | 码落发放表后进清床合并 |
| 住院**清床**净销售合并 | 入出转清床 | **3502(107)→3505**（与门诊同 Orchestrator） | 3502 失败仍继续 3505；合并口径见 09 |
| 住院**无床直结**净销售合并 | 住院结算成功且 `DISCHARGED` | 同上 | 有活动床仍待清床 |
| 反结/召回（冲销合并销售） | 收银台反结/召回 | **3506→3502(106)** / **不报**（与门诊退药同路径） | 仅已成功合并 3505；伴生失败不回写 3506 |
| **门诊**退药 | 退药页 | **3506→3502(106)**（**afterCommit + 异步**） | 伴生批次=退药单号 |
| **住院**退药 | 退药页 | **不报 3506** | 退量计入清床/无床直结净销售合并 |
| 批初始化（运维） | 进销存运维 | 3501 + 3502(106) 成对 | **3501 每条必须跟 3502** |

**不上报（院内库位间 relocation，总库存不变）**：药库出库→药房/科室、药库/药房/科室调出与调入、药房入库壳单、药房退库、科室退库等。

| **T25 冲销后再结重报** | 清床/直结 3505 SUCCESS → 召回 3506 SUCCESS → 再结算（无床直结或再清床） | 原 3505 标 `DELETED`；发放表无合成退药；新净量按现发退相抵再报（新建上报流水） |
| **T26 住院在院退药** | 发药后确认退药（不结清床） | **无** 3506；清床/无床直结净量已相抵 |

## 5. 差异比对操作示例

### 5.1 3508–3511（批次维度）

1. 进销存运维页选择契约、日期区间  
2. 差异比对 Tab → 选择「3508 库存 ↔ 本地3501」等  
3. 可选填 `fixmedins_bchno`、`med_list_codg` 缩小范围  
4. 执行比对 → 查看 MATCH / LOCAL_ONLY / PLATFORM_ONLY

### 5.2 3512/3513（追溯码维度）

1. 选择「3512 入库追溯」或「3513 销售追溯」  
2. 建议填写 `drugTracCodg` 过滤（可选）  
3. 本地侧仅包含已成功上报且写入 `yb_inv_upload_trace` 的追溯码  
4. 无追溯码的入库/销售行不会出现在 3512 本地比对结果中

## 6. 失败排查

| 现象 | 排查 |
|------|------|
| 本地无流水 | `zxplat.chs.inventory.upload-enabled`；Client 是否装配；未对码 SKIPPED |
| FAILED 可重试 | `yb_inv_upload.upload_status=FAILED`；运维重试或 `retryPendingUploads` Worker |
| 平台有、本地无 | LOCAL_ONLY → 补传或检查业务是否触发 Client |
| 本地有、平台无 | PLATFORM_ONLY → 3507 删除错传后重传；或平台延迟 |
| 契约错误 | 配置 `default-contract-bus-no` 或业务页传 `contractBusNo` |
| 3502 类型错误 | 损益行检查 `reason`（inv_chg_type 101–111） |

## 8. 已知边界（Wave V）

- 耗材：全部不上报进销存（盘点/损益 Loader 跳过 `adm_device_definition`；3501/3503–3506 仅药品）  
- 赠药：仅损益 3502(110/111)，不从 3503 `prod_geay_flag` 上报  
- 退库：药房/药库下游/科室退库不上报  
- 生产联调：本文档为操作清单，吉林省平台实网验收需在院点环境执行
