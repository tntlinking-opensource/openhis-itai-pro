# 跨省挂号费强制自费与失败改自费 — 定稿方案

> **状态**：已定稿 · 吉林方案全局生效  
> **日期**：2026-09-11  
> **关联**：江志强（汕头 `440500`）挂号费医保 2206「没有有效的门诊选点」；[21-异地就医](./21-异地就医与省市医保双通道说明.md) · [22-挂号待遇确认](./22-挂号待遇确认-设计说明.md) · 5301 参保地透传修复  
> **代码**：`openhis-pro-ui` 挂号窗 · `OutpatientRegistrationAppService` 预结算门禁

---

## 1. 背景

| 现象 | 说明 |
|------|------|
| 跨省普通门诊挂号费医保 | 参保地（如广东汕头）校验「门诊选点」，2206 失败 |
| 同人慢特病结算 | 老系统 `med_type=140104` + 糖尿病备案可成功 |
| 5301 查不到备案 | 出站未带参保地（已对齐 2001 修复） |

目标：窗口少操作、系统默认避坑；资金知情点保留人工确认。

---

## 2. 评审定稿

| # | 决策 |
|---|------|
| 1 | **跨省**（参保地医保区划前两位 ≠ `22`）：强制挂号费自费；勾选「医保支付挂号费」**灰掉**，文案「跨省挂号费仅支持自费」 |
| 2 | 生效范围：**吉林 CHS 方案全局**（非单院开关） |
| 3 | **省内异地**本版不做（如市参保人在省直） |
| 4 | **任意患者**挂号费医保预结算失败 → **弹窗**；确认后改自费并 **同流程自动继续挂号**（打开核对窗） |
| 5 | 医生站备案导入打 `140104`/`140201`：现网已有；5301 修好后验收 |
| 6 | **不做**：有慢病就不传 `11`；挂号费改传 `140104`；静默改自费 |

### 江志强预期路径

读卡（见糖尿病备案）→ 跨省挂号费医保灰掉 → 确认挂号（自费）→ 医生导备案诊断 → 收费自动慢特病。

若仍走医保挂号费失败 → 弹窗确认 → 自动自费预结算并打开核对窗。

---

## 3. 判定口径

```text
insuplc_admdvs 去非数字后：
  长度 ≥ 2 且 前两位 ≠ "22"  → 跨省 → 强制挂号费自费
  前两位 = "22" 或无法判定   → 不强制（保持窗口勾选）
```

后端与前端同一口径；后端强制覆盖请求，防止绕过。

---

## 4. 实现落点

### 4.1 前端（挂号窗）

- `charge-type-category.ts`：`isCrossProvinceInsuplc`
- `register-left-panel.vue`：
  - 跨省：`useYbRegisterFee` 强制 `false`，Checkbox `disabled` + 说明
  - 提交：`ybRegisterFee` 传有效值（跨省恒 false）
  - `preRegisterSettlement` 失败且本次曾请求医保挂号费：`ElMessageBox` 确认 → 自费重试 → 成功则打开核对窗

### 4.2 后端

- `OutpatientRegistrationAppService#preRegisterSettlement`：跨省时 `ybRegisterFee` 强制 `false`（开户 + 跳过 2203/2204/2206 挂号费链）

### 4.3 已有能力（本方案验收，不重做）

- 5301/5302A `insuplcAdmdvs` 透传（对齐 2001）
- 医生站备案导入 `resolveOpspImportMedicalTypeCode` → `140104`/`140201`
- 收费按诊断 `med_type` 分组（收银员无改类别入口）

## 5. 验收清单

- [ ] 江志强读卡：待遇区可见糖尿病备案（5301）
- [ ] 跨省：「医保支付挂号费」灰掉 + 说明；提交体 `ybRegisterFee=false`
- [ ] 跨省确认挂号：本地预结算成功，可进核对收费
- [ ] 省内患者：勾选行为与现网一致（可医保挂号费）
- [ ] 省内勾选医保挂号费且平台失败：弹窗 → 确认 → 自费重试成功并打开核对窗
- [ ] 弹窗点取消：不自动挂号
- [ ] 医生导入备案诊断后收费走 `140104`（或打标类别）
