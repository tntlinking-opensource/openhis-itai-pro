## Maven 父工程

`zxplat-module-chs-jilin`（parent：`zxplat-plugin`）· BOM：`zxplat.chs.version`

## 子模块与 Java 包

| Maven 模块 | Java 根包 | 职责 |
|------------|-----------|------|
| `module-chs-jilin-domain` | `com.zxplat.plugin.chs.domain` | `yb_*` 实体、Command/Result、DomainService |
| `module-chs-jilin-gateway` | `com.zxplat.plugin.chs.gateway` | `InsuranceGatewayClient`、scheme、HTTP |
| `module-chs-jilin-bridge` | `com.zxplat.plugin.chs.bridge` + `….bridge.integration.insurance` | ExtensionImpl、Invoker、ContextLoader |
| `module-chs-jilin-application` | `com.zxplat.plugin.chs.application` | `Insurance*AppService` |
| `module-chs-jilin-host` | `com.zxplat.plugin.chs.host` | gateway-proxy / Remote Client |
| `module-chs-jilin-starter` | `com.zxplat.plugin.chs.starter` | HIS embedded 安装入口；Flyway `db/migration/chs` |

## Enforcer 互禁

| 模块 | 禁止依赖 |
|------|----------|
| bridge | `module-chs-jilin-application` |
| application | `module-chs-jilin-bridge` |

ArchTest：`ChsJilinBridgeArchitectureTest` / `ChsJilinApplicationArchitectureTest`（application 另禁 gateway import）。

## 开关

```properties
zxplat.modules.chs.enabled=true
zxplat.chs.gateway.mode=local
```

## 编译

```bash
mvn -pl zxplat-plugin/zxplat-module-chs-jilin/module-chs-jilin-domain,\
zxplat-plugin/zxplat-module-chs-jilin/module-chs-jilin-gateway,\
zxplat-plugin/zxplat-module-chs-jilin/module-chs-jilin-bridge,\
zxplat-plugin/zxplat-module-chs-jilin/module-chs-jilin-application,\
zxplat-plugin/zxplat-module-chs-jilin/module-chs-jilin-host,\
zxplat-plugin/zxplat-module-chs-jilin/module-chs-jilin-starter -am compile
```
