## 1. 调用约定

前端与 bridge 业务均走 **1A 代理**：

```text
POST /api/app/{camelCaseServiceName}/{methodName}
  → AppServiceControllerRegistrar 自动注册
  → [embedded] chs-jilin-application Insurance*AppService
  → [remote]   ChsRemoteAppServiceClient → chs-jilin-host
```

结算挂接由 health-application 调 **Extension**，前端 URL **不变**。
