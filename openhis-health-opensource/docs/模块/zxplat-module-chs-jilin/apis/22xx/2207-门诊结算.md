## 接口说明

#### 交易说明

通过此交易进行门诊正式结算。

#### 重点说明

1、交易输入为单行数据，交易输出结算信息为单行数据，输出结算基金分项信息为多行数据；

2、医疗费总额是患者在医药机构花费的所有诊疗、药品、耗材、服务设施等项目费用的总和
= 基金支付总额 + 个人负担总金额 + 其他（如医院负担金额）；

3、基金支付总额 =
基本医保统筹基金支出（含职工基本医疗保险、居民基本医疗保险）+
补充医疗保险基金支出
（含覆盖全体参保人的居民大病保险和大额医疗费用补助、覆盖部分参保人的企业职工大额医疗费用补助和公务员医疗补助等）+
医疗救助基金支出 + 其他支出（如伤残人员医疗保障基金支出）；

4、个人账户支出中包含账户共济支付金额；

5、仅门诊挂号结算时，医疗类别传入"12 门诊挂号"。

6、仅处理离休外报时填写"out_submit"节点内容。

7、其他支出：兜底基金支出+意外伤害基金支出+离休人员医疗保障金支出+离休人员优惠金支出+财政基金支出+财政预支支出+职工大病基金支出+二乙基金支出+倾斜救助支出+医疗救助再救助基金+电子钱包。

> **ZXPlat 落地（2026-10-09）**：  
> - 2207 入参 `mdtrt_cert_*` 取自 ACTIVE 预结算快照（与 2206 同源）。市医保身份证 **SignBuff** / 社保卡卡串过期时平台报「解密卡串失败…已超时」。  
> - 挂号费 / 门诊收费确认：命中凭证过期语义 → **`INS-015`**（请重读凭证并刷新预结算）；其它 2207 失败仍 **`INS-013`**（勿重复收费）。  
> - 识别：`InsuranceCredentialExpirySupport`；前端 loading 防连点 + 02/03/01 时效提示见挂号确认弹窗。
