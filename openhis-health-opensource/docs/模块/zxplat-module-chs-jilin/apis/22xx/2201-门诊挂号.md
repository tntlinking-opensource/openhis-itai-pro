> **ZXPlat 落地（2026-07-29）**：  
> - **医保挂号确认**：`ensurePlatformRegistration` → 仅 **2201**，强制写 `yb_encounter_platform_map(med_type=11)`；**不调 2203**；自费挂号不调。  
> - **凭证**：读卡得到哪种用哪种（`01`/`02`/`03`），禁止强制改写；无读卡凭证则本地失败并提示读卡。  
> - **吉林市医保 + 身份证（02）**：规范写「02=身份证号」，但市网关 FMI 对明文证件号常报「解密卡串失败」。Win `ReadSFZ` 第二缓冲 `SignBuff`（`pOutBusiBuff`）作 `mdtrt_cert_no` 上送已验证可通（2026-08-02 朝阳）；`certno` 仍用明文证件号。无 SignBuff 时回落明文并提示改刷卡/扫码。  
> - **SignBuff / 卡串时效（2026-10-09）**：卡密有平台侧短时效（现场约数分钟）。预结算写入的 `mdtrt_cert_no` 会原样带入 **2207**；超时后 FMI 返回「解密卡串失败…已超时」。HIS 映射为 **`INS-015`**（非 INS-013）；前端对 01/02/03 做时效拦截，确认缴费前须重读身份证/刷卡/展码并刷新预结算，禁止复用过期卡密连点 2207。识别见 `InsuranceCredentialExpirySupport`。  
> - **2203**：在收费预结算链按组调用。  
> - **3101**：签发/未结算前复用挂号 map(11)；结算（trig=6/7）按本次 med_type（慢病等可 `resolveOrRegister` 补 2201）。同 med_type 不同 diseCodg 仍一次就诊。  
> 实现见 `Op2201Invoker` / `OutpatientRegistrationAppService#runInsuranceRegistrationIfNeeded`；门禁见 [AS-CHS-AUD-002](../../AppService/AS-CHS-AUD-002-事前提醒主路径门禁.md)。
