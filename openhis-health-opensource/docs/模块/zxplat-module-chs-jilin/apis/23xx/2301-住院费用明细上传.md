## ZXPlat 实现注记（院内组装）

> 以下非国家规范原文，描述 `zxplat-module-chs-jilin` 对 2301 的组装口径（与 2204 同构）。

| 场景 | 行为 |
| --- | --- |
| 非套餐 ChargeItem | 一行 → 一条 `feedetail`；`feedetl_sn` = `busNo` 或 id |
| 诊疗套餐（有子表） | 父 Charge **一对多**展开为子项行；**不上传父项** |
| 子项 `cnt` / 金额 | 父数量 × `children_num`；子项 SALE；合计 = 父 `totalPrice` |
| 子项 `feedetl_sn` | `{父feedetlSn}.{序号}`（如 `CI….01`，≤30；禁止拼雪花 childrenId） |
| 代码入口 | `ChsInpatientInsuranceContextLoader` → `ChsActivityPackageFeeExpandSupport` |
