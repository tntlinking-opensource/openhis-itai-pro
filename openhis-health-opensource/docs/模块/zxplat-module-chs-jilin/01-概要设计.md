## 1. 定位与集成模式

吉林省 FSI 网关扩展 Module；**EXTENSION** 挂接 health 收费/进销存；**hisproxy AppService** 在 `chs-jilin-application`；adapter **无** AppService。

| starter | 形态 |
|---------|------|
| `chs-jilin-starter` | embedded（同 JVM） |
| `chs-jilin-host` | remote HTTP 客户端（与 application 互斥） |

领域模型见 [18-HLD领域模型补充 §4 领域模型](./18-HLD领域模型补充.md)（历史 HLD，Maven 列以 §2 为准）。协同单/Worker 以 [13 §2.3](./13-实现状态与文档对照.md) 与门诊/住院 LLD 为准；原 [05-协同单与Worker-详细设计](./05-协同单与Worker-详细设计.md) **已作废**。

**Enforcer**：`chs-jilin-bridge` **禁止** POM 依赖 `chs-jilin-application`；`health-application` **禁止** POM 依赖 `chs-jilin-*`（委托 Extension，见 [模块化开发规范.md §4](../01-架构/模块化开发规范.md)）。

### 3.4 health-application 边界（Extension，非 Extension）

`health-application` **不** import `com.zxplat.plugin.chs.jilin.contracts.*`。收银/住院/进销存调用链：

```text
health-application AppService
  → com.zxplat.plugin.chs.bridge.integration.insurance.* Extension
  → chs-jilin-bridge: OutpatientChargeInsuranceExtensionImpl 等 @Primary
  → chs-jilin-contracts Client
  → chs-jilin-application
```

目录/会话等 **前端可见 API** 仍走 adapter 内 `Insurance*AppService` 1A 代理（§4.1 上表前两行）。

## 4. 统一调用模式（1A 代理）

所有 **面向前端或 bridge 业务** 的 CHS 能力均遵循：

```text
[前端或 bridge 内部]
  → POST /api/app/insurance{X}/{method}     # bridge 薄代理（前端 URL 不变）
  → {X}Operations facade
  → [embedded] chs-jilin-application *AppService Bean
  → [remote]   ChsRemoteAppServiceClient
               → POST {baseUrl}/api/app/chs{X}/{method}
               → chs-jilin-application *AppService
  → （如需）InsuranceGatewayClient local → 省平台 HTTP
```

### 4.1 能力对照表

| 能力 | 前端 API（bridge） | domain facade | CHS AppService | 平台 infno |
|------|-------------------|---------------|----------------|------------|
| 会话 | `/api/app/insuranceSession/signIn` | `ChsSessionOperations` | `chsSession` | 9001 |
| 国家目录 | `/api/app/insuranceNationalCatalog/*` | `ChsNationalCatalogOperations` | `chsNationalCatalog` | 1312、1301、9102 |
| 目录对照 | `/api/app/insuranceCatalogMapping/*` | `ChsCatalogMappingOperations` | `chsCatalogMapping` | 3301、3302 |
| 网关透传 | （无前端；bridge 内注入） | `ChsGatewayOperations` | `chsGateway` | 1101、2207… |
| 结算挂接 | （health-application 调 Extension） | `OutpatientChargeInsuranceExtension` 等 | adapter `*ExtensionImpl` → Client | 2207/2304 等 |
| 进销存/追溯 | （发药/库存 AppService） | `InventoryThirdPartyUploadExtension` | adapter → `InventoryInsuranceClient` | 3505/3506 等 |

### 4.2 embedded 示例（9001）

```text
POST /api/app/insuranceSession/signIn
  → InsuranceSessionAppService
  → ChsSessionAppService（同 JVM）
  → ChsInsuranceContractReaderImpl → fin_contract
  → InsuranceGatewayClientLocalImpl → 9001
```

### 4.3 remote 示例（1312 分页）

```text
POST /api/app/insuranceNationalCatalog/queryNationalCatalogPage
  → InsuranceNationalCatalogAppService
  → ChsNationalCatalogOperationsRemoteClientImpl
  → HTTP POST /api/app/chsNationalCatalog/queryNationalCatalogPage
  → ChsNationalCatalogAppService（独立进程）
  → InsuranceGatewayClientLocalImpl → 1312
```

### 4.4 remote 网关透传（结算等）

```text
bridge 内 InsuranceGatewayClient.invoke(...)
  → InsuranceGatewayClientRemoteImpl
  → ChsGatewayOperationsRemoteClientImpl
  → HTTP POST /api/app/chsGateway/invoke
  → ChsGatewayAppService → LocalImpl → 省平台
```

**禁止**：remote 模式下 bridge 业务代码直连 `{baseUrl}/chs/gateway/invoke`（测试/运维除外）。

## 6. 新增能力模板（防跑偏）

每新增一块 **前端可见** 或 **bridge 编排** 能力：

1. **`chs-jilin-domain`**：定义 `XxxOperations` facade + request/response DTO  
2. **`chs-jilin-application`**：实现 `ChsXxxAppService`（业务编排 + 调 gateway）  
3. **`chs-jilin-bridge`**：`InsuranceXxxAppService` 薄代理 → `/api/app/insuranceXxx/*`  
4. **remote**：`ChsXxxOperationsRemoteClientImpl` + `ChsRemoteAppServiceClient` → `/api/app/chsXxx/*`  
5. **仅 infno 透传、无复杂编排**：注入 `ChsGatewayOperations`（remote 已统一）
