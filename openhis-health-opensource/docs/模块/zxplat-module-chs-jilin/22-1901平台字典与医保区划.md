# 1901 平台字典与医保区划

> 版本：2026-06-24 · 院点 H22010402403  
> 依据：[1901-字典表查询.md](apis/19xx/1901-字典表查询.md)

## 1. 目标

- 通过 **1901** 从省平台拉取医保区划等字典，**手动同步**入库；
- **参保地 `insuplc_admdvs`** 展示以本地字典为准（`value` → `label`）；
- 表结构通用，后续可同步 `med_type`、`insutype` 等 1901 字典类型。

## 2. 1901 交易要点

| 入参 | 说明 |
|------|------|
| `type` | 字典类型，取自基线规范「字典表」括号内英文代码，如 **`med_type`**、**`insutype`**；**国标字典表不含医保区划 type** |
| `parentValue` | 父级键值；空串表示根级 |
| `admdvs` | 查询区划上下文，默认取费用性质 `adm_vs` 或 `100000` |
| `date` | 查询日期 `yyyy-MM-dd` |
| `vali_flag` | `1` 有效 |
| `page_num` / `page_size` | 分页 |

出参节点 **`list`**：`type`、`label`、`value`、`parentValue`、`sort`、`vali_flag`、`version` 等。

## 4. 同步策略（手动）

1. 运维/实施在医保维护页或 API 触发 **`syncFrom1901`**；
2. 默认 `dictType=med_type`，`queryAdmdvs` 取所选费用性质 `adm_vs` 或 `100000`；
3. **BFS**：从 `parentValue=""` 起，每页拉取后 upsert；`recursive=true` 时将本页各 `value` 入队作下一级 `parentValue`；
4. 分页直至当页条数 `< pageSize`；
5. 写 `yb_platform_dict_sync_log` 记录结果。

> 首次全国全量可能较慢，可按省根区划（如 `220000`）分批同步。

## 8. 与 `province-city-china` 区别

| 项 | 1901 字典 | province-city-china |
|----|-----------|---------------------|
| 来源 | 省医保平台 | GB/T 2260 国标 |
| 编码 | 6 位医保区划（含 `229900` 省本级） | 6 位民政码 |
| 用途 | **参保地/就医地展示与对账** | 患者住址、籍贯 |

**禁止**用国标库替代医保区划展示。

## 9. 联调检查项

- [ ] 1901 `type` 与基线规范「字典表」一致（如 `med_type`、`insutype`）
- [ ] `med_type` 同步成功后可验证入库链路
- [ ] 参保地 label：国标无区划 type，需局点扩展或手工维护 `insuplc_admdvs` 本地桶
