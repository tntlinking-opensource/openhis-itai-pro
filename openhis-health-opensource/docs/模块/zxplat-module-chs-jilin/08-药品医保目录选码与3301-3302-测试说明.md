# 药品医保目录选码与 3301/3302 — 测试说明

> 对应能力：药品维护 + 国家目录选码 + 3301 上传 + 3302 撤销  
> **实现状态**：[13-实现状态与文档对照.md](./13-实现状态与文档对照.md)  
> 版本：2026-06-02

## 1. 前置条件

| 项 | 要求 |
|----|------|
| 模块 | `zxplat.modules.chs.enabled=true` |
| 契约 | `fin_contract` 有医保 `bus_no`，且 `chs-contract.properties` 配置 `contract.{bus_no}.fixmedins_code`、`adm_vs` 等 |
| 目录数据 | 至少执行过一次 **1312 刷新** 或 **1301 下载**，本地 `yb_national_catalog_item` 有 `list_type=101` 且 `source_infno=1312` 行 |
| 登录 | 已医保签到（选码/3301/3302 前前端会调 `ensureInsuranceSignIn`） |

## 2. API 一览

| 方法 | AppService | 说明 |
|------|------------|------|
| `suggestMedicationCatalogMapping` | `insuranceCatalogMapping` | 按批准文号/贯标码/名称推荐候选 |
| `queryNationalCatalogPage` | `insuranceNationalCatalog` | `dedupeByHilistCode` + `sourceInfno=1312` |
| `uploadMedicationCatalog3301` | `insuranceCatalogMapping` | 单药品 3301，失败抛 `CATALOG_3301_FAILED` |
| `revokeMedicationCatalog3302` | `insuranceCatalogMapping` | 单药品 3302，失败抛 `CATALOG_3302_FAILED` |

### 2.1 推荐请求示例

```json
POST /api/app/insuranceCatalogMapping/suggestMedicationCatalogMapping
{
  "contractBusNo": "YOUR_BUS_NO",
  "listType": "101",
  "name": "阿司匹林",
  "approvalNumber": "国药准字H123",
  "nationalDrugCode": "",
  "totalVolume": "100mg",
  "queryPlatformIfMiss": true,
  "maxCandidates": 20
}
```

### 2.2 3301 上传

```json
POST /api/app/insuranceCatalogMapping/uploadMedicationCatalog3301
{
  "contractBusNo": "YOUR_BUS_NO",
  "medicationDefId": 123456789,
  "listType": "101"
}
```

成功：`yb_match_flag=true`，`yb_catalog_upload_record.operation=UPLOAD3301`。  
失败：`CATALOG_3301_FAILED`，`yb_match_flag=false`。

### 2.3 3302 撤销

```json
POST /api/app/insuranceCatalogMapping/revokeMedicationCatalog3302
{
  "contractBusNo": "YOUR_BUS_NO",
  "medicationDefId": 123456789,
  "listType": "101"
}
```

成功：`yb_match_flag=false`（`yb_no` 保留），审计表 `operation=REVOKE3302`。  
失败：`CATALOG_3302_FAILED`。

## 3. 前端 UI 测试步骤

1. **基础数据 → 药品目录** → 编辑已有药品。
2. **从国家目录选择** → 确认选用 → **保存**（`yb_match_flag=false`）。
3. **上传医保对照(3301)** → 成功则「医保对码」勾选。
4. **撤销医保对照(3302)**（仅 `yb_match_flag=true` 时显示）→ 确认 → 「医保对码」取消勾选。

## 4. 验收要点

| # | 场景 | 期望 |
|---|------|------|
| F | 3301 成功 | `yb_match_flag=true`，审计表有 `UPLOAD3301` |
| G | 3302 成功 | `yb_match_flag=false`，审计表有 `REVOKE3302` |
| E | 3301 平台拒绝 | `CATALOG_3301_FAILED`，`yb_match_flag=false` |

完整选码场景见原 T1–D（推荐、去重、1312 补库）。
