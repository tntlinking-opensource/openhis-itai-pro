# 患者历史处方与快速再开 — 详细设计

> **目标**：持久化患者已上传电子处方；复诊时 **列表秒开 + 一键套用/续方**。  
> **对齐先例**：`MedicationRequestQueryService.listTcmHerbalPrescriptionHistoryByPatient`（中医历史方）  
> **版本**：v1.0 | **日期**：2026-06-18

---

## 1. 业务场景

| 操作 | 说明 |
|------|------|
| **历史列表** | 按 `patient_id` + `prsc_time DESC` 展示已上传方 |
| **套用** | 复制药品/诊断/用法 → 新草稿；`initRxno` 为空 |
| **续方** | 同上 + `initRxno = 源方 hi_rxno`（平台续方规则） |
| **预览** | 读 snapshot JSON + 可选 PDF 路径 |

  ON yb_elep_prescription (tenant_id, contract_bus_no, hosp_rxno)

## 3. 历史列表默认过滤

```text
local_status = 'UPLOADED'
AND is_deleted = FALSE
AND (rx_stas_codg IS NULL OR rx_stas_codg NOT IN (撤销码集合))
```

撤销码集合放 `ElepPlatformConstants` 或 properties，按吉林省平台文档填充。

## 4. API（Extension + AppService）

### 4.1 列表

```java
Page<PatientElepPrescriptionSummaryDto> listPatientHistory(PatientElepHistoryQuery query);
```

`PatientElepHistoryQuery`：`patientId`, `currentEncounterId`（可选排除）, `page`, `pageSize`, `contractBusNo`（可选）

`SummaryDto` 字段：`id`, `prscTime`, `prscDrName`, `mainDiagName`, `drugSummary`, `hiRxno`, `rxTypeCode`, `localStatus`, `canContinuationRx`

### 4.2 详情

```java
PatientElepPrescriptionDetailDto getHistoryDetail(Long prescriptionId);
```

含 snapshot 解析后的结构化明细（药品行、诊断），**列表接口不返回 snapshot**。

### 4.3 套用 / 续方

```java
ElepPrescriptionDraftDto cloneToNewEncounter(CloneElepPrescriptionCommand cmd);
```

| 字段 | 说明 |
|------|------|
| `sourcePrescriptionId` | 历史方 ID |
| `patientId` | 当前患者 |
| `currentEncounterId` | 当前就诊 |
| `contractBusNo` | |
| `continuationRx` | true → 设 `initRxno` |
| `copyDiagnosis` | 默认 true |

**流程**：

1. 读 `upload_request_json`
2. 替换 `mdtrtinfo`（新 encounter、新 `hospRxno`、新 `prscTime`）
3. 续方：设 `initRxno = source.hiRxno`
4. `ElepCatalogSearchOperations.validateLines` 校验医保码
5. INSERT 新 `yb_elep_prescription` `DRAFT` + snapshot
6. **不自动 A0001**；返回草稿供医生编辑

### 4.4 续方前置校验

```text
continuationRx == true 时：
  - source.hi_rxno 非空
  - source.rept_flag = '1'（若平台有）
  - source.reptd_cnt < source.max_rept_cnt（若有）
  - now < source.vali_end_time（可选）
```

不满足则拒绝续方，提示改用「套用」。

## 5. 与 HIS 医嘱双写

```text
med_medication_request.prescription_no  ←→  yb_elep_prescription.prescription_no
```

- 签发医嘱：写 `med_medication_request`
- A0003 成功：写/更新 `yb_elep_prescription`，回填 `prescription_no`
- **再开以 snapshot 为准**，不从 med 表反推 elep 专用字段

---

## 6. 患者级 Summary 缓存（可选 P4+）

```text
key: tenant:patientId → List<SummaryDto>（最近 20 条）
失效: 该 patient 任一方 UPLOADED/REVOKED 后 evict
```

仅缓存 Summary；clone 仍读 DB snapshot。

## 9. 验收要点

- [ ] 上传成功后历史列表可见，分页 < 100ms（有索引）
- [ ] 套用生成新 DRAFT，`hosp_rxno` 不同于源方
- [ ] 续方 A0001 报文含正确 `initRxno`
- [ ] 失效医保码行返回 `needsRematchLines`
