## 1. 与 CHS / ybapp 的边界

| 系统 | 协议 | 网关 | 配置 |

## 4. Extension 挂接（health-integration-contracts）

```java
// com.zxplat.plugin.elep.bridge.integration.elep.ElepPrescriptionExtension
public interface ElepPrescriptionExtension {
    default boolean isEnabled() { return false; }
    default boolean supportsPrescription(Long prescriptionGroupId) { return false; }

    ElepUploadResult upload(ElepUploadCommand command);
    ElepRevokeResult revoke(ElepRevokeCommand command);
    ElepQueryResult query(ElepQueryCommand command);
    ElepMedResult queryMedResult(ElepMedResultQueryCommand command);

    Optional<ElepRxNoSnapshot> findRxNoByPrescription(Long prescriptionGroupId);

    Page<PatientElepPrescriptionSummaryDto> listPatientHistory(PatientElepHistoryQuery query);
    ElepPrescriptionDraftDto cloneToNewEncounter(CloneElepPrescriptionCommand command);
}
```

未装配 Module 时：`health-module-support 提供 `NoOpElepPrescriptionExtension`。

> **Extension 命名**：adapter 实现类 `{Interface}Impl`，不带 `Jilin` 等地域前缀。  
> **Client 落点**（[模块化开发规范 §5](../01-架构/模块化开发规范.md)）：`JilinElepPrescriptionClientImpl` 在 `elep-jilin-application.client`；adapter `ElepPrescriptionExtensionImpl` 注入 contracts 接口。

吉林省实现：`elep-jilin-bridge` → `ElepPrescriptionExtensionImpl`（`@Primary` + `@ConditionalOnProperty`）。

## 5. 调用链（1A AppService）

```text
POST /api/app/elepPrescription/upload
  → health-application ElepPrescriptionAppService
  → ElepPrescriptionExtension.upload(command)
  → elep-jilin-bridge ElepPrescriptionPortImpl
  → elep-jilin-application ElepPrescriptionAppService
  → ElepGatewayClient.invoke(A0001|A0002|A0003, ...)
  → 电子处方中台
```

**health-application 禁止**：

- 依赖 `elep-jilin-*` Maven artifact（仅 contracts + optional Extension 注入）
- 直接拼 `ele_base_url` 或持有 HSE 密钥

## 6. AutoConfiguration

```java
// elep-jilin-application
@Configuration
@ConditionalOnProperty(name = "zxplat.modules.elep.enabled", havingValue = "true")
@ComponentScan({"com.zxplat.elep.application", "com.zxplat.elep.domain"})
public class ElepAutoConfiguration {}

// elep-jilin-bridge
@Configuration
@ConditionalOnClass(name = "com.zxplat.elep.api.ElepGatewayClient")
@ConditionalOnProperty(name = "zxplat.modules.elep.enabled", havingValue = "true")
@AutoConfigureAfter("com.zxplat.elep.application.config.ElepAutoConfiguration")
@ComponentScan("com.zxplat.plugin.elep.bridge.integration.elep")
public class ElepJilinAdapterAutoConfiguration {}
```

## 7. 配置加载（对齐 CHS）

| 项 | CHS | ELEP |
|----|-----|------|
| 文件 | `chs-contract.properties` | `elep-contract.properties` |
| 加载器 | `ContractConfigLoader` | `ElepContractConfigLoader` |
| 段键 | `fin_contract.bus_no` | 同左 |
| 键格式 | `contract.{bus_no}.*` | 同左 |
| 外挂 | `chs.contract.config.path` | `elep.contract.config.path` |
| 热加载 | WatchService + mtime | 同构 |
| epoch | `getConfigEpoch()` | `getConfigEpoch()` |

详见 [04-elep-contract配置说明.md](./04-elep-contract配置说明.md)。
