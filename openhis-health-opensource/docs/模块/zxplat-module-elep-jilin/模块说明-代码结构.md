## Maven 父工程

`zxplat-module-elep-jilin`（parent：`zxplat-plugin`）· BOM：`zxplat.elep.version`

## 子模块与 Java 包

| Maven 模块 | Java 根包 | 职责 |
|------------|-----------|------|
| `module-elep-jilin-domain` | `com.zxplat.plugin.elep.domain` | `yb_elep_*` 实体、Command/Result、领域服务 |
| `module-elep-jilin-gateway` | `com.zxplat.plugin.elep.gateway` | `ElepGatewayClient`、GM、HSE |
| `module-elep-jilin-bridge` | `com.zxplat.plugin.elep.bridge` + `….bridge.integration.elep` | ExtensionImpl、ContextLoader |
| `module-elep-jilin-application` | `com.zxplat.plugin.elep.application` | AppService / Orchestrator |
| `module-elep-jilin-host` | `com.zxplat.plugin.elep.host` | remote Client |
| `module-elep-jilin-starter` | （依赖聚合） | embedded 安装入口 |

## Enforcer 互禁

| 模块 | 禁止依赖 |
|------|----------|
| bridge | `module-elep-jilin-application` |
| application | `module-elep-jilin-bridge` |

ArchTest：`ElepJilinBridgeArchitectureTest` / `ElepJilinApplicationArchitectureTest`。

## 开关

```properties
zxplat.modules.elep.enabled=true
zxplat.elep.deployment.mode=embedded
```

## 编译

```bash
mvn -pl zxplat-plugin/zxplat-module-elep-jilin/module-elep-jilin-domain,\
zxplat-plugin/zxplat-module-elep-jilin/module-elep-jilin-gateway,\
zxplat-plugin/zxplat-module-elep-jilin/module-elep-jilin-bridge,\
zxplat-plugin/zxplat-module-elep-jilin/module-elep-jilin-application,\
zxplat-plugin/zxplat-module-elep-jilin/module-elep-jilin-host,\
zxplat-plugin/zxplat-module-elep-jilin/module-elep-jilin-starter -am compile
```
