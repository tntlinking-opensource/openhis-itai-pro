# 【A0005】电子处方信息查询

## 说明

按 `hi_rxno` 等条件查询平台侧处方详情与状态（含复用次数、使用状态等）。

## Whale 落地

| 项 | 规划 |
|----|------|
| 网关 | `ElepGatewayClient.invoke(ElepOpCode.A0005, ...)` |
| 入参 | `ElepQueryCommand` ← ybapp `ElepQuerPrescriptionInput` |
| 出参 | `ElepQueryResult` ← ybapp `QueryPrescription` |

## 本地用途

- 刷新 `yb_elep_prescription.rx_stas_codg` / `rx_used_stas_codg` / `reptd_cnt` / `vali_end_time`
- **不作为**历史列表主数据源（列表读本地库，见 [07](../06-患者历史处方与快速再开-详细设计.md)）

## 出参关键字段（QueryPrescription）

| 字段 | 说明 |
|------|------|
| `hiRxno` | 医保处方号 |
| `rxStasCodg` / `rxUsedStasCodg` | 状态 |
| `reptFlag` / `maxReptCnt` / `reptdCnt` | 续方相关 |
| `rxDetlList` / `rxDiseList` | 明细 |

ybapp 参考：`com.openhis.domain.QueryPrescription`
