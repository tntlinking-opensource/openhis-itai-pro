# 【A0002】电子处方医保电子签名

## 说明

将 A0001 生成的 PDF（base64）提交平台进行医保电子签名，返回签名后的处方文件。

## Whale 落地

| 项 | 规划 |
|----|------|
| 网关 | `ElepGatewayClient.invoke(ElepOpCode.A0002, ...)` |
| 入参 | `ElepSignCommand` ← ybapp `ElepSignatureInput` |
| 出参 | `ElepSignResult`（含 `rxFile` base64） |
| 持久化 | `local_status=SIGNED`；更新 PDF 路径 |

## 关键入参

| 字段 | 说明 |
|------|------|
| `fixmedinsCode` | 定点机构代码 |
| `originalValue` | 原始待签名处方信息 JSON 的 base64 |
| `originalRxFile` | 原始 PDF 文件 base64 |
| `prescriptionNo` | 院内处方号（Whale 内部用，序列化时可 omit） |

ybapp 参考：`com.openhis.domain.ElepSignatureInput`

## 后续动作

调用 A0003，传入签名后 `rxFile` 与 `signDigest`。
