# 【A0006】电子处方取药结果查询

## 说明

查询电子处方在外购/定点药店的取药与结算结果信息。

## Whale 落地

| 项 | 规划 |
|----|------|
| 网关 | `ElepGatewayClient.invoke(ElepOpCode.A0006, ...)` |
| 入参 | `ElepMedResultQueryCommand` ← ybapp `ElepMedresultInput` |
| 出参 | `ElepMedResult` ← ybapp `MedicationResultInquiry` |

## 业务用途

- 医生站或药房查看「处方是否已取药」
- 运维对账（与 CHS 结算信息交叉核对）

Wave P4 实现；一期可仅 AppService 透传 + 日志。
