# 【A0003】电子处方上传

## 说明

将签名后的电子处方文件及元数据上传至医保电子处方中台；成功返回 **医保处方编号** `hiRxno`，供结算 2204 `rxno` 使用。

## Whale 落地

| 项 | 规划 |
|----|------|
| 网关 | `ElepGatewayClient.invoke(ElepOpCode.A0003, ...)` |
| 入参 | `ElepFileUploadCommand` ← ybapp `ElepUploadInput` |
| 出参 | `ElepFileUploadResult`（含 `hiRxno`） |
| 持久化 | `local_status=UPLOADED`；写入患者历史索引 |

## 关键入参

| 字段 | 说明 |
|------|------|
| `rxTraceCode` | A0001 返回 |
| `hiRxno` | 预分配或平台生成（按省规范） |
| `rxFile` | 签名后 PDF base64 |
| `signDigest` | 处方信息签名值 |
| `pharName` / `pharChkTime` | 审方药师信息 |

ybapp 参考：`com.openhis.domain.ElepUploadInput`
