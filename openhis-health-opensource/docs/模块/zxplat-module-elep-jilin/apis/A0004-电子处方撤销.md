# 【A0004】电子处方撤销

## 说明

对尚未结算或异常需作废的电子处方，向平台发起撤销。

## Whale 落地

| 项 | 规划 |
|----|------|
| 网关 | `ElepGatewayClient.invoke(ElepOpCode.A0004, ...)` |
| 入参 | `ElepRevokeCommand` ← ybapp `ElepRevokeInput` |
| 出参 | `ElepRevokeResult` |
| 持久化 | `local_status=REVOKED` |

## 业务规则

- 已用于 2204 结算且平台不允许撤销时，拒绝并提示走退费/冲正流程（CHS 2208）。
- 撤销后 `findRxNoByPrescription` 不得再返回该 `hi_rxno`。

ybapp 参考：`com.openhis.domain.ElepRevokeInput`
