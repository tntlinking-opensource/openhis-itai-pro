# 【A0001】电子处方上传预核验

## 说明

定点医疗机构在上传电子处方前，向平台提交处方信息进行预核验；成功返回 **处方追溯码** `rxTraceCode`，并作为后续 PDF 与 A0002/A0003 的前置步骤。

## Whale 落地

| 项 | 规划 |
|----|------|
| 网关 | `ElepGatewayClient.invoke(ElepOpCode.A0001, ...)` |
| 入参 | `ElepPreCheckCommand` ← ybapp `PreCheckPrescription` |
| 出参 | `ElepPreCheckResult`（含 `rxTraceCode`） |
| 持久化 | `local_status=PRE_CHECKED`；写 `yb_elep_prescription_snapshot.upload_request_json` |

## 关键入参节点

| 节点 | 说明 |
|------|------|
| `hospRxno` | 院内处方编号（新生成） |
| `initRxno` | 续方时填原 `hi_rxno` |
| `mdtrtCertType` / `mdtrtCertNo` | 就诊凭证 |
| `rxdrugdetail[]` | 药品明细（含 `medListCodg`） |
| `mdtrtinfo` | 就诊信息 |
| `diseinfo` | 诊断信息 |
| `valiDays` / `prscTime` | 有效期、开方时间 |

字段完整定义见 ybapp：

- `com.openhis.domain.PreCheckPrescription`
- `com.openhis.domain.ElepVeriPrescriptionDetail`
- `com.openhis.domain.ElepVeriVisitInfo`
- `com.openhis.domain.ElepVeriDiagnosisInfo`

## 后续动作

1. 填充 PDF 模板（`template_path`）
2. 调用 A0002 签名

详见 [04-电子处方上传链路-详细设计.md](../04-电子处方上传链路-详细设计.md)。
