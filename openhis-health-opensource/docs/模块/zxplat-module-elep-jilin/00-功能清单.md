## 1. 模块定位

| 在 ELEP | 不在 ELEP |
|---------|-----------|
| A0001–A0005 电子处方中台（**必接**） | CHS FSI 22xx/23xx 结算 |
| A0006 取药/结算结果查询（**可选**，见 §2） | ybapp 混乱 Controller |
| 处方 PDF、医保电子签名、国密加解密网关 | 在 chs-jilin-application 实现 A000x |
| 院内审方门禁、历史处方管理 | **药店侧**接口与业务（见 §4） |
| 目录搜索缓存（读 CHS 130x） | 定点零售药店配售、调剂、追溯码 |

**集成模式**：**EXTENSION** — `ElepPrescriptionExtension`；与 CHS 结算挂接经 2204 `rxno`（见 [07-与门诊医保结算挂接-详细设计](./07-与门诊医保结算挂接-详细设计.md)）。

**政策门禁**（省直定点）：自 **2025-01-01** 起，外配电子处方须经全省医保电子处方流转平台流转（见 [参考/省直定点-…md](./参考/省直定点-关于优化医保电子处方流转平台相关功能的通知.md)）。

## 2. 能力族

### 2.1 平台接口（医疗机构 → 中台）

| 能力 | 接口 | 优先级 | 详细设计 |
|------|------|--------|----------|
| 上传预核验 | A0001 | P0 | [04-电子处方上传链路-详细设计](./04-电子处方上传链路-详细设计.md) |
| 医保电子签名 | A0002 | P0 | 同上 |
| 处方上传 | A0003 | P0 | 同上 |
| 撤销 | A0004 | P0 | 同上 |
| 信息查询 | A0005 | P0 | 同上 |
| 取药/结算结果查询 | A0006 | 可选 | 同上 · [apis/A0006](./apis/A0006-电子处方取药结果查询.md) |

**标准链路**：

```text
保存草稿 → 院内审方 → A0001 预核验 → 本地 PDF → A0002 签名 → A0003 上传
                                                              ↘ A0005 刷新状态
                                                              ↘ A0004 撤销
```

A0001～A0005 对齐 [3-03 接入规范](./参考/3-03-医保电子处方中心与定点医疗机构接入规范-1.md) §3.1～§3.5。A0006 查药店侧结算/取药明细，**院方不接药店相关能力时可不做**。

| 能力 | 说明 | 优先级 | 详细设计 |
