## 标准业务链路

```text
保存草稿 → A0001 预核验 → 本地 PDF → A0002 签名 → A0003 上传 →（可选）A0005 查状态
                                                              ↘ A0004 撤销
                                                              ↘ A0006 取药结果
```

## 通信约定（摘要）

- **加解密**：HSE（`preAppId` / `preAppSecret` / `prePrvKey`），迁移自 ybapp `HseEncAndDecUtil` + `SignUtil`
- **配置**：`elep-contract.properties`，段键 = `fin_contract.bus_no`（见 [03-elep-contract配置说明.md](./03-elep-contract配置说明.md)）
- **禁止**：前端透传密钥（ybapp `BaseParam.baseInfo` 中的 `prePrvKey` 等为反模式）
