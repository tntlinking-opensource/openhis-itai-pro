# 插件模块文档

> **范围**：可选插件（`zxplat-plugin/zxplat-module-*`）的同伴文档。  
> **不在此列**：`zxplat-domain` / core 契约 → 见 [docs/领域/DomainModel/](../领域/DomainModel/)。

**代码根**：`zxplat-plugin/` · **文档根**：`docs/模块/`  
**进度**：Wave 3 · [plans/waves/wave-03-plugin.md](../../plans/waves/wave-03-plugin.md)

## 约定

每个已迁插件一个目录 `zxplat-module-{短名}/`，**入口统一 `说明.md`**（禁止再新建英文 README 作入口）。

```text
说明.md                  ← 模块入口（中文）
DomainModel/             ↔ DomainModel-SDD/   （按聚合子目录；Java 类型 L1 卡与源码同路径）
AppService/              ↔ AppService-SDD/    （扁平 AS 文件）
模块说明-代码结构.md      ← Maven 层边界（Enforcer 互禁写清）
00～17…                  ← 产品/架构 LLD（按需）
```

开关形如：`zxplat.modules.{短名}.enabled=true`。  
**禁止**把插件 DM/AS 写入 `docs/领域/DomainModel/`。  
**文档自洽**：不依赖 whale-doc / whale-sever；成对契约用**编号**，禁止文首 `> **DM**：[…](../DomainModel/…)` 类指针链。

**P0 机器门禁**（迁完 M3x / M3x-doc 必跑，退出码 0 才勾 wave）：

```powershell
pwsh -File plans/scripts/check-wave3-gates.ps1 -Module {短名}   # 单插件
pwsh -File plans/scripts/check-wave3-gates.ps1 -All            # 已有全部插件
# 等价拆分：check-docs-self-contained.ps1 / check-plugin-residue.ps1 / check-plugin-structure.ps1
```

### 样板门禁（以 M30 EMR 为准，开下一插件前对照）

| 项 | 要求 | 机器门禁 |
|----|------|----------|
| 包名 | `com.zxplat.plugin.{短名}.*`；源码无 `com.openhis` / 旧 ModuleDescriptor | `check-plugin-residue` |
| Maven 层 | domain →（gateway）→ bridge → application → starter；Enforcer 互禁 bridge↔application | `check-plugin-structure` |
| ArchTest | bridge / application 至少各 1 条层依赖扫描，CI 可跑绿 | `check-plugin-structure`（存在性；绿测仍靠 mvn） |
| 文档成对 | DomainModel↔DomainModel-SDD；AppService↔AppService-SDD（**编号对应**；正文自洽） | 人工 / 后续 P1 |
| 文档自洽 | 无 `whale-module-` / `whale-doc` / `whale-sever` / `whale-health`；无文首跨目录 Markdown 指针 | `check-docs-self-contained` |
| L1 | domain 每个 `.java` 有同路径类型卡 | 人工 / 后续 P1 |
| HIS 交叉引用 | 专题 AS/AS-SDD 指向 `docs/模块/…`，无旧插件路径前缀 | 含于 docs 自洽路径扫描 |
| 版权头 | Java 为 `Copyright © 2026 OpenHIS Contributors`；目录内无 `OpenHIS Contributors` | `check-plugin-residue` |
| 开关键 | starter/application 出现 `zxplat.modules.{key}.enabled` | `check-plugin-structure` |
| 关键单测 | 领域不变式至少覆盖 2～3 条（样板：`DocumentManagerTest`） | 人工 + `mvn test` |
| 索引 | 本页「模块一览」勾状态；`docs/代码地图.md` 有一行 | `check-plugin-structure`（代码地图） |

## 与领域文档的关系

| 文档树 | 内容 |
|--------|------|
| `docs/领域/DomainModel/` | 仅 **core**（`com.zxplat.domain.*`） |
| `docs/领域/专题/` | HIS 核心页 AS（如门诊医生站病历） |
| `docs/应用/` | 根级应用栈工程文档（application/starter/app） |
| `docs/模块/` | **插件** DM / AS / 产品架构（本页） |

HIS 页面编排 EMR 能力时：专题 AS 引用本目录下插件 DM/AS，**不**把插件契约写回 `docs/领域/DomainModel/`。
