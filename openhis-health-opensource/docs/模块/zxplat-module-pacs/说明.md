# zxplat-module-pacs

自研 PACS：**RIS + Imaging** 同一 Module、**同一开关**。

| 项 | 值 |
|----|-----|
| **代码** | `zxplat-plugin/zxplat-module-pacs/` |
| **开关** | `zxplat.modules.pacs.enabled`（classpath/`-Pwith-pacs` 默认开；yml 仅写 `false`） |
| **Profile** | `-Pwith-pacs`（国基默认激活） |
| **Flyway RIS** | `db/migration/pacs` · `flyway_schema_history_pacs` |
| **Flyway 影像** | `db/migration/imaging` · `flyway_schema_history_pacs_imaging`（同受 `pacs.enabled` 控制） |
| **部署** | `zxplat-module-pacs/deploy/` |
| **计划** | [`plans/模块拆分/wave-pacs.md`](../../plans/模块拆分/wave-pacs.md) |

产品文档：[`PacsAppService`](../应用/zxplat-application/PacsAppService/)。

## 关闭整包

```yaml
zxplat.modules.pacs.enabled: false
```

## HIS 接单入口（Port）

医生站经 `PacsOrderIngressPort` 接单/撤单；真实现在 `module-pacs-application`，未装/未启用时 HIS `NoOpPacsOrderIngressPort` 兜底。
