## 3. 出站编排

| 能力 | gateway scheme | bridge | application 调用方 |
|------|----------------|--------|-------------------|
| 开具 | `scheme.issue.assembler` + **`issue/parser/IssueOutputParser`** | `issue.invoker` + `issue.support` | `BossIssueWorkerService` → `BossIssueOutboundAccess` |
| 冲红 | `scheme.writeoff.assembler` | `writeoff.invoker` + `writeoff.support` | `BossWriteOffService` → `BossWriteOffOutboundAccess` |
| 查票 | `scheme.recover.assembler` | `recover.invoker` + `recover.support` | `BossRecoverService` → `BossRecoverOutboundAccess` |
| 对账 | `scheme.reconcile.assembler` + **parser** | `reconcile.invoker` + `reconcile.support` | `EinvoiceBossReconcileAppService` → `BossReconcileQueryAccess` |
| 入账状态 | `scheme.list.assembler` + **parser** | `list.invoker` + `list.support` | `EinvoiceBossListAppService` → `BossAccountStatusQueryAccess` |

**架构约束**：
- `module-einv-boss-application` 主源码不得 import `gateway.scheme.*`（P14 ✅）
- `module-einv-boss-application` 主源码不得 import `bridge.*`（P16 ✅ + enforcer）
- `module-einv-boss-bridge` 主源码不得 import `application.*`（架构测试 + enforcer）
