### 2.3 本模块在通用规范中的落地

| 通用规范 | einvoice-boss 落地 |
| --- | --- |
| **HTTP** | 全部 AppService → **POST** `/api/app/...`（§3.2）；禁止 RESTful GET |
| **分页** | `AbstractPageQuery` + `pageNo` 1-based + `PagedResultBuilder` |
| **枚举** | `amount_status`、`TaskStatus` 等 → VARCHAR **`getCode()`** |
| **禁 JSON 出参** | Response 禁 `payloadJson` 整段；用 `BossDocumentDto` / `BossLineDto` |
| **Repository** | 仅 `JpaRepository`；禁 `@Query` JPQL |
| **常量** | `EinvBossErrorCodes` 等放 **domain/contracts**；禁 application 散落 |
| **busNo** | health 侧已用 `BusinessSequenceService`；boss **只读** `adm_invoice.bus_no` |
| **Resolver** | AppService 禁直注 `ICurrentUser`；用模块内 Operator/Tenant Resolver |
| **注释** | `BossIssueWorker`、`BossInvoiceAmountValidator` 须有分支级 `//` 业务句 |
| **编译 Profile** | `-Pwith-einvoice-boss`（§3.4） |

### 3.1 模块与包

| 项 | 值 |
| --- | --- |
| groupId | `com.openhis` |

### 3.2 AppService HTTP 路由

与 Whale 统一约定：**全部 POST**。

```text
POST /api/app/{serviceName}/{methodName}
serviceName = 类名去掉 AppService 后首字母小写
```

| 类 | serviceName | 典型方法 |
| --- | --- | --- |
| `EinvoiceBossIssueAppService` | `einvoiceBossIssue` | `requeue`、`issueNow`、`recoverByBusNo` |
| `EinvoiceBossDocumentAppService` | `einvoiceBossDocument` | `getByInvoiceId`、`updateLines`、`validateAmount`、`saveAdjustment` |
| `EinvoiceBossQueryAppService` | `einvoiceBossQuery` | `pageDocuments`、`getIssueStatus`、`listPendingCompensation`、`getPendingCount` |
| `EinvoiceBossCashierAppService` | `einvoiceBossCashier` | `getQr` |

> [03 §7](./01-概要设计.md) 的 REST 路径为本节 AppService 方法的**逻辑别名**；实现以 `/api/app/...` 为准。

### 3.3 依赖硬约束

| 约束 | 说明 |
| --- | --- |
| `health-application` | **禁止** `com.zxplat.plugin.einvoice.boss.*` |
| `health-application` | 不调用 `ElectronicInvoice旧命名（已废止）；仅 createDraft + 发事件 |
| `einvoice-boss-bridge` | 可依赖 `health-domain`、`einvoice-boss-domain`；**禁止** `einvoice-boss-application` |
| `einvoice-boss-application` | 写 boss 表；回写 `adm_invoice` 经 adapter 调 `InvoiceDomainService` |
| 实体 | `BaseAuditedEntity`；`Long` id；`LocalDateTime`；`is_deleted` |
| 枚举落库 | VARCHAR 存 `getCode()` |
| 金额 | 全链路 `BigDecimal`；比较 scale=2 |
| 编排 | AppService：**Gate → Pre → Cmd → Asm** |

### 3.5 错误码（application 层）

| 码 | 说明 |
| --- | --- |
| `EINV_AMOUNT_MISMATCH` | 明细合计 ≠ totalAmt |
| `EINV_PAYMENT_AMOUNT_MISMATCH` | 明细合计 ≠ 支付金额（警告态，不阻断保存调额） |
| `EINV_TASK_NOT_FOUND` | 无活跃任务 |
| `EINV_ALREADY_ISSUED` | 重复开具门控 |
| `EINV_BOSS_REJECT` | 博思非 S0000 |
| `EINV_BOSS_TIMEOUT` | HTTP 超时 |
| `EINV_DOCUMENT_NOT_FOUND` | 无 document |

任务表 `last_error_code` 与上表对齐。

**BossInvoiceAmountValidator**（核心逻辑）：

```java
public void validate(BigDecimal totalAmt, List<BigDecimal> lineAmounts) {
    BigDecimal sum = lineAmounts.stream().reduce(BigDecimal.ZERO, BigDecimal::add);
    if (sum.setScale(2, RoundingMode.HALF_UP).compareTo(totalAmt.setScale(2, RoundingMode.HALF_UP)) != 0) {
        throw new BusinessException(EINV_AMOUNT_MISMATCH, "明细合计 " + sum + " 与开票总额 " + totalAmt + " 不一致");
    }
}
```

**BossIssueWorker 伪代码**：

```text
1. 抢锁 task → PROCESSING
2. 若 adm_invoice 已 ISSUED → task SUCCESS，return
3. 加载 document + lines
4. BossInvoiceAmountValidator.validate(totalAmt, line amounts)
5. payload = BossPayloadBuilder.build(document, lines)
6. result = BossSignClient.invoke(serviceId, payload)
7. 成功：更新 document QR 字段；adapter.issueElectronicInvoice(result)
8. 失败/超时：记 invoke_log；task FAILED + next_retry_at；可 recoverByBusNo
```
