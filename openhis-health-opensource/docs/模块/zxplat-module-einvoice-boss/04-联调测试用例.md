## 十七、数据核对 SQL（辅助）

> 测试环境执行；生产只读。

```sql
-- 最近 10 笔 boss 单据
SELECT d.document_id, d.invoice_id, d.issue_kind, d.bus_no, d.total_amt,
       d.boss_bill_no, d.invoice_status, d.created_at
FROM einv_boss_document d
ORDER BY d.created_at DESC
LIMIT 10;

-- 对应开票任务
SELECT t.task_id, t.invoice_id, t.status, t.attempt_count,
       t.last_error_code, t.last_error_msg, t.updated_at
FROM einv_boss_issue_task t
WHERE t.invoice_id IN (SELECT invoice_id FROM einv_boss_document ORDER BY created_at DESC LIMIT 10);

-- 待补偿粗查（DRAFT 且非 SUCCESS）
SELECT d.invoice_id, d.issue_kind, d.invoice_status, t.status AS task_status
FROM einv_boss_document d
LEFT JOIN einv_boss_issue_task t ON t.invoice_id = d.invoice_id
WHERE d.invoice_status = 'DRAFT'
ORDER BY d.created_at DESC;
```
