# zxplat-module-einvoice-boss · 代码结构

> **代码**：`zxplat-plugin/zxplat-module-einvoice-boss/`  
> **BOM**：`zxplat.einvoice.boss.version`

## 子模块与 Java 包

| Maven 模块 | Java 根包 | 职责 |
|------------|-----------|------|
| `module-einv-boss-domain` | `com.zxplat.plugin.einvoice.boss.domain` | 票据领域 |
| `module-einv-boss-gateway` | `com.zxplat.plugin.einvoice.boss.gateway` | 博思 HTTP 出站 |
| `module-einv-boss-bridge` | `….bridge` + `….bridge.integration.einvoice` | ExtensionImpl / ContextLoader |
| `module-einv-boss-application` | `….application` | AppService / Worker |
| `module-einv-boss-host` | `….host` | HTTP 中转 |
| `module-einv-boss-starter` | （依赖聚合） | embedded 安装入口 |

## Enforcer 互禁

| 模块 | 禁止依赖 |
|------|----------|
| bridge | `module-einv-boss-application` |
| application | `module-einv-boss-bridge` |

ArchTest：`EinvoiceBossBridgeArchitectureTest` / `EinvoiceBossApplicationArchitectureTest`

## 开关

zxplat.modules.einvoice-boss.enabled=true
