## Maven 父工程

`zxplat-module-booking`（旧 `zxplat-module-booking` 已删除）

## 子模块与 Java 包

| Maven 模块 | Java 根包 | 职责 |
|------------|-----------|------|
| `module-booking-domain` | `com.zxplat.plugin.booking.domain` | 日程/号源/预约实体、Command、DomainService |
| `module-booking-bridge` | `com.zxplat.plugin.booking.bridge`（含 `bridge.integration`） | ExtensionImpl、Orchestrator、ContextLoader |
| `module-booking-application` | `com.zxplat.plugin.booking.application` | UI AppService、Flyway(booking) |
| `module-booking-starter` | 聚合 domain + bridge + application | 安装入口 |

**废止**：`booking-contracts`、`booking-adapter`  
**无 gateway**（领域型）

## Extension → Orchestrator

| Extension | Orchestrator |
|-----------|--------------|
| `OutpatientBookingQueryExtension` | `BookingOutpatientQueryOrchestrator` |
| `OutpatientBookingRegistrationExtension` | `BookingOutpatientRegistrationOrchestrator` |
| `InpatientBedBookingQueryExtension` | `BookingInpatientBedQueryOrchestrator` |
| `InpatientBedBookingConsumeExtension` | `BookingInpatientBedConsumeOrchestrator` |

## 依赖

```text
module-booking-domain        → zxplat-framework + zxplat-domain
module-booking-bridge        → module-booking-domain + zxplat-domain + zxplat-framework
module-booking-application   → module-booking-domain + zxplat-domain + zxplat-framework
module-booking-starter       → domain + bridge + application
```

Enforcer：bridge 禁 application；application 禁 bridge。

## 装配

```bash
mvn -pl zxplat-plugin/zxplat-module-booking/module-booking-domain,zxplat-plugin/zxplat-module-booking/module-booking-bridge,zxplat-plugin/zxplat-module-booking/module-booking-application,zxplat-plugin/zxplat-module-booking/module-booking-starter -am install -DskipTests
```

开关：`zxplat.modules.booking.enabled=true`
