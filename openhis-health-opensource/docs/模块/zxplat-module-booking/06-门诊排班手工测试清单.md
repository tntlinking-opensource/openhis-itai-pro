# 门诊排班 · 手工测试用例清单

> **用途**：联调/验收时逐条勾选执行。  
> **前置**：`-Pwith-booking` 编译部署；Flyway **V1～V8** 已迁移；`zxplat.modules.booking.enabled=true`；已重新登录加载菜单。  
> **路径**：统一预约 → 门诊排班 / 门诊预约 / 号源日历 / 候诊叫号

## 1. 排班台 · 基础 CRUD

## 4. 停诊 · 整日 / 部分 / 向导

| ID | 步骤 | 预期 | ☐ |
|----|------|------|---|
| STOP-01 | active 日程无预约 → **整日停诊** | 日程 inactive；Slot 停诊态 | ☐ |
| STOP-02 | **部分停诊**（排班台抽屉勾选部分 Slot → 部分停诊） | 仅选中 Slot 封锁；日程仍为 active（体验项 #3） | ☐ |
| STOP-03 | 部分 Slot 有预约 → 停诊向导 | 预览影响；可转交/取消（TC-STOP-01） | ☐ |
| STOP-04 | B 余号不足时转交 | 部分成功部分失败（TC-STOP-02） | ☐ |
| STOP-05 | 已挂号预约 | 跳过自动转交（TC-STOP-03） | ☐ |
| STOP-06 | 已报到预约 | 不自动转交（TC-STOP-04） | ☐ |
| STOP-07 | 专家→普通转交 | 默认拒绝（TC-STOP-05） | ☐ |
| FRZ-01 | 停诊预览后尝试新约源 Slot | 拒绝直至向导完成或超时（TC-FRZ-01） | ☐ |
| STOP-08 | 号源日历多选 Slot 部分停诊 | 与排班台部分停诊行为一致 | ☐ |
