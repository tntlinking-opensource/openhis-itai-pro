### 3.2 AppService 路由

```text
POST /api/app/{serviceName}/{methodName}
serviceName = 类名去掉 AppService 后首字母小写
```

**硬门禁**：全部接口 **POST**；禁止 GET/PUT/PATCH/DELETE。

### 3.3 依赖硬约束

| 约束 | 说明 |
| --- | --- |
| `health-application` | **禁止** `com.zxplat.plugin.booking.domain.*` / `booking.application.*` |
| `health-application` | 仅依赖 **`health-integration-contracts`** Extension；`OutpatientBooking*Extension` 构造器注入 |
| `booking-bridge` | **可** `booking-domain`；**禁止** `booking-application`（enforcer） |
| `booking-application` | 写侧直连 `booking-domain`；读 health 主数据经 **adapter 实现的 Reader/Writer** |
| 实体 | `BaseAuditedEntity`；`Long` id；`LocalDateTime`；软删 |
| 枚举落库 | **VARCHAR 存 `getCode()`** |
| Repository | 仅 `JpaRepository` 接口；禁止 `@Query` JPQL |
| 编排 | AppService：**Gate → Pre → Cmd → Asm** |

### 3.4 Maven Profile `with-booking`

| 层级 | 改动 |
| --- | --- |
| `zxplat/pom.xml` | `<module>zxplat-module-booking</module>`；`-Pdev` 含 booking |
| `zxplat-domain/pom.xml` | `dependencyManagement`：booking 五 artifact |
| `health-app/pom.xml` | Profile `with-booking` → `booking-starter` |

```bash
cd zxplat
mvn -Pwith-booking -pl zxplat-app -am package -DskipTests
mvn -Pdev -pl zxplat-app -am compile -DskipTests
```

| 项 | 值 |
| --- | --- |

```sql
CREATE TABLE IF NOT EXISTS bkg_registration_policy (
  id                      BIGINT PRIMARY KEY,
  tenant_id               BIGINT NOT NULL,
  org_id                  BIGINT,
  walk_in_slot_mode       VARCHAR(32) NOT NULL DEFAULT 'APPOINTMENT_FIRST',
  auto_check_in_on_register BOOLEAN NOT NULL DEFAULT FALSE,
  on_cancel_policy        VARCHAR(32) NOT NULL DEFAULT 'RELEASE_SLOT_ONLY',
  -- RELEASE_SLOT_ONLY / CANCEL_APPOINTMENT：退号时释号并软删预约行（释放 uk_wkf_appt_patient_service_day）
  -- KEEP_SLOT：仅解绑 encounter
  allow_edit_practitioner_from_appointment BOOLEAN NOT NULL DEFAULT FALSE,
  is_deleted              BOOLEAN NOT NULL DEFAULT FALSE,
  created_at              TIMESTAMP NOT NULL,
  updated_at              TIMESTAMP NOT NULL,
  version                 INT NOT NULL DEFAULT 0
);
```

## 13. 错误码约定（booking 域）

| 码 | 场景 |
| --- | --- |
| `BKG-SLOT-404` | Slot 不存在 |
| `BKG-SLOT-409` | 号源已满或并发占用失败 |
| `BKG-BKG-404` | 预约不存在 |
| `BKG-BKG-409` | 重复预约 / 状态不允许 |
| `BKG-REG-404` | 无有效预约可转挂 |
| `BKG-REG-409` | 预约已关联 encounter |
| `BKG-REG-403` | 预约与岗位资格不一致 |
| `BKG-SCH-409` | 非 draft 不可编辑 / 未发布不可放号 |
