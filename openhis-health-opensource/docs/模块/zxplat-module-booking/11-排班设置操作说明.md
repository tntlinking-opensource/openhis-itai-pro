## 2. 页面结构

页顶 **排班设置说明** 区概括五类配置关系；下方为五个 Tab（默认打开「日排班」）：

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 排班设置说明（周排班 / 日排班 / 放号时段 / 放号策略 / 占位有效期提示）        │
├─────────────────────────────────────────────────────────────────────────────┤
│ [日排班] [周排班] [放号时段] [放号策略] [日历例外 (T3)]                      │
├─────────────────────────────────────────────────────────────────────────────┤
│  列表 + 搜索 + 分页  │  新建 / 编辑 / 删除                                  │
│  （日历例外 Tab：左侧月历 + 右侧例外列表）                                    │
└─────────────────────────────────────────────────────────────────────────────┘
```

数据范围按**当前登录科室**隔离（与门诊排班一致，可在页内切换科室上下文）。

| Tab | 代号 | 列表操作 |
| --- | --- | --- |
| **日排班** | T2 | 新建 / 编辑 / 删除 |
| **周排班** | TW | 新建 / 编辑 / 删除 |
| **放号时段** | T1 | 新建 / 编辑 / 删除 |
| **放号策略** | — | 新建 / 编辑 / 删除 |
| **日历例外 (T3)** | T3 | 月历点选 + 列表新建 / 编辑 / 删除 |

## 3. 推荐配置顺序（新科室上线）

Tab 默认顺序以「日排班」为首，但**首次配置建议按依赖关系从底向上**：

```text
health 主数据（科室、医师岗位、诊室、号源类型）
        ↓
① 放号时段 T1（推荐必配）
② 放号策略（可选：无 T1 时才需要）
③ 日排班 T2（核心）
④ 周排班 TW（占位预览 + 批量生成）
⑤ 日历例外 T3（节假日/调休，按需）
        ↓
门诊排班：生成正式排班 → 发布 → 放号 → 验收
```

## 4. 各 Tab 操作详解

### 4.1 放号时段（T1）

**作用**：定义一天内各出诊段的**起止时间与额定容量**。

**重要规则**：

- T1 中**每一行 = 生成 1 个 Slot**，不会自动按 15 分钟再切分。若需要 08:00–08:30、08:30–09:00 两格，须配两行。
- 一条 **日排班（T2）绑定一套 T1**；上午 + 下午等多段出诊，应在**同一套 T1 内配多行**（见下方示例），而非绑定多个 T1 编码。
- 正式排班生成或手动新建时若引用 T1，**出诊时间与批量放号**均以此为准（详见 [10 §5](./10-门诊排班页面操作说明.md)）。

**操作路径**：Tab「放号时段」→ **新建放号时段**

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 编码 | 是 | 科室内唯一，如 `T1-AM-20` |
| 名称 | 是 | 如「上午 20 号」 |
| 启用 | — | 关闭后不参与引用 |
| 时段行 | 是 | 开始时间 — 结束时间 — 容量（≥1） |

**示例（内科专家上午 + 下午，一套 T1 两行）**：

| T1 编码 | 名称 | 时段行 | 含义 |
| --- | --- | --- | --- |
| `T1-EXPERT-DAY` | 专家日出诊 | 08:00–12:00，容量 20 | 上午 1 个 Slot |
| 同上 | 同上 | 14:00–17:00，容量 15 | 下午 1 个 Slot |

也可拆成 `T1-AM-20`、`T1-PM-15` 两套 T1，但每条 T2 只能选**其中一套**；专家全天出诊更推荐**一套 T1 含两行**。

午间 12:00–14:00 无行即表示休息，不会放号。

**删除限制**：被日排班（T2）引用时不可删除，系统会提示引用关系；须先在 T2 中解除关联。

---

### 4.2 放号策略

**作用**：控制「提前几天可约、默认时段多长、每段几个号、各渠道占比」。

**生效场景**：

1. 日排班**未绑定**放号时段（T1）时，门诊排班「批量放号」按策略的时段粒度与单段容量切分；
2. 日排班**已绑定 T1** 时，生成正式排班会带入 T1 引用；门诊排班「批量放号」优先按 T1 各行出号（见 [10 §5.4](./10-门诊排班页面操作说明.md)）。

**优先级**：日排班已绑定 **T1 时，放号以 T1 为准**，放号策略不生效。

**操作路径**：Tab「放号策略」→ **新建策略**

| 字段 | 说明 | 上线建议 |
| --- | --- | --- |
| 策略编码 / 名称 | 科室内唯一 | 如 `RP-INTERNAL-DEFAULT` |
| 提前天数 | 患者最早可约未来第几天 | 7～14 天 |
| 时段粒度（分钟） | 自动切分每段长度；**0 = 整段 1 个 Slot** | 专家 15～30；普通 30～60 |
| 单段容量 | 每个时间片默认可约人数 | 专家 1；普通 5～10 |
| 渠道配额 JSON | 窗口/小程序等占比 | 初期可留空，均匀分配 |

---

### 4.3 日排班（T2）

**作用**：物化正式排班的**最小单元** — 描述「谁、什么号、在哪、用哪套时段放号」。

**操作路径**：Tab「日排班」→ **新建日排班**

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 编码 / 名称 | 是 | 如 `T2-ZHANG-EXPERT` |
| **模式** | 是 | MODE-A 医师门诊 / MODE-B 科室号 / MODE-C 诊区号 |
| **号源类型** | 是 | 对应 health `HealthcareService`（普通号、专家号、便民号等）；**绑定了医师时须在该医师用户管理「可接诊号源」范围内**，否则保存/生成正式排班拒绝 |
| 医师 | 视模式 | MODE-A 建议填；MODE-B 不填 |
| 诊室 | 视模式 | 可选；MODE-C 必填 |
| **放号时段** | 推荐 | 绑定 T1；不绑则放号时走放号策略 |
| 放号策略 | 可选 | 未绑 T1 时使用 |
| **占位有效期** | 可选 | 控制周历**虚线预览格**何时出现；留空 = 长期 |
| 占位优先级 | — | 同日多条 T2 都可占位时，数字越大越优先（默认 0） |
| 启用 | — | 关闭后不参与生成与占位 |

**排班模式速查**：

| 模式 | 典型场景 | 必选 |
| --- | --- | --- |
| MODE-A | 专家门诊、指名预约 | 号源类型；医师建议填 |
| MODE-B | 只排到科室，到院分诊 | 号源类型 |
| MODE-C | 诊区号，暂不绑医师 | 号源类型 + 诊室 |

**配置示例**：

| 场景 | 模式 | 号源类型 | 医师 | 放号时段 |
| --- | --- | --- | --- | --- |
| 张医生专家门诊 | MODE-A | 专家号 | 张医生 | `T1-EXPERT-DAY`（含上午+下午两行） |
| 内科普通号 | MODE-B | 普通号 | 不填 | `T1-AM-20`（仅上午一行） |
| 某诊区号 | MODE-C | 普通号 | 不填 | T1 + 必选诊室 |

**删除限制**：被周排班（TW）明细或日历例外（T3）引用时不可删除。

### 4.4 周排班（TW）

**作用**：

1. **占位预览**：门诊排班周历上，无正式排班的日期显示虚线格（惯例出诊预览）；
2. **批量生成**：门诊排班页「生成正式排班」选「周排班」+ 日期区间，按 weekday 映射 T2 批量落地。

**操作路径**：Tab「周排班」→ **新建周排班**

**配置顺序（弹窗内自上而下）**：

```text
① 出诊科室 — 本套周排班归属的门诊科室
② 排班方式 — 按科室 / 按医师
③ 名称、启用
④ 周明细 — 周一～周日各选一条日排班（留空 = 该日不出诊）
```

| 字段 | 说明 | 上线建议 |
| --- | --- | --- |
| **出诊科室** | 周排班与所选科室绑定；批量生成时 T2 须同属该科室 | 与登录科室一致或先切换顶部科室再建 |
| **排班方式** | **按科室**：周明细列出该科室全部**科室号**日排班；**按医师**：列出该科室全部**医师号**日排班（一周可排多位医师，各天任选） | 科室统一放号选「按科室」；专家各天不同班选「按医师」 |
| 名称 | 如 `TW-INTERNAL-DEFAULT` | — |
| 启用 | — | 是 |
| **科室默认** | 保存时系统自动设为默认，用于门诊排班周历**预览格** | 无需手工配置 |
| **周明细** | 固定周一～周日 7 行；下拉仅展示符合上方筛选的日排班 | 周六日可留空 |

**周明细规则**：

- 页面固定展示周一～周日，**不可增删行**；
- 某 weekday 日排班留空表示该日不出诊；
- 所选日排班必须与「出诊科室 + 排班方式」一致，否则无法保存。

**配置示例（按科室 — 内科普通号）**：

| 出诊科室 | 排班方式 | 周明细 |
| --- | --- | --- |
| 内科 | 按科室 | 周一至周五各选「内科普通号」科室号 T2；周六日留空 |

**配置示例（按医师 — 一周多位专家）**：

| 出诊科室 | 排班方式 | 周明细 |
| --- | --- | --- |
| 内科 | 按医师 | 周一选张医生专家 T2、周二选李医生专家 T2、周三～五各选对应医师 T2 |

> 同一套周排班明细应使用同一排班方式；若历史数据混绑科室号与医师号，编辑时会尽量回显，建议拆成多套 TW 分别维护。

### 4.5 日历例外（T3）

**作用**：覆盖常规周排班，处理节假日、调休、临时停诊、加班门诊。

**操作方式**：

- **列表**：Tab「日历例外」右侧表格 → 新建 / 编辑 / 删除；
- **月历**：左侧选月份 → 点击日期快速新建。

| 类型 | 生成行为 | 典型用途 |
| --- | --- | --- |
| **CLOSED** | 该日跳过生成；已发布则走停诊流程 | 国庆、春节 |
| **EXTRA** | 在常规之外额外生成一条排班 | 周末加班门诊 |
| **OVERRIDE** | 用指定 T2 替代当天 | 调休工作日按周六班表 |
| **REDUCED** | 用减半 T2 替代 | 半日门诊 |

| 字段 | 说明 |
| --- | --- |
| 类型 | CLOSED / EXTRA / OVERRIDE / REDUCED |
| 起始日 | 必填 |
| 结束日 | 留空 = 单日 |
| 替换日排班 | OVERRIDE / EXTRA / REDUCED 须选 T2 |
| 说明 | 如「国庆」「调休」 |
| **参与生成** | 勾选后，「生成正式排班」时自动生效 |

**示例**：

| 日期 | 类型 | 说明 |
| --- | --- | --- |
| 2026-10-01～10-07 | CLOSED | 国庆 |
| 2026-09-28 | OVERRIDE | 调休按周日班表（选对应 T2） |

## 5. 关键概念：占位预览 vs 正式排班

| 概念 | 配置位置 | 表现 | 能否预约 |
| --- | --- | --- | --- |
| **占位预览** | T2/TW 的「占位有效期」 | 门诊排班周历**虚线格** | 取决于 TW「无排班时可约」（建议关） |
| **正式排班** | 门诊排班页生成/新建 | 门诊排班周历**实线格** | 发布 + 放号后可约 |

**两个日期概念互不影响**：

| 配置项 | 位置 | 控制什么 |
| --- | --- | --- |
| **占位有效期** | 排班设置 T2/TW | 虚线预览格何时出现 |
| **生成区间** | 门诊排班 → 生成正式排班 | 本次批量落地哪些天的正式 Schedule |

## 6. 与下游页面的衔接

| 排班设置产出 | 下游页面 | 用法 |
| --- | --- | --- |
| TW + T2 | **门诊排班** | 「生成正式排班」→ 选周排班 + 日期区间 |
| 单条 T2 | **门诊排班** | 「生成正式排班」→ 选日排班 + 日期区间 |
| T3 例外 | **门诊排班** | 生成时自动跳过 CLOSED、应用 OVERRIDE 等 |
| **T1** | **门诊排班** | 随 T2 生成时写入正式日程；手动新建可选同一 T1；发布后「批量放号 → 按放号时段模板填充」 |
| 放号策略 | **门诊排班** | 仅当 T2 **未绑 T1** 时，批量放号回落到策略切分 |
| Slot | **号源日历** | 核对容量、封锁/解封 |
| Slot | **门诊预约 / 挂号** | 占号、现场取号（号源类型须与 T2 一致） |

日常作业详见 [10-门诊排班页面操作说明.md](./10-门诊排班页面操作说明.md)。

## 7. 与「预约策略」的分工

| 页面 | 路由 | 管什么 |
| --- | --- | --- |
| **排班设置** | `/booking/schedule-template` | 出诊内容、时段、容量、占位预览、节假日 |
| **预约策略** | `/booking/policy` | 现场占号模式、挂号后自动报到、退号处置、停诊策略 |

放号策略在排班设置 Tab 内维护；挂号/停诊策略在「预约策略」页，两者相互独立。

## 8. 完整配置示例（内科专家门诊）

以「内科专家门诊」为例，自 [09 §7.4](./09-门诊排班功能与上线手册.md) 提炼：

### 8.1 放号策略（可选）

| 字段 | 值 |
| --- | --- |
| 编码 | `RP-INTERNAL-EXPERT` |
| 名称 | 内科专家默认放号 |
| 提前天数 | 7 |
| 时段粒度 | 30 分钟 |
| 单段容量 | 1 |

### 8.2 放号时段 T1

| 编码 | 名称 | 时段 |
| --- | --- | --- |
| `T1-EXPERT-DAY` | 专家日出诊 | 08:00–12:00 容量 20；14:00–17:00 容量 15（**同一 T1 两行**） |

### 8.3 日排班 T2

为每位出诊医师各建一条：

| 字段 | 示例 |
| --- | --- |
| 编码 | `T2-ZHANG-EXPERT` |
| 模式 | MODE-A |
| 号源类型 | 专家号 |
| 医师 | 张医生 |
| 放号时段 | `T1-EXPERT-DAY` |
| 占位有效期 | 2026-01-01 ～ 2026-12-31 |
| 启用 | 是 |

科室号（MODE-B）示例：不填医师，只选号源类型「普通号」+ T1。

### 8.4 周排班 TW

| 字段 | 示例 |
| --- | --- |
| 编码 | `TW-INTERNAL-DEFAULT` |
| 科室默认 | **是** |
| 无排班时可约 | **否** |
| 占位有效期 | 与 T2 一致 |
| 周一 | T2-ZHANG-EXPERT |
| 周二 | T2-LI-EXPERT |
| 周三～五 | 各专家 T2 |
| 周六日 | 留空或绑周末加班 T2 |

### 8.5 日历例外 T3

| 日期 | 类型 | 说明 |
| --- | --- | --- |
| 2026-10-01～10-07 | CLOSED | 国庆 |
| 2026-09-28 | OVERRIDE | 调休按周日班表 |

### 8.6 验收

配置完成后到 **门诊排班**：

1. 周历应出现虚线占位预览（在占位有效期内）；
2. 「生成正式排班」→ 选 TW + 区间 → 建议不勾选自动发布/放号；
3. 核对草稿格出诊时间是否与 T1 一致 → **发布** → **批量放号**（点「按放号时段模板填充」）；
4. 到号源日历、门诊预约试约。

## 9. 常见问题（FAQ）

### Q1：配了排班设置，患者为什么还约不到？

排班设置只是模板。须到 **门诊排班**「生成正式排班 → 发布 → 放号」后才有 Slot，患者才能约。

### Q2：T1 和放号策略都要配吗？

**推荐只配 T1**（精确可控、一行一个 Slot）。放号策略是日排班未绑 T1 时的备选，二者通常二选一即可。

### Q3：占位有效期和生成区间有什么区别？

- **占位有效期**（T2/TW）→ 周历虚线预览何时出现；
- **生成区间**（门诊排班弹窗）→ 本次批量落地哪些天的正式排班。  
两者互不影响。

### Q4：普通号和便民号要各建 T2 吗？

若两种号别出诊规则不同（时段、容量、是否绑医师），应**各建 T2** 并在 TW 中分别引用。挂号/预约时选的号源类型须与 T2/Slot 一致，否则占不到号。

### Q5：删除模板失败？

存在引用链时不允许删除：

```text
T1 ← T2 ← TW 明细 / T3 例外
```

须自下游向上解除关联后再删。

### Q6：「无排班时可约」要不要开？

试点建议**关闭**。开启后患者可在未落地正式排班前预约（lazy 物化），号源管控难度更大；成熟后再评估开启。

### Q7：占位预览有了，但生成正式排班没反应？

检查：T2/TW 是否启用；生成区间内**同一 T2 在同日是否已有正式排班**（已有则跳过）；该日是否为 T3 CLOSED；是否选了正确的 TW/T2 模板。

### Q8：T1 配了，生成后放号还要手工填时段？

请确认 **日排班已绑定 T1**。生成正式排班后，到门诊排班 **批量放号** 弹窗点 **按放号时段模板填充**；或在生成弹窗勾选 **自动发布 + 自动放号**。手动新建日程时也可直接选同一 T1。
