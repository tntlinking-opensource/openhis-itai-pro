## 2. 架构合规（zxplat-module-booking-codegen）

### 2.1 通过项

- `booking-contracts`：Reader/Writer/Client + DTO，无 Spring/JPA 依赖
- `booking-application`：AppService 编排，Flyway 在 `db/migration/booking`
- `booking-bridge`：Reader/Writer/Client 实现，可依赖 health-domain + booking-domain
- HTTP：`POST /api/app/{serviceName}/{methodName}` 与 Registrar 一致
- health 侧通过 `health-integration-contracts` Extension 接入 booking；`isEnabled()` 门控

### 2.2 待关注

| 项 | 位置 | 建议 |
| --- | --- | --- |
| `@Transactional` 在 AppService | SlotManageAppService、OutpatientScheduleAppService 等 | 规范建议事务在领域层；存量可保留，新增写路径优先领域 `@Transactional` |
| health 仍保留 V61–V71 `wkf_*` Flyway | zxplat-domain | 与 booking V1 `IF NOT EXISTS` 共存；长期可 health 侧重定向说明 |
| OutpatientBookingWriter 直读 Repository | adapter | acceptable for thin adapter；复杂读应上收 QueryService |
