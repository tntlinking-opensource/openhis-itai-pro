## 2. 页面结构

门诊排班是排班员日常主页面，用于查看周历/月历、维护正式排班、发布放号、停诊与替诊。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 排班科室▼  医师▼  诊室▼  号源类型▼  [周视图|月视图]  选中周 …  [工具按钮] │
├─────────────────────────────────────────────────────────────────────────────┤
│ 操作提示条（虚线格 vs 实线格说明，首次可见，可点「知道了」关闭）            │
├─────────────────────────────────────────────────────────────────────────────┤
│ 图例：占位预览 | 草稿 | 已发布 | 已停用                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│                        周历 / 月历（主工作区）                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
         点击格子 ──→ 右侧抽屉：编辑 / 发布 / 放号 / 删除草稿 / 停诊 / 替诊
```

| 区域 | 功能 |
| --- | --- |
| **顶栏筛选** | 排班科室、医师、诊室、号源类型；切换周/月视图；翻页；批量工具 |
| **操作提示条** | 解释占位预览与正式排班的区别 |
| **图例** | 四种格子状态的视觉说明 |
| **周历/月历** | 按日展示排班；单击格子进入详情 |
| **详情抽屉** | 新建、编辑、发布、放号、删除草稿/作废、停诊、替诊等 |

## 3. 顶栏操作

### 3.1 筛选条件

| 控件 | 说明 |
| --- | --- |
| **排班科室** | 必选。默认等于登录科室，可切换其他门诊科室。切换后清空医师/诊室/号源类型筛选并重新加载。 |
| **医师** | 可选。按医师收窄日历显示；**选定后号源类型下拉同步收窄为该医师可接诊号源**（用户管理配置）。若下拉为空，提示「当前科室无激活医师岗」——需在用户管理维护出诊与可接诊号源或换科室。 |
| **诊室** | 可选。按诊室筛选。 |
| **号源类型** | 可选。未选医师时为全部 ACTIVE；已选医师时为该医师可接诊号源。 |

### 3.2 视图与翻页

**周视图（默认）**

- 同时展示「选中周」及其下一周（共两周）；**蓝框标注的是选中周**。
- **上一周 / 下一周**：移动选中周。
- 顶栏显示：`选中周 第 N 周（YYYY-MM-DD ~ YYYY-MM-DD）`。

**月视图**

- 顶部摘要：已发布天数、草稿天数、未排天数、已约条数。
- 每日格子显示徽章：`发`（已发布）、`草`（草稿）、`停`（停诊）。
- 点击某日：
  - 无排班 → 跳转到该日周视图；
  - 仅 1 条排班 → 直接打开详情抽屉；
  - 多条排班 → 跳转到该日周视图再选择。

### 3.3 工具按钮

| 按钮 | 说明 |
| --- | --- |
| **复制到下一周** | 将蓝框「选中周」的正式排班复制到紧接着的下一周（详见 §5） |
| **生成正式排班** | 按日排班/周排班模板批量生成指定日期区间的正式排班（详见 §5.1） |
| **刷新** | 重新加载下拉数据和日历 |
| **新建日程** | 手动创建单条草稿排班（默认日期为当前选中周锚点日） |

## 4. 看懂日历格子

| 样式 | 状态 | 含义 |
| --- | --- | --- |
| **虚线格** | 占位预览 | 来自「排班设置」中的周排班，当天尚无正式排班，仅预览惯例出诊 |
| **实线 · 灰色** | 草稿（draft） | 已落地但未发布；可编辑、可发布 |
| **实线 · 绿色** | 已发布（active） | 可放号、替诊、停诊；放号后患者可约 |
| **实线 · 红色** | 已停用（inactive） | 整日停诊 |

### 4.1 周历交互

| 操作 | 效果 |
| --- | --- |
| **单击格子** | 打开详情/编辑抽屉 |
| **双击日期列空白处**（非格子区域） | 在该日新建日程 |

## 5. 标准业务流程

整体链路：

```text
排班设置（模板） → 门诊排班（生成/维护） → 发布 → 放号 → 号源日历核对 → 门诊预约
```

单条排班生命周期：

```text
新建（draft）→ 编辑 → 发布（active）→ 批量放号 → 患者可约
    ↓                                              ↓
删除草稿（作废）                            部分 Slot 停诊
    ↓
整日停诊（inactive）→ 恢复开诊（须重新放号）→ 可作废日程
```

### 5.1 方式 A：批量生成（推荐，适合整周/整月）

**适用**：科室已配好日排班/周排班模板，需要一次性落地多天的正式排班。

1. 确认 **排班设置** 中已配置：放号时段 → 日排班 → 周排班 → 日历例外（如有）。
2. 在门诊排班页点 **生成正式排班**。
3. 在弹窗中填写：

| 字段 | 说明 |
| --- | --- |
| **排班类型** | **日排班**：同一模板在区间内逐日重复；**周排班**：按周一至周日映射不同日排班 |
| **日排班 / 周排班** | 选择已启用的模板 |
| **生成区间** | 本次要落地的起止日期（**与排班设置里「占位有效期」无关**） |
| **自动发布** | 生成后直接变为 active；首批建议关闭，核对后再手动发布 |
| **自动放号** | 须同时勾选「自动发布」；勾选后按 T2 绑定的 T1 自动出号；首批建议关闭 |

4. 点 **生成正式排班**。

**系统行为**：

- 区间内逐日生成；
- **同一日排班（T2）在同一天已有正式日程时自动跳过**（避免重复生成）；
- T3 日历例外中 `CLOSED`（停诊）日跳过；
- 若 T2 已绑定 **放号时段（T1）**：
  - 正式日程会**记录 T1 引用**（供后续批量放号使用）；
  - 草稿/发布时的**出诊时间**取 T1 各时段行的最早开始～最晚结束（不再固定为全天 00:00–23:59）。
- 仅勾选「自动放号」且未勾选「自动发布」时，系统会拒绝生成（须先发布才能放号）。

### 5.2 方式 B：单条手动新建

**适用**：临时加诊、单日调整、尚未配模板的新科室。

1. 点顶栏 **新建日程**，或 **双击** 某日空白列。
2. 在抽屉中填写：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 号源类型 | 是 | 专家号/普通号等 |
| 出诊医师 | 否 | 建议填写 |
| 诊室 | 否 | 建议填写 |
| **放号时段** | 否 | 可选；选中后自动带出出诊起止时间，放号时可按 T1 填充 |
| 规划日期 | 是 | 出诊日 |
| 出诊起止时间 | 是 | 可选手动填写，或选放号时段后自动带出 |

3. 点 **保存草稿**（可多次修改）或 **发布**（变为 active）。

> 发布时若检测到同人同时段冲突，系统弹出警告，确认后可继续。

### 5.3 方式 C：从占位预览落地单日

**适用**：周历上已有虚线占位预览，只需把某一天落地为正式排班。

1. 单击 **虚线占位预览格**。
2. 在抽屉中点 **生成本日正式排班**（会自动发布并放号）。

### 5.4 发布与放号

**发布**（草稿 → 已发布）

- 在草稿抽屉中点 **发布**。
- 须填写规划起止时间（通常等于当日出诊窗口）。

**批量放号**（已发布 → 患者可约）

1. 单击 **绿色已发布格**，打开详情抽屉。
2. 点 **批量放号**。
3. 若日程已关联 **放号时段（T1）**（来自模板生成或手动新建时选择）：
   - 点 **按放号时段模板填充**，将 T1 各行加入待放号列表；
   - 核对时段与容量后点 **确认放号**。
4. 若未关联 T1：
   - 手动填写开始/结束、每段时长（0 = 整段 1 个）、容量；
   - 或依赖 **放号策略** 默认值（须日排班未绑 T1 时在排班设置中配置）。
5. 放号成功后，可到 **号源日历**（`/booking/slot-calendar`）核对 Slot 容量与状态。

> **提示**：模板批量生成时若未勾选「自动放号」，发布后在批量放号弹窗用「按放号时段模板填充」即可，无需手工逐段录入。

### 5.5 删除草稿 / 作废日程

**适用**：误点「新建日程」、误生成草稿、或停诊后需从周历清除占位。

| 状态 | 操作 | 说明 |
| --- | --- | --- |
| **草稿（灰色）** | 打开抽屉 → **删除草稿** | 日程作废，周历灰格消失；不可恢复 |
| **已发布（绿色）** | 不可直接删除 | 须先 **整日停诊**，再视情况保留或处理预约 |
| **已停用（红色）** | 打开抽屉 → **作废日程** | 从周历移除；不会自动恢复号源 |

**注意**：

- 删除/作废后该日可重新生成或新建排班。
- 已发布且已有患者预约的日程，应走 **停诊向导**，不要直接作废。

## 6. 复制到下一周

**适用**：本周排班已确认，快速复制到下周续排。

**操作步骤**：

1. 切换到 **周视图**。
2. 用 **上一周 / 下一周** 把 **蓝框选中周** 调到要复制的源周。
3. 点 **复制到下一周**，在确认框中核对源周与目标周日期，确认。

**注意事项**：

| 项 | 说明 |
| --- | --- |
| 复制范围 | 仅复制**正式排班**；占位预览格、草稿不复制 |
| 目标周冲突 | 次周已有正式排班时会阻止复制 |
| 放号 | 复制后会在次周**重新放号**（含 Slot 生成） |
| 选中周含义 | 「选中周」= 蓝框标注的那一周，与今天是否在该周无关 |

## 7. 详情抽屉：停诊与替诊

打开方式：单击周历/月历中的排班格子。

### 7.1 替诊

**适用**：医师 A 临时不能出诊，医师 B 顶班；**患者预约与号源占用不变**。

1. 打开 **已发布（绿色）** 日程的详情抽屉。
2. 在「替诊」区域选择 **替诊医师**、填写原因（可选）。
3. 点 **确认替诊**。
4. 周历、候诊叫号显示「B 替 A」；可点 **撤销替诊** 恢复。

> 与「转交预约」的区别：转交会迁移 Slot 占用；替诊不迁移。详见 [08 §8.1](./08-门诊排班概念梳理.md)。

### 7.2 停诊

| 方式 | 入口 | 影响 |
| --- | --- | --- |
| **整日停诊** | 详情抽屉 → **整日停诊** | Schedule 变 inactive，下属 Slot 不可约 |
| **部分停诊** | 详情抽屉 → 勾选号源时段 → **部分停诊** | 仅选中 Slot 停诊 |

**有有效预约时**（未取消、未挂号）：

1. 系统弹出 **停诊向导**，预览影响人数；
2. 按「预约策略 → 停诊策略」执行转交/改约/取消或人工处置；
3. 处置完成后再完成停诊（默认策略：未处置则禁止停诊）。

### 7.3 恢复开诊

**适用**：整日停诊后重新开诊。

1. 打开 **已停用（红色）** 日程的详情抽屉。
2. 点 **恢复开诊**。
3. 日程变回 active，但**不会自动恢复号源**，须手动 **批量放号**。

## 9. 常见问题（FAQ）

### Q1：为什么看到虚线格但没有号可约？

虚线格是**占位预览**，不是正式排班。须通过「生成正式排班」、手动新建并发布，或点占位格「生成本日正式排班」，再 **批量放号** 后才有可约号源。

### Q2：生成正式排班后格子还是灰色？

灰色表示**草稿**，尚未发布。在抽屉中点 **发布**，或生成时勾选「自动发布」。

### Q3：发布后患者仍约不到？

发布只代表日程 active，还须 **批量放号** 生成 Slot。可到号源日历核对 Slot 是否已生成、容量是否正确。

### Q4：医师显示「未指定」？

日排班模板未绑定医师，或草稿未填医师。在 **排班设置 → 日排班** 中维护出诊医师后重新生成，或在草稿状态下编辑并发布。

### Q5：复制到下一周失败，提示次周已有排班？

目标周已存在正式排班。须先清空或调整次周日程，再执行复制。

### Q6：占位预览什么时候出现？

由 **排班设置 → 周排班** 中的「占位有效期」控制；与「生成正式排班」弹窗里的「生成区间」无关。

### Q7：误建了草稿怎么取消？

打开 **灰色草稿格** → 抽屉点 **删除草稿**。已发布须先 **整日停诊**；已停诊（红色）可点 **作废日程**。

### Q8：生成正式排班后，放号时段没带过来？

请确认 **排班设置 → 日排班** 已绑定 **放号时段（T1）**。生成后：

- 草稿/已发布日程的出诊时间应已按 T1 时段显示；
- 放号时在 **批量放号** 弹窗点 **按放号时段模板填充**；
- 或生成时同时勾选 **自动发布 + 自动放号**（适合熟练排班员批量作业）。

若 T2 未绑 T1，放号须手工填段或依赖放号策略。

## 10. 排班员日常 Checklist

**每周例行（建议）**

- [ ] 选择正确 **排班科室**
- [ ] 周视图核对 **选中周** 排班是否完整（草稿 → 发布 → 放号）
- [ ] 需要续排时使用 **复制到下一周**，或在次周 **生成正式排班**
- [ ] 到 **号源日历** 抽查 Slot 容量与状态
- [ ] 临时变动：替诊（医师顶班）或停诊（整日/部分）

**新科室首次上线（概要）**

- [ ] 基础资料：科室、医师岗位、诊室、号源类型
- [ ] 排班设置：放号时段 → 日排班 → 周排班（设默认 + 占位有效期）
- [ ] 门诊排班：生成正式排班（建议不勾选自动发布/放号）
- [ ] 人工核对后逐条或批量 **发布** → **放号**
- [ ] 号源日历验收 → 门诊预约试约

完整初始化步骤见 [09 §7 新医院从 0 到可预约](./09-门诊排班功能与上线手册.md)。
