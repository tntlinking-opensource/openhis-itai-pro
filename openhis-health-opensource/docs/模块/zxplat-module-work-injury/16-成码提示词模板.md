> **用途**：复制下方「主提示词」到 Cursor 新会话，替换 `{…}` 占位符后发送。  
> **须 @**：`@代码生成通用规范` `@whale-chs-jilin-gs-codegen`  
> **文档真源**：`docs/模块/zxplat-module-work-injury/`（08～11、13～15）

---

## 使用方式

1. 新开 Agent 会话，先 @ 两个 Skill/Rule（见上）。
2. 根据本轮任务选 **Wave**（W0 Win / W1 后端 / W1 前端 / 联调修复）。
3. 复制「主提示词」，填好 `{本轮任务}` 等占位符。
4. 编码完成后要求 Agent 按 [15 §8](./15-编码规范与Cursor规则对照.md) 输出「规范合规摘要」并更新 [13](./13-实现状态与文档对照.md) §2。

## 架构铁律（违反即返工）

- `health-application` 只调 `WorkInjury*Extension`，**禁止** import `com.zxplat.plugin.wi.*` / `com.zxplat.plugin.chs.application.workinjury.*`
- UI AppService 在 `health-application` · `insurance/workinjury`（`WorkInjuryInvokeAppService`）
- Extension Impl 在 `wi-jilin-bridge` · `integration.workinjury.*`；`@ConditionalOnProperty(work-injury.enabled=true)`
- 工伤结算走 `WorkInjuryOutpatientSettlementExtension`，**禁止** `OutpatientChargeInsuranceExtension` / `ChsHttpAccessor`
- 每 infno：**prepareInvoke → OpenHIS.Win :5000 → submitInvokeResult**（Whale 不直调 DLL）
- infno 链在 `WorkInjurySettleStepPlanner` Java 常量；**无历史 2204 时跳过 2205**
- Flyway：`wi-jilin-starter` · `db/migration/wi/`（anchor、invoke_session、pre_settle）
- 出站：`fixmedins_code=JL2201992002`，`recer_sys_code=LNYTH`，`bus_no=H22010402403-GS`
- `zxplat.modules.work-injury.enabled=false` 时必须 NoOp，现网行为不变
