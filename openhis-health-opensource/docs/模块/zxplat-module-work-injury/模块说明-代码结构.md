## Maven 父工程

`zxplat-module-work-injury`（parent：`zxplat-plugin`）· BOM：`zxplat.chs.version`（WI 制品与 CHS 同版本槽）

## 子模块与 Java 包

| Maven 模块 | Java 根包 | 职责 |
|------------|-----------|------|
| `module-wi-jilin-domain` | `com.zxplat.plugin.wi.domain` | `yb_wi_*` 实体、Command/Result、DomainService |
| `module-wi-jilin-gateway` | `com.zxplat.plugin.wi.gateway` | 工伤平台 Scheme（Win 出站，无 HTTP 客户端） |
| `module-wi-jilin-bridge` | `com.zxplat.plugin.wi.bridge` + `….bridge.integration.workinjury` | ExtensionImpl、Orchestrator、ContextLoader |
| `module-wi-jilin-application` | `com.zxplat.plugin.wi.application` | `WorkInjury*AppService` |
| `module-wi-jilin-starter` | `com.zxplat.plugin.wi.starter` | HIS embedded 安装入口；Flyway `db/migration/wi` |

## Enforcer 互禁

| 模块 | 禁止依赖 |
|------|----------|
| bridge | `module-wi-jilin-application` |
| application | `module-wi-jilin-bridge` |

ArchTest：`WiJilinBridgeArchitectureTest` / `WiJilinApplicationArchitectureTest`（application 另禁 gateway / bridge.integration import）。

## 开关

```properties
zxplat.modules.work-injury.enabled=true
```

## 编译

```bash
mvn -pl zxplat-plugin/zxplat-module-work-injury/module-wi-jilin-domain,\
zxplat-plugin/zxplat-module-work-injury/module-wi-jilin-gateway,\
zxplat-plugin/zxplat-module-work-injury/module-wi-jilin-bridge,\
zxplat-plugin/zxplat-module-work-injury/module-wi-jilin-application,\
zxplat-plugin/zxplat-module-work-injury/module-wi-jilin-starter -am compile
```
