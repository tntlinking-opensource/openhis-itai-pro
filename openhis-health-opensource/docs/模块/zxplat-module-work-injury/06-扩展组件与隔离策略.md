# 工伤扩展组件与隔离策略（WORK_INJURY）

> **原则**：工伤为 **可选扩展组件**；未实装时，挂号/医生站/收费/对账等 **行为与现网完全一致**。  
> **版本**：v1.1 | 日期：2026-08-03（对齐 05 v0.5：REG-001/002）

---

## 1. 开关与模块边界

| 层级 | 开关 / 条件 | 未启用时 |
|------|------------|---------|
| Maven 模块 | `zxplat-module-work-injury` **不引入 classpath** | 无工伤 Bean |
| 运行时 | `zxplat.modules.work-injury.enabled=false`（默认 **false**） | 全部 NoOp / 不注册路由 |
| 契约数据 | `fin_contract` 无 `WORKER_INSURANCE` 行 | UI 不展示「工伤保险」 |
| Bridge / Win | OpenHIS.Win 未装或未启用 | 工伤 UI 提示装客户端；**不拖垮省医保** |

> 与省医保关系：`zxplat.modules.chs.enabled=true` **不隐含** 工伤启用；两开关 **独立**。

---

## 2. 集成模式（对齐 Whale 现有 Extension）

参照 `einvoice-boss`、`zxplat-module-chs-jilin` 已落地模式：

```text
health-infrastructure              ← 中性接口（WorkInjury*Extension）
health-infrastructure/noop       ← NoOp 默认 Bean（@ConditionalOnMissingBean）
wi-jilin-bridge                  ← @Primary 实现（@ConditionalOnProperty enabled=true）
health-application               ← 只依赖 Extension 接口，不 import 工伤包
```

**铁律**：`health-application` **禁止** `import 工伤 DTO / Accessor；与 [01-概要设计](../zxplat-module-chs-jilin/01-概要设计.md) 省医保 Extension 规则相同。

---

## 3. 建议 Extension 切点

| Extension 接口 | 挂载点 | 未实装时 |
|----------------|--------|---------|
| `WorkInjuryRegisterExtension` | 挂号改费用性质=工伤 → 1101/9102 | NoOp；挂号走纯 HIS |
| `WorkInjuryApprovalUploadExtension` | 2301（挂号员/医生站入口共用） | NoOp |
| `WorkInjuryOutpatientSettlementExtension` | 收费 2201～2207 | NoOp；`OutpatientChargeInsuranceExtension` 对工伤账户 **isEnabled=false** 或不分组 |
| `WorkInjuryReconciliationExtension` | 医保办 1320/1321/1322 | NoOp；菜单不展示 |
| `WorkInjuryEncounterContextExtension` | 医生站/收费 **「工伤」角标** | NoOp；无角标 |

现有 `OutpatientChargeInsuranceExtension` **仅处理 `CHS_NATIONAL_*`**；工伤结算走 **独立 Extension**，避免在一个 Impl 里堆 if-else。

## 4. UI / 主数据隔离

| 项 | 未实装组件 | 实装后 |
|----|-----------|--------|
| 费用性质下拉 | 无「工伤保险」 | 有（依赖 `fin_contract`） |
| 挂号 9102/2301 按钮 | **不渲染** | 费用性质=工伤时显示 |
| 医生站工伤横幅/角标 | **不渲染** | 就诊 `WORKER_INSURANCE` 时显示 |
| 门诊收费预结算 | 仅省/市/自费 | 多工伤链 |
| 医保管理 · 工伤对账 | **无菜单** | 有 Tab |
| 读卡 | 省医保 FSI 1101 不变 | 工伤意向时多 WORK_INJURY 1101 |

**前端**：路由/菜单由 **后端 capability 接口** 或配置下发（`workInjuryEnabled`），避免前端写死工伤页面导致未装模块时空按钮。

## 5. 业务规则隔离（已确认 BR）

以下规则 **仅在** `work-injury.enabled=true` 且就诊/账户为工伤时生效：

| BR-ID | 规则 |
|-------|------|
| **BR-WI-REG-001** | **无有效备案不可完成挂号**（须绑定 qualification 后才可确认缴费）；**挂号费一律自费** |
| **BR-WI-REG-002** | **2301 仅挂号窗口**；医生站不提供 2301（无工伤网，仅角标只读） |
| **BR-WI-APR-001** | 2301 成功后 **必须再 9102** 取得 `qualification_id` 方可进入收费链 |
| **BR-WI-SET-001** | 无有效 `qualification_id` **阻断 2206/2207**（预结算/结算） |
| **BR-WI-SET-002** | 2201→2203→（有旧 2204 则 2205）→2204→2206→2207 |
| **BR-WI-REV-001** | 退号 **不调 2302**；仅 HIS 退号 |

未装组件：BR-WI-* **不参与校验**；挂号费、收费与现网一致。

---

## 6. 挂号费自费（BR-WI-REG-001 细则）

工伤就诊 **挂号费支付恒为自费**（现金/银联/自费账户），**禁止**省医保/工伤账户扣款：

```text
就诊标记：WORKER_INSURANCE
挂号费支付：fin_account → 自费账户（SELF_CHARGE）
禁止：省医保/工伤账户余额、统筹支付挂号费
```

IF-REG-07 支付挂号费时：若费用性质=工伤 → **支付渠道仅现金/银联/自费**，不走 `OutpatientChargeInsuranceExtension`。

**完成挂号门禁**：点「确认挂号」预结算后须绑定有效 `qualification_id`（已有审批自动绑定，否则一键 2301→9102）；否则不打开确认缴费窗。

---

## 7. 2301 入口（BR-WI-REG-002）

| 入口 | 角色 | 说明 |
|------|------|------|
| **挂号 · 一键备案** | 挂号员 | 有工伤网窗口；先绑定已有 9102，无行再 2301 |
| **医生站** | 医生 | **不提供 2301**；队列「工伤」角标只读（HIS 锚点） |

共用：`WorkInjuryApprovalUploadExtension`（仅挂号侧调用）  
成功后：**强制** 调 9102（BR-WI-APR-001），写回 `encounter.wi_qualification_id`。

## 8. 路由与 scheme 隔离

```text
InsuranceGatewayClient.invoke(contractBusNo, infno, ...)
    ↓
contract.scheme == WORK_INJURY  &&  work-injury.enabled
    → Extension 编排 + web-ele 调 OpenHIS.Win /api/work-injury/invoke
contract.scheme == CHS_NATIONAL_JILIN
    → ChsHttpAccessor（不变）
else / disabled
    → NoOp
```

`OutpatientInsuranceChargeGrouper`：仅当组件启用 **且** 账户 category=`WORKER_INSURANCE` 时分组到工伤 Extension；否则该账户 **不参与医保预结算**（等同自费）。

---

## 9. 数据与 Flyway

| 表/列 | 策略 |
|-------|------|
| `yb_settlement_record` 等 | 可共用；`scheme_code=WORK_INJURY` 过滤 |
| `yb_wi_encounter_anchor`（建议） | Flyway 在 **工伤模块**；未装模块则不建表 |
| `fin_contract` 工伤行 | 主数据脚本/院点配置；未装模块可不配 |

未装模块：**不执行** 工伤 Flyway；health 核心迁移不受影响。
