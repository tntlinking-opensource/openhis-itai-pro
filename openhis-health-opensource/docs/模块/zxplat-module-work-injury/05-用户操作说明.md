# 工伤模块 · 用户操作说明

> **状态**：产品修订 v0.5（对齐院点：无备案不可完成挂号；医生站无工伤网）  
> **依据**：[14-院方确认决策.md](./14-院方确认决策.md) · [04-院点生产日志与MVP范围.md](./04-院点生产日志与MVP范围.md) · V1.3 手册  
> **版本**：v0.5 | 日期：2026-08-03  
> **相对 v0.4**：REG-001 改为「无有效备案不可完成挂号」；REG-002 取消医生站 2301（仅角标只读）

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **可选扩展** | 未装工伤组件时，挂号/医生站/收费 **与现网完全一致**（见 [06](./06-扩展组件与隔离策略.md)） |
| **读卡** | 可直接选「工伤保险」；待遇区经 Win 做 **工伤 1101→9102**（不必先省医保读卡） |
| **9102 在挂号** | 改费用性质=工伤后 → **9102 待遇/审批查询**（**P0**；联调不通再改） |
| **2301 仅挂号窗** | 9102 无审批时，**仅挂号员** 在有工伤网的窗口做 2301；医生站不上传 |
| **2301 后再 9102** | 2301 成功 **必须再 9102** 取得 `qualification_id` |
| **2201 在结算** | 挂号不调 2201；收费预结算时 2201→…→2207 |
| **Win 覆盖** | P0：**挂号 + 收费** 安装 OpenHIS.Win；医生站可不装工伤网 |

## 2. 已确认业务规则（BR-WI-*）

| 规则 | 内容 |
|------|------|
| **BR-WI-REG-001** | **无有效备案不可完成挂号**（须绑定 `qualification_id` 后才可确认缴费）；**挂号费一律自费** |
| **BR-WI-REG-002** | **2301 仅挂号窗口**；医生站不提供 2301（无工伤网）；队列仅展示备案状态角标 |
| **BR-WI-APR-001** | **2301 成功后必须再 9102** 才能进入收费链 |
| **BR-WI-SET-001** | **无有效 `qualification_id` 阻断 2206/2207** |
| **BR-WI-SET-002** | 结算链：**2201→2203→2205?→2204→2206→2207**（**无历史 2204 时跳过 2205**） |
| **BR-WI-REV-001** | 退号 **不调 2302**；仅 HIS IF-REG-10 |

## 3. 角色与页面

| 角色 | 页面 | 工伤相关动作 |
|------|------|-------------|
| 挂号员 | 门诊挂号 | 改工伤、9102、2301/一键备案、**挂号费自费**；未备案不可确认缴费 |

## 4. 读卡与 1101

| 阶段 | 动作 | 平台 |
|------|------|------|
| 直接选「工伤保险」 | 放卡 + Win 查询 | **工伤 1101** → **9102**（推荐路径） |
| 先读省医保再改工伤 | 可选 | **省医保 1101** 后再切工伤，待遇区仍走工伤 1101→9102 |
| 读身份证 | 建档/检索 | 本地，通常不调 1101 |

推荐流程：**选工伤保险 → 工伤 1101 → 9102**。

## 5. 正向流程

### 5.1 总览

```text
选工伤保险 → 工伤1101 → 9102
  → 确认挂号（预结算落就诊）
  → [有审批：绑定 qualification] / [无审批：2301→9102]
  → 确认缴费（须已有效备案）
  → 医生站（诊断；角标只读）
  → 收费(2201→2203→[2205?]→2204→2206→2207) → 发药(3505省医保)
```

### 5.2 挂号

| 步骤 | 动作 | 系统 |
|------|------|------|
| 1 | **费用性质=工伤保险**（可直接选，不必先省医保读卡） | `med_type` 默认 **12** |
| 2 | 科室、医生、号源；患者信息 | 同现网；工伤 1101 可回填姓名 |
| 3 | **工伤 1101 + 9102** 预查 | 有审批 → 展示；无审批 → 提示须备案后才能完成挂号 |
| 4 | 点「确认挂号」 | 预结算落就诊 → 本就诊 1101/9102；有审批则绑定 |
| 5 | 无有效审批 | **一键备案 2301→9102**；取消则**不能**打开确认缴费 |
| 6 | 确认缴费 | 须 `qualificationValid`；**不调 2201** |

**挂号费**：IF-REG-07 **一律自费**（现金/银联/自费账户），**禁止**工伤/省医保账户。

### 5.3 医生站

- **「工伤」角标**只读（已备案 / 未备案等，来自 HIS 锚点）
- **不提供 2301**；备案请在挂号窗口办理
- 医生电脑可不装工伤网 / OpenHIS.Win 工伤模块

### 5.4 门诊收费

**前置**：主诊断 + **有效 `qualification_id`**。

| 步骤 | infno |
|------|-------|
| 预结算 | 2201 → 2203 → **（有旧明细则 2205）** → 2204 → **2206** |
| 确认结算 | **2207** |

### 5.5 发药

2207 后正常发药；**3505** 走 **省医保契约**。
