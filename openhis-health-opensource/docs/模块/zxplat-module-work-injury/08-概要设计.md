## 1. 定位与边界

| 项 | 说明 |
|----|------|
| **方案码** | `InsuranceSchemeCode.WORK_INJURY` |
| **费用性质** | `ContractCategory.WORKER_INSURANCE` |
| **集成形态** | **可选 Extension Module** + **OpenHIS.Win 客户端 DLL 出站** |
| **与省医保关系** | 共用 **`yb_invoke_log` / `yb_settlement_record`** 及结算领域表模式；**不**用 `yb_coordination`（库中无表）；**不**共用 FSI HTTP |
| **默认** | `zxplat.modules.work-injury.enabled=false` — 未启用时行为与现网一致（见 [06](./06-扩展组件与隔离策略.md)） |

### 1.1 MVP 范围（P0）

挂号：省医保/工伤 **双次 1101**、9102 / 2301 → 门诊收费 2201→2203→(2205?)→2204→2206→2207 → 逆流程 2202/**2208（P0）** → 对账 **1320/1321/1322（均 P0）**。  
不含：住院 240x（文档预留）、工伤侧 350x（进销存仍走省医保）、2302、9102 院点联调前为 **风险项**。

### 1.2 不在本 Module 内

| 能力 | 归属 |
|------|------|
| `JLSiInterface.dll` 加载与 `Si_Busi` | **openhis-pro-win** `OpenHIS.Win.WorkInjury` |
| 3505 发药进销存 | **zxplat-module-chs-jilin** 省医保契约 |
| 省/市医保 220x HTTP | **zxplat-module-chs-jilin** `ChsHttpAccessor` |

### 2.2 配置

```yaml
openhis:
  modules:
    chs.enabled: true              # 省医保（独立）
    work-injury.enabled: false     # 工伤（默认关；仅此开关即可）
```

- **Win 地址**：与读卡/银联相同，前端固定 `http://127.0.0.1:5000`（`PluginSettings.Http旧命名（已废止）），**不入** Whale 配置。
- **收费 infno 顺序**：`2201→2203→(2205?)→2204→2206→2207` 写在 **`WorkInjurySettleStepPlanner` 代码常量** 中（2205 条件插入，见 [14](./14-院方确认决策.md) Q7），**不做** YAML 逐步配置。

`chs-contract.properties` 工伤段：**无** `bridge_url` / `call_service_url`（见 [03](./03-fin_contract映射示例.md)）。

### 2.3 Enforcer 规则

| 规则 | 说明 |
|------|------|
| `health-application` **禁止** import `com.zxplat.plugin.chs.application.workinjury.*` | 只调 Extension |
| `health-application` **禁止** import Win / native | 客户端 invoke |
| `wi-jilin-bridge` **禁止** 依赖 `ChsHttpAccessor` 做工伤交易 | scheme 隔离 |
| `wi-jilin-starter` `@ConditionalOnProperty(work-injury.enabled=true)` | 未启用不注册 Bean |

### 3.6 前端 API（health 入口 + chs 对账页）

**原则（v2.7）**：嵌入业务走 **health-application → Extension → chs FacadeImpl**；**不再**在 `chs-jilin-application/appservice/workinjury` 暴露 UI AppService。

| 前端前缀 | 挂载 AppService | 方法 | 说明 |
|----------|-----------------|------|------|
| `/api/app/workInjuryInvoke/*` | **health** `WorkInjuryInvokeAppService` | `prepareInvoke`, `submitInvokeResult` | Win 循环；经 `WorkInjuryInvokeExtension` |
| `/api/app/outpatientRegistration/getWorkInjuryCapability` | `OutpatientRegistrationAppService` | capability 门控 | 替代原 `workInjuryModule` |
| `/api/app/outpatientRegistration/bindWorkInjuryQualification` | 同上 | 9102 后绑定 qualification | 经 `WorkInjuryRegisterExtension` |
| `/api/app/outpatientCharge/preSettle` | `OutpatientChargeAppService` | 含 `workInjuryInvokeStep` | 经 `WorkInjuryOutpatientSettlementExtension.startSettleSession` |
| `/api/app/outpatientCharge/refreshWorkInjuryPreSettleAmounts` | 同上 | 2206 后刷新应付 | Extension 读预结算快照 |
| `/api/app/outpatientCharge/confirmSettle` | 同上 | 2207 后 HIS 落账 | Extension `confirmSettle` |
| `/api/app/outpatientRefund/listWorkInjurySettlementsByPayment` | `OutpatientRefundAppService` | 退费前查回执 | Extension |
| `/api/app/outpatientRefund/startWorkInjuryReverse` | 同上 | 2208 invoke 首步 | Extension |
| `/api/app/insuranceReconciliation/startWorkInjuryRecon` | **chs** `ChsReconciliationAppService` | 1320 invoke 首步 | 对账页 `/chs/reconciliation` 工伤 Tab |

**remote 模式**：health adapter 调 `WorkInjury*FacadeRemoteImpl` → chs `*FacadeAppService`（机机 HTTP，非 web-ele 直调）。

## 4. 调用链（客户端 invoke）

```text
┌─────────────── web-ele（业务窗口 PC）────────────────────────────┐
│  invokeWorkInjuryPlugin(step)  →  OpenHIS.Win :5000/api/work-injury/invoke
└────────────┬───────────────────────────────────────┬───────────────┘
             │ POST /api/app/workInjuryInvoke/*     │
             ▼                                        │
┌──────────────────────── Whale 8081 ────────────────────────────────┐
│ OutpatientRegistrationAppService / OutpatientChargeAppService      │
│ WorkInjuryInvokeAppService（Win 循环 prepare/submit）              │
│   → WorkInjury*Extension（chs-jilin-bridge）                     │
│   → WorkInjury*FacadeImpl（chs-jilin-application）                 │
│   → DomainService / yb_wi_* / yb_invoke_log                        │
│   ← PrepareWorkInjuryInvokeResult（待 Win 执行的 payload）          │
└────────────────────────────────────────────────────────────────────┘
```

**铁律**：Whale JVM **不** HTTP 调 DLL；`InsuranceGatewayClient` **不**新增 WORK_INJURY 实现。

## 5. Extension 接口摘要（评审用）

### 5.1 WorkInjuryModuleExtension

```java
public interface WorkInjuryModuleExtension {
    default boolean isEnabled() { return false; }
    default boolean supportsContract(Long contractId) { return false; }
    /** capability 下发前端：是否展示工伤入口 */
    default WorkInjuryCapability capability() { return WorkInjuryCapability.disabled(); }
}
```

### 5.2 WorkInjuryRegisterExtension

挂载：`OutpatientRegistrationAppService`（改费用性质、9102、锚点；挂号费 BR-WI-REG-001 **一律自费**）。

```java
boolean requiresWorkInjuryFlow(Long encounterId);
PrepareWorkInjuryInvokeResult start9102(WorkInjury9102Command cmd);
void onInvokeSubmitted(WorkInjuryInvokeSubmittedCommand cmd);  // submit 后写锚点
boolean assertRegistrationFeeSelfPay(Long encounterId);        // 恒 true（工伤挂号费自费）
```

### 5.3 WorkInjuryApprovalUploadExtension

挂载：挂号员 / 医生站 **2301 双入口**（BR-WI-REG-002）；2301 submit 后强制再 9102（BR-WI-APR-001）。

### 5.4 WorkInjuryOutpatientSettlementExtension

挂载：`OutpatientChargeAppService`（预结算/结算/2208）；**独立于** `OutpatientChargeInsuranceExtension`。

```java
default boolean supportsWorkInjuryAccount(Long contractId) { return false; }
void assertQualificationBeforePreSettle(Long encounterId);     // BR-WI-SET-001
PrepareWorkInjurySettleSessionResult startSettleSession(WorkInjurySettleCommand cmd);
PrepareWorkInjuryInvokeResult nextSettleStep(WorkInjurySettleStepCommand cmd);
void onSettleStepSubmitted(WorkInjurySettleStepSubmittedCommand cmd);
PrepareWorkInjuryInvokeResult startReverse(WorkInjuryReverseCommand cmd);  // 2208 P0
```

### 5.5 WorkInjuryReconciliationExtension

挂载：医保办；1320 / **1321** / 1322（均 P0）。

### 5.6 WorkInjuryEncounterContextExtension

挂载：医生站/收费列表 API；未启用返回空。

## 7. health-application 挂接点

| AppService | 改造 |
|------------|------|
| `OutpatientRegistrationAppService` | 改费用性质=工伤 → 调 `WorkInjuryRegisterExtension`；挂号费支付前 `assertRegistrationFeeSelfPay` |
| `OutpatientChargeAppService` | 账户为 `WORKER_INSURANCE` → 走 `WorkInjuryOutpatientSettlementExtension`，**不走** `OutpatientChargeInsuranceExtension` |
| `OutpatientRefundAppService` | 工伤 **2208** 逆流程（P0） |
| `OutpatientInsuranceChargeGrouper` | 增加 `WORKER_INSURANCE` 分组 → 工伤 Extension |

**不改**：纯省医保/自费路径；`InventoryThirdPartyUploadExtension`（仍省医保）。
