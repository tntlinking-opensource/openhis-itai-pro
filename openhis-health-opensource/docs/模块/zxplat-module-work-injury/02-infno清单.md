## 2. 门诊 MVP 交易链（Whale 产品链 v0.3）

> **产品真源**：[05-用户操作说明.md](./05-用户操作说明.md) · [14-院方确认决策.md](./14-院方确认决策.md) · [06-扩展组件与隔离策略.md](./06-扩展组件与隔离策略.md)  
> **NEUSI 对照**：老系统 **9102=0**，多在挂号直接 **2301**；Whale：**双次 1101、9102 在挂号 → 2301 双入口 → 2301 后必 9102 → 挂号费一律自费 → 无 qualification_id 阻断 2206 → 首笔可跳过 2205**。

### 2.1 挂号

```text
读医保卡/码 → 省医保 1101（未改费用性质前）
改费用性质=工伤保险 → 工伤 1101 → UI 展示认定结论
    ↓
9102 审批/待遇查询
    ├─ 有审批 → 用户选择 qualification_id → HIS 挂号（不调 2201）
    └─ 无审批 → 允许挂号；挂号费 **一律自费**（BR-WI-REG-001）
                → 可选 2301（挂号员/医生站）→ 再 9102（BR-WI-APR-001）
```

### 2.2 2301（9102 无有效审批时）

```text
2301 审批信息上传（挂号员 或 医生站，用户自选 BR-WI-REG-002）
    ↓
9102 刷新 qualification_id（强制，BR-WI-APR-001）
```

### 2.3 门诊收费

```text
前置：有效 qualification_id（否则阻断 2206，BR-WI-SET-001）
2201 → 2203 → （有历史 2204 则 2205）→ 2204 → 2206 → 2207
```

### 2.4 逆流程

```text
未 2201：HIS 退号即可（不调 2302，BR-WI-REV-001）
已 2201 未 2207：2202
已 2207：2208 → 2205（按需）→ HIS 退费
```

### 与省医保门诊链差异摘要

| 步骤 | 省医保（CHS） | 工伤（WORK_INJURY） |
|------|---------------|---------------------|
| 身份 | 1101 → `psn_no`、`insuplc_admdvs` | 1101 → `qualification_id`、认定诊断 |
| 审批 | （无 2301） | **9102 查询** + **2301 上传**（无审批兜底） |
| 登记 | 2201/2203，`mdtrt_id` | 2201，`ipt_otp_no` |
| 明细 | 2204（常无前置 2205） | **2205 → 2204** |
| 结算 | 2206→2207，HTTP | 2206→2207，DLL |
| 冲正 | 2601 | **2209**（院点未用） |
| 对账 | 3201 / 3203A | **1320 → 1322**（院点未用 1321/1323） |

## 3. 编排阶段映射（非协同单）

工伤 **不**使用 `yb_coordination`。按 [11-客户端invoke会话](./11-客户端invoke会话-详细设计.md) 的 `phase` 与 infno 链：

| phase | infno 步骤 | 说明 |
|-------|------------|------|
| `REG_QUERY` | 9102 | 挂号审批查询 |
| `REG_APPROVAL` | 2301 → 9102 | 无审批兜底 |
| `OP_SETTLE` | 2201 → … → 2207 | 门诊结算 |
| `OP_REVERSE` | 2208 → … | P0 退费 |
| `WI_RECON` | 1320 → **1321** → 1322 | 对账 |

## 4. 不复用省医保 DLL 的能力

| 省医保 infno | 原因 |
|-------------|------|
| 130x 目录下载 | 工伤手册无对应 |
| 3301/3302 目录对照 | 工伤 DLL 无；仍用省医保对码 |
| 3201/3203A 对账清算 | 工伤走 1320/1322 |
| `ChsSmCryptoService` | 工伤无国密 HTTP |
| FSI `call_service_url` | 纯 DLL |

| 项 | 说明 |
