## 3. 挂号流程

### 3.1 读卡（Q4）

```text
读医保卡 → 省医保 1101（ChsHttp / OpenHIS.Win.Chs）
改费用性质=WORKER_INSURANCE
再读/确认 → 工伤 1101（OpenHIS.Win.WorkInjury invoke）
UI 展示 diagnosis[]、injureAffirmID
→ 9102
```

### 3.2 9102 / 2301

- `WorkInjuryRegisterExtension.start9102` → `prepareInvoke(REG_QUERY)`
- `WorkInjuryApprovalUploadExtension.upload2301` → `prepareInvoke(REG_APPROVAL)` → submit → **再 9102**
- `WorkInjuryRegisterExtension.bindQualification`

### 3.3 挂号费

`assertRegistrationFeeSelfPay(encounterId)` **恒 true**（工伤就诊挂号费不走医保账户）。

---

## 4. 门诊收费

### 4.1 分组

`WORKER_INSURANCE` → `WorkInjuryOutpatientSettlementExtension`；**不**进入 `OutpatientChargeInsuranceExtension`。

### 4.2 预结算

```text
assertQualificationBeforePreSettle
startSettleSession → invoke session phase=OP_SETTLE
循环 prepare → Win → submit 至 2206
```

### 4.3 2207 与落账

2207 Win+submit 成功 → `settleOutpatientPayment` → `yb_settlement_record`（`scheme=WORK_INJURY`）。

### 4.4 退费（P0）

2208 →（2205 按需）→ HIS 退费；见 [05](./05-用户操作说明.md) §6。

## 5. 数据模型

### 5.1 yb_wi_encounter_anchor

| 列 | 说明 |
|----|------|
| `encounter_id` | UK |
| `psn_no` | 工伤 1101 |
| `qualification_id` | 9102 所选 |
| `qualification_status` | NONE / PENDING_9102 / VALID |
| `ipt_otp_no` | **= HIS 就诊/挂号流水号**（Q6） |
| `injure_affirm_id` | 1101 |
| `adm_diag_code` | 主诊断 ICD |
| `med_type` | 默认 12 |
| `platform_registered` | 2201 成功 |
| `setl_id` | 2207 |

Flyway：`V{wi}_001__yb_wi_encounter_anchor.sql`

### 5.2 yb_wi_invoke_session（P0 必建）

见 [11](./11-客户端invoke会话-详细设计.md) §4.1。Flyway：`V{wi}_002__yb_wi_invoke_session.sql`

### 5.3 yb_wi_pre_settle

对齐 `yb_clinic_pre_settle`；2206 报价。Flyway：`V{wi}_003__yb_wi_pre_settle.sql`

### 5.4 ipt_otp_no

**直接采用 HIS encounter 流水号**（或挂号号，与 encounter 1:1）；不再单独生成算法。
