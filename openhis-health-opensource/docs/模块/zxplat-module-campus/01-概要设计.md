## 1. 定位与边界

**zxplat-module-campus** 是面向 **高校附属/校内医院** 的可选增值 Module，维护 **校务组织**（N 校区 / 学院 / 部门）、**学生/教职工档案**（含变更记录）、**公费医疗** 真源；与 health 患者主档、Peis 体检、CHS 医保、银联 BPC **解耦**。

| 在 Campus | 不在 Campus |
|-----------|-------------|
| 校区 / 学院 / 部门 | HIS 临床科室 `sys_dept` |
| 学生 / 教职工资质档案 | 患者主档建档（health `Patient`） |
| 公费比例、审批、拆分 | 医保结算（`zxplat-module-chs-jilin`） |
| 多校区档案同步（可选） | 体检业务流水（Peis，**读** Campus Client） |

**挂接**：Peis `GRP-01`、health 收银读 `campus-contracts` Reader；Campus **不**重复 `peis_company_college`。

## 2. 总体架构

```text
zxplat-module-campus/
  campus-contracts/      CampusOrgQueryReader、PublicExpenseCalcReader
  campus-domain/         CampusSite、CampusCollege、PatientStaff、GfRatio
  campus-application/    AS-CMP-ORG-*、STU-*、STF-*、GF-*
  campus-adapter/        nenu Open API、遗留 his_gf_* 迁移
  campus-starter/

Peis / health 收银 ──读 Reader──► campus-contracts
```

## 3. 领域模型概览

| 聚合 / 表 | 职责 |
|-----------|------|
| `CampusSite`（`cmp_campus_site`） | 多校区 |
| `CampusCollege`（`cmp_campus_college`） | 学院/部 |
| `CampusDepartment`（`cmp_campus_department`） | 教职工单位 |
| `PatientStudent`（`cmp_patient_student`） | 学生学籍（Campus 真源） |
| `PatientStaff`（`cmp_patient_staff`） | 教职工工号/医疗证 |
| `PublicExpenseProfile` / `GfFreePercent` | 公费资格与比例 |
| `CampusArchiveChangeLog` | 字段级变更 |
| `CampusArchiveTransfer` | 转院 / 调岗时间线 |

详见 [00-功能清单 §1.3](./00-功能清单.md) · 字段真源：[DomainModel/](./DomainModel/) · 表结构：[06-Flyway-表结构.md](./06-Flyway-表结构.md)。

## 4. 与 Peis / health 衔接

```text
Campus（真源）
  listActiveColleges / resolveStudentCampus
        ↓ Client
PeisAppService
  GRP-01 单位学院 → 读 Campus
  BAS-02/03 名册   → 读 Campus 档案
health 收银
  CampusChargeCalcReader → 公费拆分（INT-03）
```

## 5. 配置与装配

```yaml
zxplat:
  modules:
    campus:
      enabled: true
      profile: nenu    # 示例：BENBU/JINGYUE
      sync:
        enabled: false   # ≥2 节点时可 true
```

| 项 | 值 |
|----|-----|
| Profile | `-Pwith-campus`（规划） |
| Host | `health-app` + `campus-starter` |

非高校院点默认 `enabled=false`。
