## 4. 典型用户流程

### 4.1 公费比例审批（P0 · 双模式 · 自建审批）

比例类型二选一（与收银路径一致；[ADR-CMP-001](./ADR-CMP-001-成码前决策.md)）：

| 模式 | 含义 | 收银 |
|------|------|------|
| `SELF_PAY_GF` | 自费公费比例 | CHG-01 |
| `AFTER_YB_GF` | 医保后公费比例 | CHG-02 |

```text
收费员发起申请（必选模式）→ 待办（可按模式 Tab 筛）
  → 通过 → 回写同模式项目比例 → 申请记录
  →（D）收银员选 gfChargeMode → preview → 支付明细两行
```

UI：`/campus/gf/todo`、`/record`、目录/项目比例页均带「自费公费 | 医保后公费」Tab。  
审批：**状态机**，不接 Flowable。

挂号开户（需 Campus）：有学生档案 → 开 `PUBLIC_EXPENSE_ACCOUNT`；教职工收费时再处理。

### 4.2 学生档案维护 / 转院（P0）

```text
学院/学籍维护 → CampusStudentAppService
  → 变更写入 CampusArchiveChangeLog
  → Peis 登记读 Reader

正式转院 → transferStudent（生效日、原因、目标校区/学院）
  → cmp_archive_transfer + ChangeLog
  → 详情 Tab「调动记录」pageStudentTransfers 查看时间线
```

### 4.3 教职工调岗（P0）

```text
正式调岗 → transferStaff（目标部门/校区、生效日、原因）
  → cmp_archive_transfer + ChangeLog
  → 详情 Tab「调动记录」pageStaffTransfers 查看时间线
```
