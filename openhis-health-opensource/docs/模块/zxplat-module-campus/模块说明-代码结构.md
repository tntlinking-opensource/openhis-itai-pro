# ZXPlat Campus

ZXPlat Campus（校医院增值）是基于 ZXPlat 框架的**可插拔高校校务扩展包**。

> **模块状态**：`zxplat-plugin/zxplat-module-campus`（Batch A 组织底座已落地）  
> **成码门禁**：[07-成码前Checklist.md](./07-成码前Checklist.md) · [ADR-CMP-001](./ADR-CMP-001-成码前决策.md)  
> **结构**：对齐模块代码规范 v3（**无** `*-contracts`；`CampusOrgQueryReader` 落 `module-campus-domain`）

---

## 模块结构

```text
zxplat-module-campus/
├── pom.xml
├── module-campus-domain/       # org 聚合 + CampusOrgQueryReader 接口
├── module-campus-bridge/       # Batch A 占位；D 迭代挂 health SPI/挂号开户
├── module-campus-application/  # AS-CMP-ORG-* + ReaderImpl + ModularFlyway
└── module-campus-starter/      # health-app -Pwith-campus

zxplat-app/
  -Pwith-campus → module-campus-starter
```

### Java 包

| 层 | 包根 |
|----|------|
| domain | `com.zxplat.plugin.campus.domain.*` |
| application | `com.zxplat.plugin.campus.application.*` |
| bridge | `com.zxplat.plugin.campus.bridge.*` |

---

## 挂接要点

| 项 | 说明 |
|----|------|
| 读侧 | Peis / 收银注入 `CampusOrgQueryReader`（domain 接口，application 实现） |
| 配置 | `zxplat.modules.campus.enabled=true` · Maven：`-Pwith-campus` |
| Flyway | `db/migration/campus` · `flyway_schema_history_campus` |
| 种子 | V2：`BENBU`（自由/主）、`JINGYUE`（净月），`tenant_id=1` |

### AppService 路由

- `POST /api/app/campusSite/{method}`
- `POST /api/app/campusCollege/{method}`
- `POST /api/app/campusDepartment/{method}`
