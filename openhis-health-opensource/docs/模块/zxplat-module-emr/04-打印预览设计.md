# ZXPlat EMR 打印预览设计

> 依据《[概要设计](01-概要设计.md)》《[详细设计](03-详细设计.md)》《[UI交互说明](02-交互说明.md)》编制，规定 **OpenPDF 后端渲染** 下的预览能力边界：可渲染内容、可配置项、双层预览架构与接口契约。技术栈：**Tiptap（emrEditor）+ Java（zxplat-framework）+ OpenPDF**。

---

## 一、文档目的与范围

### 1.1 目的

- 明确「打印预览」与「正式打印/归档 PDF」共用 **同一套 OpenPdfRenderer**，保证预览即所得。
- 规定 OpenPDF **能渲染什么**（按节点类型与阶段）、**不能渲染什么**（裁剪与降级策略）。
- 规定用户/管理员 **能设置什么**（纸张、页边距、页眉页脚、水印、范围等）及配置存储与优先级。
- 约定前端 **何时请求预览**、如何避免每次按键调用服务端。

### 1.2 范围

| 在内 | 在外 |
|------|------|
| 文书/模板编辑时的 PDF 预览、正式打印、导出 PDF | 浏览器 `window.print()` 直接打印编辑器 DOM（不作为正式输出） |
| OpenPDF 渲染规则、PrintConfig 配置模型 | Hiprint / Jasper / Grid++ 等独立模板引擎 |
| 预览模式（previewMode）与正式模式（printMode）参数差异 | OFD 输出、静默打印客户端（仅消费 PDF 流，不在本文展开） |
| 编辑区 L1 即时版式预览与 L2 权威 PDF 预览的分工 | 打印机驱动、纸盒、双面等硬件控制 |

### 1.3 核心原则

| 原则 | 说明 |
|------|------|
| **单一渲染器** | 预览与正式打印均调用 `OpenPdfRenderer`，禁止预览走 CSS、打印走 OpenPDF 的双轨方案。 |
| **单一 JSON 语义** | 前端 Tiptap、服务端 `DocumentStructureParser`、`OpenPdfRenderer` 共用节点 type 与 attrs 约定（见 §三、§五）。 |
| **双层预览** | L1：emrEditor A4 纸面即时反馈；L2：OpenPDF 防抖/按需权威预览。 |
| **mm/pt 为打印真源** | 页边距、纸张、页眉页脚高度在 PrintConfig 中以 **毫米（mm）** 存储；OpenPDF 内部换算为 pt。 |
| **预览可轻、打印须全** | `previewMode=true` 时可跳过审计、简化水印、限制页数；正式打印必须完整参数并记审计。 |

## 二、双层预览架构

### 2.1 总体结构

```
┌─────────────────────────────────────────────────────────────────────────┐
│  L1 即时层（前端 emrEditor）                                              │
│  - A4 纸面（210mm × 297mm）、页边距 CSS 变量、分页符占位                    │
│  - 字体/行距/段间距/首行缩进（编辑体验）                                   │
│  - 不请求服务端；每次 onUpdate 即时刷新                                    │
└───────────────────────────────┬─────────────────────────────────────────┘
                                │ 同一 content JSON
┌───────────────────────────────▼─────────────────────────────────────────┐
│  L2 权威层（服务端 OpenPDF）                                              │
│  - POST /api/app/pdf/generate（previewMode=true|false）                  │
│  - OpenPdfRenderer：content JSON + PrintConfig → PDF 字节流               │
│  - 前端 iframe / pdf.js / blob URL 展示；正式打印前以此为准                 │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.2 何时触发 L2 预览

| 触发方式 | 说明 | 推荐 |
|----------|------|------|
| **手动刷新** | 用户点击「刷新预览」 | ✅ MVP 必选 |
| **防抖自动刷新** | 停手后 debounce（建议 **1200ms**，maxWait **3000ms**） | ✅ v2 推荐 |
| **打开预览面板** | 首次展开右侧预览栏时立即请求一次 | ✅ 推荐 |
| **正式打印/导出前** | 强制刷新一次最新 PDF，忽略缓存 | ✅ 必选 |
| **每次按键** | 每字符触发 generatePdf | ❌ 禁止 |

**并发控制**：新请求发出前 **AbortController 取消** 上一次未完成的预览请求；服务端可对相同 contentHash 短 TTL 缓存（建议 5～10 分钟）。

### 2.3 L1 与 L2 的一致性说明

| 项 | L1（编辑器） | L2（OpenPDF） | 对齐要求 |
|----|--------------|---------------|----------|
| 正文、数据元取值 | 即时展示 | 权威输出 | 同一 content JSON |
| 字体 | 系统字体 fallback | 嵌入 .ttf（宋体/仿宋等） | PrintConfig.fontFamily 与嵌入字体一致 |
| 自动分页 | CSS 流式排版 | 渲染器计算高度换页 | 长文档允许 L1/L2 页数略有差异；以 L2 为准 |
| 分页符 | `pageBreak` 占位 | 强制 `newPage()` | 必须一致 |
| 页眉页脚/总页数 | L1 一般不绘制 | OpenPDF `PdfPageEventHelper` | 仅 L2 展示 |
| 水印 | L1 可选半透明 overlay | OpenPDF 绘制 | 正式打印仅 L2 |

## 三、可渲染内容（OpenPDF 能力矩阵）

以下为 `OpenPdfRenderer` 对 ProseMirror/Tiptap JSON 节点的支持约定。**阶段**与《详细设计》§八 实现阶段对齐。

### 3.1 文档结构与结构化节点

| 节点 type | 说明 | 渲染方式 | 阶段 | 备注 |
|-----------|------|----------|------|------|
| `doc` | 根节点 | 遍历 `content` | MVP | — |
| `region` | 区域块 | 标题（attrs.title）+ 子树 | MVP | `participatePrint=false` 时跳过 |
| `section` | 数据组 | 可选小标题 + 子树 | MVP | 支持嵌套 |
| `dataElement` | 数据元 | 按 attrs.type 渲染 value | MVP | 空 value 渲染占位或空白 |
| `pageBreak` | 分页符 | `document.newPage()` | MVP | 与编辑器分页符语义一致 |

**数据元 attrs.type 渲染规则：**

| type | 渲染 | 阶段 |
|------|------|------|
| `text` / 缺省 | 文本；尊重 maxLength 截断展示 | MVP |
| `number` | 数值字符串 | MVP |
| `date` / `datetime` | 按 PrintConfig.dateFormat 格式化 | MVP |
| `select` / `multiSelect` | 选中项 label；多选用分隔符连接 | v1 |
| `checkbox` | ☑/☐ 或「是/否」 | v1 |

**过滤规则（渲染前）：**

- `attrs.deleted=true`（逻辑删除）：默认不渲染；PrintConfig.showDeletedNodes=true 时灰显。
- `attrs.participatePrint=false`：不渲染该节点及其子树。
- `regionNames` 非空：仅渲染 name 匹配的 region 子树（见 §4.4）。

### 3.2 富文本与排版（marks + 块属性）

| 内容 | JSON 来源 | 渲染 | 阶段 |
|------|-----------|------|------|
| `paragraph` | Tiptap 内置 | 流式段落；块 attrs：`lineHeight`、`textIndent`、`paragraphMarginTop/Bottom` 由 `EmrContentJsonRenderer.applyBlockLayoutAttrs` 回放 | MVP |
| `heading` | Tiptap 内置 | 按 level 映射字号/加粗 | MVP |
| `text` + marks | 加粗/斜体/下划线/删除线/字体/字号/颜色 | OpenPDF Font 样式组合；`textStyle.fontSize`（pt/em/mm 等）经 `PdfUnitUtils.parseCssLengthToPt` 回放 | MVP～v1 |
| `bulletList` / `orderedList` | Tiptap 内置 | 列表符号/编号 + 缩进 | v1 |
| `blockquote` | Tiptap 内置 | 左缩进 + 可选边框 | v2 |

**marks 支持矩阵（阶段）：**

| mark | MVP | v1 | v2 |
|------|-----|----|----|
| bold | ✔ | | |
| italic | ✔ | | |
| underline | | ✔ | |
| strike / deletion（留痕） | | ✔ | |
| highlight / insertion（留痕） | | | ✔ |
| textStyle（fontSize、fontFamily、color） | ✔ 部分 | ✔ 全量 | |

### 3.3 表格、图片与嵌入

| 节点 type | 渲染 | 阶段 | 备注 |
|-----------|------|------|------|
| `table` / `tableRow` / `tableCell` | `PdfPTable`；splitRows 跨页 | v1 | 单元格内仅文本 MVP；嵌套块 v2 |
| `image` | `Image.getInstance`；attrs.src 为 URL 或 base64 | v1 | 预览模式可降 DPI |
| `horizontalRule` / `emrHorizontalDashed` | 直线/虚线 | v2 | — |
| `hardBreak` | 换行 | MVP | — |
| `link` | 文本 + 可选下划线；URL 不强制可点击 | v2 | PDF 内链接可选 |

### 3.4 元数据与固定域（与现有 emrEditor 对齐）

| 节点 type | 说明 | 渲染 | 阶段 |
|-----------|------|------|------|
| `emrMetadataChip` | 患者元数据（姓名、性别等） | 渲染 attrs.value 或绑定 fieldKey 解析值 | MVP |
| `emrFixedText` | 模板固定字 | 渲染固定文案 | MVP |
| `emrFreeText` | 自由文本区 | 同 paragraph | MVP |
| `emrTextField` / `emrSelectField` / `emrCheckboxField` | 行内字段 | 按 attrs 映射为 dataElement 渲染 | v1 |

> **约定**：目标 Schema 为 `region` / `section` / `dataElement`；现有 `SimpleEditor` 节点在渲染器中注册 **别名映射**，统一归入 §3.1～3.4 处理逻辑。

### 3.5 明确不渲染或暂不支持

| 项 | 策略 |
|----|------|
| 视频/音频节点 | 跳过或渲染占位「[媒体]」 |
| 交互控件（按钮、下拉 UI chrome） | 仅渲染 value/选中项 |
| Vue 图表组件（体温单、产程图） | v2+：打印时提交 snapshot 图片 attrs；无图则占位 |
| 批注/签章（未落库为 content 节点） | 不渲染；签章 v2 以 image 节点或 overlay 配置 |
| 浏览器私有 CSS（阴影、动画） | 忽略 |

### 3.6 留痕打印（includeTrackChanges）

| 模式 | 行为 |
|------|------|
| `includeTrackChanges=false`（默认） | 忽略 deletion mark 文本；insertion 正常输出 |
| `includeTrackChanges=true` | deletion：删除线；insertion：高亮或下划线；与 §3.2 marks 矩阵一致 |

## 四、可配置项（PrintConfig）

### 4.1 配置模型

打印版式与「文档 content」分离：**content 管写什么，PrintConfig 管怎么纸面呈现**。

```json
{
  "paper": {
    "widthMm": 210,
    "heightMm": 297,
    "orientation": "portrait"
  },
  "margins": {
    "topMm": 25.4,
    "rightMm": 31.8,
    "bottomMm": 25.4,
    "leftMm": 31.8
  },
  "header": {
    "enabled": true,
    "heightMm": 15,
    "template": "{orgName}  {documentTypeName}",
    "firstPageDifferent": false
  },
  "footer": {
    "enabled": true,
    "heightMm": 12,
    "template": "第 {page} 页 / 共 {total} 页",
    "showPageNumber": true
  },
  "watermark": {
    "enabled": false,
    "text": "机密",
    "opacity": 0.15,
    "angle": 45,
    "fontSizePt": 48
  },
  "font": {
    "family": "SimSun",
    "defaultSizePt": 12,
    "titleSizePt": 16,
    "lineHeight": 1.5
  },
  "dateFormat": "yyyy-MM-dd",
  "datetimeFormat": "yyyy-MM-dd HH:mm",
  "showDeletedNodes": false,
  "blankPagePolicy": "hide"
}
```

**页眉页脚模板占位符：**

| 占位符 | 含义 |
|--------|------|
| `{page}` | 当前页码 |
| `{total}` | 总页数 |
| `{patientName}` `{gender}` `{age}` | 患者信息（来自请求上下文） |
| `{documentTitle}` `{documentTypeName}` | 文书标题/类型 |
| `{orgName}` `{deptName}` | 机构/科室 |
| `{printTime}` | 打印时间 |

### 4.2 配置来源与优先级

合并顺序（后者覆盖前者）：

1. **系统默认**（内置 default PrintConfig，A4 + 国标页边距）
2. **文书类型** `emr_document_type.print_config`（JSONB，可选列）
3. **模板** `emr_template.print_config`（JSONB，可选列）
4. **请求体** `GeneratePdfRequest.printConfig`（单次覆盖）
5. **请求体** 快捷字段：`watermark`、`headerTemplate`、`footerTemplate`、`pageRange` 等

**前端 emrEditor 页边距**（`pageMargins` CSS）在 **L1** 使用；发起 L2 预览/打印时，应将同一套边距 **同步写入 printConfig.margins**（mm），避免两套不一致。

### 4.3 用户可设置的 UI 项

| 设置项 | 配置路径 | 可在 UI 调整 | 默认级别 |
|--------|----------|--------------|----------|
| 纸张大小 | paper.* | 模板管理 / 打印选项弹窗 | 模板 |
| 纸张方向 | paper.orientation | 打印选项弹窗 | 请求 |
| 页边距 | margins.* | 编辑器工具栏 + 打印选项 | 模板 + 请求 |
| 页眉启用/内容 | header.* | 模板管理 | 模板 |
| 页脚启用/页码 | footer.* | 模板管理 | 模板 |
| 水印 | watermark.* | 打印选项；正式归档可强制开启 | 文书类型 + 请求 |
| 正文字体/字号 | font.* | 模板管理 | 模板 |
| 页范围 | pageRange | 打印选项 | 仅请求 |
| 按区域打印 | regionNames | 打印选项（结构树多选） | 仅请求 |
| 留痕打印 | includeTrackChanges | 打印选项 | 仅请求 |
| 预览页数上限 | previewMaxPages | 仅 previewMode 生效 | 系统 |

**权限：**

- 模板/文书类型级 PrintConfig：需「模板管理」权限。
- 单次打印选项：需「打印」权限；水印/留痕可否关闭由文书类型策略约束。

### 4.4 范围与续打参数

| 参数 | 格式 | 说明 |
|------|------|------|
| pageRange | `"all"` \| `"1-3"` \| `"fromPage:5"` | 仅输出指定页；续打用 fromPage |
| regionNames | `["主诉","现病史"]` | 仅渲染这些数据项名的 region 子树；空=全文 |
| includeTrackChanges | boolean | §3.6 |

## 五、接口契约

### 5.1 GeneratePdfRequest（扩展）

在《详细设计》§3.3 基础上增加：

| 字段 | 类型 | 说明 |
|------|------|------|
| previewMode | Boolean | true=预览：不写打印审计、可限页、可跳过部分水印策略；false=正式打印/导出 |
| printConfig | Object | PrintConfig JSON；见 §4.1 |
| contentHash | String | 可选，客户端计算的 content+config 哈希，供服务端缓存键 |
| previewMaxPages | Integer | previewMode 时最多渲染页数，默认 20 |
| patientId / encounterId | Long/String | 解析页眉页脚占位符 |
| metadata | Map\<String,String\> | 患者/文书元数据，补全占位符 |

**返回 `PdfGenerateResultDto`（扩展）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| pdfBase64 / url | — | 与现方案一致 |
| pageCount | Integer | 总页数 |
| contentHash | String | 服务端确认的内容哈希 |
| renderedAt | DateTime | 生成时间 |
| previewTruncated | Boolean | 是否因 previewMaxPages 截断 |

### 5.2 与 initEmrPage 联动

`InitEmrPageResponse.printOptions` 返回当前用户可用的：

- 默认 PrintConfig（合并后）
- 可选纸张/水印/留痕策略
- 是否启用「自动预览」功能开关

## 六、前端预览 UI 约定

与《UI交互说明》§2.5、§3.5 对齐并扩展。

### 6.1 布局模式

| 模式 | 说明 |
|------|------|
| **全屏预览** | 新标签打开 PDF（MVP） |
| **分栏预览** | 左编辑 + 右 iframe PDF（v2 推荐） |
| **打印选项抽屉** | 页范围、区域、留痕、水印；确认后生成 |

### 6.2 状态与提示

| 状态 | UI |
|------|-----|
| 生成中 | 预览区 loading；禁用重复提交 |
| 成功 | 展示 PDF；标记「预览同步于 HH:mm:ss」 |
| content 已变更且预览过期 | 提示「内容已修改，点击刷新预览」 |
| 失败 | Toast + 原因；保留上次成功预览（可选） |
| previewTruncated | 提示「仅预览前 N 页，正式打印查看全文」 |

### 6.3 正式打印流程

1. 若有未保存变更：提示保存（可选强制）。
2. `previewMode=false` 调用 generatePdf。
3. 返回 PDF 后：`usePdfPrint` 或下载；写打印审计、累加 printCount（若业务需要）。

## 七、服务端实现要点

| 类/模块 | 职责 |
|---------|------|
| `PrintConfigResolver` | 合并 §4.2 各级配置 |
| `OpenPdfRenderer` | content + PrintConfig → PDF；§三 节点矩阵 |
| `DocumentStructureParser` | 渲染前过滤 regionNames；估算块→页号 |
| `PdfPreviewCache`（可选） | contentHash + configHash → PDF 字节，TTL 5～10min |
| `PdfAppService.generate` | 区分 previewMode；正式模式写审计 |

**字体**：将 `SimSun.ttf` 放入 `module-emr-application/src/main/resources/emr/fonts/`（见 `EmrPdfFontFactory`），OpenPDF `BaseFont.createFont` 嵌入。

## 八、实现阶段

| 阶段 | 预览能力 | 配置能力 |
|------|----------|----------|
| **MVP** | 手动「打印预览」；新标签 PDF；paragraph/heading/数据元/分页符/region | 默认 A4 边距；请求 watermark |
| **v1** | 分栏预览 + 1.2s 防抖；表格/图片；select/checkbox | printConfig 入参；模板 print_config 列 |
| **v2** | 缓存；previewMaxPages；区域/页范围 | 文书类型 print_config；页眉页脚模板 UI |
| **v3** | 留痕打印；图表 snapshot | 机构级默认配置；打印策略（强制水印） |
