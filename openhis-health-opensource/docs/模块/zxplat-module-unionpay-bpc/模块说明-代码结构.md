# zxplat-module-unionpay-bpc · 代码结构

> **代码**：`zxplat-plugin/zxplat-module-unionpay-bpc/`  
> **BOM**：`zxplat.unionpay.bpc.version`  
> **层序例外**：先 `module-bpc-gateway`，再 `module-bpc-domain`

## 子模块与 Java 包

| Maven 模块 | Java 根包 | 职责 |
|------------|-----------|------|
| `module-bpc-gateway` | `com.zxplat.plugin.unionpay.bpc.gateway` | BPC 出站 / 契约配置 |
| `module-bpc-domain` | `….domain`（依赖 gateway） | 订单 / 扫码 / 退款领域 |
| `module-bpc-bridge` | `….bridge` + `….bridge.integration.payment` | ThirdPartyPaymentExtensionImpl |
| `module-bpc-application` | `….application` | AppService / Flyway |
| `module-bpc-starter` | （依赖聚合） | embedded 安装入口 |

## Enforcer 互禁

| 模块 | 禁止依赖 |
|------|----------|
| bridge | `module-bpc-application` |
| application | `module-bpc-bridge` |

ArchTest：`UnionPayBpcBridgeArchitectureTest` / `UnionPayBpcApplicationArchitectureTest`

## 开关

```properties
zxplat.modules.unionpay-bpc.enabled=true
```
