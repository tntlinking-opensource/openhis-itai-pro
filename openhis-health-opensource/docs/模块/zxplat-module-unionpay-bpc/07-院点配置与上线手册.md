## 2. 配置模板

### 2.1 application.yml（L0 · Whale）

```yaml
openhis:
  modules:
    unionpay-bpc:
      enabled: true
```

### 2.2 unionpay-bpc-contract.properties（L1 · Whale 落账）

```properties
contract.H22010402403.enabled=true
contract.H22010402403.transport=openhis-win
contract.H22010402403.mid=8982201806298BG
contract.H22010402403.tid=01216450
contract.H22010402403.pos_no=01216450
contract.H22010402403.mer_trade_no_rule=PAYMENT_INDEX_TS
contract.H22010402403.query_timeout_sec=300
contract.H22010402403.poll_interval_ms=2000
```

**通道 C 不需要** `request_url`、`md5_secret`（属通道 A）。

### 2.3 native/unionpay/nopos/B2Cpos.ini（L1 · DLL）

自现网 `UnionPayPlugin/nopos/B2Cpos.ini` 拷贝；含 mid、tid、APPID/APPKEY、银联云 URL。  
**禁止**将 APPKEY 提交 Git；生产用实施包分发。

### 2.4 外挂

| 方式 | 说明 |
| --- | --- |
| JVM | `-Dunionpay.bpc.contract.config.path=...` |
| 环境变量 | `UNIONPAY_BPC_CONTRACT_CONFIG_PATH` |

## 3. 上线步骤

```text
1. 收银 PC：安装/升级 OpenHIS.Win（含 unionpay native）→ 验证 /api/hello unionpay
2. 收银 PC：卸载 UnionPayPlugin 自启
3. 服务器：部署 Whale + unionpay-bpc-starter；transport=openhis-win
4. 试点：单窗口被扫 + 退清（收+退）
5. 全量：挂号+门诊+住院扫码
6. P1：财务订单查询页
```

## 4. 半成功补偿（P0）

| 现象 | 处理 |
| --- | --- |
| Win/DLL 已成功、HIS 未 SUCCESS | 查 `upc_bpc_order` SUCCESS + payment DRAFT |
| 收费员 | **补结算**（重传完整 `clientScanResult`，见 [03 §3.12](./03-详细设计与编码指导.md#312-半成功补偿-dto定稿-2026-06-23)） |
| 禁止 | 勿对同一 merTradeNo 重复 consumer-scan |

## 5. 通道选型

| 院点情况 | 选型 |
| --- | --- |
| **仅 MIS DLL 签约（朝阳 P0）** | **OpenHIS.Win 通道 C** + zxplat-module-unionpay-bpc 落账 |
| 将来开通 BPC HTTPS | 增 `transport=bpc-https` + request_url/md5_secret（通道 A） |
| legacy UnionPayPlugin | **退役** |
| 中行 Comlink | **`zxplat-module-boc-pay`**（与 unionpay-bpc **互斥**）；见 [zxplat-module-boc-pay/](../zxplat-module-boc-pay/README.md) |

## 6. 常见问题

| 现象 | 排查 |
| --- | --- |
| 无「扫码支付」 | Whale enabled + OpenHIS.Win 未启动 |
| Win 报 native 错误 | `verify-native.ps1`；x86；nopos 路径 |
| 被扫成功未 settle | clientScanResult 是否传入；Extension 日志 |
| 19994 仍被占用 | 旧 UnionPayPlugin 未卸载 |

---

## 7. 回滚

| 步骤 | 操作 |
| --- | --- |
| 1 | `contract.*.enabled=false` 或 Whale module enabled=false |
| 2 | 临时恢复 UnionPayPlugin（仅应急；与 OpenHIS.Win 勿同端口冲突） |
| 3 | 不删 `upc_bpc_order` 历史 |
