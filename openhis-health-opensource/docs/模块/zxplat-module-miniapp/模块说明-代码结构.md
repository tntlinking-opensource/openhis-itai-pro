# Miniapp 代码结构

| Maven 模块 | 包根 | 职责 |
|------------|------|------|
| `module-miniapp-domain` | `com.zxplat.plugin.miniapp.domain` | 微信账号/会话/绑定实体与 `MapAuthDomainService` |
| `module-miniapp-bridge` | `com.zxplat.plugin.miniapp.bridge` | 跨边界集成占位；扫描 `bridge.integration` |
| `module-miniapp-application` | `com.zxplat.plugin.miniapp.application` | Auth/PEIS AppService、Filter、配置 |
| `module-miniapp-starter` | — | 聚合 domain+bridge+application |
| `module-miniapp-gateway-starter` | `com.zxplat.plugin.miniapp.gateway` | DMZ 反向代理独立进程 |

开关：`zxplat.modules.miniapp.enabled` · 配置前缀：`zxplat.miniapp.*`

文档入口：[说明.md](./说明.md)
