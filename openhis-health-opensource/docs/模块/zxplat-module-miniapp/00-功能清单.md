## 一、模块定位

### 1.1 Miniapp 是什么

**zxplat-module-miniapp** 是 HIS 的**微信小程序患者端扩展包**（**独立可售 Module**），为院方微信小程序提供 **BFF API、微信鉴权、就诊人绑定、业务编排**，覆盖：

- **门诊线**（对齐 `openhis-miniapp`）：预约挂号、当日挂号、门诊缴费、报告、候诊  
- **体检线**（对齐 `old_peis/weapp`，院点如东北师大）：校园身份绑定、体检预约、到检/指引、体检报告、自测上传  

通过 Client **委托** health / PEIS / booking / campus / 支付 / 医保，**不重复实现** 号源、登记、收费、总检等领域事实；**不**复活 `peis_customer` / `/peis/wx/*`。

| 线 | 内容 | 负责模块 |
| --- | --- | --- |
| **A** | 微信 OAuth、会话、就诊人/校园身份绑定、审计 | zxplat-module-miniapp（[DM-MAP-AUTH](./DM-MAP-AUTH-微信登录与就诊人绑定.md)） |
| **B** | 门诊预约挂号 / 当日挂号编排 | → health + booking（`MINIAPP`） |
| **E** | **体检**预约 / 到检签到编排 / 报告与自测 | → booking H 线 + health PEIS + campus |
| **P** | 门诊缴费、体检待缴（可选）、住院预交金 | → health + 支付 Client |
| **Q** | 门诊报告、缴费记录、候诊；体检进度/指引只读 | → health / report / booking / PEIS Query |
| **C** | 小程序配置、首页宫格（门诊/体检功能位）、订阅消息 | zxplat-module-miniapp |

**与自助机 Module 的关系**：

```text
zxplat-module-miniapp          zxplat-module-kiosk
  /api/miniapp/**                /api/kiosk/**
  微信 openid + 就诊人            设备 deviceId + 读卡
  opter_type = 3                  opter_type = 2
  DMZ 网关常见                    院内专线/VPN 常见

  二者：独立 starter、独立 Flyway（map_* / ksk_*）、独立售卖
  共享：仅 health/booking/支付/医保 领域 contracts（各自 adapter 实现，禁止互相 import application）
```

**目标架构**：

```text
微信小程序（uni-app）
      │ HTTPS
      ▼
miniapp-api（/api/miniapp/** 或 miniapp-gateway-starter）
      │ MiniappContext（openid、sessionId、patientId）
      ▼
miniapp-application
      ├── MiniappRegistrationOrchestrator  → health
      ├── MiniappPaymentOrchestrator       → health + BPC/BOC
      ├── MiniappQueryOrchestrator
      ├── MiniappBookingPort               → booking（channelCode=MINIAPP）
      └── MiniappPeisOrchestrator          → booking H + PEIS Query/Bridge + Campus
```

### 1.3 部署形态（双 starter）

| starter | 形态 | 说明 |

| --- | --- |

| 方法 | 路径 | 说明 |

请求头：`Authorization: Bearer <token>` 或 `X-Miniapp-Token: <token>`。匿名仅放行 `autoLogin` / `devLogin`。

## 四、验收与依赖

### 4.1 P1 验收清单

1. 微信登录后可绑定就诊人（含校园学号/工号）并切换。  
2. 可完成门诊预约挂号，`AppointmentOrigin.channel=MINIAPP` 且带 sessionId。  
3. 可完成当日挂号与门诊缴费（支付 Module 已装时走被扫闭环）。  
4. 可查询门诊报告列表与就诊记录。  
5. health **未** import `miniapp-application`；**未**依赖 `zxplat-module-kiosk`。  
6. `mvn compile -Pwith-miniapp` 通过。

### 4.2 P2 体检验收清单（对齐 old_peis 患者主路径）

1. 学生/教职工可完成校园绑定（Campus 校验通过）并看到对应角色首页。  
2. 可浏览套餐、查询余量/时段，完成团体或个人体检预约（`PHYSICAL_EXAM` + `MINIAPP`）。  
3. 可查看预约记录并取消未到检预约。  
4. 到检签到后可展示体检码；可查询指引与体检报告 PDF。  
5. 无 `peis_customer` / `/peis/wx` 依赖；openid 仅存 `map_wechat_account`。

### 4.3 模块依赖

| Module | 必须性 |
| --- | --- |
| zxplat-domain / health-app（含 PEIS） | **必须** |
| zxplat-module-booking | **必须**（门诊 + 体检预约） |
| zxplat-module-campus | 体检院点 **必须**；纯门诊可关 |
| zxplat-module-unionpay-bpc 或 zxplat-module-boc-pay | 推荐（单卖单装） |
| zxplat-module-chs-jilin | 可选 |
| zxplat-report | 可选（报告 PDF） |
| **zxplat-module-kiosk** | **禁止依赖** |
