| # | 需求 | 方案 |

| 1 | 适用性别 | `wkf_activity_definition.permitted_gender_enum`：`BOTH`/`MALE`/`FEMALE` |

## 2. 库表

```sql
ALTER TABLE wkf_activity_definition
  ADD COLUMN IF NOT EXISTS permitted_gender_enum varchar(32) NOT NULL DEFAULT 'BOTH',
  ADD COLUMN IF NOT EXISTS sort_order int4;
```

## 3. 枚举

- `ActivityType.EXTERNAL`：`6` / 外检（Java 枚举即种子；`getDiseaseTreatmentInit` / PEIS 下拉自动带出）
- `ActivityPermittedGender`：`BOTH`/`MALE`/`FEMALE`

## 4. 检索隔离

- `pageForCatalog`（医嘱开立）：**恒排除** `category_code=PEIS`
- `pageServiceCatalog`：`categoryCode` 为空时排除 PEIS；显式 `PEIS` 时仅体检
- 门诊医生站 exclude 列表追加 `PEIS`（双保险）

## 5. 应用层（PEIS CFG-04）

- `SaveActivityRequest` / `PeisActivityDto`：`permittedGenderEnum`、`sortOrder`
- Mapper → Create/Update Command → DomainService 落库
- 前端体检目录：性别下拉 + 顺序输入；类型下拉含外检
