# OpenHIS 全流程功能测试清单（按页面）

> **写给谁看**：测试人员、实施人员、业务验收人员  
> **怎么用**：按「主流程串联」先走一遍完整业务，再按模块逐页打勾；每项测完在 `[ ]` 里打 `x`  
> **说明**：以**页面能做什么**为准，不涉及代码；菜单名称以系统实际显示为准，可能与下文略有出入

## 一、怎么测（建议顺序）

### 1.1 三条主链路（必测）

| 链路 | 大致顺序 | 目的 |
|------|----------|------|
| **门诊看病** | 建档案 → 排班/挂号 → 医生接诊开医嘱 → 收费 → 发药 → （可选）退药/退费 | 验证门诊从进门到拿药 |
| **住院看病** | 登记入科 → 医生开医嘱 → 护士校对执行 → 记账/自动计费 → 发药 → 出院结算 | 验证住院全流程 |
| **药品流转** | 药库进货 → 出库到药房 → 药房发药消耗 → 盘点/损益 → 日结报表 | 验证库存账实一致 |

### 1.2 测试前准备

- [ ] 能正常登录，账号权限覆盖要测的菜单
- [ ] 基础资料已建好：科室、医生、药品、诊疗项目、挂号类型、病区床位、库房
- [ ] 至少准备 1 个测试患者（可新建）
- [ ] 如需测医保，医保环境、对码、签到已就绪

## 二、主流程串联（端到端）

> 按真实业务顺序走，每步确认「上一步的数据在下一步能查到」。

### 2.1 门诊完整链路

```
预约/排班 → 挂号 → 医生站接诊 → 开诊断/医嘱/申请单 → 收费 → 门诊发药 → 门诊护士处置（如有）
```

| 步骤 | 去哪个页面 | 要确认什么 |
|------|------------|------------|
| 1 | 患者档案 | 能新建/查到测试患者 |
| 2 | 门诊排班 / 号源日历 | 有号可挂 |
| 3 | 门诊挂号 | 挂成功，产生挂号记录 |
| 4 | 门诊医生站 | 能接诊该患者，状态变为已诊 |
| 5 | 医生站-诊断 | 能录入诊断并保存 |
| 6 | 医生站-医嘱 | 能开西药/中药/处置，签发成功 |
| 7 | 医生站-申请单 | 能开检验/检查申请（如有） |
| 8 | 门诊收费 | 待收费列表有该患者，能收款（现金/扫码/医保） |
| 9 | 门诊发药 | 待发药队列有处方，能备药、扫码、发药、打印 |
| 10 | 门诊护士站 | 处置类医嘱能执行；皮试能登记（如有） |
| 11 | 门诊退药（可选） | 已发药能申请退、药房能确认退 |
| 12 | 门诊退费（可选） | 已收费能退，金额/医保状态正确 |
| 13 | 门诊日结 | 当日收费汇总能对上 |

### 2.2 住院完整链路

```
住院登记 → 入科分床 → 医生开医嘱 → 护士校对 → 执行 → 记账/滚费 → 汇总发药 → 出院结算
```

| 步骤 | 去哪个页面 | 要确认什么 |
|------|------------|------------|
| 1 | 住院登记 | 能登记，状态「待入科」 |
| 2 | 护士站-入出转 | 能分床入科，患者出现在在院列表 |
| 3 | 预交金（可选） | 能收预交金，余额显示正确 |
| 4 | 住院医生站 | 能选中在院患者 |
| 5 | 医生站-诊断/医嘱 | 长期/临时医嘱能开、能停 |
| 6 | 护士站-医嘱校对 | 新医嘱出现在待校对，能通过/驳回 |
| 7 | 护士站-医嘱执行 | 待执行医嘱能执行，状态变已执行 |
| 8 | 护士站-住院记账 | 能手工划价；自动滚费（床位费等）能出账 |
| 9 | 护士站-费用明细 | 费用列表与记账一致 |
| 10 | 护士站-发药汇总 | 能生成汇总领药单 |
| 11 | 住院发药 | 能按汇总单发药，追溯码能录 |
| 12 | 护士站-入出转-出院 | 能办出院、清床 |
| 13 | 住院结算 | 待结算列表有该患者，能结算、打票 |
| 14 | 住院日结 | 当日住院收费汇总正确 |

### 2.3 药品库存完整链路

```
药库订货/进货 → 药库出库 → 药房入库 → 门诊/住院发药扣库存 → 盘点 → 库存明细核对 → 库房日结
```

| 步骤 | 去哪个页面 | 要确认什么 |
|------|------------|------------|
| 1 | 药库订货单 | 能新建订货单并提交 |
| 2 | 药库进货单 | 能录入到货、批号、效期、追溯码，审核入库 |
| 3 | 库存明细 | 药库库存增加 |
| 4 | 药房请领 / 药库出库 | 药房请领后药库能出库，药房库存增加 |
| 5 | 门诊或住院发药 | 发药后药房库存减少 |
| 6 | 药房盘点 | 实盘与账面对得上，盈亏合理 |
| 7 | 库存明细 | 各库房现存量正确 |
| 8 | 库存日结报表 | 期初+入-出=期末，账平 |

## 十三、异常与边界（各模块抽测）

> 不必每页都测，选代表页面验证即可。

### 13.1 通用

- [ ] 无权限账号看不到/打不开菜单
- [ ] 必填未填时提示，不能提交
- [ ] 网络慢时 loading，重复点击不重复提交
- [ ] 长列表分页正常
- [ ] 打印预览不乱版

### 13.2 门诊

- [ ] 未挂号患者不能接诊（或提示先挂号）
- [ ] 未收费不能发药（或提示先收费）
- [ ] 部分退费：只退选中项目
- [ ] 医保患者读卡失败时的提示

### 13.3 住院

- [ ] 未入科不能开医嘱（或合理提示）
- [ ] 未校对医嘱不能执行
- [ ] 出院后不能再记账
- [ ] 预交金不足时结算提示

### 13.4 库存

- [ ] 库存不足不能出库
- [ ] 已审核单据不能改
- [ ] 批号效期必填校验
- [ ] 追溯码重复扫描提示

### 13.5 并发

- [ ] 同一处方不能重复发药
- [ ] 同一床位不能分给两个患者
