# 方案3：药房 + 护士双扫

> 一句话：药房发药扫码进入码池；护士再扫（或确认池内码）归因到具体患者。  
> 上级文档：[住院药品追溯码上传方案-院方选型.md](./住院药品追溯码上传方案-院方选型.md)

---

## 1. 谁扫

| 角色 | 是否扫 | 扫什么 | 职责 |
| --- | --- | --- | --- |
| **药房药师** | **是（第一道）** | 母盒/盒上**追溯码** | 出库，写入汇总**码池**；退药入库终态清码 |
| **病区护士** | **是（第二道）** | 池内追溯码（再扫或选池） | 把码归因到患者；退药发起带码 |
| 床旁护士 | 可选 | 一般不扫追溯码 | 本方案追溯在摆药归因完成 |
| 结算/医保 | 否 | — | 出院上传 |

**设备**：药房发药枪；病区摆药枪；母盒架。

---

## 2. 什么时候扫

| 时点 | 药房 | 护士 | 说明 |
| --- | --- | --- | --- |
| **汇总核发/发药** | **扫 → 入码池** | 不扫 | 证明「从药房发出哪些码」 |
| **病区接收后摆药归因** | — | **扫/确认池内码 → 绑患者** | 证明「码给了谁」 |
| 分药入袋后 | — | 不扫药袋 | 归因须在分袋前或持母盒完成 |
| 床旁给药 | — | 不扫追溯（本方案） | — |
| **退药** | **确认入库时扫** | **发起时扫或带出原码** | 建议药房入库为清码终态 |
| 出院 | — | — | 以上传前患者最终绑定为准 |

**依赖**：药房未扫入池时，护士提交池外码应被系统拒绝；监管品种可要求池非空。

---

## 3. 怎么扫

### 3.1 正向 · 整盒（一患者多盒）

**例**：病区领 3 盒给张三（或汇总后再分）。

**药房**

1. 核发时连续扫 `码1,码2,码3` → 写入本汇总单**码池**。  
2. 可不写患者行（由护士归因）。

**护士**

1. 打开张三待分配。  
2. **再扫**（或从池勾选）`码1,码2,码3`，须全部 ∈ 码池。  
3. 保存 → 张三发放行写入三码。  
4. 禁止扫池外码。

### 3.2 正向 · 拆零（多患者一盒）

**例**：母盒码X 分给李四/王五/赵六。

**药房**

1. 扫母盒 `码X` 入码池（及拆零出库）。  
2. 母盒随药到病区。

**护士**

1. **持母盒**扫/确认池内 `码X`。  
2. 分别为李四、王五、赵六绑定同一 `码X`。  
3. 再分入无码药袋；母盒归架。

### 3.3 逆向 · 退药怎么扫

| 场景 | 护士 | 药房 |
| --- | --- | --- |
| 整盒部分退 | 发起退药，**再扫被退盒码**（或带出） | 收盒后**再扫确认入库**，清患者该码 |
| 拆零一人退（有母盒） | 扫母盒 / 带出码，只清本患者 | 他人仍占用则**不整盒入库**；仅确认患者行已清 |
| 拆零末人退 | 清绑定，母盒交回 | **扫母盒入库**，码可再发 |
| 仅裸药无母盒 | 带出原码确认 | 同左；双签；记缺陷 |

### 3.4 两道扫的分工口诀

| 道次 | 回答的问题 | 扫的对象 |
| --- | --- | --- |
| 药房第一道 | 发出去的是哪些码？ | 实物包装追溯码 → 码池 |
| 护士第二道 | 这些码给了哪位患者？ | 仅允许池内码 → 患者行 |

### 3.5 扫码操作要点

| 要做 | 不要做 |
| --- | --- |
| 护士只用池内码 | 扫病区随手拿的外来盒码入患者 |
| 拆零先扫母盒再分袋 | 分袋后再向池外「补码」 |
| 退药两端状态一致 | 护士清了、药房未确认（或相反）长期悬空 |

---

## 4. 利弊

### 利

| 点 | 说明 |
| --- | --- |
| 双重核对最强 | 出库有池、到人有据，飞检与内部质控说服力最高 |
| 防串码 | 护士只能用池内码，降低扫外来盒码风险 |
| 职责分离清晰 | 药房对「发出哪些码」负责，护士对「给了谁」负责 |
| 整盒+拆零都能管 | 码池约束与患者归因同时成立 |
| 与现有产品贴近 | 汇总核发码池 + 护士追溯分配路径 |

### 弊

| 点 | 说明 |
| --- | --- |
| 人力成本最高 | 两端都要扫，排班与培训成本翻倍 |
| 流程最长 | 药房未入池则护士无法归因；任一端积压全链路卡住 |
| 重复劳动感强 | 一线抵触可能高于单扫方案 |
| 退药协同复杂 | 须约定谁扫清、谁确认，否则两端状态不一致 |
| 全品种双扫过重 | 不宜无差别全院强制；更宜限高值/监管重点 |

### 更适合 / 不太适合

| 更适合 | 不太适合 |
| --- | --- |
| 三甲、飞检严、高值/精麻占比高 | 人力紧、只求快速合规 |
| 已有药房扫码习惯，愿投护理二次扫 | 希望床旁闭环体验（可双扫后再叠加方案4打贴） |

---

## 5. 岗位一句话口诀

> **药房先扫入码池；护士再扫落到人；池外码一律拒；退药双侧要确认。**
