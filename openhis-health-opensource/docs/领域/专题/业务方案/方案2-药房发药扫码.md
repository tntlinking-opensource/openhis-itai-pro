# 方案2：药房发药扫码（护士不扫追溯码）

> 一句话：药房发药时扫追溯码并绑到患者；护士不扫追溯码，但须保管母盒配合退药。  
> 上级文档：[住院药品追溯码上传方案-院方选型.md](./住院药品追溯码上传方案-院方选型.md)

---

## 1. 谁扫

| 角色 | 是否扫追溯码 | 职责 |
| --- | --- | --- |
| **药房药师（发药/退药岗）** | **是（主责）** | 发药绑码、退药清码 |
| 病区护士 | **否（不扫追溯码）** | 领药、分药、给药；退药时交回原盒/说明母盒去向 |
| 运送/护工 | 否 | 整盒退药须原盒回药房 |
| 结算/医保 | 否 | 出院上传 |

**设备**：发药窗口扫码枪；退药窗口扫码枪（可共用）。

---

## 2. 什么时候扫

| 时点 | 是否扫 | 说明 |
| --- | --- | --- |
| **药房发药/核发当时** | **扫** | 绑定追溯码的唯一正向时点 |
| 病区摆药/分袋 | 不扫 | 码应已在药房绑好 |
| 床旁给药 | 不扫 | — |
| **退药确认（药房）** | **扫** | 有原盒/母盒再扫；无盒走带出原码 |
| 出院结算 | 不扫 | 系统上传已绑未清码 |

**关键约束**：汇总发药必须把码**写到每个患者发放行**，不能只扫进大池不归因——否则出院无法按人上传。

---

## 3. 怎么扫

### 3.1 正向 · 整盒（一患者多盒）

**例**：张三发 3 盒。

1. 药师拣出 3 盒，打开张三发药行。  
2. **连续扫描 3 个盒码** → 写入张三 `码1,码2,码3`。  
3. 校验码数=3、在院剩余、药+批匹配 → 确认发药。  
4. 护士接收后不再扫追溯码。

### 3.2 正向 · 拆零（多患者一盒）

**例**：母盒码X → 李四/王五/赵六。

1. 药师**扫描母盒码X一次**（或按系统要求）。  
2. 在系统中把 `码X` **分别写入**李四、王五、赵六的发放行（允许共用）。  
3. 扣减拆零剩余；发出母盒（或余药）到病区。  
4. 病区可再分袋，**不再扫追溯码**；但须**保管母盒**供退药。

若做「汇总核发」：须有「码→患者」拆分步骤（本方案若做不到，拆零应改方案3或4D）。

### 3.3 逆向 · 退药怎么扫

| 场景 | 谁操作 | 怎么做 |
| --- | --- | --- |
| 整盒退 | 药房 | 患者/病区退回原盒 → **药师再扫盒码** → 清除该患者对应码并回库 |
| 整盒部分退（3退1） | 药房 | **只扫退回的那一盒** → 只清该码 |
| 拆零一人退（母盒回药房） | 药房 | **扫母盒** → 只清该患者行；他人仍绑则母盒可再发回病区 |
| 拆零一人退（母盒留病区，只退裸药） | 药房+护士 | 护士说明母盒仍占用；系统**带出原码**药房确认清该患者；裸药倒回病区母盒 |
| 无原盒强退 | 药房 | 制度禁止或走审批+带出原码双签 |

### 3.4 护士在本方案「不扫」但仍要做的事

| 要做 | 说明 |
| --- | --- |
| 保管拆零母盒 | 用尽前不扔包装 |
| 整盒退药交原盒 | 无盒药房无法再扫 |
| 共用盒一人退时注明 | 谁还在用该母盒，避免整盒误退库 |

### 3.5 扫码操作要点

| 要做 | 不要做 |
| --- | --- |
| 发药当时扫码并绑到**患者行** | 只扫总数、不写患者 |
| 整盒 N 盒扫 N 码 | 一码顶多盒 |
| 退药扫退回实物上的码 | 要求护士扫无码药袋 |

---

## 4. 利弊

### 利

| 点 | 说明 |
| --- | --- |
| 护士零增量 | 护理排班几乎不变，落地阻力小 |
| 出库与码同源 | 发药当时扫码，监管「出库即有码」清晰，利于飞检 |
| 整盒专业高效 | 窗口连扫 N 盒，药师对批号效期更熟，差错率通常较低 |
| 与进销存衔接好 | 在院态、剩余量门控天然落在发药环节 |
| 设备简单 | 窗口扫码枪即可 |

### 弊

| 点 | 说明 |
| --- | --- |
| 药房成瓶颈 | 扫码拉长发药时长，高峰易排队 |
| 拆零归因难 | 必须写到每个患者行；只扫池不拆人则出院无法按人传码 |
| 退药依赖原盒回药房 | 病区常只有无码药袋；无盒难再扫，须带出原码或强制留母盒 |
| 码与「已给药」脱节 | 药房已绑码，病区未用即退存在空窗（出院前可纠） |
| 护士仍要管母盒 | 「不扫」不等于无责任，母盒丢失仍影响退药 |

### 更适合 / 不太适合

| 更适合 | 不太适合 |
| --- | --- |
| 整盒为主、护理紧、先求合规 | 拆零占比极高且药房无法按人写码 |
| 药房可加发药扫码岗 | 希望病区闭环护理与追溯一次完成（更宜方案4） |

---

## 5. 岗位一句话口诀

> **发药窗口扫盒码；码要落到每个人；护士用药不扫码；退药原盒回药房。**
