# 方案1：护士摆药扫码（药房不扫）

> 一句话：药房发药不扫追溯码；病区护士在摆药时扫母盒/盒码绑到患者。  
> 上级文档：[住院药品追溯码上传方案-院方选型.md](./住院药品追溯码上传方案-院方选型.md)

---

## 1. 谁扫

| 角色 | 是否扫追溯码 | 职责 |
| --- | --- | --- |
| **病区摆药护士** | **是（主责）** | 正向绑码、退药清码、维护母盒架 |
| 药房药师 | 否 | 按单发药/汇总发药，不采集追溯码 |
| 床旁责任护士 | 否（本方案） | 按常规给药，不扫追溯码 |
| 结算/医保 | 否 | 出院触发上传；处理应扫未扫清单 |

**设备**：病区摆药台固定扫码枪；母盒架。

---

## 2. 什么时候扫

| 时点 | 是否扫 | 说明 |
| --- | --- | --- |
| 药房发药/核发 | 不扫 | 只出实物 |
| **病区摆药（分到患者前）** | **扫** | 绑定追溯码的唯一正向时点 |
| 分药入袋之后 | 不扫 | 药袋/药杯无码，禁止补扫药袋 |
| 床旁给药 | 不扫 | 本方案不做床旁追溯扫 |
| **退药时** | **扫（或带出原码）** | 有母盒再扫；仅裸药则系统带出原码确认 |
| 出院结算 | 不扫 | 系统汇总已绑未清的码上传医保 |

**顺序铁律（拆零）**：先扫母盒 → 再倒药入袋 → 母盒归架。

---

## 3. 怎么扫

### 3.1 正向 · 整盒（一患者多盒）

**例**：张三发 3 盒。

1. 药房发出 3 盒，不扫。  
2. 摆药护士在系统中打开张三待绑行。  
3. **连续扫描 3 个盒上的追溯码**（码1、码2、码3）。  
4. 校验：码数 = 盒数；药名+批号匹配 → 保存。  
5. 结果：张三发放行 = `码1,码2,码3`。

### 3.2 正向 · 拆零（多患者一盒，药袋无码）

**例**：母盒码X，李四 3 片、王五 4 片、赵六 3 片。

1. 取出母盒，**先扫码X**。  
2. 在系统中为李四/王五/赵六分别绑定同一 `码X`（可扫一次后多人勾选，或每人扫一次母盒）。  
3. 再按量倒入各人无码药袋。  
4. 母盒放到母盒架（标品名、码末几位、剩余量）。  
5. 禁止：先分袋再找码；禁止给药袋另扫无关空盒码。

### 3.3 逆向 · 退药怎么扫

| 场景 | 谁操作 | 怎么做 |
| --- | --- | --- |
| 整盒全退/部分退 | 摆药护士 | **再扫要退的盒码**；从患者绑定中移除对应码 |
| 拆零一人退（母盒在） | 摆药护士 | **扫母盒**；裸药倒回母盒；只清该患者绑定 |
| 拆零一人退（仅裸药） | 摆药护士 | **禁止扫药袋**；系统带出原码 → 勾选确认 |
| 末人退整盒 | 护士清绑定后 | 母盒交药房回库（药房本方案可不扫，按院规入库） |

### 3.4 扫码操作要点

| 要做 | 不要做 |
| --- | --- |
| 对着盒/母盒包装上的追溯码扫 | 对着药袋、药杯扫 |
| 整盒发 N 盒扫 N 个不同码 | 少扫、用同一码顶多盒 |
| 拆零多人共用同一母盒码 | 整盒拿去给第二人共用 |
| 退哪个盒扫哪个盒 | 随机删一个码应付部分退 |

---

## 4. 利弊

### 利

| 点 | 说明 |
| --- | --- |
| 药房零增量 | 发药速度不受扫码拖累，适合药房人手紧、日发量大 |
| 码与患者近 | 摆药时按人绑定，拆零共用、多盒连扫直观 |
| 退药在病区闭环 | 共用母盒未退药房也可先清患者绑定 |
| 设备投入低 | 摆药台固定枪 + 母盒架即可，不必全员 PDA、瓶贴机 |
| 落地快 | 流程改动主要在护理摆药岗，培训面相对集中 |

### 弊

| 点 | 说明 |
| --- | --- |
| 护士工作量大 | 摆药高峰连扫易积压、漏扫 |
| 缺药房码池 | 飞检时「码从哪出库」说服力弱于方案2/3 |
| 母盒架依赖强 | 乱扔包装后只能走「带出原码」，质控风险高 |
| 夜班/临时领药易漏 | 需出院闸门或待扫清单兜底 |
| 退药靠护士自觉 | 未再扫清码会导致出院上传「幽灵码」 |
| 混批错扫 | 药房发出混批时，护士可能扫错盒 |

### 更适合 / 不太适合

| 更适合 | 不太适合 |
| --- | --- |
| 药房坚决不加扫码岗；病区有固定摆药台 | 飞检极严、要求出库即有码池证据 |
| 拆零多、护士愿管母盒 | 护理人力极紧、摆药班无法增派 |

---

## 5. 岗位一句话口诀

> **药房发药不扫码；摆药台上扫盒码；先扫后分母盒留；退药再扫或带码。**
