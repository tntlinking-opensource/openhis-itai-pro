# 方案5：分级组合（整盒 / 拆零 / 高值分策）

> 一句话：不搞全院单一扫法；按药品类型分别套用方案2、4、3 的扫码规则。  
> 上级文档：[住院药品追溯码上传方案-院方选型.md](./住院药品追溯码上传方案-院方选型.md)  
> 积木详述：[方案2](./方案2-药房发药扫码.md) · [方案4](./方案4-瓶贴医嘱单闭环.md) · [方案3](./方案3-药房护士双扫.md)

---

## 1. 谁扫（按药品类型）

| 药品类型 | 谁扫追溯码 | 床旁谁扫什么 | 依据积木 |
| --- | --- | --- | --- |
| **监管 · 整盒** | **药房药师** | 可不扫追溯；可选扫瓶贴做护理闭环 | 方案2（+可选4D床旁） |
| **监管 · 拆零** | **摆药/药房（打印前）** | **责任护士扫腕带+瓶贴** | 方案4（4D） |
| **高值 / 精麻 / 飞检重点** | **药房入池 + 护士归因** | 建议腕带+瓶贴 | 方案3 + 打印门控 |
| **非监管常备** | 免扫或抽查（院方定） | 按护理规范 | 配置策略 |

**系统前提**：药品目录上能标记「整盒/拆零/高值/是否监管」，发药与打印按标记切换校验。

---

## 2. 什么时候扫（总览）

```text
发药/摆药时点
  ├─ 整盒监管 ──► 药房发药当时扫追溯码（方案2）
  ├─ 拆零监管 ──► 打印瓶贴前扫母盒（方案4）
  └─ 高值精麻 ──► 药房核发扫入池 → 护士摆药再扫归因（方案3）

床旁时点
  ├─ 拆零 / 已打贴 ──► 扫腕带+瓶贴（不扫盒码）
  ├─ 整盒未打贴 ──► 可不扫追溯（码已在药房绑定）
  └─ 高值建议 ──► 扫腕带+瓶贴加强闭环

退药时点
  ├─ 整盒 ──► 原盒回药房再扫（方案2）
  ├─ 拆零 ──► 母盒或带出原码（方案4）
  └─ 高值 ──► 护士发起 + 药房确认（方案3）

出院时点
  └─ 全部 ──► 不扫；统一上传有效追溯码
```

| 时点 | 整盒监管 | 拆零监管 | 高值/精麻 |
| --- | --- | --- | --- |
| 药房发药 | **扫追溯码→患者** | 可选预扫入池 | **扫→码池** |
| 摆药/打印前 | 一般不再扫追溯 | **扫母盒→绑患者→打贴** | **再扫池内码→患者** |
| 床旁 | 可选扫贴 | **扫腕带+贴** | **建议扫腕带+贴** |
| 退药 | 药房扫退回盒 | 扫母盒/带出原码 | 双侧扫/确认 |
| 出院 | 系统上传 | 系统上传 | 系统上传 |

## 3. 怎么扫（分场景操作卡）

### 3.1 卡片 A · 监管整盒（走方案2）

| 项 | 内容 |
| --- | --- |
| **谁** | 药房药师 |
| **何时** | 发药确认当时 |
| **怎么扫** | 发 N 盒 → 连扫 N 个盒码 → 写入该患者发放行 |
| **护士追溯扫** | 不扫 |
| **退药** | 原盒回药房 → 药师再扫被退盒码清绑定 |

**口诀**：整盒窗口扫，护士不用扫盒码。

---

### 3.2 卡片 B · 监管拆零（走方案4）

| 项 | 内容 |
| --- | --- |
| **谁** | 摆药护士（或药房打印岗）绑追溯码；床旁护士扫业务码 |
| **何时** | 打印瓶贴/医嘱单**之前**绑码；给药当时扫贴 |
| **怎么扫** | ① 扫母盒追溯码绑患者（多人可共用一码）② 有码才打印 ③ 床旁扫腕带+瓶贴 |
| **不要** | 床旁扫药袋；无码强打贴 |
| **退药** | 扫瓶贴定位 + 扫母盒或带出原码；只清本患者 |

**口诀**：拆零先扫母盒再打贴，床旁只扫腕带贴。

---

### 3.3 卡片 C · 高值/精麻（走方案3）

| 项 | 内容 |
| --- | --- |
| **谁** | 药房第一道；护士第二道 |
| **何时** | 核发入池 → 摆药归因（建议归因后才允许打贴/出病区） |
| **怎么扫** | 药房扫追溯码入池 → 护士仅扫/选池内码落到患者 → 建议打贴后床旁扫贴 |
| **退药** | 护士带码发起 → 药房扫码确认入库（末人/整盒） |

**口诀**：高值两道扫，池外码进不了人。

---

### 3.4 卡片 D · 非监管（可选）

| 项 | 内容 |
| --- | --- |
| **谁** | 默认无人强制扫追溯码 |
| **何时** | — |
| **怎么扫** | 系统策略关闭强制；质控可抽查 |
| **出院** | 无码则不上传该类明细 |

---

### 3.5 一线如何判断「此刻该用哪张卡」

1. 看药品是否**监管追溯**。否 → 卡片 D。  
2. 是监管：看是否**高值/精麻/院定重点**。是 → 卡片 C。  
3. 否则看发药单位： **整盒（销售包装）→ 卡片 A**；**拆零（片/支等）→ 卡片 B**。

建议在 HIS 发药/摆药界面**直接提示本行策略**（A/B/C），避免口头记忆出错。

## 4. 组合下的「谁扫」总表

| 角色 | 整盒监管 | 拆零监管 | 高值 |
| --- | --- | --- | --- |
| 药房 | 扫追溯码绑患者 | 可选 | 扫入码池 |
| 摆药护士 | 不扫追溯 | 扫母盒+打贴 | 扫池内码归因 |
| 床旁护士 | 可选扫贴 | 扫腕带+贴 | 建议扫腕带+贴 |
| 退药 | 药房扫盒 | 母盒/带出原码 | 双侧确认 |

---

## 5. 利弊

### 利

| 点 | 说明 |
| --- | --- |
| 人力用在刀刃上 | 整盒不拖垮护理，拆零不逼床旁找盒码，高值才双扫 |
| 比「单选一方案」更贴院情 | 兼顾合规速度、飞检重点与闭环体验 |
| 可分期落地 | 先卡片 A → 再 B → 再 C，排班冲击可控 |
| 飞检口径清晰 | 不同品种对应不同证据链（窗口码 / 瓶贴 / 码池） |
| 继承各积木优点 | 同时规避「全院双扫过重」「全院只药房扫拆零归因难」等单方案短板 |

### 弊

| 点 | 说明 |
| --- | --- |
| 制度与培训更复杂 | 不能一张 SOP 打天下；一线要会判断 A/B/C |
| 系统要支持策略配置 | 药品目录标记、按行切换校验与界面提示，改造量大于单方案 |
| 质控要分场景抽查 | 漏扫原因更分散，报表需按策略维度统计 |
| 初期易混用错规则 | 若界面无提示，可能整盒走了拆零流程或相反 |
| 跨积木退药规则不统一 | 须在退药界面按原发策略引导，避免护士无所适从 |

### 更适合 / 不太适合

| 更适合 | 不太适合 |
| --- | --- |
| **大多数医院的默认推荐** | 信息化极弱、无法做品种策略配置 |
| 整盒+拆零都有、希望分步上线 | 品种极单一（例如几乎全是整盒）——可直接单选方案2 |

### 相对单方案的取舍（一览）

| 对比 | 说明 |
| --- | --- |
| vs 只选方案1 | 整盒不必全压给护士 |
| vs 只选方案2 | 拆零有 4D，避免床旁/归因断链 |
| vs 只选方案3 | 非高值不做双扫，省人力 |
| vs 只选方案4 | 整盒可走窗口快扫，不强制全品种打贴 |

---

## 6. 岗位一句话口诀

> **整盒药房扫；拆零打贴扫；高值两道扫；床旁多扫贴、少扫盒。**

---

## 7. 落地顺序（扫码培训可按此排期）

1. 先教会卡片 A（整盒窗口扫）——最快合规。  
2. 再教会卡片 B（拆零打印门控+床旁扫贴）。  
3. 最后加卡片 C（双扫）覆盖高值目录。
