# 方案4：瓶贴/医嘱单闭环（床旁不扫盒码）

> 一句话：摆药/打印前扫母盒追溯码并绑患者；打印瓶贴或医嘱单；床旁扫腕带+瓶贴/医嘱单（**不扫盒上追溯码**）。  
> 本文按推荐变体 **4D** 描述。  
> 上级文档：[住院药品追溯码上传方案-院方选型.md](./住院药品追溯码上传方案-院方选型.md)

---

## 1. 谁扫

| 角色 | 扫什么 | 是否国家追溯码 | 职责 |
| --- | --- | --- | --- |
| **摆药护士或药房** | **母盒/盒上追溯码** | **是** | 打印前完成追溯绑定 |
| **床旁责任护士** | **腕带 + 瓶贴或医嘱执行单** | **否**（业务条码） | 闭环给药核对 |
| 药房（退药） | 母盒追溯码（或带出原码） | 是/系统 | 退药清码、入库 |
| 结算/医保 | — | — | 出院上传 |

**设备**：摆药台扫码枪 + 瓶贴/执行单打印机；床旁 PDA；母盒架。

---

## 2. 什么时候扫

| 时点 | 谁 | 扫什么 | 说明 |
| --- | --- | --- | --- |
| **摆药/打印前** | 摆药/药房 | **追溯码（母盒）** | 唯一绑国家追溯码的时点 |
| **打印瓶贴/医嘱单** | 系统门控 | — | 监管品种无码 → **禁止打印** |
| **床旁给药** | 责任护士 | **腕带 + 瓶贴/医嘱单** | 不扫盒码；核对人/药/次 |
| 分药入袋后、未打贴 | — | — | 应先绑码再打贴，避免无码袋无法闭环 |
| **退药** | 护士/药房 | 瓶贴（定位行）+ 母盒或带出原码 | 清追溯绑定 |
| 出院 | 系统 | — | 上传已绑未清追溯码 |

```text
时间线：
  扫母盒追溯码 → 允许打印瓶贴/医嘱单 → 床旁扫腕带+贴 → … → 出院上传追溯码
```

---

## 3. 怎么扫

### 3.1 正向 · 绑追溯码（打印前）

#### 整盒 · 一患者多盒

1. 打开张三发放行。  
2. 连续扫 3 个盒上追溯码 → 保存。  
3. 打印张三瓶贴/执行单（条码关联本发放行；追溯码已在库中）。  
4. 盒/贴交给床旁班。

#### 拆零 · 多患者一盒

1. **先扫母盒码X**。  
2. 为李四、王五、赵六分别绑定 `码X`。  
3. 分别为三人**各打一张瓶贴**（业务条码不同，库内追溯码同为码X）。  
4. 再分入无码药袋并贴上瓶贴；母盒归架。  
5. 床旁**不必**再拿母盒。

### 3.2 正向 · 床旁怎么扫（不扫盒码）

1. PDA 扫患者**腕带**。  
2. 扫该次药的**瓶贴**或**医嘱执行单**条码。  
3. 系统核对：患者一致、药品/剂量/执行次匹配。  
4. 通过即执行给药；**屏幕无需再扫追溯码**。  
5. 失败：贴错人、未打贴、腕带不符 → 停止给药，回摆药台处理。

### 3.3 逆向 · 退药怎么扫

| 场景 | 怎么扫 |
| --- | --- |
| 定位退哪一笔 | 可先扫**瓶贴**打开对应发放行 |
| 整盒退 | 再扫**盒上追溯码**（或带出）清除绑定 |
| 拆零退（有母盒） | 扫**母盒**；裸药倒回；只清本患者 |
| 拆零退（仅裸药） | 扫瓶贴定位 + **带出原码**确认；禁止扫药袋 |
| 未给药仅作废贴 | 作废瓶贴；若已绑追溯码按是否退药决定是否清码 |

### 3.4 两种「码」不要混淆

| 类型 | 长什么样 | 谁扫 | 作用 |
| --- | --- | --- | --- |
| **国家药品追溯码** | 包装上约 20 位 | 摆药/药房（打印前） | 合规、出院上传医保 |
| **瓶贴/医嘱单业务条码** | 医院打印短码/二维码 | 床旁护士 | 闭环：对的人、对的药 |

### 3.5 扫码操作要点

| 要做 | 不要做 |
| --- | --- |
| 无追溯码不打印（监管品种） | 先打贴后补扫、空贴上床旁蒙混 |
| 床旁扫腕带+贴 | 床旁逼护士扫已拆零的无码袋/盒 |
| 一人一贴（拆零共用母盒码） | 多人共用一张瓶贴 |
| 退药清追溯码 | 以为撕掉瓶贴就等于清了追溯码 |

## 4. 利弊

### 利

| 点 | 说明 |
| --- | --- |
| 破解拆零无码 | 药袋无追溯码也不影响床旁；码在打印前已绑定 |
| 床旁体验好 | 扫腕带+瓶贴，与闭环护理习惯一致，易被护士接受 |
| 母盒不必随车 | 母盒留架即可，减轻药车负担 |
| 整盒/拆零床旁动作统一 | 都是扫贴，培训简单 |
| 打印门控可加强合规 | 无码拒打，从源头卡住漏扫 |
| 退药可先扫贴定位 | 快速打开对应发放行再清码 |

### 弊

| 点 | 说明 |
| --- | --- |
| 设备与改造成本高 | 需 PDA、瓶贴/执行单打印、条码与发放行关联 |
| 摆药岗仍要扫追溯码 | 工作量接近方案1；漏扫会卡打印 |
| 错贴/漏打风险 | 贴错患者仍可能给错药，须腕带双扫兜底 |
| 耗材与补打管理 | 瓶贴成本、作废旧贴、补打审计 |
| 退药不能只撕贴 | 仍须扫母盒或带出原码清追溯绑定 |
| 依赖移动护理成熟度 | 无 PDA/无打印体系时不宜强上 |

### 更适合 / 不太适合

| 更适合 | 不太适合 |
| --- | --- |
| 已上移动护理 + 瓶贴/执行单打印 | 无瓶贴机、无 PDA，短期只要扫码枪合规 |
| 拆零多、强调给药闭环 | 只想药房窗口扫完了事（更宜方案2） |

---

## 5. 岗位一句话口诀

> **打印之前扫盒码；有码才打瓶贴单；床旁只扫腕带贴；盒码不用拿到床。**

## 6. 本方案不推荐的变体（对照）

| 变体 | 床旁行为 | 说明 |
| --- | --- | --- |
| 4A | 床旁直接扫盒上追溯码 | 拆零药袋无码，失败率高；**不推荐** |
| 4D（本文） | 床旁扫瓶贴/医嘱单 | **推荐** |
