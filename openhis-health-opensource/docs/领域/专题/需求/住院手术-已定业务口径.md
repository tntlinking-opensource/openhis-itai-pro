## 1. 一句话口径

1. **手术只有术式特殊**：临床真源 = `ServiceRequest.procedure_definition_id`（国临术式）；`activity_id=0` 占位；执行写 Procedure、**本行不计费**。  
2. **术前嘱托挂靠术式**：医生可在手术申请下为**指定术式**开术前嘱托（类目 52）；**唯一 basedOn 主子** = 嘱托 → 术式 SR。  
3. **麻醉是普通临嘱**：麻醉项目 / 麻醉药品**平级**开立（互不 basedOn、也不挂术式）；与手术的关联靠表单级 `nestedAnesthesiaPrescriptionNo`，不写 basedOn。  
4. **费用与术式无强制一对一**：诊疗目录中 `type=手术` 的 AD 是计费项；`PD.activity_definition_id` 字段保留，**开立不门禁对码**。  
5. **开立禁止附加**：其他加收一律**护士划价**（伪需求「开立附加项目」已废弃）。

---

## 2. 背景：老系统问题（为何重做）

| 线 | 老做法 | 问题 |
|----|--------|------|
| 临床表达 | 术者开嘱托自由文本 | 无结构化手术真源 |
| 手术费用 | 护士另划价，与嘱托脱节 | 与上报脱节 |
| 上报/病案 | DRG 附加轨手选国临码 | 双真源 |

**新系统目标**：术式一条轨进病案；术前嘱托挂靠对应术式；费用走医嘱计费 / 护士划价。

## 3. 手术侧

### 3.1 术式行（真正的手术）

| 项 | 口径 |
|----|------|
| 开立 | 医生选手术目录术式（可多条 = 多条 SR）；**不开附加** |
| 落库 | `procedure_definition_id` = PD；`activity_id = 0`；`category=24`；临嘱 |
| 展示 | 一律术式名（医生站 / 护士站） |
| 执行 | 与普通医嘱同轨勾选执行（`AS-IP-NUR-004` / IF-IP-EXE-02）→ 写 Procedure；**本行不计费**；**无**专用执行弹窗 |
| 病案/清单/DRG | 只认有 `procedure_definition_id` 的完成行 |

### 3.2 术前嘱托（basedOn 术式）

| 项 | 口径 |
|----|------|
| 开立 | 手术申请内「添加术前嘱托」；须选择挂靠哪一条术式；正文必填（如「术前禁食水，术区备皮」） |
| 落库 | `category=52`；`entrust_content`；`activity_id` = 内置「嘱托」AD；**`based_on` = 对应术式 SR** |
| 主子 | **手麻申请唯一 basedOn 主子关系** |
| 签发/撤回 | 随手术申请整单签发/撤回同步处理挂靠嘱托；嵌套麻醉见 §5 签发连带 |
| 医嘱 Tab | **不展示**（与术式同在手术页）；**禁止**一刀切隐藏全部嘱托——仅排除 basedOn 术式者 |
| 执行 | 与普通嘱托相同（不计费）；护士站仍可见 |

### 3.3 手术加收（护士划价，非医生站开立）

| 项 | 口径 |
|----|------|
| 谁开 | **仅护士**医嘱计费划价；医生站 Gate **拒绝** `SURCHARGE` |
| 关联 | `basedOn` = 对应术式 SR（护士划价路径，非手麻开立） |

### 3.4 主数据

- **手术目录**（ProcedureDefinition）：不做对侧目录选码对码，不挂靠诊疗 AD。  
- 诊疗目录中类型为「手术」的 AD：仅计费/划价用。

## 4. 麻醉侧

| 项 | 口径 |
|----|------|
| 本质 | 普通临嘱（AD / 药嘱） |
| 页面 | 独立页或手术单勾选「需要麻醉」嵌套生成 |
| 选品 | **麻醉项目** / **麻醉药品**；**禁止附加** |
| 平级 | 麻醉项目与麻醉药品**无主子**；**不** basedOn 术式或彼此 |
| 与手术关联 | 表单级：手术行 `nested_anesthesia_prescription_no`；**不**写 basedOn |
| 加收 | 仅护士划价 |
| 执行计费 | 与普通诊疗/药嘱相同；发药走药房 |
| 麻醉药品剂量 | **单次剂量** + **单次剂量单位**（术语 `dose_unit`）；Init 下发 `doseUnitOptions`；开立端可**按名称/码检索改选**（如 ml、ug）；**不**按剂量单位换算开立总量（数量/总量单位另列） |

## 5. 端到端闭环

```text
【开立】
  术者 → 术式 SR（PD，activity_id=0）
       → 术前嘱托 SR（category=52，basedOn=术式）——唯一主子
  可选 → 麻醉申请：麻醉项目 ∥ 麻醉药品（平级，无 basedOn；药品与麻醉 SR 同 AR）

【签发 / 撤回】
  签发手术单 → 连带签发：术前嘱托 + 嵌套麻醉 SR + 同 AR 麻醉药品
  签发麻醉单 → 连带签发同 AR 麻醉药品
  撤回对称：手术撤回连带嵌套麻醉；麻醉撤回连带药品签退

【医嘱 Tab】
  不展示：术式(24)、麻醉(25)、挂靠术式的术前嘱托（52+basedOn 术式）
  仍展示：普通嘱托（未挂术式）及其他诊疗/药品

【校对 / 执行】
  术式 → 普通勾选执行（同治疗等），写 Procedure，本行不计费；**无**专用执行弹窗
  术前嘱托 → 普通嘱托执行，不计费
  麻醉项目 → 普通执行即计费
  麻醉药 → 校对后药房发药

【计费补录】
  护士医嘱划价（AS-IP-NUR-005「住院记账 / 医嘱计费」）：挂术式或麻醉医嘱（basedOn）——其他加收入口
  **禁止**在医嘱执行 Tab 放「补费」列/入口（补费与临床执行分轨）
```

### 时间校验（硬）

拟手术时间、执行业务时间、病案手术/麻醉起止：入院～出院窗（**BR-IP-SUR-TIME-001**）；麻醉结束不得早于开始。

---

## 6. 明确不做 / 特殊需求

- **不做**虚拟「手术」0 元 AD 作为开立媒介。  
- **不做**开立强制 PD↔AD 一对一对码。  
- **不做**医生站手术/麻醉开立「附加项目」。  
- **不做**麻醉项目↔麻醉药品、麻醉↔术式的 basedOn 主子（已废弃）。  
- 院点若维护 PD 挂靠 AD：字段保留，不挡开立。
