# 中西医处方打印规则（门诊-住院）【建议方案】

## 一、总则

### 1.1 适用范围

本规则依据《处方管理办法》及中医药相关诊疗规范制定，适用于各级医疗机构门诊、住院环节中西医处方的打印管理，覆盖西医处方（普通、麻精类、工伤、慢病、急诊、儿科等）和中医处方（中药饮片、中成药）全类型。

### 1.2 核心原则

- **合法性**：严格遵循《处方管理办法》《麻醉药品和精神药品管理条例》《长期处方管理规范》等法规；
- **规范性**：处方打印格式规范、内容完整、清晰可辨；
- **安全性**：确保患者信息安全，防止处方信息泄露；
- **便捷性**：优化打印流程，提高医疗工作效率；
- **可追溯性**：打印处方需具备可追溯性，便于后续管理和审计。

### 1.3 处方打印基础要求

| 处方类型    | 专用笺颜色 | 打印纸张规格   | 保存期限 | 门诊/住院核心差异            |
| ------- | ----- | -------- | ---- | -------------------- |
| 普通处方    | 白色    | A4/处方专用纸 | ≥1 年 | 门诊需打印患者基本信息，住院需打印住院号 |
| 精一类精神药品 | 淡红色   | A4/处方专用纸 | ≥3 年 | 门诊需打印患者身份证号，住院需打印住院号 |
| 精二类精神药品 | 白色    | A4/处方专用纸 | ≥2 年 | 需标注"精二"标识            |
| 麻醉药品    | 淡红色   | A4/处方专用纸 | ≥3 年 | 门诊需打印患者身份证号，住院需打印住院号 |
| 工伤处方    | 白色    | A4/处方专用纸 | ≥1 年 | 需标注"工伤"标识及工伤认定编号     |
| 慢病处方    | 白色    | A4/处方专用纸 | ≥1 年 | 长期处方需标注"长期处方"标识      |

| 中药饮片处方  | 专用笺   | A4/处方专用纸 | ≥1 年 | 需打印中医病名、证型及炮制方法      |

## 二、处方打印基础规范

### 2.1 打印格式要求

- **纸张选择**：应使用符合要求的处方专用纸，确保打印效果清晰；
- **字体规范**：使用标准宋体或仿宋体，字号不小于五号；
- **排版整齐**：项目齐全，内容清晰，不得涂改；
- **二维码/条形码**：每张处方应打印唯一的二维码或条形码，包含处方号等关键信息；
- **水印**：可添加医院名称、处方类型等水印，增强防伪性。

### 2.2 打印内容要求

- **患者信息**：姓名、性别、年龄（门诊）/住院号（住院）、身份证号（麻/精一）；
- **处方信息**：处方号、开具日期、有效期、医师签名、药师审核签名；
- **诊断信息**：主诊断（首位）、其他诊断（≤5个）；
- **药品信息**：药品通用名、规格、数量、用法用量、频次、给药途径；
- **处方类型标识**：如"急诊"、"儿科"、"精二"、"长期处方"等；
- **特殊标识**：如"工伤"、"麻精药品"等；
- **金额信息**：药品单价、数量、总价（可选）；
- **分方信息**：分方原因、分方序号（如有）。

### 2.3 打印流程要求

- **预览功能**：处方打印前应提供预览功能，确保内容正确；
- **打印确认**：医师确认处方内容无误后，点击打印按钮；
- **自动编号**：系统自动生成处方号并打印；
- **重复打印**：支持处方重复打印，但需标注"补发"字样；
- **打印记录**：系统应记录处方打印次数、时间、操作人员等信息。

## 三、门诊处方打印规则

### 3.1 普通门诊处方

- **打印内容**：患者姓名、性别、年龄、就诊卡号、诊断、药品信息、用法用量、医师签名、药师审核签名；
- **用量限制**：≤7日，特殊情况延长需注明理由并打印；
- **金额限制**：非慢病/非长处方单张金额超500元（可配置）需分方打印；
- **特殊要求**：空白处画斜线，医师签名与留样一致。

### 3.2 麻/精一门诊处方

- **打印内容**：患者姓名、性别、年龄、身份证号、诊断（≤3个）、药品信息、用法用量、医师签名、药师审核签名、代办人信息（如有）；
- **纸张要求**：淡红色处方笺；
- **用量限制**：注射剂1次常用量，控缓释制剂≤7日，其他剂型≤3日；
- **特殊要求**：单独打印，不得与其他药品同方。

### 3.3 精二门诊处方

- **打印内容**：患者姓名、性别、年龄、诊断（≤4个）、药品信息、用法用量、医师签名、药师审核签名；
- **纸张要求**：白色处方笺，需标注"精二"标识；
- **用量限制**：≤7日，慢病患者可延至14日（注明理由并打印），控缓释制剂≤15日；
- **特殊要求**：可与普通西药/中成药同方打印（≤5种）。

### 3.4 慢病门诊处方（长期处方）

- **打印内容**：患者姓名、性别、年龄、诊断、药品信息、用法用量、医师签名、药师审核签名、"长期处方"标识；
- **用量限制**：最长≤12周（90天），需打印医师评估意见；
- **金额限制**：不受500元分方限制，可单独打印1张；
- **特殊要求**：需打印患者确认信息。

### 3.5 急诊门诊处方

- **打印内容**：患者姓名、性别、年龄、诊断（≥1个急诊相关诊断）、药品信息、用法用量、医师签名、药师审核签名；
- **纸张要求**：淡黄色处方笺，标注"急诊"标识；
- **用量限制**：≤3日；
- **特殊要求**：可与普通/儿科处方同方打印（≤5种）。

### 3.6 儿科门诊处方

- **打印内容**：患者姓名、性别、日/月龄、体重、诊断、药品信息、用法用量、医师签名、药师审核签名；
- **纸张要求**：淡绿色处方笺，标注"儿科"标识；
- **用量限制**：普通儿科≤7日，急诊儿科≤3日，慢病儿科可延至12周；
- **特殊要求**：禁用儿童禁忌药，剂量按儿童年龄/体重计算。

### 3.7 中医门诊处方

- **中药饮片**：
  - 打印内容：患者姓名、性别、年龄、中医病名、证型、饮片名称、炮制方法、剂量、用法用量、医师签名、药师审核签名；
  - 纸张要求：专用处方笺；
  - 特殊要求：单独打印，不可与西药/中成药混开。
- **中成药**：
  - 打印内容：患者姓名、性别、年龄、中医诊断、药品信息、用法用量、医师签名、药师审核签名；
  - 纸张要求：白色处方笺；
  - 特殊要求：可与西药同方打印（≤5种）。

## 四、住院处方打印规则

### 4.1 普通住院处方

- **打印内容**：患者姓名、性别、年龄、住院号、诊断、药品信息、用法用量、医师签名、药师审核签名、"住院医嘱"标识；
- **用量限制**：无7日用量限制，按住院诊疗周期开具；
- **金额限制**：不受门诊500元分方限制；
- **特殊要求**：按治疗组/给药途径分方打印。

### 4.2 麻/精一住院处方

- **打印内容**：患者姓名、性别、年龄、住院号、诊断、药品信息、用法用量、医师签名、药师审核签名；
- **纸张要求**：淡红色处方笺；
- **用量限制**：逐日开具，每张处方1日常用量；
- **特殊要求**：单独打印，不可与任何其他药品同方。

### 4.3 精二住院处方

- **打印内容**：患者姓名、性别、年龄、住院号、诊断、药品信息、用法用量、医师签名、药师审核签名、"精二"标识；
- **纸张要求**：白色处方笺；
- **用量限制**：按住院治疗需求开具，无门诊7日限制；
- **特殊要求**：可与住院常规西药/中成药同方打印（≤5种）。

### 4.4 工伤/慢病住院处方

- **工伤处方**：
  - 打印内容：患者姓名、性别、年龄、住院号、诊断、"工伤"标识、工伤认定编号、药品信息、用法用量、医师签名、药师审核签名；
  - 特殊要求：用药符合工伤保险目录，超目录药品需注明理由并打印。
- **慢病住院处方**：
  - 打印内容：患者姓名、性别、年龄、住院号、诊断、药品信息、用法用量、医师签名、药师审核签名；
  - 特殊要求：按住院诊疗方案开具，出院带药可按门诊长期处方规则打印。

### 4.5 中医住院处方

- **中药饮片**：
  - 打印内容：患者姓名、性别、年龄、住院号、中医病名、证型、饮片名称、炮制方法、剂量、用法用量、医师签名、药师审核签名；
  - 纸张要求：专用处方笺；
  - 特殊要求：单独打印，可按住院疗程（如7-14日）开具。
- **中成药**：
  - 打印内容：患者姓名、性别、年龄、住院号、中医诊断、药品信息、用法用量、医师签名、药师审核签名；
  - 纸张要求：白色处方笺；
  - 特殊要求：可与住院西药同方打印（≤5种）。

## 五、分方打印规则

### 5.1 必须分方打印场景

- **含麻/精一药品**：单独淡红处方打印，不可与任何药品同方；
- **含中药饮片**：单独专用处方打印，与西药/中成药分方；
- **西药/中成药＞5种**：拆分多张处方打印，按诊断/疗程/类别分；
- **普通 + 麻/精一/饮片**：麻/精一、饮片各自单独分方打印；
- **工伤/慢病/急诊/儿科 + 麻/精一**：麻/精一单独分方打印，其余可同方打印（≤5种）；
- **医保系统触发金额异常**：按系统提示分方打印，医师注明理由。

### 5.2 分方打印规范

- **分方序号**：多张分方时，需打印分方序号（如"1/2"、"2/2"）；
- **分方原因**：打印分方原因（如"药品数量超限"、"金额超限"等）；
- **诊断关联**：不同诊断的药品应分别打印处方；
- **药品性质**：不同性质的药品应分别打印处方（如麻/精一单独打印）；
- **医嘱关联**：有分组ID的药品应保持在同一处方打印。

### 5.3 分方打印流程

1. **系统自动分方**：根据分方规则自动拆分处方；
2. **医师确认**：医师确认分方结果，可手动调整；
3. **批量打印**：支持多张处方批量打印；
4. **打印记录**：系统记录分方打印情况，包括分方原因、分方数量等。

## 六、审核与管理规则

### 6.1 打印前审核

- **内容审核**：医师在打印前应审核处方内容的完整性、准确性；
- **合规性审核**：系统自动检查处方合规性，如用量限制、金额限制等；
- **打印确认**：医师确认无误后，点击打印按钮。

### 6.2 打印后管理

- **处方归档**：打印后的处方应按类型分类归档，麻/精一单独专柜保存≥3年，精二≥2年，其余≥1年；
- **电子处方保存**：电子处方应按《电子病历应用管理规范》保存，可追溯、不可篡改；
- **打印记录管理**：系统应保存处方打印记录，包括打印时间、操作人员、打印次数等；
- **异常处理**：对重复打印、修改后打印等情况，系统应记录并提示。

### 6.3 质量控制

- **定期检查**：定期检查处方打印质量，确保内容清晰、格式规范；
- **满意度调查**：定期开展医师、药师对处方打印系统的满意度调查；
- **持续改进**：根据反馈持续优化处方打印流程和格式。

## 七、技术实现要点

### 7.1 系统架构

- **前端层**：医生工作站、护士工作站、药房工作站的处方打印界面；
- **应用服务层**：处方打印服务、处方审核服务、规则引擎；
- **数据访问层**：处方DAO、配置DAO；
- **数据存储层**：处方表、打印记录表、配置表。

### 7.2 核心功能实现

- **处方预览**：实现处方打印前的预览功能，确保内容正确；
- **批量打印**：支持多张处方批量打印，提高工作效率；
- **模板管理**：支持不同类型处方的打印模板管理，可根据需要调整；参考前端代码public/grf中的处方打印模板：
  - 西药中成药处方.grf
  - 中草药处方.grf
- **配置管理**：支持处方打印相关参数的配置，如纸张规格、字体大小等；
- **异常处理**：处理打印失败、纸张缺纸等异常情况。

### 7.3 接口设计

- **处方打印接口**：用于打印处方；
- **处方预览接口**：用于预览处方；
- **打印记录查询接口**：用于查询处方打印记录；
- **打印模板管理接口**：用于管理打印模板。

### 7.4 安全与性能

- **数据安全**：确保患者信息安全，防止处方信息泄露；
- **性能优化**：优化打印速度，确保系统响应及时；
- **可靠性**：确保打印系统稳定运行，减少故障。

## 九、风险评估

### 9.1 技术风险

| 风险        | 影响 | 概率 | 应对措施              |
| --------- | -- | -- | ----------------- |
| 打印格式兼容性问题 | 中  | 中  | 测试不同打印机型号，确保格式兼容  |
| 系统响应速度慢   | 中  | 低  | 优化打印处理逻辑，使用缓存     |
| 打印失败率高    | 高  | 低  | 增加打印失败重试机制，提供错误提示 |

### 9.2 业务风险

| 风险      | 影响 | 概率 | 应对措施            |
| ------- | -- | -- | --------------- |
| 医师操作不熟悉 | 中  | 中  | 提供详细培训，制作操作指南   |
| 打印纸张消耗大 | 中  | 高  | 优化打印格式，减少纸张使用   |
| 处方信息泄露  | 高  | 低  | 加强数据安全措施，限制打印权限 |

### 9.3 项目风险

| 风险   | 影响 | 概率 | 应对措施           |
| ---- | -- | -- | -------------- |
| 进度延期 | 中  | 中  | 合理排期，预留缓冲时间    |
| 资源不足 | 中  | 低  | 合理分配资源，必要时增加人力 |
| 需求变更 | 高  | 中  | 需求评审，变更管理      |
