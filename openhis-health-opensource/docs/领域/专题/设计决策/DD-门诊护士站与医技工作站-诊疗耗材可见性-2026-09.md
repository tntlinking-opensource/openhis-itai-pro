## 1. 两条独立判定轴

| 轴 | 对象 | 真源字段 |
| --- | --- | --- |
| 诊疗可见性 | `ServiceRequest` | 执行科室 `org_id` → `Organization.class_enum` |
| 耗材可见性 | `DeviceRequest` / 发放行 | **发放耗材房** → Location **上级科室** `organization_id` → `class_enum` |

不按「耗材绑定哪条诊疗」拆行。

**患者列表不另立规则**：左侧出现 ⇔ 本站按 §2/§3「有活」。点选后中/右同轴过滤；禁止队列宽收、明细空单。

## 2. 中区诊疗可见性（门诊护士站 vs 医技站）

| 工作站 | 可见诊疗 |
| --- | --- |
| **医技站**（登录某 TECH 科） | 执行科室 = 当前登录医技科 |
| **门诊护士站** | 执行科室 **≠ TECH**（含 NS、口腔/康复等自执行） |

医技站切「住院」时：仍按「执行科室 = 登录 TECH」收窄，就诊类别改为住院。

## 3. 右侧耗材可见性（发放耗材房）

| 挂靠科室解析结果 | 谁看见 |
| --- | --- |
| 挂靠 = 登录医技科 | 仅该医技站 |
| 挂靠为 TECH，且是登录科的祖先（如药房挂「医技」、登录放射科） | 该登录医技站可见；护士站不可见 |
| 登录科是挂靠科室的祖先，且挂靠侧链路含 TECH | 该登录医技站可见；护士站不可见 |
| 挂靠侧自身或祖先 `class_enum=TECH`，但与登录科无祖先链关系 | 护士站不可见；其它医技科本站不可见 |
| 挂靠侧链路无 TECH | 门诊护士站 |
| 空 / 解析不到 | 门诊护士站（兜底） |

**解析**：有效库位优先 `DeviceRequest.location_id`，为空回落主发放 `DeviceDispense.location_id`（请求未写库位的院点）。再自 `Location.organization_id` 沿 `Organization.parent_id` 上溯找最近 TECH。护士站凡挂靠侧链路含 TECH 即排除。医技站：挂靠 = 登录科，或挂靠最近 TECH / 登录科互为祖先链对齐时可见；**禁止**「任意 TECH 互看」（检验科不得见超声科耗材房）。CT↔DR 等同站互看仅适用于**诊疗**共看组（`MedicalTechSharedExecutingOrgSupport`），**不**扩到耗材房。实现：`DeviceSupplyTechVisibilitySupport`。

门诊护士站须排除 TECH 耗材房行。自执行项目与其科室药房耗材都进门诊护士站。

## 3.1 检验（类目 22）在门诊护士站的例外

TECH 执行科室的**真实检验项目**仍进入 IF-NUR-02 诊疗列表，**仅供**前端下方「医技列表」打印采血贴；**不得**进入上方待执行勾选/批量执行。合管派生「采血费」（内置名称精确匹配，类目虽锁定为 22）**不**走本例外、**不**打采血贴（仅计费）。检查等其它 TECH 诊疗仍完全不进护士站。
