## 1. 问题与目标

医生可开「不足 1 个拆零单位」的单次量（例：甘精胰岛素一次 0.03 支、口服半片）。
实物无法按滴/按半片零售：划价、发药、扣库须按 **至少 1 个拆零单位** 走。
领用一整拆零后患者按医嘱慢慢消耗；改量停旧开新时若立刻再出下一单位待执行，会重复领用。

| 目标 | 口径 |
| --- | --- |
| **产品默认** | 单次临床拆零量 &lt; 1 → 执行侧按 1 拆零单位计费/发药；列表按「满 1 拆零单位」合并时间点 |
| **院点特殊** | 不可拆开关关闭且口服 + 包装≠拆零 → 仍按包装一盒一点（BR-IP-EXE-035），优先于本规则 |
| **剩余 / 改量 / 出院** | 与口服一盒一点 **同一套 BR-IP-EXE-038 算法**；差异仅「每次领入 = **1** 拆零」（非 `packageUnitRatio`） |
| **输液 / 皮下** | 药典 `inject_flag=true` 默认开瓶即弃（**不**切批/不续算）；用法展示名以「皮下注射」开头时**放行**（胰岛素等余量接着用，即使目录为输液）；写路径仍可抬到 1 拆零 |

## 2. 产品规则（BR-IP-EXE-036）

### 2.1 写路径（计费 / 发药 / 扣库同源）

1. 先解析本槽**临床量**（含长嘱首日换量；一盒一点时已是 1 包装则跳过本规则）。  
2. 换算为拆零量；若 `0 < split < 1`：  
   - `quantity = 1`  
   - `unitCode = splitUnitCode`  
3. Charge / Dispense / 库存 Gate demand **同一**抬量后业务量。  
4. 临嘱单槽同规则（不足 1 拆零也抬到 1）。

### 2.2 列表锚点（长嘱）

1. 在首日槽裁剪之后，用**临床**拆零量（禁止用已抬量）累加。  
2. 累加 `>= 1` 关闭一单位，回传该单位**首槽** `planTime`；余量滚入下一单位。  
3. 硬顶下未凑满当前单位：仍回传该单位首槽（首滴即开整单位）。  
4. pending **同时至多一个**单位首槽（与一盒一点同形态）。  
5. 单槽临床拆零 `>= 1`：不触发本规则，保持可拆日点。

### 2.3 与半片 / 胰岛素示例

| 开立 | 产品默认 | 院点一盒一点（若命中） |
| --- | --- | --- |
| 半片 QD | 约两天一个锚点；每次执行 1 片量+价 | 按包装凑整盒；整盒一个锚点 |
| 0.03 支 QD | 凑满约 1 支临床额度出一个锚点；执行 1 支量+价 | 不适用（非口服包装切盒资格时） |

## 3. 剩余计数 · 改量 · 出院（BR-IP-EXE-038 · MIN_SPLIT）

> **权威算法**见 `DD-住院长嘱口服一盒一点剩余计数与改量-2026-08`；本节只写与口服的**差异与接线**。  
> 展示字段仍用既有 `oralPackage*` 契约名（语义=单位领用剩余，含拆零下限）。

### 3.1 资格

- 长期药品 + 常规单次临床拆零 `0 < split < 1`（与列表切批同源）+ **非「输液开瓶即弃」**
- **开瓶即弃判定**：药典 `injectFlag=true` **且**用法展示名**不以**「皮下注射」开头 → 跳过列表切批与本模式剩余（保持可拆日点）
- **皮下放行**：`injectFlag=true` 但用法为「皮下注射」→ **仍命中**（胰岛素等余量接着用）
- 非输液目录（半片等）仍按原规则，**不**要求口服用法、**不**要求院点不可拆
- 若同条已命中一盒一点（035）→ **只走 PACKAGE 模式**，本模式不叠
- 写路径抬量（不足 1 拆零 → 1）与列表切批正交

### 3.2 领入 / 已吃 / 下次领用日

| 项 | 口径 |
| --- | --- |
| **领入** | 链上净 COMPLETED 单位首槽执行次数 × **1** 拆零 |
| **已吃 / 改量当天 max(旧,新) / 观察期冻结 / asOf 钳今天** | 与 PACKAGE **完全相同** |
| **下次领用日** | 自首领用日起按链日需求扣领入；首个「当日需求 &gt; 行走剩余」之日；pending 锚该日首频次点；过早 pending **抑制**；空窗 **补回**（补点须认不执行/净已执行终态，与 PACKAGE 同 **BR-IP-EXE-038**） |
| **改量** | 仍 **IF-IP-DOR-28 / BR-IP-ORD-032**（`based_on` 药嘱链）；无 basedOn 手停重开不续算 |

### 3.3 出院门禁 / 待执计数

- **BR-IP-ATD-011①′** / ATD-03 `listLongTermStoppedPendingPlanTimes`：切批后须再经 **BR-IP-EXE-038** 抑制（含 MIN_SPLIT）；剩余仍够 → **无假 pending** → **不拦**出院；**不执行后不得补假 pending**  
- **BR-IP-NUR-005** 待执计数与列表 pending **同源**抑制 + 领用日补锚（补点同认不执行终态）  
- 真 pending 须出 Tab / **IF-IP-EXE-04** 登记不执行（停嘱校对**不**自动 skip）

### 3.4 示例（0.03 支 QD）

1. 执行领 1 支后：理论日耗 0.03 → 约 33 天够用；期内**无**下一单位 pending；列表展示已吃/剩余/预计下次领用日。  
2. 改量至 0.05 支：按新量重算够吃末日；观察期（已停未开新）不扣。  
3. 改量停旧嘱若切批假锚点被抑制殆尽 → 出院门禁不因假 pending 拦截。
