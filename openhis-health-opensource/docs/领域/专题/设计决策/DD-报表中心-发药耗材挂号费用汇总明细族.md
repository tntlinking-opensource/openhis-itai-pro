## 3. 分族口径（勿混）

### 3.0 发放 + 领用（药 / 耗材共用骨架）

| 项 | 口径 |
| --- | --- |
| **两路并集** | **患者侧发放（含退）** ∪ **科室侧领用（含退领）**；明细须标 **来源** |
| **科室侧** | `SupplyRequest` / `SupplyDelivery`：已同意 **`DEPT_ISSUE`**（领用）及 **`DEPT_ISSUE_RETURN`**（退领对冲）；按行 **`item_table`** 拆药品 vs 耗材（领用单本身可选药品/耗材，见 **AS-INV-DEP-004**） |
| **域收窄** | 门诊报表 ↔ 门诊相关科室药房领用；住院报表 ↔ 住院相关科室药房领用（SDD 定组织/库位谓词） |
| **药 vs 耗差异** | **同**两路并集；**异**在汇总主关注点（见下）：药保留 **类型** 维；耗材 **禁止**类型主汇总，偏患者/科室用量 |

### 3.1 发药报表（RPT-003 / 004）

| 项 | 口径 |
| --- | --- |
| **页面来源** | 门诊侧可由「门诊发退药记录」菜单壳进报表；住院侧以 **AS-RPT-004** 为准（旧发退药记录页已废止）；**不另开**平行药品页 |
| **事实源（并集）** | ① **患者侧**：`MedicationDispense` 发/退 + `ChargeItem`（现价装载族）<br>② **科室侧**：药品行 **`DEPT_ISSUE` / `DEPT_ISSUE_RETURN`**（门诊或住院科室药房领用/退领） |
| **明细** | 两路并集平铺；含发退/退领；字段尽量全；须区分 **患者发药** vs **科室领用** |
| **汇总** | **净用量/净金额**：按 **药房**、按 **品规**、按 **药品类型**（西药/中成药/中草药等）；并支持按 **科室** 看领用净量（及必要的患者发药净量视角） |
| **非目标** | 耗材行；用药明细（PHA-005）；写路径发退药/领用制单 |

### 3.2 耗材使用报表（RPT-005 / 006）— **与药不完全一样**

| 项 | 口径 |
| --- | --- |
| **成对关系** | 门诊/住院各一页；**同为发放+领用并集**，汇总主维与药不同 |
| **事实源（并集）** | ① **患者侧**：`DeviceDispense` + `ChargeItem`<br>② **科室侧**：耗材行 **`DEPT_ISSUE` / `DEPT_ISSUE_RETURN`**（与发药报表共用领用单能力，按 `item_table` 拆耗材） |
| **明细** | 含收退/退领；字段尽量全；须区分 **患者使用** vs **科室领用**；含 **执行人**（发耗材人：患者侧 `performer_id`、科室侧 `approver_id`） |
| **汇总（关注点）** | **患者用了多少**、**科室用了多少**（及必要的库房/品规净量净额） |
| **明确不做** | **不要**按「西药/中药式类型」做耗材主汇总（与发药汇总不同） |
| **非目标** | 护士工作量按护士统计（**AS-RPT-002**）；发药报表；纯价表明细 |

### 3.3 门诊挂号明细（RPT-007）

| 项 | 口径 |
| --- | --- |
| **汇总** | 按 **科室** 或按 **医生**：每天挂了多少 **便民 / 普通 / 专家**（号源类型）；**净**（退号冲减） |
| **明细** | 谁挂了什么号；自费/医保、医保类型等；字段尽量全 |
| **非目标** | 住院挂号；医生工作量整页（**AS-RPT-001** 可复用号源口径但不并页） |

### 3.4 费用明细（RPT-008 / 009）

| 项 | 口径 |
| --- | --- |
| **明细** | 门诊对齐现 **AS-OP-FIN-005**；住院同构（就诊块 + 财务金额列 + 收退） |
| **汇总** | **按费用类型净额**：西药 / 治疗 / 检查 / 检验等（`fin_type` / 大类细分类，与日结同精神） |
| **非目标** | 护士站在院费用操作页；未结算过程态为主入口 |

### 3.5 住院患者入出明细（RPT-010）

| 项 | 口径 |
| --- | --- |
| **形态** | 单列表 + 页脚人次（**不**强制汇总/明细双 Tab） |
| **筛选** | 日期窗；状态全部/入院/出院；**入院科室**、**入院病区**（科室→病区联动，不按病房床位筛） |
| **明细** | 一行一 Encounter；患者信息 + 当前/末次病区病房床；已结费用一列（无净额/待重结 → 空，禁止 0）；有转科则动态「转往」列 |
| **人次** | 按 Encounter：入院人次 / 出院人次（全部时两侧可重叠计） |
| **非目标** | 在院名单；费用类型拆分；与 **AS-RPT-009** 并页 |
