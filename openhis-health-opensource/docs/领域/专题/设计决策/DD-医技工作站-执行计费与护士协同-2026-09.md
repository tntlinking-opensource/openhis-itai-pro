> **范围**：**仅住院**。

> **导航**：`DD-医技工作站-模块索引-2026-09.md`

## 0. 原则

| 原则 | 口径 |
| --- | --- |
| **护士 / 医技互不卡** | 各收医生指令行事；取消本侧不互卡对方 |
| **执行记录隔离** | `cln_procedure.org_id` = **登录工作科室**（护士写 NS、医技写 TECH）；用组织 `class_enum` 分侧；**禁止**再以 `org_id` 空当护士侧（历史空值回填） |
| **出院硬校验** | 凡执行科室为 TECH 的诊疗项目，须有**该执行科**医技侧净剩 COMPLETED Procedure；耗材：自动扣库开→划完即完；关→须发放 COMPLETED |
| **医生签退** | **原门禁不动**（`InpatientAdviceRevokeGate` 扫全部净剩 Procedure）；医技已执行则须先取消医技执行（净剩含 TECH 行即拦） |
| **一键确费** | **下线入口**（前端隐藏；后端 IF/字段可保留不删）；出院**不再**读 `fee_confirmer_*` |

## 1. 两种「执行」

| 动作 | 含义 | 落点 |
| --- | --- | --- |
| 护士执行 | **计费** | 护士侧 Procedure（`org_id`=登录 NS）+ Charge |
| 医技执行 | **临床已做（=确费语义）** | 医技侧 Procedure（`org_id`=登录 TECH）；**不建诊疗 Charge** |
| 医技计费 | **只划耗材** | 登录科耗材房；计费+发放；扣库随自动扣库开关 |

- 诊疗费：护士执行挂。  
- **不要求**护士/医技谁先执行。  
- 医技项目**无长期**（临时）。  
- 护士划价**禁止**执行科室为 TECH 的诊疗（后端 Gate；耗材本期不挡）。

## 2. 执行记录隔离

| 侧 | `Procedure.org_id` | 回显 / 次数 / 工作量 |
| --- | --- | --- |
| 护士 | 登录工作科室（NS） | 仅计 `class_enum≠TECH`（含历史 `org_id` 空） |
| 医技 | 登录 TECH 科 | 仅计该 TECH `org_id` |

取消各自取消本侧；**不**互卡。

## 3. 出院（BR-IP-ATD-011⑤）

| 项 | 口径 |
| --- | --- |
| **对象** | 就诊下医生开立诊疗 SR：**执行科室 `class_enum=TECH`**（与门诊医技可见性同轴）；按**项目**校验，不以登录科汇总 |
| **通过条件** | 该 SR 存在医技侧净剩 COMPLETED（`Procedure.org_id` = SR 执行科室） |
| **候选状态** | 同出院校验其它临时项（已校对/已停嘱候选与 ATD-03 同轴） |
| **耗材** | `medical-tech-pricing`：自动扣库开→不额外拦；关→主发放须 `COMPLETED` |
| **异常** | `EX-IP-ATD-309`：请完成医技执行后再办理出院 |
| **不做** | 不再卡 `fee_confirmer_id`；无 TECH 执行科项目 → 不拦 |

## 4. 医生签退（加逻辑、不改原护士门禁）

签退仍走 `InpatientAdviceRevokeGate`（无净剩 COMPLETED / 无阻塞发药费用）。  
医技执行写入的 TECH Procedure 计入净剩 → 须先医技取消后再签退。  
从未医技执行则行为与改前一致。
