## 2. 金额列（统一）

| 列 | 规则 |
| --- | --- |
| **售价单价 / 售价总价** | 优先**账单本身**（患者侧 `ChargeItem.unit_price` / `total_price`）；**禁止**查 Payment、禁止目录 `SALE`。**仅白名单可回落批号售价**：① **药房日结**；② **住院发药报表/药品使用明细**（账单缺失时正/退同行，与日结轧差对齐；含取消执行删账）。回落时同批号 `LOT_NUMBER_PRICE` + **调价回放与进价同构**。其它报表/费用明细/门诊发退药等**禁止**售价回落，只认账单 |
| **进价单价 / 进价总价** | 来自**对应批号进价**（`LOT_NUMBER_COST`；缺则可同批号 `LOT_NUMBER_PRICE` 回落——入库时西药/耗材 1:1 写入）；调价回放仅波及批号；**禁止**目录参考价 `PURCHASE`/`SALE` |
| **诊疗 / 挂号** | **无进价**（列空/不编）；售价仍跟账单 |
| **应收 / 实收 / 其它金额列** | **本轮全部去掉**（展示与汇总都不留） |

### 2.1 平进平出（勿误解）

- **不是**报表层「进售查同一字段伪装一致」。
- **是**入库写定价时批号进/售 **1:1** 落库；报表分别查批号进价、批号售价，写对了自然一致。
- **中药**进≠售：进货时系统对售价加价写入定价表，报表照读。

### 2.2 单位与合计（硬规则）

| 规则 | 说明 |
| --- | --- |
| **定价锚** | 定价表一律**包装单位**；系统**不存**拆零进/售价 |
| **单价展示** | 与操作单位同阶：包装操作回包装价；拆零操作才折展示拆零价（**仅展示**，禁止用展示拆零价再×数量） |
| **单条进价合计（按操作单位分支）** | ① 操作单位已是包装：`包装价 × 包装数量`（**禁止**先折成拆零量再算）；② 操作单位是拆零：`满包×包装价 + 零头（包装价×余量/ratio 单步）`（BR-MON-PKG-001）；**禁止**包装价÷ratio 得拆零价再×数量 |
| **实现真源** | `ChargeItemPackageUnitRatioSupport#computePurchaseLineAmount`（ChargeItem / 发药 `unitCode` 共用）；禁止裸 `lineTotal(LOT_NUMBER_COST, quantity)` 不判单位 |
| **汇总 / 页脚** | 与明细同筛选；**本质是账单/发放行进价总额加和**；禁止报表层用「展示单价×数量」另算一套；汇总 Tab：**数量** + **进价合计/售价合计**；**进价单价/售价单价仅品规（`ITEM`）维展示**；**不展示行数**；药品进价合计一律 `sumThenPurchaseSettle`（3 位；无中药第三位为 0，不按分类分支）；售价一律 2 位；**耗材报表进价仍 2 位** |
| **明细 / 汇总接口** | 分接口；单表内明细与汇总必须一致 |
| **进价列角加载（强制）** | 见 **§2.4**：明细分页全窗进价列角独立 IF（Type A）；汇总/卡片页脚进价=当次返回行加总（Type B）；均须与查询同筛选，且与表内进价同管线 |

### 2.3 调价重现

- **进价**：只对**被调价波及的批号**回放**当时**批号进价；未波及批号不做进价重现；**禁止**把历史行编成调价后进价。
- **售价**：有账单时**不**回放（跟账单）。**仅**在售价批号回落白名单（药房日结 / 住院发药报表账单缺失行）且账单缺失时：同批号 `LOT_NUMBER_PRICE` 调价回放与进价同构；**禁止**目录 `SALE`。
- 其它场景患者侧售价仍只认账单，**禁止**为「对齐进价」而回落/回放售价。

### 2.4 进价列角加载模式（性能 + 正确性）

> **正确性优先于「先出数字」**：页脚进价必须与**同一次查询条件下**明细/汇总表内进价代数和一致；禁止另写定价分支或另扫筛选轴。

| 类型 | 适用 | 加载 | 正确性硬约束 |
| --- | --- | --- | --- |
| **Type A · 明细分页全窗列角** | 费用明细门/住 **明细 Tab**（页仅本页行，页脚要**全命中 scope**进价） | ① `page*` 先出列表 + **售价**列角（进价字段可空）；② 独立 IF `summarize*PurchaseCorner`，**Request 与 page 同筛选**（分页字段忽略），异步回填进价列角 | 列角与 `HistoricalChargeItemPurchasePriceSupport` / `FeeDetailMatchedScopePurchaseTotalSupport` **同管线**；与导出全窗行进价加总可对平；**禁止**用本页行加总冒充全窗列角 |
| **Type B · 汇总/卡片同源列角** | 费用明细**汇总 Tab**；发药/耗材**汇总**；护士卡片墙；医生工作量汇总栏 | 汇总/卡片 IF **同请求**返回行（含行进价）；页脚进价 = **当次返回行进价代数和**（前端可用 `sumReportPurchaseCornerFromRows` 强制对齐）；不另开重扫 IF | 页脚字段必须等于表内进价列加总；**禁止**页脚另扫事实/另套定价；查询条件变更后须与行一并刷新 |

**BR-RPT-PUR-CORNER-001**：列角 IF / 页脚加总的筛选轴与主查询（日期、科室、收退、维度、来源等）一致。  
**BR-RPT-PUR-CORNER-002**：列角进价与表内进价同一 `HistoricalChargeItemPurchasePriceSupport`（或报表约定 enricher）口径。  
**BR-RPT-PUR-CORNER-003**：Type B 页脚进价 ≠ 表内行加总 → 缺陷（以前端加总纠偏或修后端）。

## 6. 读价锚点（成码对照）

| 场景 | 允许 | 禁止 |
| --- | --- | --- |
| 患者侧售价 | `ChargeItem` 落库价；退药**写路径不生成自身账单**（设计），读侧**禁止**只 JOIN 退药 `dispense_id`；须补原正向发放售价再取负（`supplementRefundPricingFromOriginMedicationRequests`；**同数量总额绝对值与正向一致**；门/住发药报表汇总与明细同口径）；**仅**药房日结 / 住院发药报表在原正向仍不可得时回落批号 `LOT_NUMBER_PRICE`（正/退同行，调价回放同进价） | Payment；目录 `SALE`；参考价；其它报表回落批号售价；**汇总只冲进价不冲售价**；**仅 JOIN 退药自身 `dispense_id`**；补价用单价×数量另算与发药尾差 |
| 患者侧进价 | 批号 `LOT_NUMBER_COST`（同批号调价回放）；**按操作单位分支**行合计；账单缺失可按发放批号回落（正/退）；**门诊退药售价仍空时禁止单独回落进价**（#4M-RFND） | 目录 `PURCHASE`；串批；调价后价冒充历史；一律当拆零量走 `computeSplitQuantityLineTotal`；`包装价×数量` 不判 `quantity_unit`/`unitCode` |
| 领用侧 | Supply `price` / `total_price`（进价） | 编售价；目录参考价 |
| 诊疗 | 售价=账单；进价空 | 用账单单价冒充进价（废止旧「诊疗进价=账单价」统计口径） |
| 耗材退耗售价 | 退行 `basedOnDispenseId` 回挂源 COMPLETED 发放账单；部分退按数量折算再取负 | 只匹配退耗自身 `dispense_id`；请求级全量累加 FIFO 分段账单 |
| 药房日结进价 | 同患者侧：批号包装进价 + `ChargeItemPackageUnitRatioSupport` 按 `unitCode` 分支 | `lineTotal(LOT_NUMBER_COST, dispenseQuantity)` 不判单位 |
| 药房日结售价 / 交账头 | 优先账单；退药不查自身账单、补原正向再取负（同数量与发药总额绝对值一致）；原正向仍不可得时回落批号 `LOT_NUMBER_PRICE`（白名单）；头表 `total_income`=**售价合计**（非利润；提交现算） | 目录 `SALE`；有账单仍回落批号价；仅 JOIN 退药自身账单漏补价；补价另算与发药尾差 |
| 住院发药报表售价 | 优先账单/原正向补读；仍缺则批号售价回落（正/退同行，同日结） | 门诊发退药记录回落批号售价；费用明细回落 |
| 住院发药报表账单缺失 | 正/退 → 批号进价 +（住院）批号售价；费用性质账户缺失 → 就诊优先合同 | 门诊发药报表批号售价；**费用明细**批号售价/删账回落 |
| 护士划价/执行耗材写价 | FIFO 定批后按实发 `lotNumber` 重算 `definitionId`/单价再挂账 | 列表预填 definition 与 FIFO 串批 |

实现上：药耗历史进价/白名单售价回落走 `HistoricalChargeItemPurchasePriceSupport`（须传 `productByCompositeKey`）；行额委托 `ChargeItemPackageUnitRatioSupport#computePurchaseLineAmount`；发药报表见 `MedicationDispenseReportPricingEnricher`；退药补价见 `PharmacyDispenseRecordChargePricingAssembler`；耗材 basedOn 见 `ConsumableUsageReportAmountEnricher`。

### 6.1 账批质检（使用明细分页；不改正额）

| 项 | 口径 |
| --- | --- |
| **目的** | 显式暴露「挂账批号 ≠ 实发批号」脏数据；**不**改售价/进价统计口径 |
| **范围** | 门诊/住院药品使用明细、门诊/住院耗材使用明细的 **明细 Tab**；汇总 Tab / 汇总金额路径 **禁止** |
| **账批** | `ChargeItem.definitionId` → `LOT_NUMBER_PRICE`/`LOT_NUMBER_COST` 行 `lot_no`（`mapChargeAnchorLotByDispenseId`；**不读发放表**） |
| **实发批** | `MedicationDispense`/`DeviceDispense.lot_number`（明细已有列） |
| **输出** | `chargeLotNumber` + `lotMismatch=true`（两边均有且不等）；科室领用/无账单/任一侧无批号不打标 |
| **性能** | 复用本页 ChargeItem；额外仅一次 definitionId IN；禁止为比对再扫发放或 N+1 |
