## 1. 背景与结论摘要

### 1.1 老系统典型事故（疗区药房 2026-06）

| 来源 | 金额 | 口径 |
| --- | ---: | --- |
| 财务凭证 1405.05 贷方「5.28–6.30 疗区药品消耗」 | **7,555.69** | 库存**进价**出库（应入账项） |
| Excel Sheet3「疗区**收入**」 | **7,555.69** | 与凭证一致 → **抄了收入列** |
| Excel Sheet3「疗区**支出**」 | **9,621.06** | 更接近发药**进价**汇总 |
| 当前 BIRT 住院发药汇总（store79，FY_TIME 5.28–6.30） | **9,828.45** | 发药进价；关账后补录会继续变 |
| BIRT「发药金额」（RETAIL_PRICE×数量） | **9,688.97** | **售价**，不可入库存成本账 |

**根因归类**（非单一计算错误）：

1. **列混用**：收入 / 支出 / 发药售价 / 发药进价 四列并排，财务手抄入账。
2. **口径混用**：库存科目 1405.05 应记**进价消耗**，报表默认展示**发药金额（售价）**。
3. **时点混用**：5.28–6.30 自定义区间 vs 自然月 6 月 vs 7.1 早盘点 vs 6.30 明细账余额。
4. **范围混用**：疗区药房（西药 store79）vs 中草药向疗区支出（Sheet4 527.04）vs 调拨分项。
5. **无快照**：发药汇总为 **FY_TIME 实时扫库**，关账后补录/退药/调价导致历史报表漂移。

### 1.2 新系统目标（一句话）

> **财务只从「已冻结的库存关账快照」生成凭证；UI 上「发药售价」与「发药进价」不可混为一列；任何数字可回答：什么仓库、什么期间、什么口径、哪次关账。**

### 1.3 与 SYS-IMP-010 的分工

| 主题 | SYS-IMP-010 | 本文件 SYS-IMP-015 |
| --- | --- | --- |
| 对象 | 收费 Payment、C 类日结报表 | 库存 movement、发药出库、1405 等库存科目 |
| 快照 | `fin_daily_close_line`（收入侧） | `inv_closing_snapshot`（成本侧） |
| 共性 | **交账/关账后不可变 + 报表只读 snapshot** | 同构实现，凭证推送对称 |

## 2. 设计原则

| # | 原则 | 老系统反例 | 新系统要求 |
| --- | --- | --- | --- |
| P-01 | **一个关账动作 = 一份不可变快照** | 发药汇总随补录变化 | 关账确认后行级明细只读 |
| P-02 | **财务只认进价，业务可看售价** | 发药金额当消耗入账 | 凭证绑定「库存出库进价」指标 |
| P-03 | **凭证从系统推送，禁止手抄 Excel** | Sheet3 收入/支出抄错列 | 关账 → 对账确认 → 生成待审凭证 |
| P-04 | **对账是流程，不是万能导出** | Sheet3/Sheet4/库存汇总各算各的 | 同一对账工作台，差异结构化下钻 |
| P-05 | **期间·仓库·业务类型三维必选** | 疗区药房 vs 中草药疗区混淆 | 筛选器固定展示当前三维 |
| P-06 | **实时 vs 快照 UI 可区分** | 7.1 导出当 6.30 账 | 未关账黄条 / 已关账绿锁 / 已推送蓝链 |

## 3. 功能模块

```text
日常业务（发药/入库/调拨/报损）
        ↓
  实时看板（标注「未关账·仅供参考」）
        ↓
  月末预关账（差异清单 + 处理/强制说明）
        ↓
  库存关账（按仓库/科目组冻结 snapshot）
        ↓
  财务对账工作台 → 预览凭证 → 推送总账
        ↓
  （可选）盘点衔接 → 盘盈盘亏调整单
```

### 3.1 实时看板（药房/库管）

- **用途**：日常查询，**不得**作为财务入账依据。
- **展示**：发药量、发药进价、发药售价、退药；分门诊/住院/仓库。
- **Banner**：`未关账数据 · 按发药时间 FY_TIME 实时统计 · 补录后会变化`

### 3.2 月末预关账（药房主管）

关账前自动扫描（可配置阻断/警告）：

| 检查项 | 说明 | 默认 |
| --- | --- | --- |
| 已收费未发药 | 收入已记、库存未出 | 警告 |
| 已发药未收费 | 库存已扣、收入未记 | 警告 |
| 跨期发药 | 收费在期内、FY_TIME 在期外 | 警告 + 金额 |
| 跨期退费 | 收费在期内、退药/退费在期外 | 警告 + 金额 |
| 未审核调拨/报损 | 影响出库分项 | **阻断** |
| 进价缺失 | part_price / 批次价为空 | **阻断** |

**UI**：清单表格 + 跳转单据 + 顶部「仍有关闭风险 N 项」；全部处理或填写「强制关账原因」后方可进入关账确认。

### 3.3 库存关账（核心）

一次关账生成一条 **InventoryClosing** 记录：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `closing_no` | `INV-2026-06-STORE79` | 关账编号 |
| `period_start` / `period_end` | 2026-05-28 ~ 2026-06-30 | 可与会计月不一致，须显式配置 |
| `store_id` | 疗区药房 | 单仓库关账；合并关账另建父单 |
| `cost_basis_version` | `cost-v1` | 进价算法版本（BIRT 复刻公式哈希） |
| `frozen_at` | 2026-07-01 08:00 | 快照时刻 |
| `status` | DRAFT → CONFIRMED → GL_PUSHED → VOID | 见 §5 状态机 |

**快照固化内容**：

- 汇总：期初、入库、出库分项（门诊发药进价/住院发药进价/退药/调拨出/调拨入/报损）、期末。
- 明细：`inv_closing_line` 行级（可下钻到发药单 GD_ID / movement_id）。
- **出库入账金额 = 发药进价净额 + 报损进价 + 调拨净额**；**发药售价仅写入 `reference_metrics` 供分析**。

关账确认后：该 `(store, period)` **只读**；变更仅能通过 **关账后调整单**（记入下期或红字冲销）。

### 3.4 财务对账工作台（计财科）

**不是**导出 Excel 手算，而是绑定关账快照的对账页：

```text
┌──────────────────────────────────────────────────────────────┐
│ 库存对账 · 2026-06 · 疗区药房 · 科目 1405.05                  │
│ 关账快照 INV-2026-06-STORE79  [已冻结 2026-07-01 08:00]  🔒   │
├──────────────────────────────────────────────────────────────┤
│ 【库存成本账 · 财务入账区】              【收入参考 · 不入账】 │
│  期初库存           10,820.79            发药售价合计  9,688.97 │
│  + 本期入库          1,455.02            退药售价          0.00 │
│  - 发药出库进价      9,828.45  ← 凭证     （灰色折叠区）        │
│  - 调拨/报损           340.31                                   │
│  = 期末库存         12,238.81  ✓                              │
├──────────────────────────────────────────────────────────────┤
│ 结构化差异（0 项阻断）                                          │
│  · 与上期衔接 ✓   · 与 7.1 盘点 ⚠ 差 100.00 [下钻]            │
├──────────────────────────────────────────────────────────────┤
│ 待生成凭证（金额取自快照，不可手改）                            │
│  借：主营业务成本 / 疗区药品消耗     9,828.45                   │
│  贷：库存商品 / 疗区药房             9,828.45                   │
│  [预览凭证]  [推送总账]  [导出审计包 PDF+明细]                  │
└──────────────────────────────────────────────────────────────┘
```

### 3.5 关账后调整单

| 场景 | 处理方式 |
| --- | --- |
| 关账后发现漏发药 | 调整单关联原关账号；金额进 **下一期** 或 **红字冲销原凭证** |
| 进价追溯修正 | 调整单 + 算法版本升级说明；**不回写**已冻结 snapshot |
| 盘点差异 | 盘盈盘亏单；与关账快照并列展示，单独凭证 |

## 4. UI 与指标展现规范

### 4.1 指标命名（禁止裸写「发药金额」）

所有指标经 **MetricDefinition** 字典输出 label，格式：**名称（口径说明，时间轴）**。

| code | 界面 label | 用于 GL | 时间轴 |
| --- | --- | --- | --- |
| `disp_cost_gross` | 发药出库进价 | ✓ | FY_TIME / 关账快照 |
| `disp_retail_gross` | 发药售价合计 | ✗ | FY_TIME |
| `disp_retail_net` | 发药售价净额（扣退药） | ✗ | FY_TIME |
| `inv_opening` | 期初库存进价 | ✓ | 关账快照 |
| `inv_closing` | 期末库存进价 | ✓ | 关账快照 |

Tooltip 必含：**适用科目、不含范围、数据来源表/快照号**。

### 4.2 布局：成本账 vs 售价参考

- **左侧（默认展开、高亮）**：库存成本账 — 唯一可绑定凭证。
- **右侧（默认折叠或灰底）**：售价/收入参考 — 页面级标注「**不入库存账**」。
- **禁止**将「收入」「支出」两列并排供手抄（老系统 Sheet3 模式）。

### 4.3 关账状态 Banner

| status | Banner | 操作限制 |
| --- | --- | --- |
| 无关账 / DRAFT | 🟡 未关账 · 实时数据 | 可导出，导出带「非快照」水印 |
| CONFIRMED | 🟢 已关账 INV-xxx · 冻结于 … | 业务补录进调整单 |
| GL_PUSHED | 🔵 凭证记-xxx 已推送 | 仅主管反冲流程 |
| VOID | ⚪ 已作废 | 只读审计 |

### 4.4 导出规则

- 必须选择 **关账版本号**；禁止无版本「当前实时」导出用于财务。
- PDF/Excel 页眉：`INV-xxx · frozen_at · cost_basis_version`。
- 水印：`已关账快照，非实时数据`。

### 4.5 三条线同屏（可选高级视图）

```text
业务线（发药售价/收费）→ 分析报表
库存线（发药进价/调拨/报损）→ 关账快照 → 凭证
实物线（盘点数量）→ 盘盈盘亏 → 凭证
```

仅 **库存线 + 实物线** 驱动库存科目；业务线只读参考。

## 5. 状态机

### 5.1 InventoryClosing

```text
DRAFT ──confirm──► CONFIRMED ──push_gl──► GL_PUSHED
  │                      │
  └──cancel──► VOID      └──void(主管)──► VOID
```

| 迁移 | Gate |
| --- | --- |
| → CONFIRMED | 预关账阻断项 = 0 **或** 已填 force_reason；双人复核（可配置） |
| → GL_PUSHED | 财务对账差异已确认；凭证预览已生成 |
| → VOID | 未推送或已完成红字冲销 |

### 5.2 与总账回写

- 凭证号写入 `inv_closing.gl_voucher_id` / `gl_voucher_no`。
- 总账侧点击凭证号 → 跳关账快照 + 明细 PDF。

## 6. 数据模型（最小集）

```text
ClosingPeriod          # 会计期间或自定义区间
InventoryClosing       # 按仓库关账头
  ├─ inv_closing_summary_line   # 期初/入/出/期末分项
  ├─ inv_closing_detail         # 行级明细（只读）
  ├─ inv_closing_issue          # 预关账/对账差异项
  └─ gl_voucher_link            # 凭证关联

MetricDefinition       # 指标字典（label/tooltip/for_gl/basis/time_axis）

InventoryClosingAdjustment      # 关账后调整单
PhysicalInventoryCount          # 盘点（衔接 7.1 早盘场景）
```

**进价公式**（与 BIRT `giveDrugStoreSum` / `giveDrugZyStoreSum` 对齐，版本化）：

```sql
-- cost-v1：按单位换算后 × quantity
CASE
  WHEN si.purchaseunit_id = detail.unit_id AND detail.unit_id = bi.yp_unit_id
    THEN si.purchase_price
  WHEN si.purchaseunit_id = bi.min_unit_id
    THEN si.part_price
  ELSE si.purchase_price / IFNULL(bi.part_percent, 1)
END * detail.quantity
```

## 8. 分项：问题与修改方案

### GAP-BAT-007 发药汇总实时扫库无关账快照

| 维度 | 说明 |
| --- | --- |
| **严重度** | 中危（审计/对账） |
| **现象** | 老系统 BIRT 按 `FY_TIME` 实时查询；6.30 导出 9621.06，7.6 复算 9828.45。 |
| **根因** | 无 `InventoryClosing` 实体；报表 = 查询快照。 |
| **修改方案** | 关账时 **物化** summary + detail 表；所有财务口径报表 **只读** `closing_id`；实时看板与关账报表 **分路由**。 |

**验收用例**

- 关账 CONFIRMED 后补录 FY_TIME 在期内发药 → 关账快照金额不变；差异进「关账后变动」提示。

**工作量**：5～8 人天（含 migration + 报表改造）

---

### GAP-BAT-008 发药售价与发药进价 UI/凭证混用

| 维度 | 说明 |
| --- | --- |
| **严重度** | 高危（错误入账） |
| **现象** | 老系统将「发药金额（RETAIL）」与「发药进价」混排；财务入错科目金额。 |
| **修改方案** | MetricDefinition 强制 `for_gl` 标记；凭证生成 **仅** 读取 `for_gl=true`；UI 分区（§4.2）。 |

**验收用例**

- 财务角色在凭证预览页 **看不到** 售价字段可编辑；推送金额 = 快照 `disp_cost_gross`。

**工作量**：3～5 人天（前端 + 凭证模板）

---

### GAP-BAT-009 财务手抄多列口径无系统引导

| 维度 | 说明 |
| --- | --- |
| **严重度** | 高危 |
| **现象** | Excel Sheet3「疗区收入 7555.69」被抄入账，正确应为支出/进价侧 9621+。 |
| **修改方案** | **禁止**以万能导出作为入账路径；Workflow：关账确认 → 对账工作台 → **一键生成凭证**（金额只读）；导出仅审计包。 |

**验收用例**

- 无 `InventoryClosing.status >= CONFIRMED` 时，「推送总账」按钮不可用。

**工作量**：4～6 人天（工作流 + 权限）

### GAP-BAT-010 关账期间/仓库/科目映射未绑定

| 维度 | 说明 |
| --- | --- |
| **严重度** | 中危 |
| **现象** | 5.28–6.30 自定义区间 vs 自然月；store79 vs 中草药疗区 527.04；1405.05 多子科目。 |
| **修改方案** | 关账头 **必填** period + store + `gl_account_mapping_id`；UI 面包屑固定三维；合并关账需显式勾选仓库列表并生成 **分仓库分项** 凭证行。 |

**验收用例**

- 选择「疗区药房」关账时，Sheet4 型「中草药疗区支出」**不出现**在同一快照。

**工作量**：2～4 人天

### GAP-BAT-011 关账后补录无调整单

| 维度 | 说明 |
| --- | --- |
| **严重度** | 中危 |
| **现象** | 关账后补录发药导致「报表变了但账已结」。 |
