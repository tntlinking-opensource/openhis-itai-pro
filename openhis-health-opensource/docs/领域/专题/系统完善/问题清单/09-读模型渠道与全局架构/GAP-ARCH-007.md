# GAP-ARCH-007 业务审计覆盖

> **问题类型**：读模型渠道与全局架构
> **严重度**：低危～中危
> **影响范围**：全局
> **优先级**：P2
> **状态**：待评估
> **父文档**：[SYS-IMP-014](../09-读模型渠道与全局架构/SYS-IMP-014-渠道对账读模型与全局幂等.md)

## 1. 问题描述

框架审计未覆盖全部敏感写操作

## 2. 发生场景

`whale-audit` 通用审计存在；**改价、override 核发、反结、mergePatient** 是否全部 `@Audited` — 需清单验收。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

敏感操作清单 + 强制审计注解；与 IMP-013 REG-006 补打审计合并。
