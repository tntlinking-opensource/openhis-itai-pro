# GAP-ARCH-004 投影 lag（取消/退费后列表）

> **问题类型**：读模型渠道与全局架构
> **严重度**：中危
> **影响范围**：门+住
> **优先级**：P2
> **状态**：见 IMP-007
> **父文档**：[SYS-IMP-014](../09-读模型渠道与全局架构/SYS-IMP-014-渠道对账读模型与全局幂等.md)
> **关联 IF/BR**：IMP-007 BND-STALE-004

---

## 1. 问题描述

取消执行/退费后列表标签滞后（投影 lag）

## 2. 发生场景

取消执行 CANCEL Procedure 后，执行列表读组装仍可能显示「已执行」直到刷新。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

1. 写路径发布 `EncounterClinicalStateChangedEvent`；2. 读侧短 TTL 缓存失效；3. 关键 Query **写后读** 走主库（`@Transactional(readOnly)` 同连接可见）。
