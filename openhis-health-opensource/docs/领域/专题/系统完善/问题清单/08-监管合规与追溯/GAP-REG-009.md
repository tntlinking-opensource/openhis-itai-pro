# GAP-REG-009 急诊绿色通道 override

> **问题类型**：监管合规与追溯
> **严重度**：低危～中危
> **影响范围**：门+住
> **优先级**：P3
> **状态**：待评估
> **父文档**：[SYS-IMP-013](../08-监管合规与追溯/SYS-IMP-013-监管合规链与核发追溯.md)

---

## 1. 问题描述

急诊/绿色通道 override 无统一审计模型

## 2. 发生场景

急诊处方类型 `rxTypeCode` 有推导；**先药后付、先出后审** 等 override 分散，无统一 `ClinicalOverrideRecord`。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

产品定义 override 类型枚举 + 双签 + 审计；与 IMP-012 皮试 override（BND-CLN-001）统一模型。
