# GAP-REG-007 批号召回禁发

> **问题类型**：监管合规与追溯
> **严重度**：中危
> **影响范围**：门+住
> **优先级**：P2
> **状态**：待实施
> **父文档**：[SYS-IMP-013](../08-监管合规与追溯/SYS-IMP-013-监管合规链与核发追溯.md)

---

## 1. 问题描述

批号召回/禁发未阻断核发

## 2. 发生场景

药库有批号/lot；**未见** `LotRecall` 主数据与核发 Gate「召回批号禁止出库」。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

1. 主数据维护召回批号列表；2. `prepare/dispense` 前 `assertLotNotRecalled(lotNumber, medicationId)`；3. 与库存 Query 联动。
