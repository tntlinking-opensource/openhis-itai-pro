# GAP-REG-008 高值植入物 UDI

> **问题类型**：监管合规与追溯
> **严重度**：中危
> **影响范围**：住
> **优先级**：P2
> **状态**：待评估
> **父文档**：[SYS-IMP-013](../08-监管合规与追溯/SYS-IMP-013-监管合规链与核发追溯.md)

---

## 1. 问题描述

高值耗材/植入物 UDI 与 Charge 锚点

## 2. 发生场景

IMP-001 GAP-EXE-004 覆盖绑定耗材扣库；**手术植入物 UDI 与 Charge/患者终身追溯** 未成文。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

手术耗材发放扩展 `DeviceDispense` 存 UDI；Charge 锚点 `udi`；报表对接 SPD（若上线）。
