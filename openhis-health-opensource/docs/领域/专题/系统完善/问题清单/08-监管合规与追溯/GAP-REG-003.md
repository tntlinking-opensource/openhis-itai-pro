# GAP-REG-003 本地追溯 vs 3505

> **问题类型**：监管合规与追溯
> **严重度**：中危
> **影响范围**：药库
> **优先级**：P1
> **状态**：见 SYS-IMP-011
> **父文档**：[SYS-IMP-013](../08-监管合规与追溯/SYS-IMP-013-监管合规链与核发追溯.md)

---

## 1. 问题描述

本地追溯记录与 3505 上报不一致

## 2. 发生场景

在 药库 场景下，本地追溯 vs 3505。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

见 **SYS-IMP-011 [GAP-INT-001](../06-外部集成与分布式顺序/GAP-INT-001.md)/002**；核发成功 → outbox 3505；对账台比对 `trace_number_record` 与 `yb_inv_upload`。
