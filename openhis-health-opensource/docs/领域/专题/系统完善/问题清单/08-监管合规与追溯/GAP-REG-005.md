# GAP-REG-005 法定疗程 BR-MRQ-018

> **问题类型**：监管合规与追溯
> **严重度**：中危
> **影响范围**：门诊
> **优先级**：P2
> **状态**：待验收
> **父文档**：[SYS-IMP-013](../08-监管合规与追溯/SYS-IMP-013-监管合规链与核发追溯.md)

---

## 1. 问题描述

法定疗程/用量（BR-MRQ-018）签发验收不足

## 2. 发生场景

DM 定义普通 ≤7 日、急诊 ≤3 日；签发 FIFO/数量校验 **需逐路径验收**是否全覆盖。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

签发 Gate：`assertDurationWithinLegalLimit(therapy, encounterClass, daysSupply)`；急诊 encounter 标记走 3 日上限。
