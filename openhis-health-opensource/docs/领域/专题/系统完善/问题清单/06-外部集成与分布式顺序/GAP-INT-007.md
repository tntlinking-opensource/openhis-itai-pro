# GAP-INT-007 外部回调幂等

> **问题类型**：外部集成与分布式顺序
> **严重度**：中危
> **影响范围**：全局
> **优先级**：P2
> **状态**：待评估
> **父文档**：[SYS-IMP-011](../06-外部集成与分布式顺序/SYS-IMP-011-外部集成最终一致性与补偿.md)

---

## 1. 问题描述

外部回调/Webhook 无 idempotency

## 2. 发生场景

第三方重复 POST 报告/支付回调可能双写。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

全局 `ExternalCallbackIdempotencyStore`（messageId 唯一）。
