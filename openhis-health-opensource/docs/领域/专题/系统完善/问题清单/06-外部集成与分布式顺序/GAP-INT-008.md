# GAP-INT-008 运维对账台

> **问题类型**：外部集成与分布式顺序
> **严重度**：中危
> **影响范围**：全局
> **优先级**：P1
> **状态**：待实施
> **父文档**：[SYS-IMP-011](../06-外部集成与分布式顺序/SYS-IMP-011-外部集成最终一致性与补偿.md)

---

## 1. 问题描述

集成失败无运维对账台

## 2. 发生场景

半成功态分散在 yb_*、outbox、日志，无统一视图。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

管理端「集成对账」：医保结算/3505/2201/发票 四 Tab；支持按日导出差异清单。
