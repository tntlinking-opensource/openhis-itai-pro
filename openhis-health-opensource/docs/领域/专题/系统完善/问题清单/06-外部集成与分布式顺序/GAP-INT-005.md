# GAP-INT-005 电子发票顺序

> **问题类型**：外部集成与分布式顺序
> **严重度**：中危
> **影响范围**：门+住
> **优先级**：P2
> **状态**：待实施
> **父文档**：[SYS-IMP-011](../06-外部集成与分布式顺序/SYS-IMP-011-外部集成最终一致性与补偿.md)

---

## 1. 问题描述

电子发票开票/冲红与 Payment 顺序

## 2. 发生场景

正式结算触发开票草稿；退费/反结需冲红 — 若冲红失败本地已 REFUNDED，票账不一致。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

与退费 Saga 绑定：冲红 SUCCESS → 本地 REFUND SUCCESS；失败进 outbox；禁止跳过冲红直接 REFUND（可配置应急 role）。


## 6. 涉及代码

- `InvoiceDomainService`、门诊/住院退费 AppService
