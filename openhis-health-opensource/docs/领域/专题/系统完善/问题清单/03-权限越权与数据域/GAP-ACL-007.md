# GAP-ACL-007 跨模块无统一 Access Facade

> **问题类型**：权限越权与数据域
> **严重度**：低危～中危
> **影响范围**：全局
> **优先级**：P2
> **状态**：待评估
> **父文档**：[SYS-IMP-008](../03-权限越权与数据域/SYS-IMP-008-多租户岗位与财务数据域.md)

---

## 1. 问题描述

跨租户/跨机构 API 无统一 Facade

## 2. 发生场景

护士站、药房、财务、医生站各自实现可见性，规则易漂移。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

中长期：`EncounterAccessPolicy` 接口 + 各模块 Adapter；短期至少财务与护士站共享 org/ward 解析器。
