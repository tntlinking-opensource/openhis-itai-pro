# GAP-ACL-005 列表 Query 与写 Gate 不一致

> **问题类型**：权限越权与数据域
> **严重度**：中危
> **影响范围**：门+住
> **优先级**：P2
> **状态**：待实施
> **父文档**：[SYS-IMP-008](../03-权限越权与数据域/SYS-IMP-008-多租户岗位与财务数据域.md)

---

## 1. 问题描述

财务列表 Query 与写路径 Gate 不一致

## 2. 发生场景

写路径加 Gate 后，若列表仍全量，攻击者仍可从别处获知 encounterId；正常用户也可能「列表无、API 有」。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

财务/挂号所有 `*QueueLoader`、`*PageQuery` 与 `EncounterFinancialAccesssupport 共用 Specification；集成测试「列表 ⊆ 写权限」。
