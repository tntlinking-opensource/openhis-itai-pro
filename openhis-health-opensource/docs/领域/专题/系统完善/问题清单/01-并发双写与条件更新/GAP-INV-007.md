# GAP-INV-007 医保 3505 与盘点同意

> **严重度**：低危～中危
> **影响范围**：药库
> **优先级**：P3
> **状态**：见 SYS-IMP-006
> **父文档**：[SYS-IMP-005](../01-并发双写与条件更新/SYS-IMP-005-进销存单据与汇总发药并发边界.md)

## 1. 问题描述

医保 3505 盘点上报与库存同意顺序

## 2. 发生场景

在 药库 场景下，医保 3505 与盘点同意。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

见 **SYS-IMP-006**；盘点同意后异步 3505 须幂等键。
