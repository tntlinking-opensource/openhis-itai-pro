# GAP-FIN-012 转医保/转自费切账户

> **问题类型**：并发双写与条件更新
> **严重度**：低危～中危
> **影响范围**：门诊
> **优先级**：P3
> **状态**：待评估（视现场是否启用医保切换）
> **父文档**：[SYS-IMP-002](../01-并发双写与条件更新/SYS-IMP-002-收费结算与账户并发边界.md)

---

## 1. 问题描述

转医保/转自费批量切账户无 ChargeItem 行锁

## 2. 发生场景

并发「转医保」与「正式结算」：ChargeItem `accountId` 与结算账户不一致风险。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

切账户时 `UPDATE adm_charge_item SET account_id=? WHERE id=? AND status_enum='PLANNED'`；结算前再校验 account 与 draft 一致。
