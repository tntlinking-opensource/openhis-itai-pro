# GAP-FIN-010 护士写路径重复 Charge（交叉项）

> **问题类型**：并发双写与条件更新
> **严重度**：中危
> **影响范围**：住
> **优先级**：P1
> **状态**：见 SYS-IMP-001
> **父文档**：[SYS-IMP-002](../01-并发双写与条件更新/SYS-IMP-002-收费结算与账户并发边界.md)

## 1. 问题描述

护士执行/划价重复写 Charge（→ GAP-EXE-002 等）

## 2. 发生场景

在 住 场景下，护士写路径重复 Charge（交叉项）。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

执行侧见 **SYS-IMP-001 [GAP-EXE-002](../01-并发双写与条件更新/GAP-EXE-002.md)**；划价侧：写批次幂等键 / 自然键唯一（同患者+同产品+同 occurrence 等按 BR 定义）。
