# GAP-BKG-005 候补提升与释放竞态

> **问题类型**：并发双写与条件更新
> **严重度**：低危～中危
> **影响范围**：门诊
> **优先级**：P2
> **状态**：**已实施**（2026-06-28）
> **父文档**：[SYS-IMP-003](../01-并发双写与条件更新/SYS-IMP-003-预约号源与床位预留并发边界.md)

---

## 1. 问题描述

候补提升与取消/改约释放竞态

## 2. 发生场景

取消预约释放 slot 同时 `tryPromoteWaitlist`；两候补提升或提升与直接预约并发。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

**已采用**（2026-06-28）：

1. `OutpatientWaitlistPromotesupport：提升与直接预约共用 slot 乐观锁（`SLOT_003` / 满号则跳过）
2. `WaitlistDomainService#markPromotedIfWaiting` + `WaitlistEntry @Version` 条件更新
3. 提升失败回滚（取消预约 + 释号）
4. 窗口/渠道取消均触发 `tryPromoteWaitlist`
