# GAP-FLW-004 清床 vs 办理出院 Gate 不一致

> **问题类型**：流程状态机与硬门禁
> **严重度**：中危
> **影响范围**：住
> **优先级**：P2
> **状态**：待实施
> **父文档**：[SYS-IMP-009](../04-流程状态机与硬门禁/SYS-IMP-009-出院转科召回与财务硬门禁.md)

---

## 1. 问题描述

清床 Gate 与结算 Gate 口径不一致

## 2. 发生场景

清床要求无未结算（401）、账户余额为零（403）；办理出院不要求 — 用户可「待出院 + 未结 + 占床」。

## 3. 根因分析

见父文档；核心为读 Gate + 无源态条件更新或 Gate 缺失。

## 4. 业务影响

账实/账价不一致，或合规与安全风险。

## 5. 修改方案

文档化产品口径；或办理出院后自动触发占床释放策略与 IMP-004 床位联动。
