## 框架包 → 源码

单一 jar：`com.zxplat:zxplat-framework`  
根包：`com.zxplat.framework.*`  
源码根：`zxplat-framework/src/main/java/com/zxplat/framework/`

| 包目录 | 文档 | 代码里先看 |
|--------|------|------------|
| `core/` | [框架/包/核心.md](./框架/包/核心.md) | `ZxplatCoreAutoConfiguration`、`Result`、`TenantContext` |
| `identity/` | [框架/包/身份认证.md](./框架/包/身份认证.md) | `AuthAppService`、`JwtTokenProvider` |
| `permission/` | [框架/包/权限.md](./框架/包/权限.md) | `PermissionAppService` |
| `tenant/` | [框架/包/租户.md](./框架/包/租户.md) | `TenantAppService` |
| `setting/` | [框架/包/设置.md](./框架/包/设置.md) | `SettingAppService` |
| `menu/` | [框架/包/菜单.md](./框架/包/菜单.md) | `MenuAppService` |
| `audit/` | [框架/包/审计.md](./框架/包/审计.md) | `AuditLog`、审计切面 |
| `job/` | [框架/包/定时任务.md](./框架/包/定时任务.md) | `ScheduledJobAppService`、`ScheduledJobQuartzBridge` |
| `runtime/` | [框架/包/运行时.md](./框架/包/运行时.md) | `FrameworkRuntimeProperties`（默认不同步外网） |
| `web/` | [框架/包/Web层.md](./框架/包/Web层.md) | `AppServiceControllerRegistrar`、`OpenApiConfig` |

装配入口：`META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`  
顺序要点：先 `ZxplatCoreComponentRegistrationConfiguration`，再 `ZxplatCoreAutoConfiguration`，最后 `ZxplatFrameworkAutoConfiguration`（web）。详见 [框架/包/核心.md](./框架/包/核心.md)。

运行时默认同步：**关闭**（`zxplat.framework.runtime.remote-sync-enabled=false`）。见 [框架/包/运行时.md](./框架/包/运行时.md)。
