## 硬门禁：文档不是垃圾场（全 Skill 适用）

| 规则 | 说明 |
|------|------|
| **默认不写文档** | 用户**未明示**「写文档 / 补 DM·SDD·AS / 落盘 docs / 留脚本」时，**禁止**新建或扩写任何 `docs/**` 下的 Markdown、运维 SQL、排查脚本、「补单-*.sql」等 |
| **改库直接执行** | 补数、刷枚举、修 org、一次性纠错 → **连目标库执行**；**禁止**为留痕在 `docs/领域/专题/ops/`（或其它 docs）堆可执行 SQL 文件 |
| **契约文档例外** | 仅当：① 用户要求；② @ 了文档类 Skill（DM/AS/SDD 等）；③ 本轮已声明走「文档代码一致性」且变更触及契约（方法/BR/状态机/IF）须同闭环回写——才允许改 DM/SDD/AS |
| **热修/展示/前端文案** | 默认**只改代码（+必要库数据）**；禁止「顺手」扩写 AS/DM「留个记录」 |
| **专题/ops 用途** | 仅收纳用户**明确要求保留**的运维材料；不是 Agent 会话垃圾桶 |

违反上述 → 视为交付失败；应删掉未要求留下的文档/SQL，而不是解释「方便以后」。
