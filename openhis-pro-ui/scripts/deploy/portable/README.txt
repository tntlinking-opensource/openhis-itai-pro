OpenHIS portable web bundle (extract and run)
===============================================

1. Unzip openhis-web-deploy-*.zip to any folder
2. Start backend (default http://127.0.0.1:8081)
3. Double-click start.bat
4. Open http://localhost:8080/
5. Stop: double-click stop.bat

Config (config.env, then restart start.bat)
-------------------------------------------
  LISTEN_PORT=8080
  BACKEND_HOST=127.0.0.1
  BACKEND_PORT=8081

See docs/framework/ops/frontend-deployment.md for details.
