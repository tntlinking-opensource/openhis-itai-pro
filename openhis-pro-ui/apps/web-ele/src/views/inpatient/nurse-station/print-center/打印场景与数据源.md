**患者范围说明**

- **单人**：左侧必须只勾 1 人
- **多选**：至少 1 人
- **病区**：可不绑患者，按日期拉病区单据

**统一入口**

- 待打：`load-print-pending.ts` → `loadPrintPendingRows`
- 打印：`print-center-print.ts` → `printInpatientPrintCenter` → `print({ scenarioCode, source })`
- 业务→PrintData：`build-print-source.ts` + `utils/print/mappers/*`

## 1. 输液巡视卡（`patrol_card`）

### 实际业务场景

按**患者**打一张「输液巡视卡」：表头为患者信息，表体为当日/截止前**输液途径成组药品**；滴速、巡视时间、签名留空手写。  
**没有输液药品则不应出现在待打、也不可打印。**

### 现有接口

| 用途 | 接口 | 有无 |
| --- | --- | --- |
| 待打 / 打印明细 | `POST /nurseStationDispenseSummary/pagePendingDispenseSummaryLines` | **有**（汇总领药·待汇总明细） |
| 独立「巡视」业务接口 | — | **无** |

### 数据从哪来

| 字段 | 来源 |
| --- | --- |
| 床号/姓名/病区/年龄 | 左侧患者卡片 `NurseStationModulePatient` |
| 组药明细 | 待汇总明细，筛 `methodCode ∈ INFUSION_METHOD_CODES`，按 `groupId`/`medReqId` 成组 |
| 滴速/时间/签名 | 固定空串（手写） |

### 当前实现注意

- Tab 已改为「输液巡视卡」；待打仅在有输液药时出一行/患者。
- 与「输液贴」**同源接口**，版式不同（一页多人组药 vs 一组成组瓶签）。

## 2. 腕带（`wristband`）

### 实际业务场景

入院/在床患者打印腕带：姓名、性别、年龄、科室/病区、床号、住院号、过敏、诊断等。

### 现有接口

| 用途 | 接口 | 有无                                         |
| ---- | ---- | -------------------------------------------- |
| 待打 | —    | **无专用接口**（按勾选患者本地生成）         |
| 打印 | —    | **无专用打印聚合接口**；字段来自左侧患者卡片 |

### 数据从哪来

| 字段 | 来源 |
| --- | --- |
| 姓名/性别/年龄/床号/住院号/科室/病房/诊断 | `NurseStationModulePatient`（科室=`organizationName`，病房=`wardName`） |
| 过敏 | 当前写空（患者卡片暂无过敏字段回填） |

### 当前实现注意

- 有人选就能进待打；不校验是否已打过腕带。
- `allergyText` 目前为空，若业务要过敏源需补读模型或接口。

## 2.1 床头卡（`bed_card`）

### 实际业务场景

入院/在床患者打印床头卡：姓名、性别、住院号、年龄、入院日期、主治医生、医保类别。

### 现有接口

| 用途 | 接口 | 有无                                                        |
| ---- | ---- | ----------------------------------------------------------- |
| 待打 | —    | **无专用接口**（按勾选患者本地生成）                        |
| 打印 | —    | **无专用打印聚合接口**；字段来自左侧患者卡片 / 入院弹窗详情 |

### 数据从哪来

| 字段                  | 来源                                                    |
| --------------------- | ------------------------------------------------------- |
| 姓名/性别/年龄/住院号 | `NurseStationModulePatient`                             |
| 入院日期              | `admissionAt`（缺省 `inWardAt`），格式 `YYYY-MM-DD`     |
| 主治医生              | `attendingDoctorName`（列表读模型；入院弹窗可详情兜底） |
| 医保类别              | `feeType`（读模型 `contractDisplay`）                   |

### 当前实现注意

- 打印中心护理文书 Tab 可选「床头卡」；入院分床弹窗提供「打床头卡」。
- 模板场景码 `ip-bedCard-print`，纸张长 21cm × 宽 13cm。

## 3. 输液贴（`infusion_label`）

### 实际业务场景

按**输液成组**打瓶签/贴签（可多天）；同组药品打在一张贴上。

### 现有接口

| 用途        | 接口                                                                | 有无   |
| ----------- | ------------------------------------------------------------------- | ------ |
| 待打 / 打印 | `POST /nurseStationDispenseSummary/pagePendingDispenseSummaryLines` | **有** |
| 打印引擎    | 复用门诊 `op-infusionLabel-print` + `printInfusionLabel`            | **有** |

### 数据从哪来

| 字段       | 来源                                                         |
| ---------- | ------------------------------------------------------------ |
| 待打行     | 待汇总明细，筛输液途径，按 `groupId`/`medReqId` **一组一行** |
| 瓶签药品行 | 同上接口，按勾选组回取成组药 → 映射为门诊瓶签 PrintSource    |
| 患者头信息 | 左侧患者卡片                                                 |

### 当前实现注意

- 住院场景复用**门诊瓶签模板**；若住院瓶签版式不同，需单独场景码/模板。

## 4. 口服药贴（`oral_med_label`）

### 实际业务场景

按**口服药医嘱**打小药贴（床号、姓名、药名、规格、剂量等）。

### 现有接口

| 用途        | 接口                                                                | 有无   |
| ----------- | ------------------------------------------------------------------- | ------ |
| 待打 / 打印 | `POST /nurseStationDispenseSummary/pagePendingDispenseSummaryLines` | **有** |

### 数据从哪来

| 字段     | 来源                                                          |
| -------- | ------------------------------------------------------------- |
| 待打行   | 待汇总明细，筛 `methodCode ∈ ORAL_METHOD_CODES`，**一药一行** |
| 贴签字段 | 同上，按 `medReqId` 匹配                                      |

### 当前实现注意

- 与巡视卡/输液贴同源「待汇总」；筛选靠给药途径 code，不用中文用法猜。

### 当前实现注意

- **打印中心明确不接**：待打恒为空；约定后续**纯前端打印**（页面内打印），不走 hiprint 场景码。

## 6. 护理记录（`nursing_record`）

### 实际业务场景

按日期区间打一般护理记录单（生命体征、出入量、病情与措施、护士签名等）。

### 现有接口

| 用途        | 接口                                                             | 有无   |
| ----------- | ---------------------------------------------------------------- | ------ |
| 待打 / 打印 | `POST /nurseStationNursingRecord/listNurseStationNursingRecords` | **有** |

### 数据从哪来

| 字段        | 来源                                          |
| ----------- | --------------------------------------------- |
| 纸质单头    | 接口 `paperHeader` + 患者卡片兜底             |
| 记录行      | 接口 `rows`（日期区间 `recordedAtFrom`~`To`） |
| 医院名/标题 | 前端机构名 + 固定「护理记录单」               |

### 当前实现注意

- 选中单人即出待打行；区间内无记录仍可打空表（当前产品行为）。若业务要求「无记录不可打」，需再收紧。

## 7. 长期医嘱（`long_order`）

### 实际业务场景

打印长嘱执行记录（开嘱时间、内容、医生、执行护士/时间）；支持全部 / 未打 / 续打筛选。

### 现有接口

| 用途 | 接口 | 有无 |
| --- | --- | --- |
| 待打 / 打印 | `POST /nurseStationOrderExecute/listNurseStationOrderExecute` | **有** |
| 独立长嘱打印模板 | — | **无**（复用临嘱模板 `ip-tempOrder-print`，标题改为「长嘱执行记录」） |

### 数据从哪来

| 字段     | 来源                                                                |
| -------- | ------------------------------------------------------------------- |
| 待打行   | `therapyType=long`，并行拉 `executeTab=pending` + `executed` 后合并 |
| 打印明细 | 同上，按勾选 `listRowKey` 过滤槽位展开为行                          |

### 当前实现注意

- 后端 **没有** `executeTab=all`；必须分 Tab 拉再合并。
- 「未打」前端用 `statusCode===pending`（仍有待执行槽）近似，并非独立打印状态落库。

## 11. 摆药单（`dispense_sheet`）

### 实际业务场景

按汇总单号打印摆药明细（按患者分床展示药名、剂量、用法等）。

### 现有接口

| 用途 | 接口                                                                      | 有无   |
| ---- | ------------------------------------------------------------------------- | ------ |
| 待打 | 同汇总：`pageMedicationSummarySlipHeaders`                                | **有** |
| 打印 | `POST /nurseStationDispenseSummary/getMedicationSummarySlipPatientDetail` | **有** |

### 数据从哪来

| 字段 | 来源                                                               |
| ---- | ------------------------------------------------------------------ |
| 待打 | 与汇总领药单共用单头列表（当前实现未区分「汇总 vs 摆药」单头状态） |

### 当前实现注意

- 待打列表与汇总领药单**同一批单头**；若业务上「可打汇总」与「可打摆药」状态不同，需后端筛字段或分接口。

## 接口复用关系（简图）

```text
pagePendingDispenseSummaryLines
  ├─ 输液巡视卡（按患者，筛输液）
  ├─ 输液贴（按成组，筛输液）
  └─ 口服药贴（按医嘱，筛口服）

listNurseStationOrderExecute
  ├─ 临时医嘱（therapy=temp）
  └─ 长期医嘱（therapy=long）  ← 模板复用临嘱

pageMedicationSummarySlipHeaders
  ├─ 汇总领药单 → getMedicationSummarySlipDetail
  └─ 摆药单     → getMedicationSummarySlipPatientDetail

listNurseStationNursingRecords → 护理记录
queryNurseStationInpatientCostDetail → 费用清单
左侧患者卡片 → 腕带（及各单据患者头）
体温单接口有，打印中心不接
```

## 缺口与风险（建议后续拍板）

1. **体温单**：业务页有数据接口，打印中心不接；纯前端打印方案需另开。
2. **长嘱无独立模板**：版式与临嘱完全相同，仅标题不同。
3. **腕带过敏等字段**：患者卡片缺字段时打印为空。
4. **汇总 vs 摆药待打**：共用单头列表，可能重复/状态不准。
5. **输液贴复用门诊模板**：住院贴签尺寸/字段若不同需新 scenario。
6. **护理记录空表可打**：是否允许需产品确认。
7. **无「已打印」落库**：未打/续打多为前端槽位状态近似，不是打印履历。
