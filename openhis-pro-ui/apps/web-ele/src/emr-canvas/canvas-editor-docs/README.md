# canvas-editor 官方文档（本地副本）

病历画布编辑器改配置、命令、控件或渲染之前，先看本目录，再改代码。

这些文件是上游原文，不要在里面记本项目的改动。本项目依赖 `@hufe921/canvas-editor` `^1.0.4`。副本取自 GitHub `main` 分支 `docs/guide`，下载日期 2026-10-14。若和 `node_modules/@hufe921/canvas-editor` 里的类型不一致，以当前安装的包为准，并对照上游更新本目录。
